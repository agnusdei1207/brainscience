0. 핵심 인사이트

핵심: BRM (Business Reference Model)의 본질은 조직의 업무 기능을 중복 없이 계층적으로 분류해 무엇을 하는 조직인지 공통 언어로 설명하게 만드는 것이다.

비유: 도서관에서 책을 주제별로 분류해 어떤 책이 어디에 속하는지 한눈에 찾게 하는 분류표와 같다.

📝 모범 답안

1. 개요 및 필요성

BRM (Business Reference Model)은 조직의 업무 기능을 표준 분류 체계로 정리한 업무 참조 모델이다. 부서명이나 시스템명은 조직마다 달라도 실제 업무 기능은 유사한 경우가 많다. BRM은 이러한 기능을 중복 없이 계층적으로 정리해 업무 구조를 비교 가능하게 만든다.

BRM이 필요한 이유는 정보화 사업이 부서 단위 요구에 끌려가면 같은 기능이 여러 이름으로 반복 투자되기 때문이다. 공통 기능 분류가 있으면 어떤 사업이 어떤 업무를 지원하는지 명확해지고, 중복·누락·책임 경계를 판단하기 쉬워진다.

2. 구성요소

요소역할핵심 포인트
기능 계층대기능-중기능-소기능 구조업무를 계층적으로 분해
기능 정의각 기능의 범위와 의미 설명유사 기능 간 경계 명확화
조직 매핑기능과 수행 조직 대응부서와 기능을 분리해 파악
사업 매핑정보화 과제와 기능 연결어떤 사업이 어떤 기능을 지원하는지 확인

기능 계층은 BRM의 구조를 만들고, 기능 정의는 중복과 혼동을 막는다. 조직 매핑은 같은 기능이 여러 조직에서 수행되는 현실을 보여주고, 사업 매핑은 정보화 투자가 어떤 기능을 강화하는지 설명한다. 이 연결 덕분에 BRM은 단순 분류표를 넘어 투자 판단 도구가 된다.

3. 구조 및 원리

핵심 조건: 각 기능은 상호배타적이며 전체를 포괄하도록 정의되어야 하고, 조직 구조와 기능 구조를 혼동하지 않아야 한다.

BRM은 조직도 중심이 아니라 기능 중심으로 업무를 바라본다. 조직은 바뀌어도 기능은 상대적으로 안정적이기 때문에, 기능 단위로 구조를 잡으면 장기적인 아키텍처 관리가 가능하다. 또한 기능 단위 분류는 중복 투자와 책임 모호성을 줄이는 기준이 된다.

동작 순서:

  1. 상위 기능 정의: 기관의 핵심 미션을 기준으로 대기능을 설정한다.
  2. 세부 기능 분해: 중기능·소기능으로 내려가며 업무 범위를 구체화한다.
  3. 기능 정의와 경계 설정: 유사 기능 간 중복과 포함 관계를 정리한다.
  4. 조직·사업 매핑: 현재 조직과 정보화 사업을 BRM 기능에 대응시킨다.
[기관 미션]
   ↓
[대기능] ─▶ [중기능] ─▶ [소기능]
   │                         │
   └──── 조직/사업 매핑 ──────┘

BRM은 부서 구조를 그대로 옮기면 안 된다. 부서명은 조직개편에 따라 쉽게 바뀌지만 기능은 비교적 안정적이므로, 기능 정의를 조직 독립적으로 유지해야 한다. 또한 너무 세분화하면 실무 활용이 어렵고, 너무 거칠면 중복 분류가 생긴다.

4. 비교 및 연결

항목BRM조직도프로세스 맵
관점기능 분류조직 책임 구조업무 흐름
안정성상대적으로 높음조직개편에 따라 변동절차 변경 시 변동
주요 활용업무 중복 제거, 사업 매핑인력/권한 관리병목 진단, 자동화
핵심 질문무슨 기능을 수행하는가?누가 수행하는가?어떤 순서로 수행하는가?

조직도는 책임 주체를, 프로세스 맵은 수행 순서를 설명한다. BRM은 그 중간에서 “무슨 기능 자체가 존재하는가”를 분류한다. 따라서 BRM은 조직개편이나 프로세스 개선에도 비교적 안정적인 기준 축이 된다.

5. 실무 적용 및 판단

채택 조건:

  • 공공기관 기능 분류, 중복 사업 점검, 업무 체계 정비 시
  • 정보화 과제를 업무 기능과 연결해야 할 때
  • 기관 간 비교와 공통 기능 표준화가 필요할 때

회피 조건:

  • 부서명을 그대로 기능 계층으로 쓰는 경우
  • 기능 정의 없이 계층만 나누는 경우
  • 프로세스와 기능을 혼동하는 경우

체크리스트:

  1. 기능 계층이 중복 없이 정의되는가?
  2. 기능 설명과 경계가 명확한가?
  3. 조직과 기능이 구분되어 있는가?
  4. 사업/시스템이 BRM 기능에 매핑되는가?

공공기관은 BRM을 통해 민원, 심사, 통계, 지원 같은 기능을 표준 분류해 사업 심의의 기준으로 사용한다. 민간에서도 그룹 공통 기능 분류를 정의해 ERP, CRM, HR 시스템 투자의 중복을 줄일 수 있다.

6. 기대효과 및 결론

BRM은 업무를 기능 관점에서 재정렬해 정보화 투자와 조직 운영을 같은 언어로 연결해 준다. 이를 통해 부서 중심 사고에서 벗어나 전사 기능 체계를 기반으로 중복 제거와 책임 명확화를 추진할 수 있다. 향후에는 프로세스 로그와 서비스 카탈로그가 결합되어 BRM의 실증적 유지관리 수준이 높아질 것이다.
