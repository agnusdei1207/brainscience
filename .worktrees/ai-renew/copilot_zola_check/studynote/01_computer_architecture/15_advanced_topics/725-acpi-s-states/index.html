핵심 인사이트 (3줄 요약)

  1. 앞서 배운 C-State(코어), P-State(성능)가 CPU 하나만의 미시적인 전력 관리라면, **S-State (Sleep States)**는 램(RAM), 하드디스크, 모니터, 메인보드를 포함한 컴퓨터 시스템 전체의 거시적인 수면 상태를 뜻한다.
  2. 윈도우의 '절전 모드'는 램에만 전기를 살려두는 **S3 상태(Suspend to RAM)**이고, '최대 절전 모드'는 램의 내용을 디스크에 다 써버리고 전원을 아예 뽑아버리는 **S4 상태(Suspend to Disk)**다.
  3. 스마트폰처럼 화면은 꺼졌지만 백그라운드에서 카톡 알람이 오고 즉시 켜지는 현대적인 대기 모드를 위해 최근 **S0ix (Modern Standby)**라는 새로운 상태가 도입되었다.

Ⅰ. S-State의 기본 분류 체계

ACPI(고급 구성 및 전원 인터페이스) 규격은 시스템의 전원 상태를 S0부터 S5까지 6단계로 나눕니다.

  • S0 (Working) 컴퓨터가 정상적으로 켜져서 돌아가는 중입니다. (화면 켜짐, 팬 돌아감)
  • S1 / S2 (Power on Suspend) 초창기 절전 모드. CPU와 RAM에 전기가 다 들어가 있고 단순히 화면과 하드디스크만 끕니다. 전기 소모가 너무 많아 요즘은 안 씁니다.
  • S3 (Suspend to RAM / Sleep) 우리가 흔히 쓰는 **"절전 모드"**입니다. CPU, 하드디스크, 쿨링팬의 전원 플러그를 물리적으로 뽑아버립니다. 오직 RAM(메모리)에만 대기 전력을 줘서 데이터가 증발하지 않게 꽉 붙잡고 있습니다. 마우스를 흔들면 RAM의 기억을 바탕으로 1초 만에 화면이 뜹니다. 단점: 컴퓨터 콘센트(배터리)를 뽑으면 RAM이 죽어서 작업하던 내용이 다 날아갑니다.

📢 섹션 요약 비유: S3(절전 모드)는 직원이 하던 일을 책상(RAM) 위에 그대로 다 펼쳐두고, 불 끄고 잠깐 자러 간 상태입니다. 부르면 바로 일어납니다. 단, 도둑이 들어와서 책상을 엎어버리면(정전) 큰일 납니다.

Ⅱ. 딥 슬립: S4와 S5

  • S4 (Suspend to Disk / Hibernation) 윈도우의 **"최대 절전 모드"**입니다. OS가 RAM에 있는 모든 데이터를 C드라이브(SSD)의 찌꺼기 파일(hiberfil.sys)로 복사해 버립니다. 복사가 끝나면 RAM, CPU 할 것 없이 컴퓨터의 전원 코드를 완전히 뽑아버린 것과 동일한 0W 소모 상태가 됩니다. 콘센트를 뽑고 이사가도 됩니다. 나중에 전원 버튼을 누르면, SSD에 저장된 파일을 다시 RAM으로 퍼 올려서(복구) 끄기 직전의 화면을 그대로 띄워줍니다. (부팅 시간 10초 내외)
  • S5 (Soft Off) 윈도우에서 **"시스템 종료"**를 누른 상태입니다. RAM 데이터를 저장하지 않고 그냥 싹 다 버리고 끕니다. (단, 메인보드 끄트머리에 랜선으로 전원을 켜는 Wake-on-LAN(WOL)이나 전원 버튼 인식을 위해 아주 미세한 전류만 흐르고 있습니다.)

📢 섹션 요약 비유: S4(최대 절전)는 직원이 하던 일을 꼼꼼히 장부(SSD)에 다 적어놓고 아예 퇴근해버린 것입니다. 전기는 1원도 안 들지만, 다음 날 출근해서 장부를 보고 다시 책상을 세팅하느라 시간이 좀 걸립니다. S5(종료)는 하던 일을 싹 다 버리고 백지상태로 퇴근한 것입니다.

Ⅲ. S3(전통적 절전)의 몰락과 S0ix의 대두

스마트폰의 화면을 껐다고 생각해 봅시다. 화면은 까맣고 잠을 자고 있지만, 카톡이 오면 즉시 띠링! 하고 알림이 옵니다. 스마트폰은 S3(절전 모드)에 들어간 걸까요?

아닙니다. 만약 스마트폰이 S3 상태라면 CPU와 랜카드가 완전히 꺼져있기 때문에 카톡을 받을 수 없습니다. 카톡을 받으려면 CPU가 1초라도 깨어나서 확인해야 합니다. 전통적인 S3 모드는 "한 번 자면 외부에서 마우스를 흔들기 전까지는 완벽하게 뻗어있는" 멍청한 수면입니다.

현대의 노트북(Intel Evo, 맥북 등)과 스마트폰은 이 멍청한 S3를 버리고, 화면이 꺼져있을 때도 백그라운드에서 CPU가 0.01초씩 깼다 잤다를 반복하며 이메일을 수신하는 스마트한 수면 모드로 진화했습니다. 이것이 다음 장에서 다룰 **S0ix (Modern Standby)**입니다.
