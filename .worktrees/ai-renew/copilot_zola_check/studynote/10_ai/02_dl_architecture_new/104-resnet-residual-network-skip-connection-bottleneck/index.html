핵심 인사이트 (3줄 요약)

  1. 본질: ResNet (Residual Network)은 입력 데이터를 변형하지 않고 다음 층으로 직접 전달하는 우회로(Skip Connection)를 도입해 잔차(Residual)만 학습하게 만든 신경망 구조다.
  2. 가치: 망이 깊어질수록 오차 신호가 사라지는 기울기 소실(Vanishing Gradient) 문제를 해결하여, 딥러닝 모델의 층수를 152층 이상으로 획기적으로 깊게 쌓을 수 있게 만들었다.
  3. 판단 포인트: 모델 성능을 높이기 위해 단순히 층을 쌓는 것은 성능 저하(Degradation)를 부르므로, 파라미터 수를 줄이는 보틀넥(Bottleneck) 구조와 잔차 연결을 결합해야 실질적인 고성능 초심층 모델을 구현할 수 있다.

Ⅰ. 개요 및 필요성

ResNet (Residual Network)은 2015년 마이크로소프트 연구진이 제안한 합성곱 신경망 (CNN, Convolutional Neural Network) 아키텍처다. 딥러닝에서 모델의 성능을 높이려면 신경망을 깊게 쌓아야 하지만, 기존 방식은 한계가 명확했다. 입력 데이터가 여러 층을 거치면서 정보가 변질되고, 역전파 (Backpropagation) 시 오차 신호가 점차 0에 수렴하는 기울기 소실 (Vanishing Gradient) 문제가 발생했기 때문이다.

이로 인해 층을 20개 쌓은 모델보다 56개 쌓은 모델의 성능이 오히려 떨어지는 망각 및 저하 (Degradation) 현상이 나타났다. 모델이 깊어질수록 학습이 어려워지는 이 모순을 극복하기 위해, 정보가 손실 없이 통과할 수 있는 직통 고속도로인 잔차 연결 (Skip Connection)이 등장하게 되었다.

  • 📢 섹션 요약 비유: 깊은 신경망은 수십 명의 사람이 일렬로 서서 귓속말을 전달하는 게임과 같습니다. 중간에 한 명만 말을 잘못 옮겨도 마지막 사람은 전혀 다른 말을 듣게 되는데, 잔차 연결은 처음 사람이 마지막 사람에게 직접 쪽지를 날려 원본을 확인시켜 주는 셈입니다.

Ⅱ. 아키텍처 및 핵심 원리

ResNet의 핵심 원리는 기존의 네트워크가 $H(x)$라는 최적의 함수를 직접 학습하려 했던 것과 달리, 출력과 입력의 차이인 $F(x) = H(x) - x$ 즉, '잔차(Residual)'를 학습하도록 구조를 바꾼 것이다. 최종 출력은 $F(x) + x$가 되며, 여기서 $x$는 아무런 변형 없이 전달되는 스킵 커넥션 (Skip Connection)이다.

┌──────────────────────────────────────────────────────────────┐
│                  잔차 블록 (Residual Block)                  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│       입력 x ─────────────────────────┐                      │
│         │                             │ (Skip Connection)    │
│         ▼                             │                      │
│    [ 가중치 층 (Weight Layer) ]       │                      │
│         │                             │                      │
│         ▼                             │                      │
│    [ ReLU 활성화 (Activation) ]       │                      │
│         │                             │                      │
│         ▼                             │                      │
│    [ 가중치 층 (Weight Layer) ]       │                      │
│         │                             │                      │
│         ▼                             ▼                      │
│      F(x)  ────────── (+) ────────▶ F(x) + x                 │
│         (잔차)      더하기(Add)     (최종 출력)              │
│                                                              │
└──────────────────────────────────────────────────────────────┘

이 구조 덕분에 가중치 층이 학습해야 할 양이 줄어들고, 역전파 과정에서 미분을 수행할 때 $x$에 대한 미분값 1이 항상 유지되어 오차 신호가 앞단까지 강력하게 전달된다. 또한, 152층 이상의 깊은 네트워크에서는 연산량을 줄이기 위해 $1 \times 1$ 합성곱 층을 앞뒤로 배치하여 차원을 축소했다가 다시 늘리는 보틀넥 (Bottleneck) 구조를 적용한다.

  • 📢 섹션 요약 비유: 학생에게 어려운 수학 문제의 전체 정답을 무에서 유로 만들어내라고 하는 대신, 기본 공식(x)을 미리 던져주고 거기서 부족한 부분(F(x))만 채워 넣으라고 하는 것과 같습니다. 훨씬 학습하기가 쉬워집니다.

Ⅲ. 비교 및 연결

ResNet은 이전 세대의 대표적인 심층 신경망인 VGGNet 등과 비교할 때 설계 철학의 근본적인 차이를 보인다. 기존 모델들이 단순히 계층을 직렬로 연장하는 데 집중했다면, ResNet은 데이터 경로의 우회를 통해 깊이의 한계를 구조적으로 극복했다.

항목일반 심층 신경망 (예: VGGNet)ResNet (Residual Network)
학습 목표최적 함수 $H(x)$를 직접 매핑잔차 함수 $F(x) = H(x) - x$ 매핑
정보 전달모든 층을 순차적으로 통과스킵 커넥션으로 이전 정보를 건너뛰어 결합
기울기 소실층이 깊어질수록 급격히 심화됨덧셈 연산을 통해 기울기가 1 이상으로 보존됨
파라미터 효율깊이에 비례하여 기하급수적 증가보틀넥 구조로 깊이 대비 연산량 크게 절감

이러한 잔차 연결 개념은 이후 자연어 처리의 트랜스포머 (Transformer) 아키텍처나 밀집 연결을 사용하는 DenseNet 등 수많은 현대 딥러닝 모델의 기본 뼈대로 이식되며 딥러닝 아키텍처의 패러다임을 바꿨다.

  • 📢 섹션 요약 비유: 일반 신경망이 모든 짐을 등에 지고 계단을 하나씩 힘겹게 오르는 등산객이라면, ResNet은 무거운 짐은 엘리베이터(스킵 커넥션)에 실어 보내고 가벼운 몸으로 계단을 오르는 스마트한 등산객입니다.

Ⅳ. 실무 적용 및 기술사 판단

실무에서 이미지 분류, 객체 탐지 등 시각 지능 모델을 설계할 때 ResNet 계열(ResNet-50, ResNet-101 등)은 백본 (Backbone) 네트워크의 사실상 표준(De facto standard)으로 사용된다. 깊이와 성능의 트레이드오프를 고려하여 모델을 선택해야 한다.

  1. 모델 깊이 선택: 실시간 처리가 중요하고 모바일 환경에 배포해야 한다면 파라미터가 적은 ResNet-18이나 ResNet-34를 채택한다. 반면, 높은 정확도가 요구되는 서버 기반의 복잡한 비전 태스크에는 보틀넥 구조가 적용된 ResNet-50 이상을 사용한다.
  2. 사전 학습 (Pre-trained) 모델 활용: 처음부터 학습하기보다는 ImageNet 데이터셋으로 사전 학습된 ResNet 가중치를 전이 학습 (Transfer Learning)하는 것이 빠르고 안정적인 수렴을 보장한다.
  3. 안티패턴 주의: 잔차 블록 내부에서 활성화 함수(ReLU)나 배치 정규화 (Batch Normalization)의 순서를 임의로 바꾸면 원래의 기울기 보존 효과가 훼손될 수 있으므로, 검증된 사전 활성화 (Pre-activation) 구조 등을 정확히 적용해야 한다.
  • 📢 섹션 요약 비유: 건물을 지을 때 설계도를 처음부터 새로 그리지 않고, 이미 내진 설계(스킵 커넥션)가 완벽하게 검증된 철골 뼈대(사전 학습된 ResNet)를 가져와 겉면의 인테리어만 우리 회사에 맞게 바꾸는 것이 가장 안전한 건축법입니다.

Ⅴ. 기대효과 및 결론

ResNet의 도입으로 딥러닝 모델은 수백 층 이상으로 깊어질 수 있었고, 이는 이미지 인식 대회(ILSVRC)에서 인공지능이 인간의 시각 인지 오류율을 최초로 뛰어넘는 결정적 계기가 되었다. 표현력의 한계와 최적화의 어려움을 동시에 해결한 것이다.

그러나 층이 깊어짐에 따라 여전히 절대적인 메모리 사용량과 추론 지연시간 (Latency)은 증가하므로, 초경량화가 필요한 에지 (Edge) 환경에서는 MobileNet이나 모델 압축 기술이 추가로 요구된다. 결론적으로 ResNet은 딥러닝에서 '깊이'라는 무기를 온전히 사용할 수 있게 해 준 가장 위대한 건축적 혁신으로 기억되어야 한다.

  • 📢 섹션 요약 비유: 20층짜리 건물만 짓던 인류가 'H빔 철골 구조'를 발명하여 100층, 200층짜리 마천루를 지을 수 있게 된 것과 같습니다. ResNet은 딥러닝 세계의 마천루 시대를 연 H빔 철골입니다.
