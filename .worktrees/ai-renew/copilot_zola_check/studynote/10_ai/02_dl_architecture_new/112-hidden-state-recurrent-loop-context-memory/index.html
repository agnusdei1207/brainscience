핵심 인사이트 (3줄 요약)

  1. 본질: 은닉 상태(Hidden State, $h_t$)는 RNN이 시간 단계 t까지 읽은 **모든 과거 입력의 압축된 요약(Context Vector)**이며, 순환 루프(Recurrent Loop)를 통해 $h_{t-1}$이 다음 단계의 입력으로 재주입되어 시간적 문맥을 유지한다.
  2. 가치: $h_t = f(W_h \cdot h_{t-1} + W_x \cdot x_t + b)$로 정의되어, 과거 기억($h_{t-1}$)과 현재 입력($x_t$)을 비선형 함수(tanh/ReLU)로 혼합하여 새 기억($h_t$)을 생성한다. 이것이 RNN의 "기억력"의 수학적 실체다.
  3. 판단 포인트: 바닐라 RNN의 $h_t$는 시간이 길어질수록 **과거 정보가 희석(기울기 소실)**되며, LSTM의 Cell State($C_t$)와 게이트가 이 문제를 해결한다.

Ⅰ. 개요 및 필요성

FC 네트워크는 입력을 독립적으로 처리하여 "나는 학교에 간다"의 순서 정보를 버린다. RNN은 순환 루프로 이전 은닉 상태를 재주입하여 순서(시간) 정보를 보존한다.

┌───────────────────────────────────────────────────────┐
│    순환 루프: 은닉 상태의 시간 흐름                     │
├───────────────────────────────────────────────────────┤
│  ┌──────┐     ┌──────┐     ┌──────┐                  │
│  │ h_0  │──▶  │ h_1  │──▶  │ h_2  │──▶ ...          │
│  └──────┘     └──────┘     └──────┘                  │
│     ▲           ▲           ▲                         │
│     │           │           │                         │
│   x_0="나"    x_1="는"    x_2="학교"                  │
│                                                       │
│  h_2 = tanh(W_h · h_1 + W_x · "학교" + b)           │
│  → h_2에는 "나는"이라는 과거 문맥이 압축되어 있음     │
└───────────────────────────────────────────────────────┘
  • 📢 섹션 요약 비유: 은닉 상태는 독서 중인 뇌의 "지금까지 읽은 내용 요약"이다. 2장을 읽을 때 뇌에는 1장 내용이 압축되어 있고, 3장에서는 1~2장이 합쳐진 요약이 남는다.

Ⅱ. 아키텍처 및 핵심 원리

은닉 상태의 수학적 구조

요소역할차원
$x_t$현재 입력 벡터$d_{input}$
$h_{t-1}$이전 은닉 상태 (과거 문맥)$d_{hidden}$
$W_x$입력→은닉 가중치$d_{hidden} \times d_{input}$
$W_h$은닉→은닉 가중치 (순환)$d_{hidden} \times d_{hidden}$
$h_t$새 은닉 상태$d_{hidden}$

정보 희석 문제

$h_t$는 고정 크기 벡터이므로, 시퀀스가 길어질수록 초기 입력 정보가 새 입력에 의해 덮어씌워진다(Overwrite). 이것이 기울기 소실의 근본 원인이며, LSTM은 Cell State라는 별도 고속도로를 추가하여 해결한다.

  • 📢 섹션 요약 비유: 은닉 상태는 칠판에 분필로 쓰는 메모다. 새 내용을 쓰면 옛 내용이 지워진다. LSTM의 Cell State는 지우지 않는 노트북이다.

Ⅲ. 비교 및 연결

비교바닐라 RNN $h_t$LSTM $C_t$ + $h_t$
기억 보호없음 (매번 덮어쓰기)게이트로 선택적 보존
장기 의존성실패 (기울기 소실)성공
파라미터$W_h, W_x$ 2개Forget·Input·Output 게이트 4세트

Ⅳ. 실무 적용 및 기술사 판단

은닉 상태 활용

  1. Seq2Seq: 인코더의 마지막 $h_T$가 디코더의 초기 은닉 상태로 전달 → 전체 입력 문장의 압축 요약 역할.
  2. Attention: $h_T$ 하나로는 정보 손실이 크므로, 모든 시간 단계의 $h_1, ..., h_T$를 가중 합산하여 디코더가 참조 → Transformer의 시초.

Ⅴ. 기대효과 및 결론

은닉 상태와 순환 루프는 신경망에 "시간적 기억"을 부여한 최초의 메커니즘이며, LSTM·GRU·Attention·Transformer로 이어지는 시퀀스 모델링 진화의 출발점이다.
