핵심 인사이트 (3줄 요약)

  1. 본질: 마르코프 결정 과정 (MDP, Markov Decision Process)은 강화 학습 (Reinforcement Learning) 문제를 상태-행동-전이-보상-할인율 구조로 정리해, 불확실한 환경에서도 최적 정책을 계산할 수 있게 만드는 표준 수학 모델이다.
  2. 가치: MDP는 "현재 상태가 충분히 잘 정의되면 과거 이력을 모두 들고 다니지 않아도 된다"는 마르코프 성질 (Markov Property)을 전제로, 복잡한 의사결정 문제를 가치 함수와 정책 최적화 문제로 바꿔 준다.
  3. 판단 포인트: 실무에서 MDP의 성패는 알고리즘보다 모델링에 달려 있다. 상태를 충분히 표현했는지, 보상 함수가 목표를 왜곡하지 않는지, 할인율이 단기·장기 목표 균형을 맞추는지가 핵심이다.

Ⅰ. 개요 및 필요성

마르코프 결정 과정 (MDP, Markov Decision Process)은 에이전트가 환경과 상호작용하며 장기 누적 보상을 최대화하도록 의사결정 문제를 표현하는 확률 모델이다. 지도 학습처럼 정답 레이블이 주어지지 않는 상황에서는 "지금 어떤 행동을 해야 결국 가장 큰 성과를 얻는가"를 직접 계산해야 하는데, MDP는 그 질문을 수학적으로 다룰 수 있게 만든다. 자율주행, 로봇 제어, 게임 플레이, 자원 스케줄링처럼 결과가 연속된 선택의 누적으로 결정되는 문제에서 특히 중요하다.

MDP가 필요한 이유는 현실의 의사결정이 한 번의 선택으로 끝나지 않기 때문이다. 지금의 행동은 즉시 보상만 바꾸는 것이 아니라 다음 상태와 미래 선택지를 함께 바꾼다. 따라서 "당장 이득"만 보는 규칙으로는 장기 최적해를 얻기 어렵고, 상태 전이와 미래 보상 할인까지 포함한 구조가 필요하다.

또한 MDP는 강화 학습의 공통 언어 역할을 한다. Q-러닝 (Q-Learning), 정책 경사 (Policy Gradient), 액터-크리틱 (Actor-Critic) 같은 다양한 알고리즘도 결국은 MDP 위에서 가치 함수나 정책을 어떤 방식으로 추정할지의 차이로 이해할 수 있다.

  • 📢 섹션 요약 비유: MDP는 여행 계획표와 같다. 지금 숙소비가 싸다고 바로 예약하는 것이 아니라, 그 선택이 다음 이동 경로와 전체 일정 비용까지 어떻게 바꾸는지 함께 보게 만드는 지도다.

Ⅱ. 아키텍처 및 핵심 원리

MDP는 보통 ⟨S, A, P, R, γ⟩의 다섯 요소로 표현된다. 여기서 상태 집합 S는 환경의 현재 상황, 행동 집합 A는 가능한 선택, 전이 확률 P는 행동 이후 다음 상태로 이동할 가능성, 보상 함수 R은 행동 결과의 즉시 가치, 할인율 γ는 미래 보상의 현재 가치를 뜻한다. 핵심은 에이전트가 이 구조 위에서 누적 보상(Return)을 가장 크게 만드는 정책 π(a|s)를 찾는 것이다.

요소의미설계 시 질문
상태 (State, S)의사결정에 필요한 현재 정보과거 이력을 따로 보지 않아도 될 만큼 충분한가?
행동 (Action, A)상태에서 가능한 선택실제 시스템이 실행 가능한 선택만 포함했는가?
전이 확률 (Transition Probability, P)행동 이후 상태 변화 가능성환경의 불확실성을 반영했는가?
보상 (Reward, R)즉시 얻는 점수 또는 비용최종 목표와 일치하는가, 편법을 유도하지 않는가?
할인율 (Discount Factor, γ)미래 보상 반영 비율단기 대응과 장기 전략의 균형이 맞는가?

아래 그림은 MDP가 단순 점수판이 아니라, 상태 변화와 미래 가치까지 포함하는 순환 구조임을 보여준다.

┌──────────────────────────────────────────────────────────────┐
│               MDP 의사결정 루프: 현재 선택이 미래를 바꾼다    │
├──────────────────────────────────────────────────────────────┤
│ 현재 상태 s_t                                                │
│     │                                                        │
│     ├─ 정책 π(a|s) ──▶ 행동 a_t 선택                         │
│     │                                                        │
│     └──────────────────────────────────────┐                 │
│                                            ▼                 │
│                               환경 전이 P(s_{t+1}|s_t,a_t)   │
│                                            │                 │
│                                            ├─ 즉시 보상 r_t  │
│                                            ▼                 │
│                                   다음 상태 s_{t+1}          │
│                                            │                 │
│                                            └─ 미래 가치 반영 │
│                                               γ · V(s_{t+1}) │
└──────────────────────────────────────────────────────────────┘

이 구조는 벨만 기대 방정식 (Bellman Expectation Equation)과 벨만 최적 방정식 (Bellman Optimality Equation)으로 이어진다. 현재 상태의 가치는 "지금 받는 보상 + 다음 상태 가치의 할인 합"으로 재귀적으로 표현되므로, MDP를 푼다는 말은 결국 이 재귀 관계를 만족하는 가치 함수와 정책을 찾는다는 뜻이다. 따라서 상태 정의가 부정확하면 그 위에 어떤 알고리즘을 올려도 최적화가 흔들린다.

  • 📢 섹션 요약 비유: MDP는 네비게이션이 단순히 다음 코너만 알려주는 것이 아니라, 지금 우회전이 이후 교통 체증과 도착 시간까지 어떻게 바꾸는지 계속 계산하는 방식과 같다.

Ⅲ. 비교 및 연결

MDP의 경계를 이해하려면 비슷해 보이는 다른 의사결정 모델과 비교해야 한다. 특히 다중 슬롯머신 문제인 밴딧 (Bandit)은 상태 전이가 거의 없고, 부분 관찰 마르코프 결정 과정 (POMDP, Partially Observable Markov Decision Process)은 상태를 완전히 볼 수 없다는 점에서 MDP와 다르다.

구분밴딧 (Bandit)MDPPOMDP
상태 개념사실상 없음 또는 매우 단순현재 상태를 명시적으로 사용진짜 상태를 직접 볼 수 없음
미래 영향행동의 미래 상태 영향 작음행동이 다음 상태와 장기 보상에 영향상태 불확실성까지 함께 고려
대표 문제광고 클릭 선택게임, 로봇, 자원 배분자율주행 사각지대, 센서 노이즈 환경
난이도상대적으로 낮음중간가장 높음

강화 학습의 핵심 개념도 MDP를 중심으로 연결된다. 가치 함수 (Value Function)는 상태 또는 상태-행동의 장기 가치를 추정하고, 정책 (Policy)은 각 상태에서 행동을 선택하는 규칙이며, 탐험 (Exploration)과 활용 (Exploitation)은 아직 불확실한 행동을 시험할지 이미 유리한 행동을 반복할지의 균형 문제다. 즉 MDP는 강화 학습의 "환경 모델", 가치 함수와 정책은 그 위에서 움직이는 "해결 전략"이다.

실무적으로는 마르코프 성질이 깨지는 순간이 중요하다. 현재 상태만으로 미래를 설명하지 못하면, 표면상 MDP로 보이는 문제도 실제로는 POMDP이거나 시계열 메모리가 필요한 문제일 수 있다. 이런 경우에는 상태에 이력 요약치를 추가하거나, 순환 신경망 (RNN, Recurrent Neural Network)·트랜스포머 기반 메모리 구조를 보완적으로 사용한다.

  • 📢 섹션 요약 비유: 밴딧은 매번 독립적으로 자판기 버튼을 고르는 문제이고, MDP는 미로를 걸어가는 문제이며, POMDP는 안개 낀 미로를 손전등 하나 들고 걷는 문제에 가깝다.

Ⅳ. 실무 적용 및 기술사 판단

실무에서 MDP는 알고리즘 선택보다 먼저 모델링 품질을 점검해야 한다. 첫째, 상태는 의사결정에 필요한 최소 충분 정보여야 한다. 너무 단순하면 마르코프 성질이 깨지고, 너무 과하면 상태 공간이 폭증해 학습이 느려진다. 둘째, 보상은 최종 목표를 직접 반영해야 하며, 중간 지표만 보상하면 보상 해킹(Reward Hacking) 위험이 커진다.

셋째, 할인율은 도메인 특성과 맞아야 한다. 재고 관리나 장기 자산 운용처럼 미래 파급효과가 큰 문제는 높은 할인율이 유리할 수 있지만, 실시간 입찰이나 짧은 세션 추천처럼 즉시 반응이 중요한 문제는 지나치게 높은 할인율이 오히려 학습을 불안정하게 만든다. 넷째, 안전 제약이 있는 시스템에서는 탐험 과정 자체가 위험할 수 있으므로, 오프라인 강화 학습 (Offline Reinforcement Learning), 시뮬레이터, 제약 조건 기반 정책 탐색을 함께 고려해야 한다.

실무 체크리스트

  1. 상태 정의만으로 다음 상태와 보상을 충분히 설명할 수 있는가?
  2. 보상 함수가 실제 비즈니스 목표와 같은 방향을 가리키는가?
  3. 할인율이 도메인의 시간 지평(Time Horizon)과 맞는가?
  4. 시뮬레이션과 실제 운영 환경의 전이 차이를 검증했는가?
  5. 안전·규제 제약 때문에 온라인 탐험을 제한해야 하는가?

채택과 회피 기준

  • 채택: 상태, 행동, 보상을 비교적 명확히 정의할 수 있고 연속 의사결정의 장기 효과가 중요한 문제

  • 회피 또는 보완: 상태를 완전히 관찰하기 어렵거나, 보상 정의가 모호하거나, 탐험 비용이 지나치게 큰 문제

  • 📢 섹션 요약 비유: MDP 설계는 아이에게 용돈 규칙을 정하는 일과 같다. 무엇을 잘한 것으로 볼지, 당장 사탕과 미래 저축 중 무엇을 더 중요하게 볼지 규칙을 잘못 잡으면 행동도 엉뚱하게 배운다.

Ⅴ. 기대효과 및 결론

MDP를 올바르게 적용하면 복잡한 의사결정 문제를 체계적으로 분해할 수 있다. 상태와 행동이 분리되면 문제 구조가 선명해지고, 가치 함수와 정책을 통해 장기 최적화 관점에서 의사결정을 평가할 수 있다. 이는 강화 학습 알고리즘 선택, 시뮬레이터 설계, 성능 비교 기준을 모두 통일하는 장점으로 이어진다.

다만 MDP는 현실을 단순화한 모델이므로 한계도 분명하다. 부분 관찰, 거대한 상태 공간, 희소 보상, 안전 제약이 강한 환경에서는 기본 MDP만으로 충분하지 않다. 그래서 실제 시스템은 함수 근사, 보상 설계, 제약 최적화, 오프라인 데이터 학습 같은 보완 전략과 함께 사용된다.

결국 MDP는 "강화 학습 알고리즘" 그 자체가 아니라, 장기 의사결정 문제를 올바르게 표현하는 사고 틀로 기억하는 것이 맞다. 문제를 MDP로 잘 모델링하면 해법은 여러 알고리즘 중에서 선택할 수 있지만, 모델링이 틀리면 어떤 고급 알고리즘도 방향을 잃는다.

  • 📢 섹션 요약 비유: MDP는 건물을 짓기 전 그리는 구조도와 같다. 설계도가 정확하면 어떤 공법을 써도 완성 가능성이 높아지지만, 설계도가 틀리면 좋은 자재와 기술도 소용이 없다.
