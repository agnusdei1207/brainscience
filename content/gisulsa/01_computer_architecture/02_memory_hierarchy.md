# 🎯 핵심 키워드: 메모리 계층 (Memory Hierarchy), 가상 메모리 (Virtual Memory), TLB (Translation Lookaside Buffer)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

메모리 계층(Memory Hierarchy)은 레지스터-캐시-주기억장치-보조기억장치를 속도와 용량의 절충 구조로 배치한 시스템 설계 원리다.  
가상 메모리(Virtual Memory)는 프로세스마다 독립된 논리 주소 공간을 제공해 보호와 확장성을 보장하는 운영체제·하드웨어 공동 메커니즘이다.  
TLB(Translation Lookaside Buffer)는 주소 변환 결과를 캐싱하여 페이지 테이블 탐색 오버헤드를 줄이는 MMU 내부 고속 캐시다.
