# 🎯 핵심 키워드: 명령어 집합 구조 (ISA), RISC (Reduced Instruction Set Computer), CISC (Complex Instruction Set Computer)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

명령어 집합 구조(ISA)는 소프트웨어가 하드웨어를 제어하기 위해 사용하는 명령어 형식, 주소 지정 방식, 레지스터 모델의 계약이다.  
RISC는 단순하고 고정 길이의 명령어를 빠르게 처리해 파이프라이닝과 저전력에 유리한 구조다.  
CISC는 복잡한 명령어와 높은 코드 밀도를 활용해 하위 호환성과 범용성을 확보하지만 디코딩과 마이크로코드 부담이 크다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | RISC | CISC |
| --- | --- | --- |
| 명령어 형태 | 고정 길이, 단순 연산 중심 | 가변 길이, 복합 연산 포함 |
| 하드웨어 복잡도 | 낮음 | 높음 |
| 코드 밀도 | 상대적으로 낮음 | 상대적으로 높음 |
| 장점 | 파이프라인과 저전력에 유리 | 호환성과 풍부한 명령 세트 |
| 대표 활용 | ARM, RISC-V 기반 모바일/임베디드 | x86 기반 PC/서버 |
