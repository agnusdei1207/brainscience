# 🎯 핵심 키워드: 입출력 (I/O), DMA (Direct Memory Access), 인터럽트 (Interrupt)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

입출력(I/O)은 CPU 외부 장치와 데이터를 교환하는 과정이며, 장치 속도와 CPU 속도의 차이를 조정하는 제어 구조가 핵심이다.  
DMA(Direct Memory Access)는 CPU 개입을 최소화하고 장치가 메모리에 직접 접근하여 대량 데이터를 전송하는 메커니즘이다.  
인터럽트(Interrupt)는 비동기 사건 발생 시 CPU 실행 흐름을 잠시 전환해 빠르게 대응하는 하드웨어/소프트웨어 신호 체계다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | Programmed I/O | DMA |
| --- | --- | --- |
| 데이터 이동 주체 | CPU가 직접 레지스터를 읽고 씀 | DMA 컨트롤러가 메모리와 장치를 연결 |
| CPU 부하 | 높음 | 낮음 |
| 적합한 데이터량 | 소량/단순 제어 | 대량/연속 전송 |
| 장점 | 구현 단순 | 전송 효율과 병렬성 우수 |
| 주의점 | Busy waiting 비효율 | 버스 경합과 캐시 일관성 고려 필요 |
