# 🎯 핵심 키워드: 병렬 처리 (Parallel Processing), 멀티코어 (Multicore), NUMA (Non-Uniform Memory Access)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

병렬 처리(Parallel Processing)는 작업을 여러 실행 단위로 나누어 동시에 수행함으로써 처리량과 응답성을 높이는 방식이다.  
멀티코어(Multicore)는 하나의 칩에 다수의 코어를 집적하여 TLP(Thread Level Parallelism)를 구현하는 대표 아키텍처다.  
NUMA는 코어가 로컬 메모리에 더 빠르게 접근하고 원격 메모리에는 더 느리게 접근하는 비균일 메모리 구조로, 대규모 서버에 적합하다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | SMP/UMA | NUMA |
| --- | --- | --- |
| 메모리 접근 | 모든 코어가 동일 지연으로 공유 메모리 접근 | 로컬/원격 메모리 지연이 다름 |
| 확장성 | 소켓 수 증가 시 한계가 큼 | 대규모 멀티소켓 확장에 유리 |
| 운영 포인트 | 구현 단순 | CPU affinity, memory binding 필요 |
| 장점 | 프로그래밍 단순성 | 대용량 메모리와 높은 처리량 |
| 주의점 | 버스 병목 | 원격 접근 시 성능 급락 |
