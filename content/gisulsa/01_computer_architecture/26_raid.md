# 🎯 핵심 키워드: RAID, 스트라이핑, 미러링, 패리티, 핫스페어

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆ | **특성**: 매회 빈출 기본 토픽

## 1. 정의

RAID(Redundant Array of Independent Disks)는 여러 개의 물리 디스크를 하나의 논리 디스크로 구성하여 **성능 향상**과 **결함 허용(Fault Tolerance)**을 동시에 달성하는 스토리지 기술이다.

## 2. RAID 레벨 비교 (핵심 암기)

| 레벨 | 방식 | 장점 | 단점 | 최소 디스크 |
|------|------|------|------|-----------|
| **RAID 0** | 스트라이핑 | 성능 ↑↑ | 결함 허용 없음 | 2 |
| **RAID 1** | 미러링 | 안전성 최고 | 용량 50% 낭비 | 2 |
| **RAID 5** | 분산 패리티 | 성능+안전 균형 | 쓰기 패널티 | 3 |
| **RAID 6** | 이중 패리티 | 디스크 2개 동시 장애 허용 | 비용 높음 | 4 |
| **RAID 10** | 미러링+스트라이핑 | 최고 성능+안전 | 비용 최고 | 4 |

## 3. 답안 목차 템플릿

**문제**: "RAID 레벨별 특징을 비교하고, 엔터프라이즈 환경에서의 선택 기준을 설명하시오."

```
I. RAID 정의 및 목적
   - 성능: 병렬 I/O (스트라이핑)
   - 안전: 중복 저장 (미러링/패리티)
   - 가용성: 핫스페어 (Hot Spare)로 자동 재구성

II. 핵심 RAID 레벨 구조
   
   [RAID 0 - 스트라이핑]
   데이터: A1|A2|A3|A4
   디스크1: A1   A3
   디스크2:   A2   A4
   
   [RAID 1 - 미러링]
   디스크1: A1 A2 A3
   디스크2: A1 A2 A3  ← 완전 복사본
   
   [RAID 5 - 분산 패리티]
   디스크1: A1  A2  P3
   디스크2: A2  P2  A3
   디스크3: P1  A3  A4
   (P = XOR 패리티)

III. 선택 기준
   | 환경           | 권장 RAID | 이유               |
   |---------------|-----------|-------------------|
   | 데이터베이스   | RAID 10   | 랜덤 I/O 성능+안전 |
   | 파일 서버     | RAID 5/6  | 비용-효율 균형     |
   | 백업 스토리지 | RAID 6    | 이중 장애 허용     |
   | 고성능 캐시   | RAID 0    | 속도 최우선(비중요 데이터)|

IV. 현대 트렌드
   - 소프트웨어 RAID: Linux MD RAID, ZFS RAID-Z
   - 클라우드: S3 + 오브젝트 스토리지(자체 복제)
   - NVMe RAID: 초고성능 스토리지 구성
   - 핫스페어(Hot Spare): 장애 시 자동 교체 및 재구성
```

## 4. 핵심 암기 포인트

- **RAID 0**: 성능만, 안전 없음
- **RAID 1**: 완전 미러, 용량 반토막
- **RAID 5**: 디스크 1개 장애 허용, n-1 용량
- **RAID 6**: 디스크 2개 장애 허용, n-2 용량
- **RAID 10**: 성능+안전 최고, 비용 최고 (용량 50%)

## 5. 관련 개념 연결

| 개념 | 연결 포인트 |
|------|------------|
| 스토리지 가상화 | RAID 위에 논리 볼륨 구성 |
| SSD (NVMe) | NVMe RAID로 초고속 스토리지 |
| 오브젝트 스토리지 | 클라우드에서 RAID를 대체하는 분산 복제 |
| RPO/RTO | RAID가 보장하는 가용성 지표 |
