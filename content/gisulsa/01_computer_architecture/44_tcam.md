### Ⅱ. 핵심 구성요소

```
데이터 비트 | 마스크 비트 | 의미
    0       |     0      | 정확히 0
    1       |     0      | 정확히 1
    0 or 1  |     1      | X (Don't Care, 무시)
```
```
입력 IP 주소: 10.0.0.5 (이진수)

TCAM 엔트리 1: 10.0.0.0/24 → 마스크: 11111111.11111111.11111111.00000000
TCAM 엔트리 2: 10.0.0.0/8  → 마스크: 11111111.00000000.00000000.00000000
TCAM 엔트리 3: 0.0.0.0/0   → 마스크: 00000000.00000000.00000000.00000000 (기본경로)

→ 모든 엔트리 동시 비교 → 최장 prefix 매칭(LPM) → 1클럭에 결과
```


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.
