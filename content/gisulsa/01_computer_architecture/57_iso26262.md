# ISO 26262, 기능안전 (Functional Safety), ASIL, 자동차 E/E 시스템

> 출제 빈도: ★★★★☆ | 난이도: ★★★★☆ | 기출: ★134회 (컴시응 특화 필출)

---

## 답안.

### Ⅰ. 개요

ISO 26262는 자동차 전기/전자(E/E) 시스템의 기능안전(Functional Safety)을 위한 국제 표준으로, 시스템 오작동으로 인한 비합리적 위험을 방지하기 위한 개발 생명주기 전반의 요구사항을 정의한다.
ASIL(Automotive Safety Integrity Level) A~D로 위험 수준을 분류하며, ASIL D가 가장 높은 안전 무결성 수준이다.

### Ⅱ. 핵심 구성요소

```
I. ISO 26262 정의 및 배경
   - 자동차 전자화(E/E 시스템) 증가 → 소프트웨어 결함 위험
   - 2011년 제정, 2018년 2판 (비승용차 확대)
   - 목적: 시스템 오작동으로 인한 비합리적 위험(Unreasonable Risk) 방지

II. ASIL 결정 프로세스 (위험 분석 및 위험 평가, HARA)
   
   위험 결정 3요소:
   ┌──────────┬────────────────────────────────┐
   │ 심각도(S) │ S0(해없음) ~ S3(생명 위협)      │
   │ 노출도(E) │ E0(불가) ~ E4(거의 항상)        │
   │ 제어성(C) │ C0(쉬움) ~ C3(제어 불가)        │
   └──────────┴────────────────────────────────┘
   
   ASIL 등급:
   | 등급   | 의미             | 적용 예시                |
   |--------|-----------------|------------------------|
   | QM     | 품질관리만으로 충분 | 엔터테인먼트 시스템      |
   | ASIL A | 최저 안전 요구    | 와이퍼 제어              |
   | ASIL B | 낮은 안전 요구    | 에어백 트리거 보조       |
   | ASIL C | 중간 안전 요구    | ABS, ESC                |
   | ASIL D | 최고 안전 요구    | 스티어링, 브레이크       |

III. ISO 26262 V 모델 개발 프로세스

        ↓                        ↑
