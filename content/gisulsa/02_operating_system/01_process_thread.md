# 🎯 핵심 키워드: 프로세스 (Process), 스레드 (Thread), PCB (Process Control Block)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

프로세스(Process)는 독립된 주소 공간과 자원을 가진 실행 단위이며, 운영체제가 격리와 보호를 제공하는 기본 객체다.  
스레드(Thread)는 프로세스 내부에서 실행 흐름만 분리한 경량 실행 단위로 코드·데이터·파일을 공유한다.  
PCB(Process Control Block)는 프로세스 상태, 레지스터, 스케줄링 정보, 메모리 정보를 저장하여 문맥 교환(Context Switch)을 가능하게 한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 프로세스 | 스레드 |
| --- | --- | --- |
| 주소 공간 | 독립적 | 같은 프로세스 내 공유 |
| 문맥 교환 비용 | 높음 | 상대적으로 낮음 |
| 장점 | 안정성과 격리 우수 | 통신 비용 낮고 병렬 처리 용이 |
| 단점 | IPC 비용 큼 | 오류 전파와 경쟁 상태 위험 |
| 적합 사례 | 강한 격리 필요 서비스 | 웹 요청 처리, 병렬 계산 |

## 5. 인출 훈련 문제 (Output Drills)

### 단답형 (30초)
1. 프로세스 (Process)의 정의를 한 문장으로 쓰시오.
2. 프로세스·스레드·PCB 답안에서 반드시 써야 할 핵심 구성요소 3가지를 나열하시오.
3. 프로세스와 스레드의 가장 큰 차이점을 설명하시오.
4. "격리 수준, 공유 자원, 문맥 교환 비용을 한 번에 비교하는 연습"를 답안 키워드 3개로 압축하시오.
5. 웹 서버와 배치 시스템의 동시성 설계 중 하나를 들고 기대효과 2가지를 말하시오.

### 서술형 (5분)
6. "프로세스와 스레드의 차이, 그리고 PCB의 역할을 설명하시오."의 핵심 구성요소와 기대효과를 5분 답안으로 정리하시오.
7. "프로세스 vs 스레드"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
8. "프로세스와 스레드의 차이, 그리고 PCB의 역할을 설명하시오." (개념, 구조, 비교, 적용사례, 향후전망 포함)
