# 🎯 핵심 키워드: 메모리 관리 (Memory Management), 페이징 (Paging), 세그멘테이션 (Segmentation)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

메모리 관리는 프로세스에 안전하고 효율적으로 주소 공간을 할당·보호·회수하는 운영체제 핵심 기능이다.  
페이징(Paging)은 고정 크기 페이지 단위로 메모리를 나누어 외부 단편화를 줄이는 기법이다.  
세그멘테이션(Segmentation)은 코드·데이터·스택처럼 논리적 단위별로 메모리를 분리하여 보호와 공유를 쉽게 하지만 외부 단편화가 발생한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 페이징 | 세그멘테이션 |
| --- | --- | --- |
| 분할 기준 | 고정 크기 페이지 | 논리적 의미 단위 |
| 단편화 | 내부 단편화 가능 | 외부 단편화 발생 |
| 보호/공유 | 페이지 단위 권한 관리 | 세그먼트 단위 보호와 공유 용이 |

5. 대규모 애플리케이션의 주소 공간 보호와 메모리 효율화 중 하나를 들고 기대효과 2가지를 말하시오.

7. "페이징 vs 세그멘테이션"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
