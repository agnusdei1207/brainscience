# 🎯 핵심 키워드: 파일 시스템 (File System), 입출력 버퍼링 (I/O Buffering), 저널링 (Journaling)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

파일 시스템(File System)은 데이터를 파일과 디렉터리 구조로 조직하고 저장 장치에 지속적으로 보존하는 운영체제 서브시스템이다.  
입출력 버퍼링(I/O Buffering)은 장치와 프로세스의 속도 차이를 흡수해 시스템 호출 횟수와 디스크 접근 비용을 줄이는 기법이다.  
저널링(Journaling)은 메타데이터 또는 데이터 변경 이력을 로그로 먼저 기록해 장애 발생 시 일관성을 복구하는 보호 메커니즘이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | Buffered I/O | Direct I/O |
| --- | --- | --- |
| 데이터 경로 | OS 버퍼 캐시를 경유 | 애플리케이션 버퍼로 직접 전송 |
| 장점 | 시스템 호출 감소와 일반 워크로드 효율 | 중복 복사와 캐시 오염 감소 |
| 단점 | 이중 버퍼링 가능 | 정렬 제약과 구현 복잡도 |
| 적합 사례 | 일반 파일 처리 | DB, 고성능 스토리지 엔진 |
| 시험 포인트 | 캐시 활용 | 일관성과 지연 제어 |
