# 🎯 핵심 키워드: 라우팅 (Routing), 스위칭 (Switching), VLAN (Virtual LAN)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

라우팅(Routing)은 목적지 네트워크까지의 최적 경로를 선택하고 패킷을 전달하는 3계층 기능이다.  
스위칭(Switching)은 MAC 주소를 기반으로 프레임을 전달하여 동일 브로드캐스트 도메인 내 통신을 효율화하는 2계층 기능이다.  
VLAN(Virtual LAN)은 물리적으로 같은 스위치에 연결된 장비를 논리적으로 분리하여 브로드캐스트 도메인과 보안 정책을 재구성하는 기술이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 2계층 스위칭 | 3계층 라우팅 |
| --- | --- | --- |
| 전달 기준 | MAC 주소 | IP 주소 |
| 브로드캐스트 도메인 | 같은 VLAN 내 공유 | 네트워크별 분리 |
| 장점 | 고속 내부 전달 | 경로 제어와 정책 적용 가능 |
| 대표 장비 | L2 Switch | Router, L3 Switch |
| 시험 포인트 | VLAN tagging | Inter-VLAN routing |
