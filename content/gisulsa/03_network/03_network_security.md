# 방화벽 (Firewall), IDS (Intrusion Detection System), VPN (Virtual Private Network)

> 출제 빈도: ★★★★★ | 난이도: ★★★☆☆

---

## 답안.

### Ⅰ. 개요

방화벽(Firewall)은 정책 기반으로 패킷 또는 세션을 허용·차단하여 네트워크 경계 통제를 수행하는 보안 장비다.  
IDS(Intrusion Detection System)는 비정상 트래픽이나 공격 패턴을 탐지하여 경보를 생성하는 감시 체계다.  
VPN(Virtual Private Network)은 공용망 위에 암호화 터널을 구성해 기밀성과 무결성을 확보하는 원격 접속/지사 연결 기술이다.
