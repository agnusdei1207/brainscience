# 🎯 핵심 키워드: 방화벽 (Firewall), IDS (Intrusion Detection System), VPN (Virtual Private Network)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

방화벽(Firewall)은 정책 기반으로 패킷 또는 세션을 허용·차단하여 네트워크 경계 통제를 수행하는 보안 장비다.  
IDS(Intrusion Detection System)는 비정상 트래픽이나 공격 패턴을 탐지하여 경보를 생성하는 감시 체계다.  
VPN(Virtual Private Network)은 공용망 위에 암호화 터널을 구성해 기밀성과 무결성을 확보하는 원격 접속/지사 연결 기술이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 방화벽 | IDS | VPN |
| --- | --- | --- | --- |
| 핵심 역할 | 허용/차단 정책 적용 | 침입 징후 탐지 | 암호화 터널 제공 |
| 배치 위치 | 경계 또는 세그먼트 사이 | 미러링 구간/탭 | 사용자-게이트웨이 사이 |
| 장점 | 즉시 차단 가능 | 공격 가시성 확보 | 원격 접속 보안 강화 |
| 한계 | 내부 위협 탐지 한계 | 차단 기능은 별도 장비 필요 | 과도한 신뢰 부여 가능 |
| 시험 포인트 | ACL/Stateful | Signature/Anomaly | IPSec/SSL VPN |
