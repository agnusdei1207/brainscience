# 🎯 핵심 키워드: 샤논 채널 용량 정리, C=B×log2(1+S/N), SNR, 나이퀴스트

> **출제 빈도**: ★★★★★ | **기출**: ★135회 (컴시응 기초이론 필출)

## 1. 정의

**샤논의 채널 용량 정리**: 잡음이 있는 통신 채널에서 오류 없이 전송 가능한 **이론적 최대 데이터 전송률**.

```
C = B × log₂(1 + S/N)  [bps]
```
- C: 채널 용량 (Channel Capacity) [bps]
- B: 대역폭 (Bandwidth) [Hz]
- S/N: 신호 대 잡음비 (Signal-to-Noise Ratio)

## 2. 답안 목차 템플릿

**문제**: "샤논의 채널 용량 정리와 나이퀴스트 정리를 설명하고, 현대 통신 시스템에서의 의미를 논하시오."

```
I. 샤논 정리 (Shannon's Theorem)
   
   C = B × log₂(1 + S/N)
   
   예시 계산:
   - 전화선: B=3.1kHz, SNR=30dB (1000배)
   - C = 3100 × log₂(1+1000) = 3100 × 9.97 ≈ 30.9 kbps
   - 의미: 어떤 기법을 써도 이 값을 넘을 수 없음
   
   파라미터 영향:
   - B 2배 → C 2배 (선형)
   - SNR 2배 → C ≈ 1비트 증가 (로그)
   - 결론: SNR 향상보다 대역폭 확대가 용량 증가에 효과적

II. 나이퀴스트 정리 (Nyquist Theorem, 무잡음)
   
   최대 전송률 = 2 × B × log₂(M)
   - M: 신호 레벨 수 (QAM의 성상도 포인트 수)
   
   비교:
   | 항목   | 나이퀴스트        | 샤논                |
   |-------|-----------------|---------------------|
   | 대상   | 무잡음 채널       | 잡음 채널            |
   | 변수   | 대역폭, 신호레벨  | 대역폭, SNR          |
   | 의미   | 샘플링 이론       | 정보이론적 상한      |

III. 현대 통신 기술과 샤논 한계
   
   [Wi-Fi 7과 샤논]
   - QAM-4096 (12비트/심볼), 320MHz 대역폭
   - 이론 최대: 수십 Gbps
   - 현실: 다중안테나(MIMO) + OFDMA로 샤논 한계에 근접
   
   [5G/6G와 샤논]
   - 밀리미터파(mmWave): B 수백MHz → C 수십 Gbps
   - 6G 테라헤르츠: B 수GHz → C 수백 Gbps 목표
   
   [MIMO와 채널 용량]
   - M×N MIMO: C = B × min(M,N) × log₂(1+SNR) 근사
   - 다중 공간 스트림으로 용량 선형 확장

IV. 엔트로피와 정보이론 연계
   - 샤논 엔트로피: H = -Σ p(x)×log₂p(x)
   - 채널 용량 = 상호정보량 최대화
   - 압축 이론: 허프만 코딩, LZ77 → 엔트로피 하한에 수렴
```

## 3. 핵심 암기 포인트

- **C = B × log₂(1 + S/N)** — 반드시 암기
- **대역폭 효과**: B 증가 → C 선형 증가
- **SNR 효과**: SNR 2배 ≈ C 1bps 증가 (로그 효과 작음)
- **나이퀴스트** = 무잡음 / **샤논** = 잡음 있는 실제 환경

## 4. 관련 개념 연결

| 개념 | 연결 포인트 |
|------|------------|
| Wi-Fi 7 (★134회) | 320MHz+QAM4096으로 샤논 한계 근접 |
| 5G 아키텍처 (★133회) | 밀리미터파로 대역폭 확대 |
| 6G (☆예측) | 테라헤르츠 대역 → 샤논 한계 재정의 |
| MIMO | 공간 다중화로 용량 배수 증가 |
