# ETSI ZSM, 제로터치 자율 네트워크, E2E 자동화, 폐쇄 루프

> 출제 빈도: ★★★★★ | 기출: ★135회

---

## 답안.

### Ⅰ. 개요

ETSI ZSM(Zero-touch network & Service Management)은 ETSI(유럽전기통신표준화기구)가 정의한 **AI/자동화 기반 통신망 완전 자율 관리** 프레임워크이다.
사람의 개입 없이(Zero-touch) 네트워크 구성, 최적화, 장애 복구, 서비스 관리를 자동으로 수행하는 E2E(End-to-End) 자율 관리 아키텍처.

### Ⅱ. 핵심 구성요소

```
I. ZSM 정의 및 배경
   - 5G 이후 네트워크 복잡도 폭증 → 수동 관리 불가
   - 네트워크 슬라이싱: 슬라이스별 SLA를 수동 관리 불가
   - ETSI ISG ZSM: 2017년 설립, 표준화 진행 중

II. ZSM 아키텍처
   
   [ZSM 계층 구조]
   ┌─────────────────────────────────────────────┐
   │ 크로스도메인 통합 관리 레이어 (E2E 서비스)     │
   │  - E2E 서비스 SLA 보장                       │
   │  - 크로스도메인 폐쇄루프                      │
   ├─────────────────────────────────────────────┤
   │ 도메인 관리 레이어 (각 기술 도메인)            │
   │  [무선 도메인] [코어 도메인] [엣지 도메인]     │
   │  각 도메인 내 폐쇄루프 자동화                  │
   ├─────────────────────────────────────────────┤
   │ 네트워크 인프라 (물리/가상 자원)               │
   └─────────────────────────────────────────────┘
   
   핵심: 폐쇄루프 (Closed-Loop) 자동화
   수집(Monitor) → 분석(Analyze) → 결정(Decide) → 실행(Execute)

III. ZSM 핵심 개념
   
   1) 폐쇄루프 (Closed-Loop Automation)
      Monitor: KPI, 트래픽, 장애 데이터 수집
      Analyze: AI/ML 이상탐지, 원인 분석 (Root Cause)
      Decide: 최적 대응 정책 결정


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.
