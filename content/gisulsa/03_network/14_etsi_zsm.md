# 🎯 핵심 키워드: ETSI ZSM, 제로터치 자율 네트워크, E2E 자동화, 폐쇄 루프

> **출제 빈도**: ★★★★★ | **기출**: ★135회

## 1. 정의

ETSI ZSM(Zero-touch network & Service Management)은 ETSI(유럽전기통신표준화기구)가 정의한 **AI/자동화 기반 통신망 완전 자율 관리** 프레임워크이다.

사람의 개입 없이(Zero-touch) 네트워크 구성, 최적화, 장애 복구, 서비스 관리를 자동으로 수행하는 E2E(End-to-End) 자율 관리 아키텍처.

## 2. 출제 포인트

| 포인트 | 내용 | 채점 비중 |
|--------|------|----------|
| 정의 | 제로터치, E2E 자율화, 5G 이후 | 20% |
| 아키텍처 | 도메인, 폐쇄루프, 크로스도메인 | 35% |
| AI 역할 | AI 기반 이상탐지, 자동 복구 | 25% |
| 5G/6G 연계 | 네트워크 슬라이싱 자율 관리 | 20% |

## 3. 답안 목차 템플릿

**문제**: "ETSI ZSM의 개념과 아키텍처를 설명하고, 5G/6G 네트워크 관리에서의 역할을 논하시오."

```
I. ZSM 정의 및 배경
   - 5G 이후 네트워크 복잡도 폭증 → 수동 관리 불가
   - 네트워크 슬라이싱: 슬라이스별 SLA를 수동 관리 불가
   - ETSI ISG ZSM: 2017년 설립, 표준화 진행 중

II. ZSM 아키텍처
   
   [ZSM 계층 구조]
   ┌─────────────────────────────────────────────┐
   │ 크로스도메인 통합 관리 레이어 (E2E 서비스)     │
   │  - E2E 서비스 SLA 보장                       │
   │  - 크로스도메인 폐쇄루프                      │
   ├─────────────────────────────────────────────┤
   │ 도메인 관리 레이어 (각 기술 도메인)            │
   │  [무선 도메인] [코어 도메인] [엣지 도메인]     │
   │  각 도메인 내 폐쇄루프 자동화                  │
   ├─────────────────────────────────────────────┤
   │ 네트워크 인프라 (물리/가상 자원)               │
   └─────────────────────────────────────────────┘
   
   핵심: 폐쇄루프 (Closed-Loop) 자동화
   수집(Monitor) → 분석(Analyze) → 결정(Decide) → 실행(Execute)

III. ZSM 핵심 개념
   
   1) 폐쇄루프 (Closed-Loop Automation)
      Monitor: KPI, 트래픽, 장애 데이터 수집
      Analyze: AI/ML 이상탐지, 원인 분석 (Root Cause)
      Decide: 최적 대응 정책 결정
      Execute: 자동 재구성, 트래픽 재경로, 용량 증설
   
   2) 의도 기반 네트워킹 (Intent-Based Networking)
      인간: "슬라이스 A의 지연 < 1ms 보장"
      ZSM: 자동으로 자원 할당, 경로 최적화
   
   3) 크로스도메인 E2E
      RAN ↔ 코어 ↔ 전송 ↔ 엣지를 통합 관리

IV. 5G/6G 적용
   - 네트워크 슬라이싱 자율 관리: 슬라이스별 SLA 자동 보장
   - 6G AI 네이티브: ZSM + 분산 AI (단말, 엣지, 코어 협력)
   - 스마트팩토리 5G 특화망: ZSM으로 무중단 자율 운영
```

## 4. 핵심 암기 포인트

- **Zero-touch**: 사람 개입 없는 완전 자동화
- **폐쇄루프**: Monitor→Analyze→Decide→Execute 4단계 자동 반복
- **E2E**: RAN부터 코어까지 통합 자율 관리
