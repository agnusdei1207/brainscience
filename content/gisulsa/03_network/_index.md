# 03. 네트워크 (Network)

> **섹션 목표**: 계층 구조, 전달 경로, 보안 통제를 묶어 통신 품질과 확장성을 설명하는 훈련을 수행한다.

## 학습 전략

- **30초 훈련**: 정의 1문장, 비교축 1개, 적용사례 1개를 말로 바로 꺼내는 연습을 한다.
- **5분 훈련**: 개요-구성요소-비교-사례의 4단 구조로 압축 답안을 손으로 써본다.
- **25분 훈련**: 비교표를 먼저 그린 뒤, 장단점과 실무 판단을 연결하는 기술사형 서술을 완성한다.

## 과목 공략 포인트

- 네트워크 답안은 계층별 기능, 제어 프로토콜, 운영 지표를 함께 써야 논리성이 살아난다.
- 라우팅·무선·보안은 각각 다른 주제처럼 보여도 결국 지연, 가용성, 정책 통제의 균형 문제다.
- 실무 사례는 데이터센터, 캠퍼스, 이동통신망으로 나누어 설명하면 적용성이 높아진다.

## 키워드 마스터 리스트

| 번호 | 파일 | 키워드 클러스터 | 훈련 포인트 |
|------|------|----------------|-------------|
| 01 | [OSI 7계층·TCP/IP](/gisulsa/03_network/01_osi_tcp/) | OSI 7계층 (OSI 7 Layers), TCP/IP, 캡슐화 (Encapsulation) | 계층명과 PDU를 함께 외워 장애 지점을 빠르게 특정하는 연습 |
| 02 | [라우팅·스위칭·VLAN](/gisulsa/03_network/02_routing_switching/) | 라우팅 (Routing), 스위칭 (Switching), VLAN (Virtual LAN) | 브로드캐스트 도메인과 충돌 도메인을 구분해 설명하는 연습 |
| 03 | [방화벽·IDS·VPN](/gisulsa/03_network/03_network_security/) | 방화벽 (Firewall), IDS (Intrusion Detection System), VPN (Virtual Private Network) | 통제, 탐지, 터널링 역할을 혼동하지 않도록 분리해 말하는 연습 |
| 04 | [무선랜·5G·IoT](/gisulsa/03_network/04_wireless_5g/) | 무선랜 (Wi-Fi), 5G, 사물인터넷 (IoT) | 대역폭·지연·커버리지 3축으로 무선 기술을 비교하는 연습 |
| 05 | [SDN·NFV·OpenFlow](/gisulsa/03_network/05_sdn_nfv/) | SDN (Software Defined Networking), NFV (Network Functions Virtualization), OpenFlow | 제어 분리와 기능 가상화를 구분해 설명하는 연습 |

## 실전 사용법

1. 가장 자주 출제되는 파일부터 3일 주기로 회독한다.
2. 비교표는 소리 내어 암기하고, 목차 템플릿은 빈 종이에 재현한다.
3. 실무 사례는 자신이 경험한 프로젝트로 치환해 1분 면접 답변까지 연결한다.
