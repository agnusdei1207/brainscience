# 🎯 핵심 키워드: GoF (Gang of Four), 생성 패턴 (Creational Pattern), 구조 패턴 (Structural Pattern), 행위 패턴 (Behavioral Pattern)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

디자인 패턴은 반복적으로 등장하는 설계 문제를 재사용 가능한 구조와 협력 방식으로 정리한 설계 지식이다.  
GoF는 패턴을 생성(Creational), 구조(Structural), 행위(Behavioral) 세 범주로 분류하여 객체 설계 의사결정을 체계화했다.  
기술사 답안에서는 패턴 이름보다 적용 맥락, 해결하려는 변경 축, 남는 부작용까지 설명해야 점수가 높다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 생성 패턴 | 구조 패턴 | 행위 패턴 |
| --- | --- | --- | --- |
| 핵심 질문 | 객체를 어떻게 만들 것인가 | 객체를 어떻게 조합할 것인가 | 객체가 어떻게 협력할 것인가 |
| 대표 패턴 | Factory Method, Builder, Singleton | Adapter, Decorator, Facade | Strategy, Observer, Command |
| 장점 | 생성 책임 분리 | 확장성과 인터페이스 정리 | 행위 변경 유연성 |
| 주의점 | Singleton 남용 | 래핑 구조 과다 | 객체 수 증가와 추적 난이도 |
| 시험 포인트 | 생성 시점 제어 | 구조적 결합 완화 | 행위 캡슐화 |
