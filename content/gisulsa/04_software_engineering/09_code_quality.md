# 🎯 코드 품질 지표 — 순환복잡도, 결합도, 응집도

> **별점**: ★★★★☆ | 기본 필수

## 1. 핵심 지표

| 지표 | 정의 | 목표값 |
|------|------|--------|
| **순환복잡도** (CC) | 독립 경로 수 = E-N+2P | 10 이하 권장 |
| **결합도** (Coupling) | 모듈 간 의존성 | 낮을수록 좋음 |
| **응집도** (Cohesion) | 모듈 내 기능 관련성 | 높을수록 좋음 |
| **코드 커버리지** | 테스트로 실행된 코드 비율 | 80% 이상 권장 |
| **기술 부채** | 나쁜 설계/코드로 인한 미래 비용 | 최소화 |

## 2. 결합도 vs 응집도

```
[결합도 — 낮을수록 좋음 (강 → 약 순서)]
내용결합 > 공통결합 > 외부결합 > 제어결합 > 스탬프결합 > 자료결합

[응집도 — 높을수록 좋음 (약 → 강 순서)]
우연적 < 논리적 < 시간적 < 절차적 < 통신적 < 순차적 < 기능적

목표: 결합도 ↓ + 응집도 ↑ = 유지보수성 ↑

[순환복잡도 계산]
CC = 분기수 + 1
또는 CC = E - N + 2P (E: 간선, N: 노드, P: 연결 컴포넌트)
CC > 10: 리팩토링 권고
CC > 20: 심각한 복잡도
```

## 3. 답안 포인트

**3단락**: ① 품질 지표 정의(CC, 결합도, 응집도) → ② 측정 방법 & 기준값 → ③ SonarQube 등 정적 분석 도구 적용

## 4. 관련 개념

`기술부채` → 낮은 품질의 누적 비용 | `TDD` → 품질 지표 조기 확보 | `DevSecOps` → 코드 품질 파이프라인 통합
