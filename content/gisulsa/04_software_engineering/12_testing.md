# 🎯 테스트 수준 & 기법 (블랙박스/화이트박스)

> **별점**: ★★★★★ | 매회 기본 필출

## 1. 테스트 레벨

| 레벨 | 대상 | 주체 |
|------|------|------|
| 단위 테스트 | 함수/메서드 | 개발자 |
| 통합 테스트 | 모듈 간 인터페이스 | 개발자/QA |
| 시스템 테스트 | 전체 시스템 기능 | QA |
| 인수 테스트 (UAT) | 사용자 요구사항 | 사용자/QA |

## 2. 블랙박스 vs 화이트박스

```
[블랙박스 기법] — 내부 구조 모름, 입출력 기반
- 동치 분할: 유효/무효 입력값 그룹화
- 경계값 분석: 경계값(min, min+1, max-1, max) 테스트
- 결정 테이블: 조건-행동 조합 테스트
- 상태 전이: 상태 변화에 따른 동작

[화이트박스 기법] — 내부 구조 기반
- 구문 커버리지: 모든 문장 실행 (C0)
- 분기 커버리지: 모든 분기(True/False) 실행 (C1)
- 조건 커버리지: 조건식 내 원자 조건 (C2)
- 경로 커버리지: 모든 경로 실행 (가장 강력)

[커버리지 목표]
라인: 70% 이상 | 분기: 80% 이상 | MC/DC: 항공/의료
```

## 3. 뮤테이션 테스팅 (★133회)

```
변이 연산자로 코드에 의도적 결함 주입
→ 테스트가 탐지하면 "Kill", 못 하면 "Survive"
뮤테이션 점수 = Kill수/전체변이수 × 100%
목적: 테스트의 실효성(결함 탐지력) 검증
```

## 4. 답안 포인트

**3단락**: ① 테스트 레벨 피라미드 → ② 블박/화박 기법 & 커버리지 → ③ TDD/BDD/뮤테이션테스트 최신 트렌드

## 5. 관련 개념

`뮤테이션테스팅(★133회)` → 화이트박스 고급 기법 | `TDD` → Red-Green-Refactor | `DevSecOps` → SAST/DAST 파이프라인
