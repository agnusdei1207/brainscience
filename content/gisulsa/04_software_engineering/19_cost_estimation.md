# 🎯 SW 비용 산정 — 기능점수(FP) & COCOMO II

> **별점**: ★★★★★ | 매회 기본 필출

## 1. 비용 산정 방법 분류

| 방법 | 특징 | 종류 |
|------|------|------|
| **전문가 판단** | 경험 기반 | 델파이 기법 |
| **하향식** | 유사 프로젝트 비교 | COCOMO, PUTNAM |
| **상향식** | 기능별 상세 합산 | 기능점수(FP) |
| **LOC** | 코드 라인 기반 | 단순, 부정확 |

## 2. 기능점수 (Function Point)

```
[기능점수 산정 절차]
① 기능 유형 식별:
   내부논리파일(ILF), 외부인터페이스파일(EIF) — 데이터 기능
   외부입력(EI), 외부출력(EO), 외부조회(EQ) — 트랜잭션 기능

② 미조정 기능점수 계산:
   UFP = Σ(기능 유형 × 복잡도 가중치)

③ 기술적 복잡도 조정:
   AFP = UFP × (0.65 + 0.01 × Σfi)
   fi: 14개 일반 시스템 특성 (0~5)

국내 적용: 기능점수기반 SW 대가 산정 기준 (과기부)
공공 SW 사업 의무 적용
```

## 3. COCOMO II

```
[COCOMO II 기본 공식]
노력(PM) = A × Size^B × ΠEM_i
기간(TDEV) = C × PM^D
인력 = PM / TDEV

Size: KSLOC(천 줄) 또는 기능점수
B: 규모 조정 인자 (1.01~1.26)
EM_i: 비용 드라이버 (신뢰도, 복잡도, 경험 등)

[3가지 모드]
유기(Organic): 소규모, 경험팀
중간(Semi-detached): 중간 규모
내장(Embedded): 높은 제약 (항공, 국방)
```

## 4. 답안 포인트

**3단락**: ① 비용 산정 방법 분류 → ② 기능점수 5가지 기능유형 & 계산 → ③ COCOMO II 공식 & 국내 공공 SW 대가 산정

## 5. 관련 개념

`SW 대가 산정` → 공공 사업 입찰 기준 | `EVM` → 비용 산정 후 성과 관리 | `애자일 추정` → 스토리포인트, 벨로시티
