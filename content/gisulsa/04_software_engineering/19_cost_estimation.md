# SW 비용 산정 — 기능점수(FP) & COCOMO II

> 별점: ★★★★★ | 매회 기본 필출

---

## 답안.

### Ⅰ. 개요

   내부논리파일(ILF), 외부인터페이스파일(EIF) — 데이터 기능
   외부입력(EI), 외부출력(EO), 외부조회(EQ) — 트랜잭션 기능
   UFP = Σ(기능 유형 × 복잡도 가중치)

### Ⅱ. 핵심 구성요소

```
[기능점수 산정 절차]
① 기능 유형 식별:
   내부논리파일(ILF), 외부인터페이스파일(EIF) — 데이터 기능
   외부입력(EI), 외부출력(EO), 외부조회(EQ) — 트랜잭션 기능

② 미조정 기능점수 계산:
   UFP = Σ(기능 유형 × 복잡도 가중치)

③ 기술적 복잡도 조정:
   AFP = UFP × (0.65 + 0.01 × Σfi)
   fi: 14개 일반 시스템 특성 (0~5)

국내 적용: 기능점수기반 SW 대가 산정 기준 (과기부)
공공 SW 사업 의무 적용
```
```
[COCOMO II 기본 공식]
노력(PM) = A × Size^B × ΠEM_i
기간(TDEV) = C × PM^D
인력 = PM / TDEV

Size: KSLOC(천 줄) 또는 기능점수
B: 규모 조정 인자 (1.01~1.26)
EM_i: 비용 드라이버 (신뢰도, 복잡도, 경험 등)

[3가지 모드]
유기(Organic): 소규모, 경험팀
중간(Semi-detached): 중간 규모
내장(Embedded): 높은 제약 (항공, 국방)


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
