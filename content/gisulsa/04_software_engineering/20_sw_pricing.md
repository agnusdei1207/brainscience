# 🎯 SW 대가 산정 & SW 기술성 평가

> **별점**: ★★★★★ | ★132회 기출 (법제도 연계)

## 1. SW 대가 산정

```
국내 공공 SW 사업 의무 적용 (과기부 고시)

[기능점수 기반 산정]
개발비 = 기능점수 × 단가 × 보정계수
         (FP)      (원/FP)
단가: 매년 과기부 고시 (2024년: 약 75만원/FP)

보정계수:
- 애플리케이션 유형 (신규/유지보수)
- 언어 유형 (Java/Python/코볼 등)
- 품질 수준 (CMMI 적용 등)

[투입 공수 기반 산정]
비용 = 투입 인력(M/M) × 인월단가
인월단가: SW기술자 직급별 고시 단가
→ 기능점수 산정 불가 시 대안
```

## 2. SW 기술성 평가

```
[평가 목적]
공공기관 SW 개발 사업 적정성 검토
입찰 참여 업체의 기술력 평가

[주요 평가 항목]
기술 제안서: 아키텍처 설계 (30%)
프로젝트 관리: WBS, 위험관리 (20%)
품질 보증: 테스트 계획, 품질지표 (20%)
보안: 보안 설계, ISMS 적용 (15%)
유지보수: 전환 계획, SLA (15%)
```

## 3. 답안 포인트

**3단락**: ① SW 대가 산정 방법(FP/투입공수) 비교 → ② 기능점수 산정 절차 & 국내 고시 → ③ SW 기술성 평가 항목 & 감리 연계

## 4. 관련 개념

`FP(기능점수)` → 대가 산정 기준 | `감리(★134회)` → 기술성 평가와 감리 연계 | `PMO(★132회)` → 사업 관리 거버넌스
