# 🎯 일정 관리 — CPM, PERT, WBS

> **별점**: ★★★★☆ | 기본 필수

## 1. WBS (Work Breakdown Structure)

```
프로젝트를 계층적으로 분해한 작업 목록

WBS 계층 예:
0. 시스템 개발
  1. 요구사항 분석
  2. 설계
    2.1 아키텍처 설계
    2.2 DB 설계
    2.3 UI 설계
  3. 구현
  4. 테스트
  5. 전개

WBS 특징:
- 100% 규칙: 모든 작업을 포함
- 작업 패키지(최하위): 추정·할당·모니터링 단위
```

## 2. CPM (Critical Path Method)

```
[네트워크 다이어그램]
활동 A(3일) → 활동 B(5일) → 활동 E(2일)
활동 A(3일) → 활동 C(4일) → 활동 E(2일)
활동 A(3일) → 활동 D(6일) ─────────────→ 완료

[크리티컬 패스 계산]
경로1: A+B+E = 3+5+2 = 10일
경로2: A+C+E = 3+4+2 = 9일
경로3: A+D   = 3+6   = 9일

크리티컬 패스: 경로1 (10일) = 프로젝트 최소 기간
여유(Float): 경로2 = 10-9 = 1일 (지연 허용)

핵심: 크리티컬 패스 활동 지연 = 프로젝트 지연
```

## 3. PERT (Program Evaluation and Review Technique)

```
불확실성이 높은 프로젝트의 확률적 일정 추정

기대 시간 = (낙관적 + 4×최빈 + 비관적) / 6
분산 = ((비관적 - 낙관적) / 6)²

예) 낙관=2, 최빈=4, 비관=9
기대 = (2 + 4×4 + 9) / 6 = 4.17일
→ 불확실성이 높을수록 비관적 값 활용
```

## 4. 답안 포인트

**3단락**: ① WBS 작성 → ② CPM 크리티컬 패스 계산 → ③ PERT 확률적 추정 & EVM 연계

## 5. 관련 개념

`EVM` → CPM 일정 + 비용 성과 통합 | `PMO(★132회)` → 일정 모니터링 조직 | `애자일` → 스프린트 번다운 차트 대안
