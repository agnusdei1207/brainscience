# 일정 관리 — CPM, PERT, WBS

> 별점: ★★★★☆ | 기본 필수

---

## 답안.

### Ⅰ. 개요

프로젝트를 계층적으로 분해한 작업 목록
- 작업 패키지(최하위): 추정·할당·모니터링 단위
활동 A(3일) → 활동 B(5일) → 활동 E(2일)

### Ⅱ. 핵심 구성요소

```
프로젝트를 계층적으로 분해한 작업 목록

WBS 계층 예:
0. 시스템 개발
  1. 요구사항 분석
  2. 설계
    2.1 아키텍처 설계
    2.2 DB 설계
    2.3 UI 설계
  3. 구현
  4. 테스트
  5. 전개

WBS 특징:
- 100% 규칙: 모든 작업을 포함
- 작업 패키지(최하위): 추정·할당·모니터링 단위
```
```
[네트워크 다이어그램]
활동 A(3일) → 활동 B(5일) → 활동 E(2일)
활동 A(3일) → 활동 C(4일) → 활동 E(2일)
활동 A(3일) → 활동 D(6일) ─────────────→ 완료

[크리티컬 패스 계산]
경로1: A+B+E = 3+5+2 = 10일
경로2: A+C+E = 3+4+2 = 9일
경로3: A+D   = 3+6   = 9일

크리티컬 패스: 경로1 (10일) = 프로젝트 최소 기간


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
