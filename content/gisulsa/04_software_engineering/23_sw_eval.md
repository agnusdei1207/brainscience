# 🎯 SW 기술성 평가 & ISO/IEC 25010

> **별점**: ★★★★★ | ★132회 기출

## 1. SW 기술성 평가 (국내 고시)

```
[평가 목적]
공공 SW 개발 사업의 기술 제안서를 평가하여
낙찰자 선정 및 사업 품질 보장

[주요 평가 항목 (과기부 고시)]
기술 제안서 평가:
① 아키텍처 설계 (적정성, 확장성, 보안)
② 개발 방법론 (애자일, 감리 계획)
③ 품질 관리 (테스트 계획, 커버리지)
④ 보안 설계 (ISMS, 개인정보보호)
⑤ 유지보수 (전환, SLA, 매뉴얼)
⑥ 비용 산정 (FP 산정 타당성)

PMO 기술성 평가:
프로젝트 관리 계획, 위험 관리, 형상 관리
```

## 2. ISO/IEC 25010 (SQuaRE)

```
[8대 품질 특성]
1. 기능 적합성: 기능 완전성, 정확성, 적절성
2. 성능 효율성: 시간, 자원, 용량
3. 호환성: 공존, 상호운용성
4. 사용성: 인식성, 학습성, 운용성, 접근성
5. 신뢰성: 성숙성, 가용성, 결함허용, 복구성
6. 보안성: 기밀성, 무결성, 부인방지, 책임추적성
7. 유지보수성: 모듈성, 재사용성, 분석성, 변경성, 시험성
8. 이식성: 적응성, 설치성, 대체성
```

## 3. CMMI (성숙도 모델)

```
레벨 1 (초기): 프로세스 비정형적, 개인 능력 의존
레벨 2 (관리됨): 프로젝트별 계획, 추적
레벨 3 (정의됨): 조직 표준 프로세스 수립
레벨 4 (정량관리): 통계적 측정, 예측
레벨 5 (최적화): 지속적 개선

국내 적용: CMMI 3 = 공공 SW 사업 참여 요건
```

## 4. 답안 포인트

**3단락**: ① SW 기술성 평가 항목 → ② ISO 25010 품질 특성 8가지 → ③ CMMI 성숙도 & 국내 공공사업 연계

## 5. 관련 개념

`SW 대가 산정(20번)` → FP 기반 비용 + 기술성 평가 병행 | `감리(★134회)` → 기술성 평가 후 감리 | `SPICE` → ISO 15504 프로세스 능력
