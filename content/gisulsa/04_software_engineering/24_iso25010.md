# 🎯 ISO/IEC 25010 (SQuaRE) & CMMI & SPICE

> **별점**: ★★★★★ | 기본 필수

## 1. ISO/IEC 25010 상세

```
제품 품질 모델 8대 특성:

1. 기능 적합성 (Functional Suitability)
   - 기능 완전성: 명세된 기능 모두 제공
   - 기능 정확성: 올바른 결과 산출
   - 기능 적절성: 목적에 맞는 기능

2. 성능 효율성 (Performance Efficiency)
   - 시간 효율성: 응답/처리시간
   - 자원 효율성: CPU/메모리
   - 용량: 처리량, 저장량 한계

3. 호환성 (Compatibility)
   - 공존성: 동일 환경 다른 SW와 공존
   - 상호운용성: 다른 시스템과 데이터 교환

4. 사용성 (Usability)
   - 인식성: 목적 파악 용이
   - 학습성: 학습 난이도
   - 운용성: 조작 용이성
   - 접근성: 장애인/노인 접근

5. 신뢰성 (Reliability)
   - 성숙성: 평상시 신뢰성
   - 가용성: 요청 시 동작
   - 결함 허용성: 장애 시에도 동작
   - 복구성: 장애 후 복구

6. 보안성 (Security)
   - 기밀성, 무결성, 부인방지, 책임추적성

7. 유지보수성 (Maintainability)
   - 모듈성, 재사용성, 분석성, 변경성, 시험성

8. 이식성 (Portability)
   - 적응성, 설치성, 대체성
```

## 2. CMMI vs SPICE 비교

| 항목 | CMMI | SPICE (ISO 15504) |
|------|------|------------------|
| 주관 | SEI (Carnegie Mellon) | ISO |
| 레벨 | 성숙도 1~5 | 능력 0~5 |
| 단위 | 프로세스 영역(PA) | 프로세스 참조 모델 |
| 평가 | CMMI 등급 | 프로세스별 능력 수준 |
