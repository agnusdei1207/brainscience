## 답안.

### Ⅰ. 개요

정의: 단순 AI 도구 도입을 넘어 조직의 의사결정·프로세스·
     비즈니스 모델 자체를 AI 기반으로 혁신하는 변혁
DX (디지털 전환): 디지털 기술로 프로세스 자동화

### Ⅱ. 핵심 구성요소

```
정의: 단순 AI 도구 도입을 넘어 조직의 의사결정·프로세스·
     비즈니스 모델 자체를 AI 기반으로 혁신하는 변혁

[DX vs AX 비교]
DX (디지털 전환): 디지털 기술로 프로세스 자동화
AX (AI 전환): AI로 의사결정·업무 자체를 AI 에이전트가 수행

AX 추진 단계:
1단계: AI 도구 도입 (Copilot, ChatGPT 사용)
2단계: 업무 프로세스 AI 통합 (AI 기반 자동화)
3단계: AI 에이전트 기반 워크플로우 (대부분 자율 수행)
4단계: AI 네이티브 조직 (AI 중심 의사결정 체계)
```
```
[Agentic 코딩]
전통: 개발자 → 코드 → 테스트 → 배포
Agentic: 개발자(목표) → AI 에이전트 → 코드+테스트+PR 생성

도구:
- Devin AI: 자율 SW 엔지니어 (실험적)
- GitHub Copilot Workspace: 이슈→PR 자동 생성
- Cursor, Windsurf: 에이전틱 IDE

[AI가 바꾸는 SDLC]
요구분석: AI 인터뷰 → 명세 초안 생성
설계: AI 아키텍처 제안
구현: AI 코드 생성 (70% 이상 AI 작성 예측)
테스트: AI 테스트 케이스 자동 생성
배포: AI 기반 이상 탐지 + 자동 롤백


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.
