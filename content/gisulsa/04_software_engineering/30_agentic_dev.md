# 🎯 에이전틱 SW 개발 & Vibe Coding

> **별점**: ★★★★★ | ☆ 2026 확실 예측

## 1. 에이전틱 개발 패러다임

```
[전통 SW 개발 vs 에이전틱 개발]
전통:
개발자 → 코드 작성 → 테스트 → 코드리뷰 → 배포

에이전틱:
개발자(요구사항/목표)
  ↓
AI 에이전트 (코드생성 + 테스트 + 디버깅 + 최적화)
  ↓
개발자 검토·승인
  ↓
자동 배포 (GitOps)

[도구]
Cursor: 에이전틱 IDE, 코드베이스 전체 컨텍스트
GitHub Copilot Workspace: 이슈→PR 자동화
Devin AI: 독립 SW 엔지니어 AI (실험적)
Bolt/Lovable: 프롬프트→전체 앱 생성
```

## 2. SW 개발 생산성 변화

```
GitHub 데이터 (2024):
- Copilot 사용 개발자: 코드 작성 속도 55% 향상
- 예측 (2025~): 개발자의 30% 이상 코드를 AI가 생성

품질 위험:
- 환각: 없는 라이브러리/API 호출
- 보안: 취약한 패턴 생성 (SQL 인젝션 등)
- 저작권: GPL 코드 포함 가능성
- 과신: 검토 없이 사용

대응:
- SAST + AI 코드 스캐닝
- 코드 리뷰 필수 유지
- SBOM: AI 생성 코드 의존성 추적
```

## 3. 답안 포인트

**3단락**: ① 에이전틱 개발 정의 & 전통 개발과 비교 → ② 주요 도구 & 생산성 효과 → ③ 품질/보안 위험 & 거버넌스

## 4. 관련 개념
