# 🎯 핵심 키워드: 관계형 모델 (Relational Model), 함수 종속 (Functional Dependency), 정규화 (Normalization)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

관계형 모델은 데이터를 릴레이션과 키 중심으로 표현하여 무결성과 질의 용이성을 확보하는 데이터 모델이다.  
함수 종속(Function Dependency)은 한 속성 집합이 다른 속성 값을 결정하는 관계로, 정규화 판단의 근거가 된다.  
정규화(Normalization)는 중복과 이상 현상을 줄이기 위해 스키마를 단계적으로 분해하는 설계 기법이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 정규화 | 반정규화 |
| --- | --- | --- |
| 목적 | 중복 제거와 이상 현상 방지 | 조회 성능과 단순 질의 확보 |
| 장점 | 무결성과 변경 용이성 | 조인 감소와 읽기 성능 향상 |
| 단점 | 조인 비용 증가 | 중복 데이터로 인한 정합성 관리 필요 |
| 적합 환경 | OLTP, 규칙 기반 업무 | 집계 위주 조회 시스템 |
| 시험 포인트 | 함수 종속 기반 분해 | 성능 목적 구조 조정 |
