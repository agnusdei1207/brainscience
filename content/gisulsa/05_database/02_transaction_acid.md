# 🎯 핵심 키워드: 트랜잭션 (Transaction), ACID, 격리 수준 (Isolation Level)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

트랜잭션(Transaction)은 데이터베이스 상태를 하나의 논리적 작업 단위로 묶어 모두 반영되거나 모두 취소되도록 관리하는 실행 단위다.  
ACID는 원자성(Atomicity), 일관성(Consistency), 고립성(Isolation), 지속성(Durability)을 의미하며 트랜잭션 신뢰성의 기본 원칙이다.  
격리 수준은 동시성 처리 시 Dirty Read, Non-repeatable Read, Phantom Read 허용 범위를 조절해 성능과 정합성을 균형화한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 2PL | MVCC |
| --- | --- | --- |
| 동시성 방식 | 락 기반 직렬화 | 버전 기반 읽기/쓰기 분리 |
| 장점 | 직관적 일관성 보장 | 읽기 성능 우수와 락 경합 감소 |
| 단점 | 교착상태와 대기 가능 | 버전 관리 비용 증가 |
| 적합 환경 | 강한 직렬화 요구 | 읽기 많은 OLTP |
| 시험 포인트 | Lock escalation | Snapshot isolation |
