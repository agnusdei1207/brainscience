# 🎯 핵심 키워드: 인덱스 (Index), 옵티마이저 (Optimizer), 실행 계획 (Execution Plan)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

인덱스(Index)는 원하는 행의 위치를 빠르게 찾기 위해 정렬된 보조 구조를 유지하는 데이터베이스 성능 최적화 수단이다.  
옵티마이저(Optimizer)는 통계 정보를 바탕으로 여러 실행 계획 중 비용이 가장 낮은 접근 경로를 선택한다.  
실행 계획 분석은 인덱스 설계, 조인 순서, 풀스캔 여부를 검증하는 핵심 튜닝 활동이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 클러스터형 인덱스 | 비클러스터형 인덱스 |
| --- | --- | --- |
| 데이터 저장 순서 | 인덱스 순서와 물리적 정렬 유사 | 별도 인덱스 구조 유지 |
| 장점 | 범위 조회에 유리 | 여러 개 생성 가능 |
| 단점 | 테이블당 보통 1개 | 룩업 비용 발생 가능 |
| 적합 사례 | PK 기반 정렬 조회 | 다양한 검색 조건 |
| 시험 포인트 | Range scan | Covering index |
