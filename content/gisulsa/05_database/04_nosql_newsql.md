# 🎯 핵심 키워드: NoSQL, NewSQL, 스키마 유연성 (Schema Flexibility)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

NoSQL은 대규모 분산 환경에서 확장성과 유연성을 확보하기 위해 비관계형 데이터 모델을 채택한 데이터 저장 기술군이다.  
NewSQL은 관계형 SQL과 ACID를 유지하면서도 분산 확장성과 고성능을 달성하려는 차세대 DBMS 접근이다.  
기술사 답안에서는 Key-Value, Document, Column, Graph 등 NoSQL 유형과 NewSQL의 차별점을 같이 제시해야 한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | NoSQL | NewSQL |
| --- | --- | --- |
| 핵심 가치 | 확장성·유연성 | SQL·ACID 유지 + 확장성 |
| 데이터 모델 | 다양한 비관계형 모델 | 관계형 모델 중심 |
| 장점 | 대규모 분산 저장에 유리 | 기존 SQL 자산 활용 가능 |
| 단점 | 표준 질의와 조인 제약 | 구현 복잡도와 비용 |
| 적합 사례 | 세션, 로그, 콘텐츠 | 금융, 주문, 글로벌 OLTP |
