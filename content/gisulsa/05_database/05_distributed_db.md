# 🎯 핵심 키워드: 분산 데이터베이스 (Distributed Database), CAP 정리 (CAP Theorem), 샤딩 (Sharding), 복제 (Replication)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

분산 데이터베이스는 데이터를 여러 노드에 분산 저장하여 가용성과 확장성을 높이는 데이터 관리 구조다.  
CAP 정리는 네트워크 분할 상황에서 일관성(Consistency), 가용성(Availability), 분할 허용성(Partition Tolerance)을 동시에 완전하게 만족시킬 수 없음을 설명한다.  
샤딩은 데이터를 분할해 저장 용량과 처리량을 확장하고, 복제는 가용성과 읽기 성능을 높이지만 동기화 지연 관리가 중요하다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 샤딩 | 복제 |
| --- | --- | --- |
| 주 목적 | 쓰기 분산과 용량 확장 | 가용성·읽기 성능 향상 |
| 데이터 구성 | 서로 다른 데이터 조각 저장 | 같은 데이터 여러 사본 유지 |
| 장점 | 확장성 우수 | 장애 대응과 읽기 확장 유리 |
| 단점 | 분산 질의와 재샤딩 복잡 | 복제 지연과 충돌 해결 필요 |
| 시험 포인트 | Shard key | Sync/Async replication |
