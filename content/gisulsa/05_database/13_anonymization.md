# 비식별화 & 개인정보 보호

> 별점: ★★★★★ | 기본 필수

---

## 답안.

### Ⅰ. 개요

  - 추가 정보 없이 개인 특정 불가
  - 통계·연구 목적 허용 (개인정보보호법 28조)
  - 개인정보가 아님 → 보호법 적용 제외

### Ⅱ. 핵심 구성요소

```
[가명처리 vs 익명처리]
가명처리: 개인정보 → 가명정보
  - 추가 정보 없이 개인 특정 불가
  - 재식별 가능 (잠재적)
  - 통계·연구 목적 허용 (개인정보보호법 28조)
  
익명처리: 완전 식별 불가 상태
  - 개인정보가 아님 → 보호법 적용 제외
  - 공공통계, 오픈데이터

[비식별화 기법 종류]
가명처리: 홍길동 → 임*동
마스킹: 주민번호 뒷자리 → XXXXXXX
총계처리: 개인 값 → 평균/합계
데이터 범주화: 나이 → 20대, 30대
데이터 삭제: 민감 속성 제거
```
```
k-익명성 (k-Anonymity):
동일 준식별자 조합 k명 이상 보장
예) k=3: 30대/남/서울이 최소 3명

문제: 동일 민감속성 집중 시 취약

l-다양성 (l-Diversity):
각 동치 집합 내 민감속성 l가지 이상 다양
예) l=2: 질병 종류 2가지 이상

t-근접성 (t-Closeness):


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
