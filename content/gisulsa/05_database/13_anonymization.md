# 🎯 비식별화 & 개인정보 보호

> **별점**: ★★★★★ | 기본 필수

## 1. 비식별화 기법

```
[가명처리 vs 익명처리]
가명처리: 개인정보 → 가명정보
  - 추가 정보 없이 개인 특정 불가
  - 재식별 가능 (잠재적)
  - 통계·연구 목적 허용 (개인정보보호법 28조)
  
익명처리: 완전 식별 불가 상태
  - 개인정보가 아님 → 보호법 적용 제외
  - 공공통계, 오픈데이터

[비식별화 기법 종류]
가명처리: 홍길동 → 임*동
마스킹: 주민번호 뒷자리 → XXXXXXX
총계처리: 개인 값 → 평균/합계
데이터 범주화: 나이 → 20대, 30대
데이터 삭제: 민감 속성 제거
```

## 2. 프라이버시 보호 모델

```
k-익명성 (k-Anonymity):
동일 준식별자 조합 k명 이상 보장
예) k=3: 30대/남/서울이 최소 3명

문제: 동일 민감속성 집중 시 취약

l-다양성 (l-Diversity):
각 동치 집합 내 민감속성 l가지 이상 다양
예) l=2: 질병 종류 2가지 이상

t-근접성 (t-Closeness):
민감속성 분포가 전체 분포와 t 이내
가장 강력한 프라이버시 보호

차분 프라이버시 (Differential Privacy):
쿼리 결과에 수학적 노이즈 추가
개인 포함/미포함 시 결과 차이 ε 이하
→ Apple/Google 실제 적용
```

## 3. 개인정보보호법 주요 조항

```
- 제24조: 고유식별정보 처리 제한 (주민번호 등)
- 제28조: 가명정보 처리 특례
- 제29조: 안전조치 의무 (암호화 등)
- 개인정보 국외이전: 표준계약조항, CBPR
```

## 4. 답안 포인트

**3단락**: ① 비식별화 기법 종류(가명/익명/마스킹) → ② k-익명성·l-다양성·t-근접성 비교 → ③ 차분 프라이버시 & 법적 기준

## 5. 관련 개념

`CBPR(★131회)` → 개인정보 국경간 이전 | `동형암호(★133회)` → 암호화 상태 분석 | `마이데이터` → 개인 데이터 주권
