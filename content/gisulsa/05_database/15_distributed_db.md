# 🎯 분산 데이터베이스 & 투명성

> **별점**: ★★★★★ | ★131회 기출

## 1. 분산 DB 정의

```
분산 데이터베이스: 물리적으로 여러 장소에 분산되어 있지만
논리적으로 하나의 DB처럼 동작하는 시스템
```

## 2. 분산 투명성 (5대 투명성)

| 투명성 | 의미 | 예시 |
|--------|------|------|
| **위치 투명성** | 데이터 위치 몰라도 접근 | 서울/부산 DB 구분 없이 쿼리 |
| **분할 투명성** | 데이터 분할 방식 몰라도 접근 | 수평/수직 분할 숨김 |
| **복제 투명성** | 복제 여부 몰라도 접근 | 최신 복제본 자동 선택 |
| **장애 투명성** | 일부 노드 장애 시에도 동작 | 자동 페일오버 |
| **병행 투명성** | 동시 접근 충돌 없이 동작 | 분산 잠금 관리 |

## 3. 분산 DB 설계

```
[데이터 분할 방식]
수평 분할: 행(Row) 기준 → 샤딩
수직 분할: 열(Column) 기준 → 주로 접근 빈도 기반

[복제 전략]
완전 복제: 모든 노드에 전체 데이터 → 읽기 성능 ↑, 쓰기 비용 ↑
부분 복제: 일부 노드에만 복제 → 트레이드오프
비복제: 분할만 (단순, 가용성 ↓)

[분산 쿼리 처리]
옵티마이저: 네트워크 전송 비용 최소화 경로 선택
세미조인: 조인 전 필터링으로 전송량 감소
```

## 4. 답안 포인트

**3단락**: ① 분산 DB 정의 & 필요성 → ② 5대 투명성 상세 설명 → ③ 분할·복제 전략 & CAP 정리 연계

## 5. 관련 개념

`CAP 정리(★134회)` → 분산 DB 일관성-가용성 트레이드오프 | `샤딩` → 수평 분할 구현 | `NewSQL` → 분산 DB + ACID
