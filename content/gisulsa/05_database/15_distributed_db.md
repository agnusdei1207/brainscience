# 분산 데이터베이스 & 투명성

> 별점: ★★★★★ | ★131회 기출

---

## 답안.

### Ⅰ. 개요

분산 데이터베이스: 물리적으로 여러 장소에 분산되어 있지만
논리적으로 하나의 DB처럼 동작하는 시스템
수평 분할: 행(Row) 기준 → 샤딩

### Ⅱ. 핵심 구성요소

```
분산 데이터베이스: 물리적으로 여러 장소에 분산되어 있지만
논리적으로 하나의 DB처럼 동작하는 시스템
```
```
[데이터 분할 방식]
수평 분할: 행(Row) 기준 → 샤딩
수직 분할: 열(Column) 기준 → 주로 접근 빈도 기반

[복제 전략]
완전 복제: 모든 노드에 전체 데이터 → 읽기 성능 ↑, 쓰기 비용 ↑
부분 복제: 일부 노드에만 복제 → 트레이드오프
비복제: 분할만 (단순, 가용성 ↓)

[분산 쿼리 처리]
옵티마이저: 네트워크 전송 비용 최소화 경로 선택
세미조인: 조인 전 필터링으로 전송량 감소
```


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.
