# 스마트 시티 (Smart City)

> 별점: ★★★★★ | ★135회 기출

---

## 답안.

### Ⅰ. 개요

스마트 시티: ICT 기술로 도시 인프라(교통, 에너지, 안전, 행정)를 최적화하여 **삶의 질을 높이고 지속가능성을 달성**하는 미래 도시 모델.

### Ⅱ. 핵심 구성요소

```
[스마트 시티 레이어 구조]
서비스 레이어: 교통 최적화 / 에너지 관리 / 안전 / 복지
       ↑
플랫폼 레이어: 도시 통합 플랫폼 (데이터 허브, AI 분석)
       ↑
인프라 레이어: IoT 센서 / CCTV / 5G / 디지털 트윈
       ↑
데이터 레이어: 실시간 수집 → 빅데이터 → AI 예측

핵심 기술:
- 디지털 트윈: 도시 물리 환경의 실시간 가상 복제
- AI CCTV: 보행자 안전, 범죄 예측
- 5G + MEC: 실시간 데이터 처리
- 통합 플랫폼: 부서 간 데이터 공유
```
```
- K-스마트시티: 세종·부산 스마트시티 국가시범도시
- 스마트시티 통합플랫폼: 행안부 공공데이터 통합
- 데이터 허브: 개인정보 비식별화 + 공공 데이터 공유
- 스마트시티 법: 스마트도시법 개정 (2023)
```


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
