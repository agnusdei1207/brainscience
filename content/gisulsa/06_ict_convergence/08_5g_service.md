# 🎯 5G 융합 서비스 & 이음5G (5G 특화망)

> **별점**: ★★★★★ | ★133회, ★134회 기출

## 1. 정의

**이음5G(5G 특화망)**: 특정 지역/목적을 위해 별도로 구축된 **사설 5G 네트워크**. 스마트팩토리, 항만, 병원, 국방 등 특화된 서비스 SLA 보장.

## 2. 이음5G vs 공공 5G

| 항목 | 이음5G (특화망) | 공공 5G |
|------|--------------|---------|
| 구축 | 특정 기업/기관 전용 | 전국 통신사 |
| 주파수 | 별도 할당 (28GHz 등) | 공유 주파수 |
| 지연 | 1ms 이하 (URLLC) | 5~10ms |
| 보안 | 데이터 외부 미전송 | 외부 전송 |
| 적용 | 스마트팩토리, 항만 | 일반 소비자 |

## 3. 5G URLLC & 산업 적용

```
5G 3대 서비스 슬라이스:
eMBB: 초고속 (20Gbps) — 영상, 스트리밍
URLLC: 초저지연(1ms) + 고신뢰(99.9999%) — 자율주행, 원격수술
mMTC: 대규모 IoT — 스마트시티, 센서

[이음5G 스마트팩토리 적용]
로봇 ─ 이음5G(URLLC) ─ MEC 서버 ─ 제어 시스템
1ms 지연으로 실시간 제어 → 유선(케이블) 대체
```

## 4. 국내 이음5G 현황

```
- 2021년: 이음5G 제도화 (과기부)
- 주파수 대역: 4.7GHz, 28GHz 할당
- 적용 사례:
  현대자동차: 스마트팩토리 로봇 제어
  인천항: 항만 자율운반 차량
  삼성병원: 의료기기 실시간 모니터링
- 2024~: 6GHz 대역 추가 논의
```

## 5. 답안 포인트

**3단락**: ① 이음5G 정의 & 공공 5G 차이 → ② URLLC 기반 스마트팩토리 적용 → ③ 국내 확산 & 6G 연계 전망

## 6. 관련 개념

`5G 아키텍처(★133회)` → SA/NSA, 네트워크 슬라이싱 | `ISO 26262(★134회)` → 자율주행 5G 연계 | `ETSI ZSM(★135회)` → 이음5G 자율 관리
