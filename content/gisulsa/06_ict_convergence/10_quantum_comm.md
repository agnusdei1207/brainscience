# 🎯 양자통신 & QKD (양자키분배)

> **별점**: ★★★★☆ | ☆ 예측 (PQC 연계)

## 1. 정의

**QKD (Quantum Key Distribution)**: 양자역학 원리를 이용해 **도청 불가능한 암호키를 분배**하는 기술. 측정 즉시 양자 상태가 변하여 도청을 탐지할 수 있음.

## 2. QKD vs PQC

| 항목 | QKD | PQC |
|------|-----|-----|
| 방식 | 하드웨어(광섬유/위성) | 소프트웨어(수학 알고리즘) |
| 보안 근거 | 양자역학 법칙 | 수학적 어려움 |
| 거리 | 수백km (중계 필요) | 거리 무제한 |
| 비용 | 매우 높음 | 낮음 (SW 업데이트) |
| 표준화 | 초기 단계 | NIST 2024 완료 |
| 도입 | 국방·금융 특수목적 | 범용 |

## 3. BB84 프로토콜

```
[BB84 동작 원리]
Alice(송신) → 양자 채널(광자) → Bob(수신)
  ↓
무작위 편광 기저 선택 (직선/대각)
  ↓
Bob: 무작위 기저로 측정
  ↓
공개 채널로 기저 비교 (키값은 공개 안함)
  ↓
일치 기저만 키로 사용

도청 탐지:
Eve가 측정 → 양자 상태 붕괴 → 오류율 25% 이상
→ 도청 즉시 탐지 가능
```

## 4. 국내 현황

```
- KT: 서울-부산 구간 양자암호통신망 구축
- SKT: 양자보안칩 개발
- 국가망 양자암호: 금융·공공기관 적용 확대
- 6G + QKD: 핵심 보안 인프라 연구
```

## 5. 답안 포인트

**3단락**: ① QKD 정의 & BB84 원리 → ② PQC와의 비교(HW vs SW 보안) → ③ 국내 적용 현황 & 한계

## 6. 관련 개념
