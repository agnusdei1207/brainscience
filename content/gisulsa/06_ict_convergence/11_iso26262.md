# 🎯 ISO 26262 & 자율주행 시스템

> **별점**: ★★★★★ | ★134회 기출

## 1. 정의

ISO 26262: 자동차 전기/전자 시스템의 **기능 안전성** 국제 표준. 차량 안전 무결성 수준(ASIL)을 정의하고, 개발 프로세스 전반(설계→검증→운영)에 안전 요구사항을 부과.

## 2. ASIL (자동차 안전 무결성 수준)

| 등급 | 위험도 | 적용 예 |
|------|--------|---------|
| QM | 품질 관리만 필요 | 인포테인먼트 |
| ASIL A | 낮음 | 와이퍼, 시트 조절 |
| ASIL B | 중간 | 에어백 ECU |
| ASIL C | 높음 | ABS, ESC |
| **ASIL D** | **최고** | **스티어링, 브레이크, ADAS** |

## 3. 자율주행 SAE 레벨

```
L0: 비자동화 (경고만)
L1: 운전지원 (ACC 또는 차선유지)
L2: 부분자동화 (ACC + 차선유지 동시)
L3: 조건부자동화 (특정 조건에서 자율, 운전자 대기)
L4: 고도자동화 (특정 구역에서 완전 자율)
L5: 완전자동화 (모든 조건, 핸들 불필요)

현재 상용화: L2+(테슬라 오토파일럿), L3(Mercedes)
2026~: L4 robo-taxi 확대 (Waymo)
```

## 4. 센서 퓨전 & V2X

```
자율주행 핵심 기술:
- 센서 퓨전: 카메라+LiDAR+RADAR+GPS 통합
- V2X (Vehicle-to-Everything):
  V2V: 차량 간 통신 (충돌 예방)
  V2I: 차량-신호등 통신 (교통 최적화)
  V2N: 5G 네트워크 연결 (클라우드 AI)

보안: ISO/SAE 21434 자동차 사이버보안
```

## 5. 답안 포인트

**3단락**: ① ISO 26262 정의 & ASIL 등급 → ② 자율주행 SAE 레벨 & 핵심 기술(센서퓨전, V2X) → ③ ASIL D 시스템 개발 프로세스 & 검증

## 6. 관련 개념
