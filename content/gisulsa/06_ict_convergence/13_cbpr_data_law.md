# 🎯 CBPR & 데이터 3법 & 개인정보 국제이전

> **별점**: ★★★★★ | ★131회 기출 / 기본 필수

## 1. 데이터 3법

```
[2020년 개정 3법]
1. 개인정보보호법: 가명정보 처리 허용
   - 가명정보: 추가정보 없이 특정 불가
   - 통계·연구·공익 목적 활용 허용

2. 정보통신망법: 개인정보 규정 → 개인정보보호법 이관
   - 온라인 사업자 규제 통합

3. 신용정보법: 금융 데이터 활용 촉진
   - 마이데이터 사업 근거
   - 금융 가명정보 연구 허용

효과: 데이터 규제 일원화, AI·데이터 산업 활성화
```

## 2. CBPR (Cross-Border Privacy Rules)

```
정의: APEC 회원국 간 개인정보의 국경간 이전을 위한
     자율 규제 인증 체계

[CBPR 인증 절차]
기업 → 책임감독기관 심사 → APEC 인증
↓
인증된 기업 간 개인정보 이전 허용

참여국: 미국, 캐나다, 일본, 한국, 싱가포르 등
한국: 2023년 CBPR 시스템 가입

비교:
GDPR(EU): 적정성 결정 / SCCs(표준계약조항)
CBPR(APEC): 기업 자율 인증
PIPL(중국): 보안 평가 + 인증
```

## 3. 마이데이터

```
정의: 개인이 자신의 데이터를 직접 관리하고
     원하는 기관에 이전 동의 권리

국내 마이데이터:
- 금융 마이데이터: 은행/보험/카드 데이터 통합
- 의료 마이데이터(마이헬스웨이): 진료·건강 데이터
- 공공 마이데이터: 행정·공공기관 데이터

표준: FHIR(의료), OpenFinance(금융) API
```

## 4. 답안 포인트

**3단락**: ① 데이터 3법 개정 내용 & 효과 → ② CBPR 국경간 이전 체계 & GDPR 비교 → ③ 마이데이터 추진 현황
