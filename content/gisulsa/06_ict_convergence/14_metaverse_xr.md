# 🎯 메타버스 & XR (확장현실)

> **별점**: ★★★★☆ | ★134회 연계

## 1. 메타버스 정의 & 특성

```
메타버스 (Metaverse): 물리적 현실과 디지털 세계가 융합된
3D 가상 공간. 아바타를 통한 사회·경제 활동 영위.

[메타버스 4대 특성]
지속성: 사용자 없어도 세계 유지
실시간: 이벤트 즉시 반영
상호작용: 실시간 소통 가능
경제 생태계: NFT, 가상화폐, 창작 경제

[유형]
라이프로깅: 일상 디지털 기록 (SNS, 헬스 앱)
증강현실 세계: 현실+디지털 정보 중첩 (AR)
거울 세계: 현실 복제 (구글맵, 배달앱)
가상세계: 완전 독립 가상공간 (로블록스, 포트나이트)
```

## 2. XR (확장현실) 기술

```
[XR 스펙트럼]
현실 ─── AR (증강현실) ─── MR (혼합현실) ─── VR (가상현실)
     현실 80%+디지털  현실+디지털 상호작용    완전 가상 100%

AR (Augmented Reality):
- 현실 위에 디지털 정보 중첩
- 예) 포켓몬고, 스마트 글래스, IVAS(군용)

VR (Virtual Reality):
- 완전 가상 환경 몰입
- 예) Meta Quest, 군 훈련 시뮬레이터

MR (Mixed Reality):
- AR+VR 결합, 현실 객체와 상호작용
- 예) Microsoft HoloLens, Apple Vision Pro

공간 컴퓨팅 (Spatial Computing):
- Apple Vision Pro가 명명
- 3D 공간에서 손/눈 제스처로 인터페이스
```

## 3. 인프라 요구사항

```
XR/메타버스 네트워크:
- 지연: < 20ms (시각적 멀미 방지)
- 대역폭: 8K×2 = 100Mbps 이상
- 5G URLLC + Wi-Fi 7 필수

컴퓨팅:
- 클라우드 렌더링: 단말 경량화
- 엣지 컴퓨팅(MEC): 지연 감소
```

## 4. 답안 포인트

**3단락**: ① 메타버스 정의 & 4가지 유형 → ② XR 스펙트럼(AR/MR/VR) & 대표 기기 → ③ Wi-Fi 7/5G 인프라 & 산업 응용

## 5. 관련 개념

`Wi-Fi 7(★134회)` → XR의 실시간 통신 기반 | `디지털 트윈(★135회)` → 메타버스의 산업적 응용 | `온디바이스AI(★134회)` → XR 기기 AI 처리
