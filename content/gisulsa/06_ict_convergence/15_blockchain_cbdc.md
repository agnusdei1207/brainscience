# 🎯 블록체인 & CBDC

> **별점**: ★★★★☆ | ★133회 연계

## 1. 블록체인 기초

```
정의: 거래 데이터를 블록에 담아 체인 형태로 연결하고
     분산 네트워크에서 공유·관리하는 분산원장 기술

[핵심 특성]
탈중앙화: 중앙 관리자 없이 P2P 합의
불변성: 기록된 데이터 변조 불가 (해시 체인)
투명성: 모든 참여자 거래 내역 공유
스마트 컨트랙트: 조건 충족 시 자동 실행

[합의 알고리즘]
PoW (작업증명): Bitcoin, 에너지 소비 多
PoS (지분증명): Ethereum(2.0), 에너지 효율
DPoS: Delegated PoS, 위임 투표
PBFT: 허가형(Private), 빠른 합의

[블록체인 유형]
퍼블릭: Bitcoin, Ethereum (완전 개방)
프라이빗: 허가된 참여자만 (Hyperledger Fabric)
컨소시엄: 여러 기관 공동 운영
```

## 2. CBDC (중앙은행 디지털화폐)

```
정의: 중앙은행이 발행하는 디지털 형태의 법정화폐
≠ 암호화폐 (중앙화, 법적 보호, 가치 안정)

[CBDC 유형]
소매형(Retail): 일반 국민 직접 사용
도매형(Wholesale): 금융기관 간 결제

[국내외 현황]
중국: 디지털 위안(e-CNY) 시범 서비스 中
유럽: 디지털 유로 파일럿 (2024~)
한국: 한국은행 CBDC 파일럿 (2024년 테스트)

[특징]
오프라인 결제: 인터넷 없이 단말 간 전송
프로그래밍: 특정 조건 충족 시만 사용 가능
개인정보: 거래 추적 가능성 → 프라이버시 우려
```

## 3. 답안 포인트

**3단락**: ① 블록체인 정의 & 합의 알고리즘 비교 → ② 스마트 컨트랙트 & 산업 응용 → ③ CBDC 현황 & 프라이버시 이슈

## 4. 관련 개념
