# 🎯 6G 기술 전망

> **별점**: ★★★★☆ | ☆ 2026 예측

## 1. 6G 주요 성능 목표

| 지표 | 5G | 6G 목표 |
|------|-----|--------|
| 최고 전송속도 | 20Gbps | **1Tbps** |
| 지연 | 1ms | **0.1ms** |
| 연결 밀도 | 100만개/km² | 1000만개/km² |
| 에너지 효율 | - | 5G 대비 100배 |
| 서비스 가용성 | 99.999% | 99.99999% |

## 2. 6G 핵심 기술

```
[주파수]
테라헤르츠(THz) 대역: 100GHz~10THz
초고속, 단거리 → 실내·도심 집중 배치
mmWave 확장: 더 광범위 활용

[AI 네이티브 네트워크]
6G = AI 네이티브 설계
AI가 네트워크 관리·최적화를 기본으로 수행
(5G는 AI 추가, 6G는 AI 내장)

[기술 요소]
지능형 반사면(RIS, Reconfigurable Intelligent Surface):
  전파 경로를 메타물질로 반사·조향
탄소 중립: 재생에너지 + 에너지 효율 100배
비지상 네트워크(NTN): 위성+UAM+지상 통합
```

## 3. 국내외 동향

```
[국제 경쟁]
한국: 2028 시범서비스, 2030 상용화 목표
중국: '863계획' 차세대, 주도권 경쟁
미국: 'Next G Alliance', DARPA 연구
EU: Hexa-X 프로젝트

[활용 서비스]
홀로그래픽 통신: 3D 홀로그램 실시간 전송
촉각 인터넷(★134회 연계): 1ms 이하 촉각 피드백
확장현실(XR): 완전 몰입형 공간 컴퓨팅
자율이동체: 완전 자율주행 + 드론 군집
```

## 4. 답안 포인트

**3단락**: ① 6G 성능 목표(1Tbps, 0.1ms) → ② 테라헤르츠·AI 네이티브·RIS 핵심 기술 → ③ 국제 경쟁 & 표준화 동향

## 5. 관련 개념

`5G 아키텍처(★133회)` → 6G의 진화 기반 | `ETSI ZSM(★135회)` → 6G 자율 관리 확장 | `AI 네이티브` → 6G + Agentic AI 결합
