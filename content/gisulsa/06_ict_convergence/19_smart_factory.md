# 🎯 스마트 팩토리 & IIoT

> **별점**: ★★★★★ | ★132회 연계

## 1. 스마트 팩토리

```
정의: ICT와 제조 기술의 융합으로 생산 전 과정을
     지능화·자동화한 공장

[스마트 팩토리 레벨 (국내 스마트제조혁신추진단)]
Level 1: ICT 미적용 (수동)
Level 2: 일부 자동화 (설비 자동화)
Level 3: IT 적용 (MES, ERP 연동)
Level 4: IoT 적용 (실시간 모니터링)
Level 5: 완전 스마트 (AI 자율 제어)

핵심 기술:
MES (제조실행시스템): 생산 현장 실시간 관리
ERP: 경영 계획과 현장 연계
IIoT: 산업용 IoT 센서 (설비 상태)
디지털 트윈: 공장 가상화·시뮬레이션
AI 품질검사: 비전 AI, 불량품 탐지
이음5G: 무선 실시간 제어 (URLLC)
```

## 2. 스마트 팩토리 아키텍처

```
[ISA-95 계층 구조]
Level 4: 비즈니스 계획 (ERP)
Level 3: 제조 운영 (MES, SCADA)
Level 2: 감시·제어 (HMI, DCS)
Level 1: 기본 제어 (PLC, CNC)
Level 0: 물리 프로세스 (센서, 로봇)

[OT/IT 융합]
IT (Information Technology): ERP, 비즈니스 데이터
OT (Operational Technology): PLC, 설비 제어
→ 경계 소멸: OT 데이터가 IT 분석으로 → 지능화

보안 이슈: OT 보안 (ISA/IEC 62443) 필수
```

## 3. 답안 포인트

**3단락**: ① 스마트 팩토리 레벨 & 핵심 기술 → ② ISA-95 계층 구조 & OT/IT 융합 → ③ 이음5G + AI + 디지털트윈 적용
