# 🎯 핵심 키워드: BPM (Business Process Management), RPA (Robotic Process Automation), 워크플로우 (Workflow)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

BPM은 업무 프로세스를 모델링, 실행, 모니터링, 개선하는 지속적 관리 체계다.  
RPA는 사람이 수행하던 반복 규칙 기반 작업을 소프트웨어 봇으로 자동화하는 기술이다.  
워크플로우는 업무 단계와 승인 흐름을 표준화하여 프로세스 실행 일관성을 높이는 절차 정의 메커니즘이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | BPM | RPA |
| --- | --- | --- |
| 적용 범위 | 업무 프로세스 전체 설계·개선 | 개별 반복 작업 자동화 |
| 장점 | 프로세스 가시성과 통제 확보 | 빠른 자동화와 ROI 가시화 |
| 단점 | 도입 범위가 넓고 시간이 필요 | 업무 변경 시 봇 수정 잦음 |
| 적합 사례 | 승인 프로세스, 업무 표준화 | 전표 입력, 데이터 이관, 조회 |
| 시험 포인트 | 프로세스 KPI | UI 기반 자동화 |
