# 🎯 IT 거버넌스 — COBIT, ISO 38500

> **별점**: ★★★★★ | 매회 기본 필출

## 1. 정의

IT 거버넌스는 조직의 **IT 투자와 운영이 경영 전략에 부합하도록** 의사결정 권한, 책임, 프로세스를 체계화하는 경영 관리 체계.

## 2. 주요 프레임워크

| 프레임워크 | 목적 | 구성 |
|-----------|------|------|
| **COBIT 2019** | IT 통제 목표 | 40개 목표, 도메인 기반 |
| **ISO 38500** | 이사회 수준 | 6대 원칙(책임/전략/취득/성과/적합성/인적행동) |
| **ITIL v4** | IT 서비스 관리 | SVS, 4차원 모델 |
| **COSO** | 내부통제 | 위험관리, 컴플라이언스 |

## 3. COBIT 2019 핵심

```
[거버넌스 목표]
EDM (Evaluate-Direct-Monitor): 이사회 수준
  EDM01: 거버넌스 체계 보장
  EDM02: 이익 전달 보장
  EDM03: 위험 최적화
  EDM04: 자원 최적화
  EDM05: 이해관계자 투명성

[관리 목표]
APO (Align Plan Organize) — 계획
BAI (Build Acquire Implement) — 구축
DSS (Deliver Service Support) — 운영
MEA (Monitor Evaluate Assess) — 평가
```

## 4. 답안 포인트

**3단락**: ① IT 거버넌스 정의 & 필요성 → ② COBIT/ISO38500 프레임워크 비교 → ③ 기업 적용 (이사회-IT경영진 역할 분리)

**핵심**: 거버넌스(What/Why) vs 관리(How) 구분 명확히

## 5. 관련 개념

`ITIL v4` → IT 서비스 관리 연계 | `CMMI` → SW 프로세스 거버넌스 | `PMO(★132·136회)` → 프로젝트 거버넌스
