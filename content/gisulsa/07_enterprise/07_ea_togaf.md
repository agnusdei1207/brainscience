# 🎯 EA (엔터프라이즈 아키텍처) & TOGAF

> **별점**: ★★★★★ | ★134회 기출

## 1. EA (Enterprise Architecture)

```
정의: 조직의 비즈니스 목표 달성을 위해 IT 자원(시스템,
     데이터, 기술, 프로세스)를 체계적으로 정렬하는 프레임워크

EA 4대 아키텍처 도메인:
비즈니스 아키텍처: 프로세스, 역할, 조직 구조
데이터 아키텍처: 데이터 자산, 표준, 모델
애플리케이션 아키텍처: SW 시스템, 인터페이스
기술 아키텍처: 인프라, 플랫폼, 보안

[EA 프레임워크 비교]
Zachman: 6×6 매트릭스 (분류 체계)
TOGAF: 개발 방법론 (ADM 사이클)
DoDAF: 미국 국방부
FEAF: 미국 연방 정부
```

## 2. TOGAF ADM (Architecture Development Method)

```
[ADM 사이클]
예비단계 → A(비전) → B(비즈니스) → C(정보시스템)
         → D(기술) → E(기회·해결) → F(이전계획)
         → G(구현 거버넌스) → H(변경관리) → 요구사항관리

핵심: 현재 아키텍처 → 목표 아키텍처 → 전환 로드맵

아키텍처 리포지토리:
- 아키텍처 원칙, 참조 모델, 표준
- 재사용 가능한 아키텍처 구성 요소
```

## 3. 국내 정보화 참조모델

```
[BRM (업무참조모델)]: 정부 업무 분류
[SRM (서비스참조모델)]: IT 서비스 유형
[DRM (데이터참조모델)]: 공통 데이터 정의
[TRM (기술참조모델)]: 기술 표준 목록
[PRM (성과참조모델)]: KPI, 성과 지표

전자정부 프레임워크와 연계 적용
```

## 4. 답안 포인트

**3단락**: ① EA 정의 & 4대 도메인 → ② TOGAF ADM 사이클 단계 → ③ 국내 정보화 참조모델 & 전자정부 적용

## 5. 관련 개념
