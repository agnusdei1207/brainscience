# 🎯 IT 아웃소싱 & API 경제 & 데이터 기반 경영

> **별점**: ★★★★☆ | 기본 필수

## 1. IT 아웃소싱

```
정의: IT 업무를 외부 전문업체에 위탁하는 전략

[아웃소싱 유형]
선택적 아웃소싱: 특정 기능만 (인프라, 앱 개발)
전략적 아웃소싱: IT 전체를 장기 위탁
클라우드 아웃소싱: IaaS/PaaS/SaaS 활용
BPO: 비즈니스 프로세스 전체 위탁

[SLA 관리]
성과 지표: 가용성, 응답시간, 처리량
벤더 관리: 정기 성과 평가, 에스컬레이션
멀티벤더: 벤더 락인 방지

[클라우드 전환 후 아웃소싱 변화]
온프레미스 운영 아웃소싱 → 클라우드 관리 서비스(MSP)
```

## 2. API 경제 (API Economy)

```
정의: API를 통해 데이터·기능을 외부에 개방하고
     생태계를 구축하는 비즈니스 모델

[Open API 전략]
공개 API: 외부 개발자 생태계 확장
파트너 API: 특정 파트너 연계
내부 API: 내부 서비스 통합

[API 수익화]
페이쿼리: API 호출당 과금
프리미엄: 기본 무료 + 고급 유료
에코시스템: API 기반 플랫폼 구축

[사례]
카카오: 카카오맵 API, 카카오페이 API
Twilio: SMS/음성 API로 시가총액 수십조
AWS: 모든 서비스가 API 기반
```

## 3. DDDM (데이터 기반 의사결정)

```
Data-Driven Decision Making:
직관이 아닌 데이터 분석으로 의사결정

[구성]
CDO (Chief Data Officer): 데이터 전략 총괄
데이터 민주화: 전 직원 데이터 접근
셀프서비스 BI: 비기술자 직접 분석 (Tableau, Power BI)
데이터 리터러시: 데이터 이해·활용 역량
```

## 4. 답안 포인트

**3단락**: ① IT 아웃소싱 유형 & SLA → ② API 경제 개념 & 수익화 모델 → ③ DDDM & 데이터 문화

## 5. 관련 개념

`SLA` → 아웃소싱 성과 관리 | `MSA` → API 기반 서비스 분리 | `데이터 거버넌스` → DDDM의 기반
