# 🎯 RPA & BPM & 업무 자동화

> **별점**: ★★★★★ | ★132회 연계

## 1. RPA (Robotic Process Automation)

```
정의: 규칙 기반의 반복적 업무를 SW 로봇(BOT)이 자동화
     하는 기술. 기존 시스템 UI를 그대로 사용.

[RPA 특성]
비침투적: 기존 시스템 변경 없이 UI 자동화
빠른 구현: 코딩 불필요 (로우코드)
사람 대체: 데이터 입력, 파일 이동, 보고서 생성

[RPA 적용 사례]
재무: 세금계산서 처리, 대사·정산
HR: 근태 집계, 입퇴사 처리
IT: 시스템 모니터링, 패스워드 리셋
구매: 발주서 생성, 송장 매칭

[도구]
UiPath, Automation Anywhere, 삼성SDS Brity Works
```

## 2. RPA 진화: Intelligent Automation

```
[단계적 발전]
RPA (규칙 기반) → IA (지능형 자동화) → HIA (초지능 자동화)

IA (Intelligent Automation) = RPA + AI:
- OCR: 비정형 문서 인식 (계약서, 영수증)
- NLP: 이메일·채팅 이해
- ML: 패턴 학습으로 예외 처리

Agentic AI + RPA:
- LLM이 비정형 요청 이해 → RPA BOT 실행
- 사람 개입 없이 E2E 자동화
```

## 3. BPM (Business Process Management)

```
BPM: 비즈니스 프로세스의 설계·실행·모니터링·개선 체계

[BPMN 2.0]
프로세스 표기 표준
이벤트(원): 시작·종료·중간
활동(사각형): 작업, 서브프로세스
게이트웨이(마름모): 분기·합류 조건
흐름: 순차, 메시지, 데이터
```

## 4. 답안 포인트

**3단락**: ① RPA 정의 & 특성(비침투적/빠른구현) → ② 지능형 자동화(RPA+AI) 진화 → ③ BPM과의 연계 & 한계(복잡 프로세스)
