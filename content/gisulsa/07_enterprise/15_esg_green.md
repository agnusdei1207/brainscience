# 🎯 ESG & 지속가능경영 & 그린IT

> **별점**: ★★★★☆ | ★135회 연계

## 1. ESG (환경·사회·지배구조)

```
E (Environmental): 탄소중립, 온실가스, 자원 절약
S (Social): 인권, 노동, 지역사회, 다양성
G (Governance): 이사회 구성, 투명성, 반부패

[IT 기업 ESG]
탄소 발자국: 데이터센터 전력 소비
공급망 관리: 공급업체 ESG 평가
그린 소프트웨어: SW SCI 탄소 측정
다양성: 기술 인력 성별·인종 다양성
```

## 2. 그린 IT 데이터센터

```
[PUE (Power Usage Effectiveness)]
PUE = 총 설비 전력 / IT 장비 전력
PUE 1.0: 완벽 효율 (불가능)
PUE 1.5: 우수 (글로벌 평균 1.57)
PUE 2.0: 평균
구글 데이터센터: PUE 1.11 (업계 최저)

[냉각 기술]
공랭식: 전통적, PUE 1.5~2.0
수랭식: 서버 직냉, PUE 1.1~1.2
액침냉각: 서버 직접 냉각액 침수, PUE 1.03
자연냉각: 외기 활용 (추운 지역)

[재생에너지]
구글: 100% 재생에너지 (PPA)
애플: 전 공급망 탄소중립 2030 목표
네이버: IDC 각 100% 재생에너지 목표
```

## 3. IT 리스크 관리

```
[IT 리스크 유형]
전략적 리스크: IT 전략과 비즈니스 미정렬
운영 리스크: 시스템 장애, 데이터 손실
보안 리스크: 사이버 공격, 개인정보 유출
규제 리스크: 법규 미준수 (GDPR, AI 법)

[리스크 관리 프로세스 (ISO 31000)]
리스크 식별 → 분석 → 평가 → 처리
처리 방법: 회피, 감소, 이전(보험), 수용
```

## 4. 답안 포인트

**3단락**: ① ESG 정의 & IT 부문 ESG 요소 → ② 그린IT(PUE, 냉각기술, 재생에너지) → ③ IT 리스크 관리(ISO 31000)
