# 🎯 공공 IT 조달 & 전자정부 표준

> **별점**: ★★★★☆ | 기본 필수

## 1. 공공 SW 사업 구조

```
[공공 SW 사업 관련 법·제도]
소프트웨어진흥법: SW 산업 육성, 대기업 참여 제한
전자정부법: 디지털플랫폼정부 구현
정보통신공사업법: ICT 인프라 공사
국가계약법: 공공 조달 절차

[공공 SW 사업 유형]
정보화 전략 계획 (ISP): 정보화 마스터플랜 수립
시스템 개발: 행정시스템 신규 개발
운영·유지보수: 기존 시스템 운영
클라우드 전환: 온프레미스 → 클라우드

[대기업 참여 제한 제도]
20억 미만 사업: 대기업 직접 참여 불가
→ 중소 SW 기업 시장 보호
→ 컨소시엄: 대기업(PM) + 중소(개발)
```

## 2. 전자정부 표준 프레임워크

```
정의: 공공 정보시스템 개발의 표준 기술 플랫폼
     (자바 기반, Spring Framework 기반)

목적:
- 공공 시스템 간 호환성 확보
- 중복 개발 방지
- 유지보수 효율성

구성 요소:
개발환경, 운영환경, 관리환경, 배치환경

국내 표준: 행안부 공식 지정 (전자정부 사업 의무)
버전: 현재 4.x 계열 (Spring Boot 기반)
```

## 3. 정보화 사업 예산 & 타당성 조사

```
[예비타당성 조사 (기재부)]
500억 이상 정보화 사업: 예타 필수
비용편익분석 (B/C 비율 > 1.0)
AHP (계층분석법)으로 우선순위

[정보화 사업 평가]
ISP 적정성 검토 (과기부)
감리 의무: 5억 이상 정보화 사업
사후 평가: 개통 1년 후 성과 측정
```

## 4. 답안 포인트

**3단락**: ① 공공 SW 사업 법적 구조 → ② 전자정부 표준 프레임워크 & 의무화 → ③ 예타·감리·사후 평가 체계
