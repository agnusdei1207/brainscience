# 🎯 핵심 키워드: 정렬 (Sorting), 탐색 (Searching), 이진 탐색 (Binary Search)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

정렬은 데이터를 일정한 기준 순서로 재배열하여 탐색·집계·출력 효율을 높이는 기본 연산이다.  
탐색은 원하는 값을 찾는 과정이며, 정렬 여부에 따라 선형 탐색과 이진 탐색의 성능 차이가 크게 난다.  
기술사 답안에서는 Quick, Merge, Heap 정렬의 평균/최악 복잡도와 안정성, 메모리 사용을 비교하는 것이 핵심이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | Quick Sort | Merge Sort | Heap Sort |
| --- | --- | --- | --- |
| 평균 시간 | O(n log n) | O(n log n) | O(n log n) |
| 최악 시간 | O(n²) | O(n log n) | O(n log n) |
| 추가 메모리 | 작음 | 큼 | 작음 |
| 안정성 | 불안정 | 안정 | 불안정 |
| 적합 사례 | 일반 메모리 정렬 | 대용량 안정 정렬 | 메모리 제약 환경 |

## 5. 인출 훈련 문제 (Output Drills)

### 단답형 (30초)
1. 정렬 (Sorting)의 정의를 한 문장으로 쓰시오.
2. 정렬·탐색 답안에서 반드시 써야 할 핵심 구성요소 3가지를 나열하시오.

4. "시간 복잡도와 안정성을 함께 비교하는 연습"를 답안 키워드 3개로 압축하시오.
5. 대량 로그 정렬과 실시간 검색 서비스 최적화 중 하나를 들고 기대효과 2가지를 말하시오.
