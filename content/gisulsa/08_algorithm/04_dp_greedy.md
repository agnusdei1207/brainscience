# 🎯 핵심 키워드: 동적 계획법 (Dynamic Programming), 그리디 (Greedy), 분할 정복 (Divide and Conquer)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

동적 계획법은 중복 부분 문제와 최적 부분 구조를 이용해 부분 해를 저장하며 최적해를 구하는 방법이다.  
그리디는 매 단계에서 현재 최선이라고 판단되는 선택을 반복해 전체 해를 구성하는 기법이다.  
분할 정복은 문제를 작은 하위 문제로 나누고 독립적으로 해결한 뒤 결합하는 알고리즘 설계 전략이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | DP | Greedy |
| --- | --- | --- |
| 해결 방식 | 부분 문제 해를 저장하며 누적 | 현재 최선 선택 반복 |
| 필수 조건 | 중복 부분 문제·최적 부분 구조 | 탐욕 선택 속성 |
| 장점 | 최적해 보장 가능 | 구현이 단순하고 빠름 |
| 단점 | 메모리 사용 증가 | 전역 최적 보장 실패 가능 |
| 대표 사례 | 배낭, 최장 공통 부분수열 | 거스름돈, 활동 선택 |

## 5. 인출 훈련 문제 (Output Drills)

1. 동적 계획법 (Dynamic Programming)의 정의를 한 문장으로 쓰시오.

3. DP와 Greedy의 가장 큰 차이점을 설명하시오.
4. "문제 구조를 먼저 판단한 후 알고리즘을 선택하는 연습"를 답안 키워드 3개로 압축하시오.
5. 최적화 문제와 대규모 계산 구조 설계 중 하나를 들고 기대효과 2가지를 말하시오.

7. "DP vs Greedy"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
