# 🎯 핵심 키워드: 확률 (Probability), 기술 통계 (Descriptive Statistics), 추론 통계 (Inferential Statistics)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

확률은 불확실한 사건이 발생할 가능성을 수치로 표현하는 도구이며 위험 평가와 예측의 기초가 된다.  
기술 통계는 평균, 분산, 표준편차처럼 데이터를 요약하고 분포 특성을 설명하는 방법이다.  
추론 통계는 표본을 통해 모집단 특성을 추정하거나 가설을 검정하여 의사결정을 지원한다.

## 3. 답안 목차 템플릿 (Answer Outline Template)

문제: "확률과 통계의 기본 개념 및 실무 활용 포인트를 설명하시오."

```text
Ⅰ. 개요
   1. 정의
   2. 데이터 기반 의사결정 확대

Ⅱ. 핵심 구성요소
   1. 기본 통계 지표
   2. 표본 기반 추정과 검정

Ⅲ. 특징 및 장단점
   1. 데이터 해석력과 의사결정 품질 향상
   2. 표본 편향과 지표 오해 위험

Ⅳ. 유사 기술과의 비교
   - 기술 통계 vs 추론 통계 비교표

Ⅴ. 적용사례 및 향후전망
   1. 품질 관리, A/B 테스트, 리스크 분석
   2. 실험 설계와 AI 모델 평가 중요성 증가
```

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 기술 통계 | 추론 통계 |
| --- | --- | --- |
| 목적 | 데이터 요약과 설명 | 모집단 특성 추정과 검정 |
| 대표 지표 | 평균, 중앙값, 분산 | 신뢰구간, p-value, 회귀계수 |
| 장점 | 직관적 이해가 쉬움 | 의사결정 근거 제공 |
| 한계 | 원인 추론이 제한적 | 가정 위반 시 해석 오류 |
| 시험 포인트 | 분포 특성 | 표본-모집단 관계 |

## 5. 인출 훈련 문제 (Output Drills)

### 단답형 (30초)
1. 확률 (Probability)의 정의를 한 문장으로 쓰시오.
2. 확률·통계 기초 답안에서 반드시 써야 할 핵심 구성요소 3가지를 나열하시오.
3. 기술 통계와 추론 통계의 가장 큰 차이점을 설명하시오.
4. "지표 의미를 경영 의사결정과 연결해 말하는 연습"를 답안 키워드 3개로 압축하시오.
5. 품질 관리, A/B 테스트, 리스크 분석 중 하나를 들고 기대효과 2가지를 말하시오.

### 서술형 (5분)
6. "확률과 통계의 기본 개념 및 실무 활용 포인트를 설명하시오."의 핵심 구성요소와 기대효과를 5분 답안으로 정리하시오.
7. "기술 통계 vs 추론 통계"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
8. "확률과 통계의 기본 개념 및 실무 활용 포인트를 설명하시오." (개념, 구조, 비교, 적용사례, 향후전망 포함)
