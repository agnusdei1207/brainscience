# 🎯 알고리즘 최신 트렌드 — 근사/확률적/진화

> **별점**: ★★★★☆ | ☆ 예측

## 1. 근사 알고리즘

```
정의: NP-hard 문제를 다항 시간에 근사 해를 구하는 방법

[성능 보장]
근사 비율 α: 알고리즘 해 / 최적 해 ≤ α
α=2: 최적 해의 최대 2배 이내

[예시]
TSP 근사 (크리스토피데스):
  근사 비율 1.5
  실제 사용: 배달 경로 최적화

정점 커버 근사:
  간단한 2-근사 알고리즘 존재

적용: 자원 스케줄링, 클러스터링
```

## 2. 확률적·휴리스틱 알고리즘

```
[랜덤화 알고리즘]
Randomized QuickSort: 피벗 랜덤 선택 → 최악 케이스 회피
Monte Carlo: 확률적 결과 (정확성 확률)
Las Vegas: 항상 정확, 시간이 확률적

[메타휴리스틱]
유전 알고리즘 (GA):
  자연 선택 모방: 선택→교차→돌연변이
  조합 최적화에 적합

시뮬레이티드 어닐링 (SA):
  금속 냉각 모방, 확률적 최적해 탐색
  지역 최적 탈출 가능

입자 군집 최적화 (PSO):
  새 무리 이동 모방, 연속 최적화

[적용]
AI 하이퍼파라미터 탐색, 회로 배선, 물류 최적화
```

## 3. 알고리즘 & AI 결합

```
[딥러닝 + 알고리즘]
Alpha Zero: 몬테카를로 트리 탐색 + 딥러닝
AlphaFold: 단백질 구조 예측 = AI + 생물정보 알고리즘

[학습 기반 알고리즘]
신경망으로 알고리즘 파라미터 학습
예) 학습 기반 인덱스 (Learned Index)
    신경망으로 B-tree 대체

[알고리즘 복잡도 AI 예측]
Big-O 분석을 넘어 실제 실행시간 ML 예측
```

## 4. 답안 포인트

**3단락**: ① NP-hard & 근사 알고리즘 근사 비율 → ② 유전 알고리즘 & 메타휴리스틱 → ③ AlphaZero/AlphaFold AI + 알고리즘 융합
