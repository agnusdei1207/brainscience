# 🎯 핵심 키워드: 차원의 저주, 고차원 공간, PCA, 임베딩, 과적합

> **출제 빈도**: ★★★★☆ | **기출**: ★135회

## 1. 정의

차원의 저주(Curse of Dimensionality)는 데이터의 차원(특성 수)이 증가함에 따라 데이터 분석에 필요한 샘플 수가 기하급수적으로 증가하고, 거리 함수의 의미가 퇴색되는 현상이다.

Bellman(1961)이 동적 프로그래밍 연구에서 최초 명명.

## 3. 답안 목차 템플릿

**문제**: "차원의 저주(Curse of Dimensionality) 현상을 설명하고, 머신러닝에서의 대응 방법을 논하시오."

```
I. 차원의 저주 3가지 문제
   
   1) 데이터 희소성 (Sparsity)
      - d차원 공간에서 균일 커버리지: 10^d 샘플 필요
      - d=10: 10^10 샘플 → 현실 불가능
   
   2) 거리 집중 현상 (Distance Concentration)
      고차원에서: max_dist / min_dist → 1
      → 최근접 이웃(K-NN)이 의미 없어짐
      
      직관: d=1에서 가장 가까운 점과 가장 먼 점 차이 크지만
           d→∞에서 모든 점이 비슷한 거리
   
   3) 과적합 (Overfitting)
      특성 수 >> 샘플 수 → 모델이 노이즈 학습
      → 일반화 성능 저하

II. 수학적 이해
   
   [단위 구의 부피 변화]
   d=2: π × r² (원)
   d=3: (4/3)π × r³ (구)
   d→∞: V_d → 0 (초구의 부피가 0에 수렴!)
   
   → 고차원에서 데이터가 "껍데기"에만 분포
   → 중심 근처에는 거의 데이터 없음

III. 해결 방법
   
   1) 차원 축소 (Dimensionality Reduction)
      a) PCA (주성분분석): 분산 최대화 방향으로 선형 투영
         - SVD 기반, 설명 분산 비율로 차원 결정
         - 단점: 비선형 구조 포착 불가
      
      b) t-SNE: 비선형, 시각화 특화 (2D/3D)
      c) UMAP: t-SNE보다 빠름, 구조 보존 우수
   
   2) 특성 선택 (Feature Selection)
      - 필터 방법: 상관계수, 카이제곱
      - 래퍼 방법: RFE (재귀적 특성 제거)
      - 임베디드: Lasso (L1 정규화)
   
   3) 정규화 (Regularization)
      - L1 (Lasso): 희소 모델, 불필요 특성 계수=0
      - L2 (Ridge): 계수 값 축소

IV. AI/LLM 시대 차원의 저주
   - LLM 임베딩: 768~4096차원 → 벡터 DB 유사도 검색
   - 거리 집중 문제: 코사인 유사도가 유클리드보다 안정적
   - RAG: 고차원 임베딩 → HNSW 인덱스로 근사 검색
   - 해결: HNSW, Faiss, Product Quantization (PQ)
```

## 4. 핵심 암기 포인트

- **차원 ↑ → 데이터 희소성 ↑ / 거리 집중 / 과적합**
- **PCA**: 분산 최대 방향으로 선형 투영 (가장 많이 쓰임)
- **고차원 벡터 검색**: HNSW + 코사인 유사도 → RAG의 핵심
