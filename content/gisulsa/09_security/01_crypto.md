# 🎯 핵심 키워드: 대칭키 암호 (Symmetric Encryption), 공개키 암호 (Asymmetric Encryption), 해시 (Hash), PKI (Public Key Infrastructure)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

대칭키 암호는 하나의 비밀키로 데이터를 빠르게 암호화·복호화하는 방식이다.  
공개키 암호는 공개키와 개인키 쌍을 사용하여 키 교환과 전자서명을 지원하는 비대칭 암호 방식이다.  
해시와 PKI는 각각 무결성 검증과 신뢰 기반 인증 체계를 제공하여 암호화 기술을 실무에 연결한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 대칭키 암호 | 공개키 암호 |
| --- | --- | --- |
| 키 구조 | 같은 키 사용 | 공개키/개인키 쌍 사용 |
| 장점 | 빠른 처리 속도 | 키 분배와 전자서명에 유리 |
| 단점 | 키 공유가 어려움 | 연산 비용이 큼 |
| 대표 알고리즘 | AES | RSA, ECC |
| 시험 포인트 | Bulk data encryption | Key exchange / signature |
