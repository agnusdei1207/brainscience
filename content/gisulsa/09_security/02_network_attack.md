# 🎯 핵심 키워드: DDoS (Distributed Denial of Service), SQL Injection, XSS (Cross Site Scripting)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

DDoS는 다수의 분산된 출발지에서 대량 트래픽을 유발해 서비스 가용성을 떨어뜨리는 공격이다.  
SQL Injection은 입력값 검증 부재를 악용해 악의적 SQL을 실행시키는 대표적인 웹 애플리케이션 공격이다.  
XSS는 웹 페이지에 악성 스크립트를 삽입해 사용자 브라우저에서 실행되도록 하는 공격으로 세션 탈취와 피싱에 악용된다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | SQL Injection | XSS | DDoS |

| 핵심 원인 | 입력값 검증 부재 | 출력 인코딩 미흡 | 대량 트래픽 유입 |
