# 🎯 핵심 키워드: 제로 트러스트 (Zero Trust), ZTNA (Zero Trust Network Access), SASE (Secure Access Service Edge)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

제로 트러스트는 네트워크 내부·외부를 불문하고 항상 검증하고 최소 권한으로 접근을 허용하는 보안 원칙이다.  
ZTNA는 사용자·디바이스·애플리케이션 상태를 지속 검증하여 애플리케이션 단위로 접근을 허용하는 구현 방식이다.  
SASE는 네트워크와 보안을 클라우드 기반 서비스로 통합 제공하여 분산 근무 환경의 정책 일관성을 높인다.
