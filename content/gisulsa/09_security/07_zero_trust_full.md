# 🎯 핵심 키워드: Zero Trust, NIST SP 800-207, Never Trust Always Verify, SDP

> **출제 빈도**: ★★★★★ | **기출**: ★131회, ★134회, ★136회 (매회 연속 출제)

## 1. 정의

Zero Trust(제로 트러스트)는 **"절대 신뢰하지 말고, 항상 검증하라(Never Trust, Always Verify)"**는 보안 철학으로, 내부 네트워크도 이미 침해됐다고 가정하고 모든 사용자/장치/서비스에 지속적 인증과 최소 권한을 적용하는 보안 아키텍처.

NIST SP 800-207이 공식 Zero Trust 아키텍처 표준.

## 2. 출제 포인트

| 포인트 | 내용 | 채점 비중 |
|--------|------|----------|
| 정의 | 기존 경계보안 vs Zero Trust | 20% |
| 7대 원칙 | NIST SP 800-207 | 30% |
| 구현 기술 | ZTNA, SDP, IAM, mTLS | 30% |
| 성숙도 | 도입→고급→최적 단계 | 20% |

## 3. 답안 목차 템플릿

**문제**: "Zero Trust 아키텍처의 개념과 핵심 원칙, 국내 공공 부문 적용 방안을 설명하시오."

```
I. 기존 경계 보안 vs Zero Trust
   
   [기존 성곽형 보안]
   인터넷 ─── 방화벽 ─── 내부망 (신뢰 구역)
   단점: 내부 침해 시 무방비, 재택·클라우드 대응 불가
   
   [Zero Trust]
   어디서든 ─── 신원확인 ─── 최소권한 ─── 지속 검증
   VPN 없이 정확한 사용자/기기/컨텍스트 기반 접근 결정

II. NIST SP 800-207 Zero Trust 7대 원칙
   
   1. 모든 자원을 서비스로 취급
   2. 모든 통신 암호화 (네트워크 위치 무관)
   3. 세션 기반 접근 결정 (사전 신뢰 없음)
   4. 동적 정책으로 접근 결정 (행동+환경 분석)
   5. 모든 자산 무결성 모니터링
   6. 인증·인가 엄격 시행 및 동적 적용
   7. 네트워크 상태 정보 수집·분석으로 보안 개선

III. Zero Trust 핵심 구성 기술
   
   [Zero Trust 아키텍처]
   
   사용자/기기 ─── PE (정책 엔진) ←── PIP (정책 정보 포인트)
                    │              ← CDM, SIEM, 위협인텔, IAM
                    ↓
                   PA (정책 어드민)
                    ↓
   ─── PEP (정책 집행 포인트) ─── 보호 대상 자원
   
   구현 기술:
   | 기술   | 역할                          |
   |--------|------------------------------|
   | ZTNA   | 네트워크 수준 접근 제어 (VPN 대체) |
   | SDP    | 소프트웨어 정의 경계 (마이크로세그먼테이션) |
   | IAM    | 신원관리, MFA, 조건부 접근      |
   | mTLS   | 서비스 간 상호 인증             |
   | CASB   | 클라우드 접근 보안              |
   | UEBA   | 사용자 행동 분석, 이상 탐지      |

IV. 국내 Zero Trust 성숙도 & 적용
   - KISA '제로 트러스트 가이드라인 1.0' (2023)
   - 성숙도 1단계: 전통→전환 (IAM, MFA 도입)
   - 성숙도 2단계: 고급 (ZTNA, 마이크로세그먼테이션)
   - 성숙도 3단계: 최적 (AI 기반 동적 정책, 자동화)
   - 공공기관: 2027년까지 2단계 달성 목표
```

## 4. 핵심 암기 포인트

- **Never Trust, Always Verify** = Zero Trust 핵심 철학
- **NIST SP 800-207** = 공식 표준
- **PE-PA-PEP** = 정책 엔진-어드민-집행 포인트 (3축)
- **ZTNA** = Zero Trust Network Access (VPN 대체)
