# 🎯 핵심 키워드: MLOps, 모델 서빙 (Model Serving), 드리프트 (Drift)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

MLOps는 데이터 수집, 학습, 배포, 모니터링, 재학습을 자동화하여 모델 운영을 안정적으로 관리하는 체계다.  
모델 서빙은 학습된 모델을 배치 또는 실시간 API 형태로 제공하여 비즈니스 프로세스에 연결하는 단계다.  
드리프트는 데이터 분포나 개념이 변화하여 모델 성능이 저하되는 현상으로 지속 모니터링과 재학습이 필요하다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 배치 서빙 | 온라인 서빙 |
| --- | --- | --- |
| 응답 방식 | 주기적 대량 처리 | 실시간 API 응답 |
| 장점 | 구현 단순, 비용 효율 | 즉시성 높은 서비스 대응 |
| 단점 | 지연 발생 | 인프라 복잡성과 SLA 부담 |
| 적합 사례 | 일별 예측·리포트 | 추천·사기탐지·개인화 |
| 시험 포인트 | Batch scoring | Realtime inference |
