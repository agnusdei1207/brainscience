# 🎯 AI 보안 & LLM 취약점

> **별점**: ★★★★★ | ★136회 기출

## 1. LLM 취약점 (OWASP LLM Top 10)

```
LLM01 프롬프트 인젝션:
  악의적 입력으로 LLM 지시 우회
  직접: 사용자가 직접 주입
  간접: 웹 페이지·문서에 숨겨진 주입

LLM02 안전하지 않은 출력 처리:
  LLM 출력을 신뢰하여 코드 실행

LLM03 학습 데이터 중독:
  학습 데이터 조작 → 편향·백도어 삽입

LLM06 민감 정보 노출:
  개인정보·기밀을 학습 → 추출 공격

LLM09 과도한 에이전트 신뢰:
  에이전트에 과도한 권한 → 위험한 동작

[대응]
입력 검증, 출력 필터링, 최소 권한 에이전트
시스템 프롬프트 보호, 가드레일 (Guardrails AI)
```

## 2. 적대적 공격 (Adversarial Attack)

```
[회피 공격 (Evasion Attack)]
사람 눈에 안 보이는 작은 노이즈 추가
  → 모델이 오분류

FGSM (Fast Gradient Sign Method):
  그래디언트 방향으로 노이즈 생성
  판다 이미지 + 노이즈 → 긴팔원숭이로 인식

[물리적 적대적 예시]
자율주행: 정지 표지판에 스티커 → Stop 미인식
얼굴인식: 특수 안경 착용 → 오인식

[방어]
Adversarial Training: 적대적 예제로 재학습
인증된 방어 (Certified Defense): 수학적 보장
입력 전처리: 노이즈 제거, 평활화
```

## 3. 모델 도난 & 프라이버시

```
[모델 도난 (Model Stealing)]
API로 많은 쿼리 → 응답으로 모델 역공학
대응: 쿼리 제한, 워터마킹, 모니터링

[멤버십 추론 공격]
학습 데이터에 특정 샘플이 있었는지 추론
프라이버시 침해

[연합 학습 (Federated Learning)]
데이터 이동 없이 분산 학습
각 디바이스에서 로컬 학습 → 가중치만 공유
의료·금융 프라이버시 보호 AI 학습

차등 프라이버시 (Differential Privacy):
  노이즈 추가 → 개별 데이터 식별 방지
  Apple, Google 적용
```

## 4. 답안 포인트

**3단락**: ① OWASP LLM Top 10 & 프롬프트 인젝션 → ② 적대적 공격(FGSM) & 자율주행 위협 → ③ 연합 학습 & 차등 프라이버시 보호
