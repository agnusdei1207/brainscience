# 🎯 핵심 키워드: Agentic AI, ReAct, MCP, 멀티에이전트, 자율 실행

> **출제 빈도**: ★★★★★ | **기출**: ★136회 | **2026 최우선 예측**

## 1. 정의

Agentic AI(에이전틱 AI)는 LLM이 단순 응답을 넘어 **목표를 자율적으로 분해하고, 도구를 사용하며, 반복적으로 계획-실행-피드백하여 복잡한 작업을 완수**하는 AI 패러다임이다.

인간의 최소 개입으로 다단계 태스크를 수행하는 "자율 AI 에이전트"를 구현한다.

## 2. 출제 포인트

| 포인트 | 내용 | 채점 비중 |
|--------|------|----------|
| 정의 | 에이전틱 AI vs 생성형 AI 차이 | 20% |
| 핵심 구성요소 | ReAct, 도구 사용, 메모리 | 30% |
| MCP 표준 | Model Context Protocol, 도구 연결 | 20% |
| 멀티에이전트 | 오케스트레이터-워커, 협업 | 15% |
| 보안/위험 | 프롬프트 인젝션, 자율 실행 위험 | 15% |

## 3. 답안 목차 템플릿

**문제**: "Agentic AI의 개념과 핵심 구성요소, 기업 적용 시 고려사항을 설명하시오."

```
I. Agentic AI 정의 및 생성형 AI와의 차이
   
   | 항목      | 생성형 AI (GenAI)  | Agentic AI             |
   |----------|------------------|------------------------|
   | 입력/출력  | 요청 → 단일 응답   | 목표 → 자율 다단계 실행  |
   | 도구 사용 | 없음              | API, 코드실행, 검색 등  |
   | 자율성    | 낮음              | 높음 (계획-실행-피드백)  |
   | 사용자 개입| 매 요청마다       | 최소화                  |

II. Agentic AI 핵심 구성요소
   
   [에이전트 루프]
   목표 입력
      ↓
   ┌─────────────────────────────────┐
   │ LLM (추론 엔진)                  │
   │  ↓ 계획 (Plan)                  │
   │  ↓ 행동 선택 (Tool 호출)         │
   │  ↓ 실행 결과 관찰 (Observation)  │
   │  ↓ 다음 행동 결정                │
   └─────────────────────────────────┘
      ↓
   최종 결과
   
   핵심 구성요소:
   1) ReAct (Reasoning + Acting): 추론→행동→관찰 루프
   2) 도구 (Tools): 웹 검색, 코드 실행, DB 쿼리, API 호출
   3) 메모리: 단기(컨텍스트), 장기(벡터DB), 에피소딕
   4) 계획 (Planning): CoT, ToT, 태스크 분해

III. MCP (Model Context Protocol)
   - Anthropic 주도, 2024년 발표, 사실상 표준화
   - 목적: AI 에이전트와 외부 도구/데이터소스 연결 표준화
   
   [MCP 아키텍처]
   AI 에이전트 ──MCP 클라이언트──→ MCP 서버 ──→ 도구/DB
                 (표준 프로토콜)
   
   지원: GitHub, Slack, DB, 파일시스템, 웹 브라우저

IV. 멀티에이전트 시스템
   - 오케스트레이터: 전체 목표 분해, 서브에이전트 위임
   - 워커 에이전트: 전문화된 작업 수행
   - 사례: AutoGPT, CrewAI, LangGraph, Microsoft AutoGen

V. 보안 및 거버넌스
   - 프롬프트 인젝션: 악의적 도구 응답이 에이전트 오작동 유도
   - 자율 실행 위험: 금융 거래, 코드 배포 등 되돌릴 수 없는 행동
   - AI 기본법: 고위험 Agentic AI 규제 의무화 예상
   - 대응: 인간 승인 게이트, 최소 권한 원칙
```

## 4. 핵심 암기 포인트

- **ReAct**: Reasoning + Acting = 추론+행동 루프
- **MCP**: AI 에이전트↔도구 연결의 USB 표준 역할
- **멀티에이전트**: 오케스트레이터+워커 구조로 복잡 태스크 분산
