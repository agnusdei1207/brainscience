# 🎯 정보시스템 감리 (IS Audit)

> **별점**: ★★★★★ | ★134회, ★136회 기출

## 1. 정의

정보시스템 감리: 정보화 사업의 **과정 및 결과가 감리기준에 부합하는지 독립적·전문적으로 확인**하는 활동.

근거: 전자정부법 제57조, 의무 감리 대상: 5억 이상 정보화 사업

## 2. 감리 단계 & 점검 항목

```
[감리 시기]
① 착수 감리 (사업 시작 전):
  - 계획 적정성, 방법론 타당성, WBS 검토
  - 요구사항 정의 적정성

② 중간 감리 (중반~2/3):
  - 설계 품질, DB 설계, 보안 설계
  - 개발 진척도, 계획 대비 실적

③ 완료 감리 (완료 후):
  - 기능 충족성 (요구사항 대비)
  - 성능 테스트 결과
  - 보안 취약점 점검
  - 문서 완성도

[전문 감리 영역]
시스템 아키텍처, 데이터베이스, 보안,
네트워크, SW 품질, UI/UX, 접근성
```

## 3. 감리 vs PMO

| 항목 | 감리 | PMO |
|------|------|-----|
| 독립성 | 독립 제3자 | 발주기관 소속 or 위탁 |
| 역할 | 검토·확인·승인 | 관리·지원·협력 |
| 법적 근거 | 전자정부법 의무 | 과기부 고시 권고 |
| 시기 | 단계별 주요 시점 | 상시 |

## 4. 답안 포인트

**3단락**: ① 감리 정의 & 법적 근거 → ② 3단계 감리(착수/중간/완료) 점검 항목 → ③ PMO와의 역할 차이

## 5. 관련 개념

`PMO(★132회)` → 감리와 상호보완 | `SW 기술성 평가(★132회)` → 감리 선행 활동 | `ISMS-P` → 보안 감리 체크리스트
