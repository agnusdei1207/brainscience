# 🎯 위험 관리 (PMBOK & ISO 31000)

> **별점**: ★★★★☆ | 기본 필수

## 1. PMBOK 위험 관리 6단계

```
① 위험 관리 계획: 위험 접근법, 역할, 예산
② 위험 식별: 위험 등록부 작성
   - 방법: 체크리스트, 브레인스토밍, 인터뷰, SWOT
③ 정성적 분석: 발생확률×영향도 매트릭스
   - 고/중/저 분류, 우선순위
④ 정량적 분석: 몬테카를로, 의사결정트리
   - 화폐 가치로 표현 (EMV = P × I)
⑤ 위험 대응 계획: 위험 처리 전략
⑥ 위험 통제: 모니터링, 재식별
```

## 2. 위험 대응 전략

| 위협(Risk) | 기회(Opportunity) | 내용 |
|-----------|-----------------|------|
| 회피 | 활용 | 위협 제거/기회 확보 |
| 전가 | 공유 | 보험/파트너십 |
| 감소 | 강화 | 완화/확대 |
| 수용 | 수용 | 비상계획 or 무대응 |

## 3. 정량적 위험 분석

```
EMV (기대화폐가치):
위험A: 발생확률 30%, 손실 100만원 → EMV = -30만원
기회B: 발생확률 20%, 이익 500만원 → EMV = +100만원
순 EMV = -30+100 = +70만원 (긍정적)

의사결정 트리:
       [개발]
      /      \
  성공(60%)  실패(40%)
  +200만원   -100만원
EMV = 0.6×200 + 0.4×(-100) = 120-40 = 80만원
```

## 4. 답안 포인트

**3단락**: ① 위험 관리 6단계 프로세스 → ② 정성적(P×I 매트릭스) vs 정량적(EMV, 몬테카를로) 분석 → ③ 위험 대응 4전략 & 잔여위험 관리

## 5. 관련 개념

`PMBOK` → 프로젝트 관리 지식체계 | `ISO 31000` → 기업 전사 위험관리 | `EVM(04_sw 22번)` → 위험 실현 시 EVM 지표 변화
