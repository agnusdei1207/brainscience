# 🎯 국가정보화 법규 & 표준 체계

> **별점**: ★★★★★ | 기본 필수

## 1. 주요 법령 체계

```
[IT 관련 주요 법령]
전자정부법: 전자정부 구현, 디지털플랫폼정부
소프트웨어진흥법: SW 산업 육성, 대기업 참여 제한
클라우드컴퓨팅 발전법: 공공 클라우드 전환 근거
정보통신망법: 개인정보, ISMS, 침해사고 대응
개인정보보호법: 개인정보 수집/처리/보호
AI 기본법 (2024): 고위험 AI 규제, AI안전
국가사이버안보기본법 (2025): 사이버 안보 종합

[행정 고시]
SW 대가 산정 기준 (과기부): FP 기반 공공 SW 비용
공공 SI 감리 기준 (NIA): 감리 절차·점검항목
HW 규격 (조달청): 공공기관 HW 구매 기준
```

## 2. 디지털플랫폼정부

```
추진 목표: 2027년 AI+데이터 기반 플랫폼 정부 실현

[핵심 과제]
데이터: 공공 데이터 민간 개방 확대
AI: 공공 AI 서비스 (민원 챗봇, 복지 추천)
연결: 부처 간 데이터 연계 플랫폼
보안: 클라우드 안전성, 개인정보 보호

[추진 체계]
디지털플랫폼정부위원회 (대통령 직속)
디지털플랫폼정부 기본계획 (5개년)
행안부: 전자정부 총괄
과기부: IT/AI 정책
```

## 3. 공공 클라우드 정책

```
[클라우드 우선 정책 (Cloud First)]
공공기관 신규 정보시스템: 클라우드 우선 도입
행정정보시스템 클라우드 전환 (2030년)

[클라우드 보안 인증 (CSAP)]
공공클라우드 의무 인증
보안등급: 상(IaaS)/중(PaaS)/하(SaaS)
```

## 4. 답안 포인트

**3단락**: ① 주요 IT 법령 체계 → ② 디지털플랫폼정부 비전 & 과제 → ③ 클라우드 전환 정책 & CSAP
