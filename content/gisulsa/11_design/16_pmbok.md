# 🎯 PMBOK & 프로젝트 관리 5대 프로세스

> **별점**: ★★★★★ | 기본 필수

## 1. PMBOK 5대 프로세스 그룹

```
착수 → 계획 → 실행 → 감시/통제 → 종료

[착수 (Initiating)]
프로젝트 헌장 승인, 이해관계자 식별
→ 공식 프로젝트 시작

[계획 (Planning)]
범위: WBS, 요구사항
일정: CPM/PERT, 간트 차트
비용: 예산, 예비비
품질: 품질 계획
위험: 위험 등록부, 대응 계획
인적자원, 조달, 이해관계자

[실행 (Executing)]
팀 구성, 작업 실행
품질 보증, 조달 관리

[감시/통제 (Monitoring & Controlling)]
EVM: 일정/비용 성과 측정
변경 통제: 변경 요청→승인→반영

[종료 (Closing)]
인수 테스트, 교훈 문서화
계약 종료, 팀 해산
```

## 2. PMBOK 10대 지식 영역

| 지식영역 | 주요 활동 |
|---------|---------|
| 통합 관리 | 헌장, 변경통제, EVM |
| 범위 관리 | WBS, 요구사항 |
| 일정 관리 | CPM, 간트 |
| 비용 관리 | 예산, EVM |
| 품질 관리 | QA/QC, ISO 25010 |
| 자원 관리 | 팀 구성, RACI |
| 의사소통 관리 | 보고서, 회의 |
| 위험 관리 | 위험 등록부, EMV |
| 조달 관리 | 계약, 벤더 |
| 이해관계자 관리 | 참여 전략 |

## 3. 답안 포인트
