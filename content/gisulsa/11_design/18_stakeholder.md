# WBS & CPM & 이해관계자 관리

> 별점: ★★★★★ | 기본 필수

---

## 답안.

### Ⅰ. 개요

  높은 권력 + 높은 관심: 긴밀 협력 (후원자, PM)
  높은 권력 + 낮은 관심: 만족 유지 (임원)
  낮은 권력 + 높은 관심: 정보 제공 (사용자)

### Ⅱ. 핵심 구성요소

```
[이해관계자 식별 & 분류]
권력/관심도 격자:
  높은 권력 + 높은 관심: 긴밀 협력 (후원자, PM)
  높은 권력 + 낮은 관심: 만족 유지 (임원)
  낮은 권력 + 높은 관심: 정보 제공 (사용자)
  낮은 권력 + 낮은 관심: 모니터링 (일반 이해관계자)

[참여 수준]
인식 → 저항 → 중립 → 지지 → 주도
목표: 핵심 이해관계자를 지지 수준으로 끌어올림
```
```
R (Responsible): 실행 책임자
A (Accountable): 최종 책임자 (1인)
C (Consulted): 자문/협의 (양방향)
I (Informed): 결과 통보 (단방향)

예시:
업무         PM    개발    QA    고객
요구사항 정의  A     C      I     R
설계          A     R      C     I
코딩          C     R      I     I
테스트        A     C      R     C
```
```
[변경 통제 프로세스]
변경 요청 → 영향 분석 → 변경통제위원회(CCB) 승인
  → 계획 수정 → 구현 → 검토


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
