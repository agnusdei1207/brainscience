# 🎯 WBS & CPM & 이해관계자 관리

> **별점**: ★★★★★ | 기본 필수

## 1. 이해관계자 관리 (PMBOK)

```
[이해관계자 식별 & 분류]
권력/관심도 격자:
  높은 권력 + 높은 관심: 긴밀 협력 (후원자, PM)
  높은 권력 + 낮은 관심: 만족 유지 (임원)
  낮은 권력 + 높은 관심: 정보 제공 (사용자)
  낮은 권력 + 낮은 관심: 모니터링 (일반 이해관계자)

[참여 수준]
인식 → 저항 → 중립 → 지지 → 주도
목표: 핵심 이해관계자를 지지 수준으로 끌어올림
```

## 2. RACI 매트릭스

```
R (Responsible): 실행 책임자
A (Accountable): 최종 책임자 (1인)
C (Consulted): 자문/협의 (양방향)
I (Informed): 결과 통보 (단방향)

예시:
업무         PM    개발    QA    고객
요구사항 정의  A     C      I     R
설계          A     R      C     I
코딩          C     R      I     I
테스트        A     C      R     C
```

## 3. 변경 관리 (Change Management)

```
[변경 통제 프로세스]
변경 요청 → 영향 분석 → 변경통제위원회(CCB) 승인
  → 계획 수정 → 구현 → 검토

[CCB (Change Control Board)]
범위, 일정, 비용에 영향 = CCB 승인 필수
PM 단독 승인: 소규모, 비용 영향 없음

SW 공학 관점: 형상관리(SCM) 연계
  변경 → SCM에 이력 기록 → 릴리즈 관리
```

## 4. 답안 포인트

**3단락**: ① 이해관계자 식별 & 권력/관심도 분류 → ② RACI 매트릭스 역할 정의 → ③ 변경 통제 프로세스 & CCB
