# 🎯 애자일 & 스크럼 실무

> **별점**: ★★★★★ | 기본 필수

## 1. 애자일 선언 4가지 가치

```
개인과 상호작용 > 프로세스와 도구
작동하는 소프트웨어 > 포괄적인 문서
고객과의 협력 > 계약 협상
변화에 대한 반응 > 계획 따르기

→ 오른쪽도 가치 있지만 왼쪽을 더 높이 평가
```

## 2. 스크럼 (Scrum)

```
[스크럼 역할]
Product Owner (PO): 제품 백로그 관리, 우선순위 결정
Scrum Master (SM): 스크럼 촉진, 장애물 제거
Development Team: 자기조직화, 교차기능 팀 (3~9인)

[스크럼 아티팩트]
Product Backlog: 전체 요구사항 목록 (PO 관리)
Sprint Backlog: 이번 스프린트 작업 목록
Increment: 완성된 동작 소프트웨어

[스크럼 이벤트 (2주 스프린트 기준)]
Sprint Planning: 스프린트 목표, 작업 선정 (4시간)
Daily Scrum: 15분 일일 동기화 (어제/오늘/장애물)
Sprint Review: 완성 결과물 시연, 피드백 (2시간)
Sprint Retrospective: 프로세스 개선 (1.5시간)
```

## 3. 칸반 & SAFe

```
[칸반 (Kanban)]
풀 시스템: 용량에 맞게 작업 진행
WIP 제한: 동시 진행 작업 수 제한
시각화: 칸반 보드 (To-do → Doing → Done)
스프린트 없음: 지속적 흐름

[SAFe (Scaled Agile Framework)]
대규모 애자일: 수백~수천명 조직
PI Planning (Program Increment): 8~12주 단위
ART (Agile Release Train): 50~125명 팀
Epic → Feature → Story → Task 계층
```

## 4. 답안 포인트

**3단락**: ① 애자일 선언 4가지 가치 → ② 스크럼 역할/아티팩트/이벤트 → ③ SAFe 대규모 애자일 확장
