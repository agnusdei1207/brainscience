# 🎯 위험 관리 프레임워크 & 컴플라이언스

> **별점**: ★★★★★ | 기본 필수

## 1. NIST RMF (위험 관리 프레임워크)

```
[NIST RMF 7단계]
Prepare → Categorize → Select → Implement →
Assess → Authorize → Monitor

Categorize: 시스템 분류 (영향도: Low/Mod/High)
Select: 보안 통제 선택 (NIST SP 800-53)
Implement: 통제 적용
Assess: 통제 효과성 평가
Authorize: 운영 허가 (ATO)
Monitor: 지속적 모니터링
```

## 2. ISO 31000 위험 관리

```
[ISO 31000 원칙]
통합성, 구조화, 맞춤화, 포용성
역동성, 최선 정보 활용, 인간적 요소

[위험 관리 프로세스]
컨텍스트 수립 → 위험 평가(식별+분석+평가)
→ 위험 처리 → 모니터링+검토 → 소통

위험 처리 옵션:
회피, 감소, 공유(보험/아웃소싱), 수용
```

## 3. 컴플라이언스 관리

```
[주요 컴플라이언스]
SOX (사베인스-옥슬리법): 상장사 내부통제 (미국)
GDPR: EU 개인정보보호 규정
PCI DSS: 카드결제 보안 표준
HIPAA: 의료정보 보호 (미국)
개인정보보호법: 국내 (ISMS-P)
AI 기본법: 국내 2024 제정

[내부 감사 vs 외부 감사]
내부 감사: 조직 자체 감사부서
외부 감사: 독립 감사법인, 규제기관
정보감사(IT Audit): IT 통제 효과성 검토
```

## 4. SOD (직무 분리)

```
중요 프로세스에서 승인자 = 실행자 동일 금지

예) 발주→승인→수령→지급을 서로 다른 사람
IT에서: 개발자가 운영 직접 접근 금지
       변경 승인자가 변경 실행 금지
```

## 5. 답안 포인트

**3단락**: ① NIST RMF 단계 & 보안 통제 → ② ISO 31000 위험관리 프로세스 → ③ 주요 컴플라이언스(SOX/GDPR/개보법) & SOD
