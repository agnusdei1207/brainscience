# 🎯 BCP 경영 & 연속성 전략

> **별점**: ★★★★★ | ★133회 기출

## 1. BIA (비즈니스 영향 분석)

```
BIA (Business Impact Analysis):
장애 발생 시 비즈니스에 미치는 영향을 정량화

[BIA 절차]
① 핵심 비즈니스 프로세스 식별
② 의존성 파악 (IT 시스템, 공급업체)
③ MTD (최대 허용 중단 시간) 결정
   → 비즈니스 생존 시간 한계
④ RTO/RPO 결정:
   RTO ≤ MTD
   RPO = 허용 데이터 손실 시점
⑤ 재무적 영향 산정:
   매출 손실, 페널티, 복구 비용

[우선순위]
Tier 1: 즉시 복구 (금융거래, 결제)
Tier 2: 4시간 내 복구 (핵심 업무)
Tier 3: 24시간 내 복구 (일반 업무)
```

## 2. 복구 전략 결정

```
[BIA 기반 DR 사이트 결정]
RPO ≈ 0, RTO < 1시간 → Active-Active (핫)
RPO < 4시간, RTO < 4시간 → 핫 사이트
RPO < 1일, RTO < 1일 → 웜 사이트
RPO 수일, RTO 수일 → 콜드 사이트

[클라우드 DR]
Multi-Region: 다른 리전에 복제
AWS: us-east-1 ←→ eu-west-1 복제
→ BIA 비용 대비 복구 시간 최적화
```

## 3. BCP 테스트 유형

```
① 체크리스트 검토: BCP 문서 검토
② 워크스루/구조화 워크스루: 팀 토론
③ 시뮬레이션: 모의 재난 훈련 (데스크탑)
④ 병행 테스트: DR 시스템 동시 가동 검증
⑤ 완전 중단 테스트: 실제 운영 중단 (위험↑)
→ 연간 1회 이상 의무 (금융, 공공)
```

## 4. 답안 포인트

**3단락**: ① BIA 절차 & MTD/RTO/RPO 관계 → ② DR 사이트 선택 기준 → ③ BCP 테스트 5단계 & 클라우드 DR

## 5. 관련 개념

`BCP/DRS(★133회, 07_enterprise)` → 기업-IT 연계 시각 | `클라우드 전환(★135회)` → 클라우드 DR 비용 절감 | `가용성 SLA` → BCP 목표 = SLA 보장
