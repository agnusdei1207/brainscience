# BCP 경영 & 연속성 전략

> 별점: ★★★★★ | ★133회 기출

---

## 답안.

### Ⅰ. 개요

BIA (Business Impact Analysis):
장애 발생 시 비즈니스에 미치는 영향을 정량화
② 의존성 파악 (IT 시스템, 공급업체)

### Ⅱ. 핵심 구성요소

```
BIA (Business Impact Analysis):
장애 발생 시 비즈니스에 미치는 영향을 정량화

[BIA 절차]
① 핵심 비즈니스 프로세스 식별
② 의존성 파악 (IT 시스템, 공급업체)
③ MTD (최대 허용 중단 시간) 결정
   → 비즈니스 생존 시간 한계
④ RTO/RPO 결정:
   RTO ≤ MTD
   RPO = 허용 데이터 손실 시점
⑤ 재무적 영향 산정:
   매출 손실, 페널티, 복구 비용

[우선순위]
Tier 1: 즉시 복구 (금융거래, 결제)
Tier 2: 4시간 내 복구 (핵심 업무)
Tier 3: 24시간 내 복구 (일반 업무)
```
```
[BIA 기반 DR 사이트 결정]
RPO ≈ 0, RTO < 1시간 → Active-Active (핫)
RPO < 4시간, RTO < 4시간 → 핫 사이트
RPO < 1일, RTO < 1일 → 웜 사이트
RPO 수일, RTO 수일 → 콜드 사이트

[클라우드 DR]
Multi-Region: 다른 리전에 복제
AWS: us-east-1 ←→ eu-west-1 복제


해당 키워드의 기술적 구성요소와 동작 원리를 서술한다.

### Ⅲ. 특징 및 비교

핵심 기술의 장단점과 유사 기술과의 차이를 분석한다.

### Ⅳ. 적용 사례

실무 환경에서의 적용 사례와 기대효과를 제시한다.

### Ⅴ. 전망

최신 기술 동향과 향후 발전 방향을 서술한다.
