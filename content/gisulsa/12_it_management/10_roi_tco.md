# 🎯 IT 투자 성과 관리 — ROI, TCO, NPV

> **별점**: ★★★★★ | 기본 필수

## 1. 주요 재무 지표

```
[ROI (Return on Investment)]
ROI = (편익 - 비용) / 비용 × 100%
예) 시스템 구축 비용 10억, 5년간 편익 18억
  ROI = (18-10)/10 × 100% = 80%

[TCO (Total Cost of Ownership)]
TCO = 구매비 + 운영비 + 유지보수비 + 폐기비
직접비: 라이선스, HW, 구현
간접비: 교육, 다운타임 손실, 생산성 저하

클라우드 TCO vs 온프레미스:
- 초기: 클라우드 저렴 (CAPEX 없음)
- 장기: 대규모 시 온프레미스가 유리할 수 있음
```

## 2. NPV & IRR

```
[NPV (순현재가치)]
NPV = Σ(연도별 현금흐름 / (1+r)^n) - 초기투자
r: 할인율 (기회비용)
NPV > 0: 투자 가치 있음

예) 초기 10억, 매년 3억 편익, 할인율 10%, 5년
NPV = 3/(1.1) + 3/(1.1²) + ... + 3/(1.1⁵) - 10
    = 11.37억 - 10억 = 1.37억 > 0 (투자 타당)

[IRR (내부수익률)]
NPV = 0이 되는 할인율
IRR > 최소 요구 수익률 → 투자 가치
```

## 3. IT 투자 성과 측정

```
[BSC (Balanced Scorecard)]
재무 관점: ROI, 비용 절감
고객 관점: 만족도, 서비스 품질
내부 프로세스: 처리 시간, 자동화율
학습 & 성장: 직원 역량, IT 혁신

[가치 실현 관리]
IT 투자 → 중간 성과 → 최종 가치
예) ERP 도입 → 재고 감소 → 비용 절감 → ROI

ISACA Val IT 프레임워크:
IT 가치 거버넌스, 투자 관리, 포트폴리오 관리
```

## 4. 답안 포인트
