# 🎯 데이터 기반 경영 & CDO

> **별점**: ★★★★★ | ☆ 2026 예측

## 1. 데이터 기반 경영 (DDDM)

```
Data-Driven Decision Making:
데이터와 분석을 의사결정의 핵심 근거로 활용

[데이터 성숙도 모델]
Level 1 데이터 수집: 데이터 저장만
Level 2 데이터 접근: 리포팅, SQL 쿼리
Level 3 데이터 분석: BI, 트렌드 분석
Level 4 데이터 예측: ML 모델, 예측 분석
Level 5 데이터 처방: AI 자율 의사결정

[데이터 문화 3요소]
접근성: 모든 직원이 데이터 접근 가능
역량: 데이터 리터러시 교육
신뢰: 데이터 품질 보장 → 믿고 사용
```

## 2. CDO (Chief Data Officer)

```
역할: 데이터를 기업의 전략적 자산으로 관리
     데이터 거버넌스, 품질, 활용 전략 총괄

[CDO vs CIO vs CAO]
CIO: IT 인프라, 운영 안정성
CDO: 데이터 자산, 분석, 거버넌스
CAO: AI 전략, 모델, 윤리

[CDO 주요 책임]
데이터 전략: 데이터 비즈니스 가치 창출
거버넌스: 정책, 표준, 데이터 카탈로그
품질: MDM, 데이터 스튜어드 운영
분석: BI, 고급 분석, AI/ML 지원
규제: 개인정보보호, 컴플라이언스
```

## 3. 데이터 분석 도구 & 플랫폼

```
Self-Service BI:
  Tableau, Power BI, Looker
  → 비기술자도 직접 분석 가능

데이터 분석 언어:
  Python (pandas, scikit-learn), R
  SQL (복잡 분석 쿼리)
  Spark SQL (대규모 분산 분석)

GenAI 기반 분석:
  "지난달 매출 하락 원인이 뭐야?" → AI가 데이터 분석 후 설명
  → Text-to-SQL, 자연어 데이터 쿼리
```

## 4. 답안 포인트

**3단락**: ① DDDM 정의 & 데이터 성숙도 레벨 → ② CDO 역할 & CIO/CAO와의 차이 → ③ Self-Service BI & GenAI 기반 분석 트렌드

## 5. 관련 개념

`데이터 거버넌스(05_database)` → CDO 업무 기반 | `AI 기반 분석(10_ai)` → DDDM + AI = 처방적 분석 | `AX(★136회)` → AI로 DDDM 자동화
