# 🎯 CIO & CDO & IT 리더십

> **별점**: ★★★★☆ | ☆ 예측

## 1. IT 임원 역할

```
[CIO (Chief Information Officer)]
역할: IT 인프라·운영·전략 총괄
특성: 안정적 운영, 비용 효율
지표: 가용성, 시스템 비용, 서비스 수준

[CDO (Chief Digital Officer)]
역할: 디지털 전환 전략 주도
특성: 변화·혁신·신규 비즈니스 모델
지표: DX 진행률, 디지털 매출 비중

[CDO-D (Chief Data Officer)]
역할: 데이터 자산 관리, 거버넌스
특성: 데이터 품질, 분석, 규제 준수
지표: 데이터 품질, 분석 활용도

[CAO (Chief AI Officer)]
역할: AI 전략, 거버넌스, 윤리
신설 추세: 글로벌 기업 50% 이상 설치 (2025)
지표: AI ROI, 편향 없음, 규제 준수

[CISO (Chief Information Security Officer)]
역할: 보안 전략, 사이버 방어
지표: 침해 건수, 복구 시간, 컴플라이언스
```

## 2. 이원화 IT 전략 (Bimodal IT)

```
Gartner 제안:
Mode 1 (전통): 안정적, 예측 가능, 효율 중심
  → CIO 담당: ERP, 핵심 운영 시스템

Mode 2 (탐색): 민첩, 실험, 혁신 중심
  → CDO 담당: 디지털 신사업, AI, 앱

비판: 두 속도는 결국 충돌
현대 대안: DevOps로 속도와 안정성 동시 달성
```

## 3. IT 역량 변화

```
[현대 IT 리더 역량]
기술: 클라우드, AI, 보안, 데이터
비즈니스: P&L 이해, ROI 분석
변화관리: 조직 변화 이끌기
데이터 리터러시: 데이터 기반 의사결정
```

## 4. 답안 포인트

**3단락**: ① CIO/CDO/CAO/CISO 역할 구분 → ② 이원화 IT 전략(Bimodal IT) → ③ AI 시대 IT 리더십 역량 변화
