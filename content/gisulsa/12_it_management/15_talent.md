# 🎯 IT 인재 전략 & 조직 구조

> **별점**: ★★★☆☆ | 기본 필수

## 1. IT 조직 구조

```
[기능 조직 vs 스쿼드 조직]
전통 기능 조직:
  개발팀 | QA팀 | 운영팀 (사일로)
  장점: 전문성 집중
  단점: 협업 병목, 느린 배포

스쿼드/트라이브 (Spotify 모델):
  스쿼드(Squad): 7~10인 독립 팀
    자체 PO, 개발, 테스트, 운영 (교차기능)
  트라이브(Tribe): 관련 스쿼드 묶음
  챕터(Chapter): 동일 역할자 학습 그룹
  길드(Guild): 관심사 기반 커뮤니티

DevOps 조직:
  개발+운영 통합 → 배포 책임 개발팀
  "You build it, you run it" (아마존)
```

## 2. IT 인재 전략

```
[AI 시대 인재 수요]
AI/ML 엔지니어: 수요 급증
프롬프트 엔지니어: 신직종
DataOps/MLOps: 운영 자동화
사이버보안: 공격 증가 → 방어 인력 부족

[인재 확보 전략]
Build: 내부 육성 (교육, 순환 배치)
Buy: 경력직 채용 (빠르나 비쌈)
Borrow: 아웃소싱, 파트타임
Bot: AI 자동화 (인력 대체)

[인재 역량 5S]
Skill: 기술 역량 (클라우드, AI, 보안)
Speed: 빠른 학습, 민첩성
Scale: 대규모 시스템 설계
Strategy: 비즈니스 이해
Soft: 소통, 협업, 리더십
```

## 3. 답안 포인트

**3단락**: ① 기능조직 vs 스쿼드 조직 비교 → ② AI 시대 인재 수요 변화 → ③ 4B 인재 전략 (Build/Buy/Borrow/Bot)
