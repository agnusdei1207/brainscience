# 🎯 이노베이션 관리 & 린 스타트업

> **별점**: ★★★☆☆ | ☆ 예측

## 1. 이노베이션 유형

```
[혁신 유형 (클레이튼 크리스텐슨)]
존속적 혁신 (Sustaining Innovation):
  기존 제품 성능 개선
  기존 고객 대상, 기존 기업 강점

파괴적 혁신 (Disruptive Innovation):
  저가·단순 제품으로 새 시장 개척
  → 기존 강자 위협
  예) 스마트폰 vs 피처폰, 클라우드 vs IDC

디지털 파괴:
  디지털 기술로 전통 산업 재편
  예) 우버(택시), 에어비앤비(숙박), 넷플릭스(미디어)
```

## 2. 린 스타트업 (Lean Startup)

```
에릭 리스 제안:

[핵심 사이클]
구축(Build) → 측정(Measure) → 학습(Learn)
→ 피벗 or 지속

[MVP (Minimum Viable Product)]
가장 적은 노력으로 검증 가능한 최소 제품
→ 빠른 시장 피드백 수집

[가설 검증]
가설 수립 → MVP 제작 → 사용자 테스트
→ 데이터로 검증 → 피벗/지속

디자인 씽킹:
  공감→정의→아이디어→프로토타입→테스트
  사용자 중심 혁신
```

## 3. IT 기반 비즈니스 모델 혁신

```
[디지털 비즈니스 모델]
플랫폼: 생산자-소비자 연결 (카카오, 네이버)
구독: 정기 수익 (넷플릭스, SaaS)
데이터 비즈니스: 데이터 분석·판매
에코시스템: API로 파트너 연결

[IT 역할]
비용 센터 → 가치 창출 센터 → 수익 센터 진화
"IT as a Product" 관점 전환
```

## 4. 답안 포인트

**3단락**: ① 파괴적 혁신 정의 & 사례 → ② 린 스타트업 사이클 & MVP → ③ 디지털 비즈니스 모델 혁신 유형
