## 2. 그린 IT 전략

```

[SW 탄소 발자국]

그린SW 원칙: SCI 지표로 탄소 측정
```

## 3. 탄소 중립 IT

```
[3가지 감축 접근]
Scope 1: 직접 배출 (자체 발전기)
Scope 2: 구매 전력 (재생에너지 구매 = 0)
Scope 3: 공급망 배출 (가장 어려움)

목표:
넷제로: Scope 1+2+3 감축 + 흡수
탄소 네거티브: 배출보다 더 많이 흡수
탄소 중립: 배출+상쇄 = 0
```
