# 🎯 핵심 키워드: IaaS (Infrastructure as a Service), PaaS (Platform as a Service), SaaS (Software as a Service)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

IaaS는 가상 서버, 스토리지, 네트워크 등 인프라 자원을 서비스 형태로 제공하는 모델이다.  
PaaS는 애플리케이션 실행 환경과 미들웨어, 개발 플랫폼을 관리형으로 제공하여 개발 생산성을 높인다.  
SaaS는 최종 사용자가 즉시 사용하는 완성형 소프트웨어를 구독형으로 제공하는 서비스 모델이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | IaaS | PaaS | SaaS |
| --- | --- | --- | --- |
| 제공 범위 | 인프라 자원 | 실행 플랫폼 | 완성형 애플리케이션 |
| 고객 관리 범위 | OS 이상 직접 관리 | 애플리케이션·데이터 중심 | 설정과 사용 중심 |
| 장점 | 유연성과 제어권 높음 | 개발 생산성 우수 | 빠른 도입과 운영 부담 최소 |
| 단점 | 운영 책임 큼 | 플랫폼 제약 존재 | 커스터마이징 한계 |
| 시험 포인트 | Responsibility split | Managed runtime | Subscription service |
