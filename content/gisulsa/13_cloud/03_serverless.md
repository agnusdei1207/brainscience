# 🎯 핵심 키워드: 서버리스 (Serverless), FaaS (Function as a Service), 이벤트 기반 (Event-driven)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

서버리스는 서버 프로비저닝과 운영을 서비스 제공자가 관리하고 사용자는 코드와 이벤트 처리에 집중하는 실행 모델이다.  
FaaS는 함수 단위 코드를 이벤트에 따라 실행하고 사용량 기반으로 과금하는 서버리스의 대표 형태다.  
서버리스는 빠른 개발과 확장성 장점이 크지만 실행 시간 제약, 콜드스타트, 상태 관리 문제가 존재한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 서버리스 | 컨테이너 |
| --- | --- | --- |
| 운영 책임 | 인프라를 거의 관리하지 않음 | 런타임·배포 환경 직접 관리 |
| 과금 방식 | 실행량 기반 | 리소스 할당 기반 |
| 장점 | 빠른 개발과 자동 확장 | 유연한 제어와 장기 실행 적합 |
| 단점 | 콜드스타트와 제약 존재 | 운영 부담이 큼 |
| 적합 사례 | 이벤트 처리, 간헐적 워크로드 | 상태 있는 서비스, 복잡한 마이크로서비스 |
