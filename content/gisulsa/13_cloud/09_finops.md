# 🎯 FinOps — 클라우드 재무 운영

> **별점**: ★★★★★ | ★135회 기출

## 1. FinOps 정의

```
FinOps (Financial Operations):
클라우드 비용 가시성 확보, 최적화, 팀 간 공유를 통해
클라우드 소비를 비즈니스 가치와 연결하는 관행

3대 원칙:
팀이 협력: 엔지니어 + 재무 + 비즈니스 협력
클라우드 이익 활성화: 변동 비용이 혁신 기회
보고서 접근성: 실시간 비용 가시성

[FinOps 라이프사이클]
정보 제공 → 최적화 → 운영 → 반복
```

## 2. 클라우드 비용 최적화 전략

```
[비용 절감 레버]
예약 인스턴스 (Reserved Instance):
  1년/3년 약정 → 최대 72% 할인
  예측 가능한 워크로드에 적합

Spot 인스턴스 (Spot/Preemptible):
  잉여 용량 → 최대 90% 할인
  중단 가능 워크로드 (배치, 학습)

Savings Plans:
  AWS: 1~3년 약정, 서비스 유연
  RI보다 유연, 비슷한 할인율

Right-Sizing:
  실제 사용률 분석 → 과잉 사양 축소
  예) CPU 5% 사용 m5.2xlarge → m5.large

자동화:
  스케줄 기반 자원 해제 (dev 환경 주말 종료)
  오토스케일링으로 유휴 자원 제거
```

## 3. 비용 거버넌스

```
[태그 전략]
모든 자원에 태그 부착: 팀, 환경, 프로젝트
비용 분배: 태그 기반 팀별 비용 산정
예산 경보: 임계값 초과 시 알림

[비용 도구]
AWS Cost Explorer: 비용 분석, 예측
AWS Budgets: 예산 설정 & 경보
Infracost: 인프라 코드 비용 사전 예측
Kubecost: K8s 비용 배분
```

## 4. 답안 포인트

**3단락**: ① FinOps 정의 & 3대 원칙 → ② 비용 절감(RI/Spot/RightSizing) 전략 → ③ 비용 거버넌스(태그/예산/도구)
