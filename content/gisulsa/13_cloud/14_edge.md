# 🎯 엣지 컴퓨팅 & MEC (모바일 엣지 컴퓨팅)

> **별점**: ★★★★★ | ★135회 기출

## 1. 엣지 컴퓨팅

```
정의: 데이터 발생 지점(엣지)에서 직접 처리하는 분산 컴퓨팅
vs 클라우드: 데이터를 클라우드로 보내서 처리

[엣지가 필요한 이유]
지연 요구: 자율주행·AR/VR → 1~5ms 요구 (클라우드 왕복 100ms+)
대역폭: IoT 기기 수백만 → 모두 전송 불가
프라이버시: 민감 데이터 로컬 처리
오프라인: 연결 없어도 동작
```

## 2. MEC (Multi-Access Edge Computing)

```
정의: ETSI가 표준화한 5G 기지국 근처 클라우드 인프라
     → 이동 사용자를 위한 저지연 엣지

[MEC 아키텍처]
스마트폰 ─5G─→ [기지국 + MEC 서버] ─→ 클라우드
                       ↑
                  여기서 바로 처리 (1~5ms)

응용:
AR/VR 렌더링: MEC에서 클라우드 렌더링 → 폰 전송
자율주행 V2X: MEC에서 주행 계획 최적화
스마트팩토리: 이음5G + MEC = 실시간 제어
게임: 클라우드 게이밍 저지연
```

## 3. 엣지-클라우드 연속체

```
[컴퓨팅 스펙트럼]
디바이스 엣지 (온디바이스 AI):
  스마트폰, 자율주행 SoC
  예) Apple Silicon AI 추론

근거리 엣지 (Near Edge):
  공장 내부 엣지 서버
  MEC 기지국 근처

원거리 엣지 (Far Edge):
  리전 데이터센터 (클라우드 CDN PoP)

클라우드 코어:
  글로벌 데이터센터

[엣지 AI]
온디바이스: 데이터 전송 없이 AI 추론
프라이버시 보호: 사진·음성 로컬 처리
도구: TensorFlow Lite, ONNX Runtime, NPU
```

## 4. 답안 포인트

**3단락**: ① 엣지 컴퓨팅 정의 & 필요성(지연/대역폭) → ② MEC 아키텍처 & 5G 연계 → ③ 엣지-클라우드 연속체 & 온디바이스 AI
