# 🎯 핵심 키워드: DW (Data Warehouse), 데이터 마트 (Data Mart), 데이터 레이크 (Data Lake)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

데이터 웨어하우스는 주제 지향, 통합, 시계열, 비휘발성 특성을 가진 분석용 데이터 저장소다.  
데이터 마트는 부서나 특정 업무 목적에 맞춘 소규모 분석 저장소로, DW의 부분집합 또는 독립형으로 운영된다.  
데이터 레이크는 구조화·비구조화 데이터를 원본 형태로 대규모 저장하는 유연한 저장소다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | DW | 데이터 레이크 | 데이터 마트 |
| --- | --- | --- | --- |
| 데이터 형태 | 정제된 구조화 데이터 | 원본 포함 다양한 형식 | 업무 목적 중심 데이터 |
| 장점 | 분석 성능과 일관성 우수 | 유연성과 저장 확장성 우수 | 사용자 접근성이 좋음 |
