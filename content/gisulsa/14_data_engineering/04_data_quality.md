# 🎯 핵심 키워드: 데이터 품질 (Data Quality), 라인리지 (Lineage), 데이터 카탈로그 (Data Catalog)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

데이터 품질은 정확성, 완전성, 일관성, 적시성 등 데이터가 사용 목적에 부합하는 수준을 의미한다.  
라인리지는 데이터가 어디서 왔고 어떤 변환을 거쳐 어디로 소비되는지 추적하는 계보 정보다.  
데이터 카탈로그는 메타데이터와 소유자, 용어, 사용 방법을 정리해 데이터 탐색성과 거버넌스를 높이는 체계다.

| 포인트 | 내용 | 채점 비중 |

## 3. 답안 목차 템플릿 (Answer Outline Template)

문제: "데이터 품질, 라인리지, 카탈로그의 역할과 연계 방안을 설명하시오."

```text
Ⅰ. 개요
   1. 정의
   2. 데이터 신뢰성과 규제 대응 요구 확대

Ⅱ. 핵심 구성요소
   1. 품질 관리 개념
   2. 계보와 메타데이터 운영

Ⅲ. 특징 및 장단점
   1. 데이터 신뢰도와 탐색성 향상
   2. 도구만 도입하고 운영 책임이 없으면 실패

Ⅳ. 유사 기술과의 비교
   - 데이터 품질 vs 라인리지 vs 데이터 카탈로그 비교표

Ⅴ. 적용사례 및 향후전망
   1. 데이터 거버넌스와 규제 대응 플랫폼 구축
   2. Active metadata와 데이터 관측성 도구 발전
```

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 데이터 품질 | 라인리지 | 데이터 카탈로그 |
| --- | --- | --- | --- |
| 핵심 질문 | 데이터가 믿을 만한가? | 어디서 와서 어디로 가는가? | 무엇이 있고 누가 책임지는가? |
| 대표 기능 | 규칙 검증, 알림 | 변환 추적, 영향 분석 | 검색, 태깅, 용어집 |
| 장점 | 의사결정 신뢰 향상 | 문제 원인 분석 용이 | 셀프서비스 분석 지원 |
| 단점 | 규칙 설계와 유지비 필요 | 추적 범위 누락 가능 | 메타데이터 갱신 소홀 위험 |
| 시험 포인트 | Accuracy | Traceability | Discoverability |

## 5. 인출 훈련 문제 (Output Drills)

### 단답형 (30초)
1. 데이터 품질 (Data Quality)의 정의를 한 문장으로 쓰시오.
2. 데이터 품질·라인리지·카탈로그 답안에서 반드시 써야 할 핵심 구성요소 3가지를 나열하시오.
3. 데이터 품질와 라인리지 vs 데이터 카탈로그의 가장 큰 차이점을 설명하시오.
4. "신뢰성, 추적성, 탐색성 3축으로 구분해 말하는 연습"를 답안 키워드 3개로 압축하시오.
5. 데이터 거버넌스와 규제 대응 플랫폼 구축 중 하나를 들고 기대효과 2가지를 말하시오.

### 서술형 (5분)
6. "데이터 품질, 라인리지, 카탈로그의 역할과 연계 방안을 설명하시오."의 핵심 구성요소와 기대효과를 5분 답안으로 정리하시오.
7. "데이터 품질 vs 라인리지 vs 데이터 카탈로그"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
8. "데이터 품질, 라인리지, 카탈로그의 역할과 연계 방안을 설명하시오." (개념, 구조, 비교, 적용사례, 향후전망 포함)
