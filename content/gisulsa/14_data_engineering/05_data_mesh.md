# 🎯 핵심 키워드: 데이터 메시 (Data Mesh), 데이터 패브릭 (Data Fabric), 데이터 제품 (Data Product)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

데이터 메시는 도메인별 팀이 데이터를 제품처럼 소유·제공하도록 조직과 아키텍처를 재설계하는 접근이다.  
데이터 패브릭은 분산된 데이터 자산을 메타데이터와 자동화 계층으로 연결해 일관된 접근과 관리를 제공하는 구조다.  
둘 다 데이터 사일로 해소를 목표로 하지만, 메시가 조직 운영 모델에 더 초점을 두고 패브릭은 통합 기술 계층에 초점을 둔다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 데이터 메시 | 데이터 패브릭 |
| --- | --- | --- |
| 주 초점 | 조직·운영 모델 | 기술 통합·자동화 |
| 핵심 개념 | 도메인 소유 데이터 제품 | 메타데이터 기반 연결 |
| 장점 | 도메인 민첩성과 책임 강화 | 이기종 데이터 통합 효율 |
| 단점 | 거버넌스 분산 위험 | 도구 중심으로 끝날 수 있음 |
| 시험 포인트 | Data product | Metadata automation |

## 5. 인출 훈련 문제 (Output Drills)

### 단답형 (30초)
1. 데이터 메시 (Data Mesh)의 정의를 한 문장으로 쓰시오.
2. 데이터 메시·데이터 패브릭 답안에서 반드시 써야 할 핵심 구성요소 3가지를 나열하시오.
3. 데이터 메시와 데이터 패브릭의 가장 큰 차이점을 설명하시오.
4. "조직 관점과 기술 관점을 분리해 설명하는 연습"를 답안 키워드 3개로 압축하시오.
5. 대기업 데이터 조직 개편과 플랫폼 전략 수립 중 하나를 들고 기대효과 2가지를 말하시오.

6. "데이터 메시와 데이터 패브릭의 개념 및 차이를 설명하시오."의 핵심 구성요소와 기대효과를 5분 답안으로 정리하시오.
7. "데이터 메시 vs 데이터 패브릭"의 선택 기준과 실패 시 발생하는 운영 리스크를 서술하시오.

### 답안 작성 (25분)
8. "데이터 메시와 데이터 패브릭의 개념 및 차이를 설명하시오." (개념, 구조, 비교, 적용사례, 향후전망 포함)
