# 🎯 핵심 키워드: 데이터 패브릭, 데이터 메시, 데이터 민주화, 분산 소유권

> **출제 빈도**: ★★★★★ | **기출**: ★135회 (데이터 거버넌스 핵심 트렌드)

## 1. 정의

**데이터 패브릭(Data Fabric)**: 이기종 데이터 소스를 **통합된 메타데이터와 자동화**로 연결하는 데이터 관리 아키텍처. 중앙 집중식.

**데이터 메시(Data Mesh)**: 데이터를 **도메인별로 분산 소유**하고 각 도메인이 데이터 제품을 책임지는 분산 아키텍처. 탈중앙화.

## 2. 비교

| 항목 | 데이터 패브릭 | 데이터 메시 |
|------|-------------|-----------|
| 조직 구조 | 중앙 데이터팀 | 도메인별 분산팀 |
| 소유권 | 중앙화 | 도메인 소유 |
| 통합 방식 | 기술적 통합 (메타데이터) | 사회적/조직적 통합 |
| 거버넌스 | 중앙 정책 | 연합 거버넌스 |
| 적합 규모 | 중소 기업 | 대기업, 복잡한 도메인 |

## 3. 답안 목차 템플릿

**문제**: "데이터 패브릭과 데이터 메시의 개념을 비교하고, 데이터 민주화와의 관계를 설명하시오."

```
I. 데이터 거버넌스의 발전
   데이터 웨어하우스 → 데이터 레이크 → 레이크하우스 → 패브릭/메시
   
   기존 문제: 중앙 데이터팀 병목, 데이터 사일로, 느린 분석

II. 데이터 패브릭 (Data Fabric)
   
   [데이터 패브릭 아키텍처]
   다양한 소스 (온프레미스, 클라우드, SaaS)
        ↓ 자동 메타데이터 수집
   통합 메타데이터 레이어 (지식 그래프)
        ↓ AI 기반 데이터 발견·연결
   통합 데이터 접근 레이어
        ↓
   분석, AI/ML, 리포팅
   
   핵심 기능:
   - 메타데이터 자동 수집 및 카탈로그
   - AI 추천: "이 데이터를 찾으세요"
   - 데이터 계보(Lineage) 자동 추적
   - 구현: IBM Cloud Pak, AWS Lake Formation, Azure Purview

III. 데이터 메시 (Data Mesh) — Zhamak Dehghani 제안
   
   4가지 원칙:
   1. 도메인 지향 분산 소유권
      - 각 도메인(결제팀, 물류팀)이 자신의 데이터 소유
      - "데이터 제품(Data Product)" 개념
   
   2. 데이터를 제품으로 (Data as a Product)
      - 소비자 관점: 발견 가능, 신뢰 가능, 자가 서비스
      - 품질 SLA, 문서화, API 제공
   
   3. 셀프서비스 데이터 인프라 플랫폼
      - 도메인팀이 쉽게 데이터 제품 생성/관리
   
   4. 연합 거버넌스 (Federated Governance)
      - 글로벌 정책 + 도메인 자율성
      - 표준 메타데이터 스키마, 개인정보 정책

IV. 데이터 민주화 (Data Democratization) 연계
   - 목표: 비기술직 직원도 데이터 분석 가능
   - 패브릭+메시 → 데이터 민주화의 기술/조직 기반
   - 도구: Self-service BI (Tableau, Power BI, Looker)
   - 데이터 리터러시 교육 + 거버넌스 = 민주화 완성
```

## 4. 핵심 암기 포인트

- **패브릭**: 기술적 통합, 중앙 메타데이터
- **메시**: 조직적 분산, 도메인 소유권
- **데이터 제품**: 메시의 핵심 — 발견·신뢰·자가서비스 가능한 데이터 API
