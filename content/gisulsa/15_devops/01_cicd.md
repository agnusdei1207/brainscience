# 🎯 핵심 키워드: CI (Continuous Integration), CD (Continuous Delivery/Deployment), GitOps

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

CI는 코드 변경을 자주 통합하고 자동 빌드·테스트하여 통합 리스크를 줄이는 실천이다.  
CD는 검증된 변경을 일관된 방식으로 전달하거나 자동 배포하여 릴리스 리드타임을 줄이는 체계다.  
GitOps는 선언형 인프라/애플리케이션 상태를 Git을 단일 진실원으로 관리하고 자동 동기화하는 운영 방식이다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | CI | CD | GitOps |
| --- | --- | --- | --- |
| 핵심 목표 | 통합 품질 확보 | 배포 자동화 | 운영 상태 일관성 유지 |
| 대표 도구 | Jenkins, GitHub Actions | Argo Rollouts, Spinnaker | Argo CD, Flux |
| 장점 | 통합 문제 조기 발견 | 릴리스 속도 향상 | 감사 추적과 드리프트 교정 |
| 단점 | 느린 테스트 병목 | 실수 전파 가능 | 선언형 관리 체계 필요 |
| 시험 포인트 | Build/Test | Release automation | Git as source of truth |
