# 🎯 핵심 키워드: DevSecOps, SAST (Static Application Security Testing), DAST (Dynamic Application Security Testing), SBOM (Software Bill of Materials)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

DevSecOps는 보안을 개발과 배포 파이프라인에 내재화하여 빠른 전달과 안전성을 동시에 달성하려는 접근이다.  
SAST는 소스코드·바이너리 수준에서 정적 분석으로 취약점을 찾고, DAST는 실행 중 애플리케이션에 공격을 시도해 취약점을 발견한다.  
SBOM은 소프트웨어 구성요소와 의존성 목록을 명세해 공급망 보안과 취약점 추적의 기반을 제공한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | SAST | DAST | SCA |
| --- | --- | --- | --- |
| 탐지 시점 | 개발 단계 | 실행 단계 | 의존성·라이브러리 분석 |
| 장점 | 코드 수준 문제 조기 발견 | 실행 환경 기준 현실적 탐지 | 공급망 취약점 가시성 확보 |

| 적합 사례 | 개발 파이프라인 초기 | 릴리스 전 검증 | 오픈소스 관리 |
| 시험 포인트 | Static scan | Dynamic scan | Dependency risk |
