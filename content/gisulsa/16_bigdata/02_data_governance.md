# 🎯 핵심 키워드: 데이터 거버넌스 (Data Governance), MDM (Master Data Management), 데이터 표준화 (Data Standardization)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

데이터 거버넌스는 데이터 소유권, 품질, 표준, 보안, 활용 정책을 조직적으로 관리하는 체계다.  
MDM은 고객, 상품, 조직 같은 핵심 기준정보를 일관성 있게 관리하여 전사 데이터 정합성을 높이는 활동이다.  
표준화는 용어, 코드, 메타데이터를 통일해 데이터 통합과 활용성을 높이는 기반이다.
