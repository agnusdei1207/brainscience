# 🎯 핵심 키워드: BI (Business Intelligence), OLAP (Online Analytical Processing), 데이터 분석 (Data Analytics)

> **출제 빈도**: ★★★★★ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

BI는 데이터를 시각화하고 지표화하여 경영 의사결정을 지원하는 분석 체계다.  
OLAP은 다차원 구조를 기반으로 집계, Drill-down, Slice & Dice 분석을 빠르게 수행하는 분석 방식이다.  
데이터 분석은 통계, 시각화, 모델링을 통해 패턴과 인사이트를 도출하는 활동으로 BI보다 범위가 넓다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | OLTP | OLAP |
| --- | --- | --- |
| 목적 | 일상 거래 처리 | 분석과 의사결정 지원 |
| 데이터 특성 | 정규화·실시간 갱신 | 집계·주제 중심 |
| 장점 | 정합성과 빠른 트랜잭션 | 복잡한 분석 쿼리에 유리 |
| 단점 | 분석 질의 부적합 | 실시간 갱신은 상대적으로 약함 |
| 시험 포인트 | Transaction | Multidimensional analysis |
