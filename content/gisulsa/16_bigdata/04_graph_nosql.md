# 🎯 핵심 키워드: 그래프 데이터베이스 (Graph Database), 문서형 NoSQL (Document NoSQL), 관계 탐색 (Relationship Traversal)

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★☆☆

## 1. 정의 (Definition)

그래프 데이터베이스는 노드와 엣지로 관계를 저장하고 탐색하는 데 최적화된 NoSQL 유형이다.  
문서형 NoSQL은 JSON 유사 문서 단위로 데이터를 저장하여 유연한 스키마와 빠른 개발을 지원한다.  
관계가 깊고 연결 중심 질의가 많을수록 그래프 DB가 유리하며, 콘텐츠·이벤트 저장에는 문서형이 적합한 경우가 많다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 그래프 DB | 문서형 NoSQL |
| --- | --- | --- |
| 모델 | 노드·엣지 중심 | 문서 중심 |
| 장점 | 관계 탐색 질의에 강함 | 스키마 유연성과 개발 속도 우수 |
| 단점 | 대량 단순 집계에는 불리할 수 있음 | 복잡한 관계 탐색은 비효율 가능 |
| 적합 사례 | 추천, 사기탐지, 네트워크 | 콘텐츠, 프로필, 이벤트 로그 |
| 시험 포인트 | Traversal | Schema flexibility |
