# 🎯 핵심 키워드: AI + BigData, 특징 저장소 (Feature Store), Lakehouse

> **출제 빈도**: ★★★★☆ | **난이도**: ★★★★☆

## 1. 정의 (Definition)

AI와 빅데이터 융합은 대규모 데이터 수집·처리 플랫폼 위에 모델 학습·서빙 체계를 결합해 지능형 서비스를 구현하는 접근이다.  
Feature Store는 학습·추론에 쓰이는 특징을 일관되게 관리하여 데이터/모델 불일치를 줄이는 저장·제공 계층이다.  
Lakehouse는 데이터 레이크의 유연성과 웨어하우스의 관리 기능을 결합해 AI·분석 공통 기반을 제공한다.

## 4. 핵심 비교표 (Key Comparison Table)

| 구분 | 전통 BI 분석 | AI 주도 분석 |
| --- | --- | --- |
| 주요 목적 | 과거 데이터 설명과 시각화 | 예측·추천·자동화 |
| 데이터 활용 | 집계 중심 | 대규모 특징·학습 데이터 활용 |
| 장점 | 이해와 보고에 강함 | 행동 유도와 자동 의사결정 가능 |
| 단점 | 예측 능력 제한 | 운영 복잡도와 모델 리스크 존재 |
| 시험 포인트 | Descriptive analytics | Predictive/automated analytics |
