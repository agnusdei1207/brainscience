# 🎯 텍스트 마이닝 & 자연어 처리 (NLP)

> **별점**: ★★★★☆ | ★135회 연계

## 1. NLP 기본 과제

```
[핵심 NLP 태스크]
형태소 분석: 단어를 최소 의미 단위로 분리
  예) "나는학교에간다" → 나/는/학교/에/가/ㄴ다

개체명 인식 (NER): 텍스트에서 이름·날짜·기관 추출
  예) "[삼성전자]는 [2024년]에 실적을 발표했다"

감성 분석: 텍스트의 긍정/부정/중립 분류
  소셜 미디어, 리뷰 분석

텍스트 분류: 카테고리 분류
  예) 뉴스 주제 분류, 스팸 필터

기계 번역: 한국어 → 영어
  Seq2Seq, Transformer 기반

요약 (Summarization):
  추출적: 중요 문장 선택
  추상적: 새 문장 생성 (LLM)

[전통 NLP vs LLM]
전통: TF-IDF, Word2Vec, BERT 파인튜닝
LLM: GPT-4, Claude, HyperCLOVA X
     → 프롬프트만으로 모든 NLP 태스크 수행
```

## 2. 텍스트 벡터화

```
TF-IDF:
  TF(단어 빈도) × IDF(문서 역빈도)
  키워드 추출, 문서 유사도

Word2Vec:
  단어 → 벡터 (의미 공간)
  왕-남자+여자 ≈ 여왕 (벡터 연산)

BERT:
  양방향 트랜스포머, 문맥 이해
  분류·QA·NER 파인튜닝

임베딩 → 벡터DB에 저장 → 유사 검색 (RAG)
```

## 3. 답안 포인트

**3단락**: ① NLP 핵심 태스크 분류 → ② TF-IDF → Word2Vec → BERT 진화 → ③ LLM 시대 NLP 변화 & RAG 연계

## 4. 관련 개념

`LLM(10_ai)` → NLP의 현대적 통합 모델 | `벡터DB(05_db 09번)` → 텍스트 임베딩 저장 | `RAG(10_ai)` → NLP + 벡터 검색
