# 🎯 통계 & 기초 확률 (기술사 시험용)

> **별점**: ★★★★★ | 기본 필수

## 1. 가설 검정 (Hypothesis Testing)

```
귀무가설(H0) vs 대립가설(H1)

[검정 절차]
① 가설 설정: H0(효과 없음) vs H1(효과 있음)
② 유의수준 α 결정 (보통 0.05)
③ 검정통계량 계산 (t-통계량, z-통계량)
④ p-value 계산: H0가 맞을 때 현재 데이터 관측 확률
⑤ 결정: p < α → H0 기각 (대립가설 지지)

[오류 유형]
1종 오류(α): H0 참이지만 기각 (거짓 양성)
2종 오류(β): H0 거짓이지만 채택 (거짓 음성)
검정력 = 1-β: H0 거짓일 때 기각 확률
```

## 2. 상관 & 회귀

```
[피어슨 상관계수]
r: -1에서 1 사이
|r| > 0.7: 강한 상관
상관 ≠ 인과 (주의!)

[선형 회귀]
y = β0 + β1x + ε
β0: 절편, β1: 기울기
R²: 설명력 (0~1, 높을수록 좋음)

[다중 회귀]
여러 독립변수 → 하나 종속변수
다중공선성: 독립변수 간 상관 → VIF로 진단
```

## 3. 머신러닝 평가 지표

```
[분류 모델]
혼동 행렬:
       예측 Pos  예측 Neg
실제 P  TP       FN
실제 N  FP       TN

정밀도(Precision) = TP/(TP+FP): 양성 예측 정확도
재현율(Recall) = TP/(TP+FN): 실제 양성 탐지율
F1 = 2 × (P×R)/(P+R): 균형 지표
AUC-ROC: 분류 경계 무관한 성능

[회귀 모델]
MAE, MSE, RMSE, MAPE
```

## 4. 답안 포인트

**3단락**: ① 가설 검정 절차 & 1/2종 오류 → ② 상관 vs 인과, 회귀 분석 → ③ 머신러닝 평가 지표(정밀도/재현율/F1)
