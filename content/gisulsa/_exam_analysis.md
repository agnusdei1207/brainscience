> 검증 기출: 131회(2023) ~ 136회(2025.05)
> 작성일: 2026-05-17

## 1. 공식 출제기준 (2023.1.1 ~ 2026.12.31)

| 대분류 | 세부 항목 |
|--------|----------|
| **1. 컴퓨터 기초이론** | 이산구조, 알고리즘, 자료구조(스택/큐/트리/그래프), 수치해석 |
| **2. 하드웨어 시스템** | HW 구성/설계, 처리장치, 저장장치, 입출력장치, 인터페이스 설계, 디바이스 드라이버 |
| **3. 시스템/응용 SW** | 운영체제, 시스템 프로그래밍, 언어론, 컴파일러, SW공학, DBMS, 앱 설계/테스트, 임베디드 |
| **4. 통신 및 네트워크** | 통신 인터페이스, 프로토콜 분석, 네트워크 설계/품질평가, 유무선 장비 |
| **5. 시스템 보안** | 보안체계 운영관리, 보안감사, 보안인증, 보안 운영관리 |
| **6. 법규/정책/표준** | 개인정보보호법, IT투자/성과관리, 국내외 표준, 가이드라인 |

## 2. 회차별 실제 기출 (컴퓨터시스템응용기술사 확인분)

### 131회 (2023)
| 영역 | 실제 출제 키워드 |
|------|----------------|
| HW/아키텍처 | PNM(Processing Near Memory), 칩렛(Chiplet), SDN |
| 알고리즘/AI | 몬테카를로 방법, 오토인코더, 전이학습, 알고리즘 복잡도, MDP, 강화학습 |
| DB | NoSQL CAP 이론, DB 용량산정, 분산DB 투명성 |
| 보안/제도 | CSRF, CBPR, 지능정보화 기본법, Zero Trust, ISMS-P |
| 네트워크/기타 | NaaS, RPA, xAPI, ATAM/CBAM |

### 132회 (2024.01)
| 영역 | 실제 출제 키워드 |
|------|----------------|
| HW/아키텍처 | **TCAM**, **폴락의 법칙(Pollack's Rule)**, 스래싱(Thrashing) |
| 자료구조/OS | 선형 자료구조/스택/큐, 세마포어(Semaphore), 프로세스 입출력 원리 |
| 네트워크 | TCP 4-way handshake, NRTK(실시간 측위) |
| SW/관리 | SW 기술성 평가기준, PMO(전자정부사업관리), 카나리 테스트 |
| 보안 | ISA/IEC 62443, 사용자 인증(지소존행) |
| 기타 | 디지털 리터러시, 생성형 AI |

### 133회 (2024.05)
| 영역 | 실제 출제 키워드 |
|------|----------------|
| SW/아키텍처 | REST API, 뮤테이션 테스트(Mutation Test), NoSQL, 쿠버네티스, SW 요구공학, 3R(유지보수) |
| 보안 | 전자봉투, 동형암호, BCP/DRS, 딥페이크, 안티포렌식, 생성형 AI 보안 가이드라인 |
| AI/데이터 | AI 신뢰성, 인공신경망(피드포워드/역전파/활성화함수), CRUD 매트릭스 |
| 네트워크/기타 | TCP 3-way/4-way handshake, 슈퍼앱, 디지털 정부서비스 UI/UX 가이드라인 |

### 134회 (2024.07)
| 영역 | 실제 출제 키워드 |
|------|----------------|
| 최신 HW/AI | **Wi-Fi 7**, **온디바이스 AI**, **멀티모달 AI**, 촉각 인터넷(Tactile Internet), NPU |
| 보안 | 제로데이 취약점, **Zero Trust**, **SBOM**, 스푸핑 공격(ARP/IP/DNS), WAF/IDS/IPS |
| 시스템/네트워크 | **플랫폼 엔지니어링**, PoE, 디지털 계위(PDH/SDH/SONET), **교착상태**, OSI 7계층 |
| 감리/제도 | EA 도입운영 지침, 지능정보기술 감리 실무, SP 품질인증, ISMS-P 간편인증, **ISO 26262** |

### 135회 (2025.02)
| 영역 | 실제 출제 키워드 |
|------|----------------|
| AI/데이터 | **RAG**, 멀티모달 데이터 품질(TTAK.KO-10.1558), 생성형 AI, MCTS(몬테카를로 트리 탐색), 차원의 저주 |
| 아키텍처 | 모놀리식 vs MSA, 멀티클라우드, **MMU**, OS 태스크 우선순위 상속 |
| 보안/네트워크 | 접근통제 모델(MAC/DAC/RBAC/ABAC), 채널용량(샤논 제3정리), **ETSI ZSM** |
| 제도/기타 | 지식재산권, SOAP vs REST, 정보시스템 HW 규모산정 지침, 스마트시티 |

## 3. 파이프라이닝(Pipeline) 출제 현황 — 명확히 정리

> [!WARNING]
> **131~136회에서 파이프라이닝 직접 출제 확인되지 않음**
> 출제기준(처리장치 설계)에 포함된 전통 토픽이나, 최근 기출 복원 자료에서 직접 출제 증거 없음.
> 기본 이론 이해 수준 유지하되, 최우선 순위는 아님.

## 4. 실제 출제 패턴 분석

### 4.1 컴퓨터시스템응용 고유 출제 특성

1. **하드웨어 심화 문제** 매회 포함 (HW 규모산정, 처리장치 원리, 스토리지)
2. **국내 가이드라인/법령** 필수 (EA 지침, SW 기술성 평가, 감리 실무 가이드)
3. **표준 번호 암기 필요** (TTAK, ISO, IEC, ITU-T 등 구체적 표준 명칭)
4. **정보관리기술사와 공통 출제** 영역 존재 (보안, AI, 클라우드)
5. **임베디드/실시간 시스템** 관련 문제 주기적 출제 (RTOS, ISO 26262 등)

### 4.2 최근 5회차 출제 비중

| 영역 | 출제 비중 | 트렌드 |
|------|----------|--------|
| AI/LLM/에이전틱 | ★★★★★ | 급증 |
| 보안 (제로트러스트/공급망) | ★★★★★ | 매회 |
| 하드웨어 (NPU/온디바이스) | ★★★★☆ | 증가 |
| 국내 표준/가이드라인 | ★★★★☆ | 매회 |
| OS/프로세스/동기화 | ★★★★☆ | 매회 |
| 네트워크 (SDN/5G) | ★★★☆☆ | 유지 |
| 알고리즘/자료구조 | ★★★☆☆ | 유지 |
| DB/분산시스템 | ★★★☆☆ | 유지 |
| 클라우드/MSA | ★★★☆☆ | 증가 |
| 전통 컴퓨터구조 | ★★☆☆☆ | 감소 |
