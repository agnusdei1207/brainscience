## 0. 핵심 인사이트

> **핵심**: 정전용량 (Capacitance, C = Q/V)은 두 도체 사이에 전하를 저장할 수 있는 능력이며, DRAM은 High-K로 C를 극대화해야 하고 로직 배선은 Low-K로 기생 C를 극소화해야 하는 상충 관계가 설계 핵심이다.
> **비유**: 물탱크(DRAM)는 크게, 하수구(배선 간 누수)는 없애야 한다.

--- 📝 모범 답안 ---

## 1. 개요 및 필요성

정전용량은 단위 전압당 저장 전하량(패럿, F)이다. C = ε × A / d — 유전율(ε)과 면적(A)에 비례, 거리(d)에 반비례한다. DRAM 셀은 비트 에러 방지를 위해 최소 10~25fF을 확보해야 하지만, 로직 배선이 미세화되면 배선 간 기생 정전용량이 폭증하여 RC 지연의 주범이 된다.

---

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| DRAM 셀 커패시턴스 | 1비트 데이터 판별 | High-K 유전체로 용량 확보 |
| 기생 커패시턴스 (Parasitic C) | 배선 간 원치 않는 전하 축적 | Low-K·Air Gap으로 억제 |
| PDN 디커플링 C | 순간 전압 강하 완충 | 코어 가까이 고C 배치 |
| 크로스톡 결합 C | 인접 배선 신호 간섭 | GND 쉴드로 차단 |

---

## 3. 구조 및 원리

**핵심 수식**: C = ε × A / d

설계 상충:
1. DRAM: 면적(A) 수직 확장(3D 실린더) + 유전율(ε) 극대화(High-K) → C 최대화
2. 로직 배선: 유전율(ε) 극소화(Low-K, Air Gap) + 간격(d) 확보 → 기생 C 최소화
3. 기생 C 증가 → RC 지연 → 클럭 주파수 제한
4. 크로스톡: 인접 배선의 전기장이 상대측 신호를 왜곡

라우팅 규칙: 1층은 X축, 2층은 Y축 직교로 마주 보는 면적(A)을 최소화한다.

---

## 4. 비교 및 연결

| 항목 | 목적형 C (DRAM, 디커플링) | 기생 C (배선 간) |
|:---|:---|:---|
| 공정 전략 | High-K, 트렌치/3D 적층 | Low-K, Air Gap |
| 유전율 방향 | 극대화 | 극소화 |
| 실패 시 영향 | 비트 에러, 전압 강하 | RC 지연, 크로스톡 |

동일 칩 내에서 구역별로 유전체 전략이 180° 다르며, 이 상충 관리가 공정 설계의 핵심이다.

---

## 5. 실무 적용 및 판단

**채택**: 직교 라우팅(X/Y 교차), GND 쉴드 삽입, STA로 RC 핫스팟 검증
**회피**: 다층 배선을 같은 방향으로 평행 겹침(기생 C 폭탄), Low-K 적용 시 기계적 강도 무시

체크리스트:
1. 배선 간 RC 지연이 목표 클럭 타임을 초과하는 핫스팟이 STA로 검증되었는가?
2. Low-K 절연막이 패키징 압력을 견딜 기계적 강도를 확보했는가?
3. 고속 병렬 버스에 GND 쉴드가 삽입되어 크로스톡을 억제하는가?

---

## 6. 기대효과 및 결론

정전용량의 이중성을 구역별로 제어하면 DRAM 보존력과 GHz급 클럭 스위칭을 동시에 달성한다. 한계는 미세화에 따른 기생 C 폭증이며, Air Gap 공정과 양자 정전용량(Quantum Capacitance) 제어가 차세대 과제다. **정전용량은 정보를 저장하는 축복이자 속도를 늦추는 저주다.**

## 7. 관련 개념 맵 및 발전 흐름도

| 개념 | 연결 포인트 |
|:---|:---|
| 기생 커패시턴스 (Parasitic C) | 배선 밀집 시 의도치 않은 C 형성 → 신호 지연 |
| Low-K / High-K | 배선용 저유전 vs 메모리용 고유전 소재 대비 |
| 크로스톡 (Crosstalk) | 인접 배선 C 결합에 의한 노이즈 간섭 |
| RC 지연 | R × C → 신호 상승 시간 지연 |

```
C = εA/d (기본 수식)
    ↓
DRAM: High-K · 3D 적층
    ↓
로직: Low-K · Air Gap
    ↓
크로스톡 · RC 지연 관리
    ↓
양자 정전용량 제어
```
