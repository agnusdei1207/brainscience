## 0. 핵심 인사이트

> **핵심**: 멀티플렉서 (Multiplexer, MUX)는 2ⁿ개의 입력 중 n비트 선택 신호에 의해 단 하나의 입력을 출력으로 라우팅하는 조합 논리회로다.
> **비유**: 여러 방송 신호 중 리모컨 버튼(선택 신호)으로 하나의 채널만 화면(출력)에 띄우는 것과 같다.

---

> 📝 모범 답안

## 1. 개요 및 필요성

멀티플렉서는 다수의 데이터 소스 중 하나를 선택해 단일 경로로 전송하는 장치다. 제한된 통신 선로나 시스템 자원을 여러 장치가 공유하기 위해 필수적으로 요구된다. 만약 MUX가 없다면 모든 데이터 소스마다 별도의 물리적 배선이 필요해져 하드웨어 면적과 비용이 기하급수적으로 증가하게 된다.

---

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| 데이터 입력 (Data Input) | 전송될 원본 신호 제공 | 2ⁿ개 입력선 구성 |
| 선택 신호 (Select Line) | 어느 입력을 출력할지 결정 | n비트 제어선 |
| 출력 (Output) | 선택된 단일 데이터 전달 | 1개 출력선 |
| AND/OR 게이트 | 논리 조합 및 신호 통과 제어 | 진리표 기반 매핑 |

---

## 3. 구조 및 원리

**핵심 조건**: 출력 $Y = \sum (S_{조합} \cdot I_k)$ (선택 신호와 해당 입력의 AND 연산 총합)

동작 순서:
1. n비트의 선택 신호 입력 수신
2. 선택 신호의 조합에 따라 2ⁿ개의 내부 AND 게이트 중 단 하나만 활성화
3. 활성화된 AND 게이트를 통해 매칭되는 데이터 입력 신호가 통과
4. 모든 AND 게이트의 출력이 하나의 OR 게이트로 모임
5. 최종적으로 선택된 입력만이 OR 게이트를 거쳐 단일 출력됨

---

## 4. 비교 및 연결

| 항목 | 멀티플렉서 (MUX) | 디멀티플렉서 (DEMUX) |
|:---|:---|:---|
| 데이터 흐름 | 다수 입력 → 단일 출력 (N:1) | 단일 입력 → 다수 출력 (1:N) |
| 활용 목적 | 데이터 선택, 시분할 송신 | 데이터 분배, 시분할 수신 |
| 회로 구조 | AND 게이트 배열 후 단일 OR 합산 | 단일 입력과 선택 신호를 AND로 분기 |

MUX는 데이터를 하나로 모으고 DEMUX는 다시 분배하는 역관계로, 통신 채널에서 항상 쌍으로 연동되어 시분할 다중화 (Time Division Multiplexing)를 구현한다. MUX는 CPU 데이터패스 내 ALU 입력 선택에도 직결된다.

---

## 5. 실무 적용 및 판단

**채택**: ALU 입력 소스 선택, FPGA의 LUT (Look-Up Table) 구성, 공용 버스 데이터 라우팅
**회피**: 입력 수가 너무 많아 회로 지연시간이 클럭 주기를 초과하는 단일 MUX 설계

체크리스트:
1. 입력 개수에 맞는 정확한 선택 신호(n비트)가 배선되었는가?
2. MUX 확장이 필요할 때 단일 대형 MUX 대신 계층형(Hierarchical) MUX를 고려했는가?
3. 선택 신호 변경 시 발생하는 일시적 글리치(Glitch)가 후속 순차 회로에 영향을 주지 않는가?

---

## 6. 기대효과 및 결론

멀티플렉서를 적용하면 하드웨어 배선을 최소화하고 데이터 패스의 유연한 제어가 가능해진다. 다만 입력 핀의 수가 늘어날수록 내부 게이트 단수가 증가하여 전파 지연이 커지는 한계가 있다. 이를 극복하기 위해 계층형 MUX 구조나 고속 직렬화기(Serializer)로 발전하고 있다. **MUX는 단순한 스위치가 아니라 모든 논리 함수를 구현할 수 있는 범용 빌딩 블록이다.**

## 7. 발전 흐름도

```text
기계식 스위치 / 릴레이
    ↓
표준 TTL/CMOS MUX (74151 등)
    ↓
CPU 데이터패스 라우팅 제어
    ↓
FPGA LUT 및 고속 SerDes MUX
```

## 8. 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| 디멀티플렉서 (DEMUX) | MUX의 역동작으로 통신 수신부 역할 수행 |
| 범용 논리 구현 (Universal Logic) | 진리표를 MUX 입력에 매핑해 임의의 불 함수 생성 |
| LUT (Look-Up Table) | FPGA 내에서 MUX 배열 형태로 논리 연산 수행 |
| 데이터패스 (Datapath) | CPU 명령어에 따라 데이터를 라우팅하는 핵심 경로 |
