## 0. 핵심 인사이트

> **핵심**: 디멀티플렉서 (Demultiplexer, DEMUX)는 단일 입력 신호를 n비트 선택 신호에 따라 2ⁿ개의 출력 중 하나로 분배하는 조합 논리회로다.
> **비유**: 한 선로로 들어온 기차(입력)를 선로 전환기(선택 신호)로 여러 목적지(출력) 중 한 곳으로 보내는 것과 같다.

---

📝 모범 답안

---

## 1. 개요 및 필요성

디멀티플렉서는 압축되거나 다중화된 단일 데이터 스트림을 본래의 여러 경로로 분리해주는 회로다. 멀티플렉서(MUX)를 통해 하나로 모여 전송된 데이터를 수신 측에서 다시 개별 장치로 전달하기 위해 필요하다. DEMUX가 없으면 단일 채널을 통한 여러 장치 간의 데이터 공유 통신망을 구축할 수 없다.

---

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| 데이터 입력 (Data Input) | 분배할 단일 원본 신호 수신 | 1개 입력선 |
| 선택 신호 (Select Line) | 신호가 출력될 경로 지정 | n비트 제어선 |
| 출력 (Output) | 선택된 단일 경로로 데이터 전달 | 2ⁿ개 출력선 |
| AND 게이트 배열 | 입력과 선택 신호를 결합해 활성화 | 디코더 구조와 동일 |

---

## 3. 구조 및 원리

**핵심 조건**: 단일 출력 $Y_k = D \cdot (S_{조합})$ (선택된 k번째 AND 게이트만 활성화)

동작 순서:
1. n비트의 선택 신호와 1비트의 데이터 입력(D)을 수신
2. 선택 신호 조합이 2ⁿ개의 AND 게이트 중 하나만 선택적으로 개방
3. 데이터 입력 신호가 개방된 단 하나의 AND 게이트로 인가
4. 선택된 경로의 출력 핀으로 데이터가 빠져나감
5. 나머지 비선택 출력 핀들은 모두 0을 유지함

```text
[입력 / 상태 / 제어 조건]
            ↓
     [핵심 처리 로직]
            ↓
    [출력 / 상태 갱신 / 효과]
```

---

## 4. 비교 및 연결

| 항목 | 디멀티플렉서 (DEMUX) | 디코더 (Decoder) |
|:---|:---|:---|
| 주 입력 | 데이터 입력 1개 + 선택 신호 | n비트 주소 입력 |
| 출력 동작 | 입력 데이터를 특정 출력으로 전달 | 특정 출력선 1개만 활성화 (Enable) |
| 상호 변환 | 디코더의 인에이블(Enable) 핀을 데이터 입력으로 쓰면 DEMUX | 데이터 입력 핀에 항상 1을 인가하면 디코더 |

DEMUX는 구조적으로 디코더에 인에이블(Enable) 핀이 추가된 형태와 완벽히 동일하다. 따라서 하나의 칩으로 주소 해독과 데이터 분배라는 두 가지 다른 목적을 유연하게 처리할 수 있다.

---

## 5. 실무 적용 및 판단

**채택**: 시분할 다중화 (TDM) 시스템의 수신부, CPU의 메모리 뱅크 및 I/O 장치 칩 셀렉트 (Chip Select), 인터페이스 분배기
**회피**: 상태 유지가 필요한 스위칭 매트릭스 설계 (조합논리이므로 래치 별도 필요)

체크리스트:
1. 출력될 목적지 수에 맞는 선택 비트가 확보되었는가?
2. 선택 신호 동기화 불일치로 인해 원치 않는 출력 핀으로 데이터가 새어나가지(Glitch) 않는가?
3. 디코더와 DEMUX 동작 중 현재 회로 목적에 맞게 인에이블(Enable) 핀을 설정했는가?

---

## 6. 기대효과 및 결론

디멀티플렉서를 적용하면 하나의 통신 라인이나 버스를 여러 수신 장치가 공유할 수 있어 핀 수와 배선 비용을 극적으로 낮춘다. 다만 채널이 많아질수록 선택 신호 해석에 따른 지연이 발생한다. **DEMUX는 단순히 데이터를 나누는 회로를 넘어, 디코더와 함께 시스템의 주소 및 공간을 정의하는 논리적 라우터다.**

---

## 7. 발전 흐름도

```text
디코더 / 최소항 생성 회로
    ↓
인에이블(Enable) 핀 추가형 DEMUX
    ↓
메모리 주소 해독 및 TDM 수신부
    ↓
SoC 내부 버스(AXI)의 온칩 라우팅 분배망
```

## 8. 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| 디코더 (Decoder) | DEMUX와 회로가 동일하며 주소 해독에 사용 |
| 시분할 다중화 (TDM) | MUX와 DEMUX가 동기화되어 시간대별로 채널 공유 |
| 최소항 (Minterm) 생성 | DEMUX의 출력은 논리 함수의 모든 최소항을 나타냄 |
| 칩 셀렉트 (Chip Select) | 특정 메모리나 I/O 장치를 활성화하는 신호 분배 |
