## 0. 핵심 인사이트

> **핵심**: SR 래치 (Set-Reset Latch)는 논리 게이트의 피드백을 통해 1비트를 기억하는 가장 기초적인 순차 회로 소자이며, Set과 Reset 입력이 동시에 활성화되는 금지 조건(Forbidden State)이 존재한다.
> **비유**: 시소와 같아서 한쪽을 누르면 고정되지만, 양쪽을 동시에 세게 누르면 부서지는(금지 조건) 것과 같다.

---

> 📝 모범 답안

## 1. 개요 및 필요성

SR 래치는 2개의 NOR 게이트나 NAND 게이트가 서로 교차 결합하여 출력을 입력으로 다시 보내는 피드백 구조를 통해 최초의 "기억" 능력을 구현한다. 조합 논리만으로는 과거 상태를 알 수 없기 때문에 상태 유지가 필요한 모든 메모리 소자의 근간으로서 필수적이다. 비록 제어에 한계가 있어 현대 설계에 직접 쓰이진 않으나, 플립플롭이나 SRAM 셀의 작동 원리를 이해하는 핵심 뼈대이다.

---

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| Set (S) 입력 | 출력 Q를 1로 설정 | 능동 동작 (NAND는 Low에서 동작) |
| Reset (R) 입력 | 출력 Q를 0으로 초기화 | 능동 동작 (NAND는 Low에서 동작) |
| 교차 피드백 로직 | 게이트 출력을 다른 게이트 입력으로 전달 | 외부 입력 제거 후에도 상태 유지 |

---

## 3. 구조 및 원리

**핵심 조건**: 두 출력이 상호 반전(Q와 Q') 상태를 유지해야 하며, S와 R 입력을 동시에 활성화하는 금지 조건(S=1, R=1)을 절대 인가해선 안 된다.

동작 순서 (NOR 기반):
1. 대기 (S=0, R=0): 양쪽 NOR 게이트가 피드백 값을 받아 이전의 Q, Q' 상태를 그대로 유지.
2. Set (S=1, R=0): 1을 받은 Q' 측 NOR 게이트가 강제로 0 출력, 이것이 피드백되어 Q를 1로 고정.
3. Reset (S=0, R=1): 1을 받은 Q 측 NOR 게이트가 강제로 0 출력, 이것이 피드백되어 Q'를 1로 고정.
4. 금지 (S=1, R=1): Q와 Q'가 모두 0이 되어 상호 반전 원칙이 깨지고, 동시 해제 시 메타스태빌리티 발생.

---

## 4. 비교 및 연결

| 항목 | SR 래치 | D 래치 (Data Latch) |
|:---|:---|:---|
| 입력 핀 | S (Set), R (Reset) 2개 | D (Data) 1개 |
| 금지 조건 | S=1, R=1 동시 입력 불가 | 없음 (S와 R이 항상 반대되도록 구조화) |
| 안정성 | 외부에서 금지 조건 제어 필요 | 회로적으로 금지 조건 원천 차단 |

SR 래치는 두 입력을 직접 다뤄야 하므로 금지 조건에 의한 치명적인 오동작 위험을 안고 있다. 이러한 결함을 구조적으로 해결하기 위해 입력을 하나로 통일하고 인버터를 추가한 형태가 D 래치이며, 이는 현대 소자의 실질적 표준이 되었다.

---

## 5. 실무 적용 및 판단

**채택**: 기계식 스위치의 접점 바운싱(Bouncing)을 제거하는 하드웨어 디바운싱(Debouncing) 회로, SRAM 메모리 셀 내부의 6T 트랜지스터 구조  
**회피**: 동기화된 클럭 시스템의 일반적인 상태 저장용 레지스터 설계

체크리스트:
1. 회로적으로 S와 R이 동시에 활성화될 가능성을 완벽히 차단했는가?
2. 클럭(Enable) 제어 없이 동작하여 발생하는 비동기적 타이밍 이슈를 고려했는가?
3. 디바운싱 목적으로 사용할 때, 스위치 접점의 전환 속도보다 래치의 피드백 속도가 충분히 빠른가?

---

## 6. 기대효과 및 결론

SR 래치의 구조는 최소한의 트랜지스터만으로 기억 소자를 구현할 수 있게 하여 캐시 메모리(SRAM)의 극한의 집적도와 빠른 속도를 가능하게 한다. 그러나 금지 조건의 치명적 한계와 클럭 비동기성이라는 전제조건 때문에, 일반 로직 설계에서는 D 플립플롭으로 대체되었다. SR 래치는 직접 쓰이는 부품이 아니라, 복잡한 상태 저장 소자들의 동작 근원지로서 기억해야 한다.

## 7. 발전 흐름도

```
논리 게이트 (상태 유지 불가)
    ↓
교차 결합 피드백 (SR 래치 등장)
    ↓
클럭 제어 도입 (Gated SR 래치)
    ↓
금지 조건 해결 (D 래치 / JK 플립플롭)
```

## 8. 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| 게이티드(Gated) SR 래치 | SR 래치 앞에 Enable/Clock 신호를 추가하여 동기화 제어 |
| JK 플립플롭 | SR 래치의 금지 조건을 '토글(Toggle)' 기능으로 유용하게 발전 |
| 스위치 디바운싱 | SR 래치의 실무적 하드웨어 활용 사례 |
