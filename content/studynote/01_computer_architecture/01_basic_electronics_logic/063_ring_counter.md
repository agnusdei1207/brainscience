## 0. 핵심 인사이트

> **핵심**: 링 카운터 (Ring Counter)는 시프트 레지스터의 최종 출력을 첫 번째 입력으로 환원시켜 단 하나의 비트만 활성화(One-hot)되어 순환하는 상태 기계다.
> **비유**: 회전 초밥 레일 위에서 특정 접시 하나가 계속 자리를 바꿔가며 순환하는 것과 같다.

---

> 📝 모범 답안

## 1. 개요 및 필요성

제어 로직이나 LED 디스플레이 스캔 등에서는 숫자 자체보다 특정 순서에 따른 "단일 단계의 활성화"가 필요할 때가 많다. 일반적인 이진 카운터를 사용하면 출력을 해독하기 위해 복잡한 디코더(Decoder)를 추가해야 한다. 링 카운터는 One-hot 상태를 유지하며 데이터가 순환하므로, 디코더 없이 출력 핀을 직접 제어 신호로 사용할 수 있어 직관적인 순차 타이밍 제어에 필수적이다.

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| 플립플롭 (FF) 체인 | 상태 값을 일시적으로 보관하고 이동 | 플립플롭 개수 (n) = 상태 수 (n) |
| 궤환 (Feedback) 루프 | 마지막 FF의 출력을 첫 번째 FF의 입력으로 전달 | 무한 순환 구조 형성 |
| 초기화 (Preset/Clear) | 구동 시 반드시 하나의 FF만 1로 강제 | 초기 One-hot 패턴을 보장하는 핵심 |
| 공통 클럭 (Clock) | 모든 단계의 상태를 동시에 이동 | 동기식 펄스로 순차 타이밍 제공 |

## 3. 구조 및 원리

**핵심 조건**: 시스템 전원 인가 시 반드시 상태가 '1000...0' 형태의 One-hot으로 초기화되어야 한다.

동작 순서:
1. 리셋 신호로 첫 번째 플립플롭만 '1', 나머지는 '0'으로 초기화
2. 클럭 에지 발생 시 모든 플립플롭은 이전 단의 값을 읽어 들임
3. 동시에 마지막 플립플롭의 출력은 피드백 선을 통해 첫 번째 플립플롭으로 입력
4. 단일 '1' 비트가 클럭마다 한 칸씩 오른쪽(또는 왼쪽)으로 시프트
5. 활성화된 비트가 순환하며 개별 장치의 순차 제어 신호로 작용

```text
[Init 1000] → Clock → [0100] → Clock → [0010] → Clock → [0001] ─(Feedback)─┐
    ^                                                                      │
    └──────────────────────────────────────────────────────────────────────┘
```

## 4. 비교 및 연결

| 항목 | 링 카운터 (Ring Counter) | 이진 카운터 (Binary Counter) |
|:---|:---|:---|
| 상태 표현 수 | n개 (FF 개수와 동일) | 2^n개 |
| 출력 해독 (Decoding) | 불필요 (출력 핀이 곧 제어 신호) | 필요 (별도 디코더 로직 추가) |
| 하드웨어 자원 효율 | 낮음 (사용하지 않는 상태 많음) | 높음 (모든 이진 조합 사용) |

링 카운터는 n개의 플립플롭으로 n가지 상태만 표현하므로 하드웨어 효율이 극히 낮다. 하지만 복잡한 디코더가 필요 없기 때문에 칩의 특정 위치로 라우팅하는 배선과 논리 단계를 줄일 수 있어, 해석의 단순함이 자원 효율보다 중요한 순차 제어기에 유리하다.

## 5. 실무 적용 및 판단

**채택**: 다중 디스플레이 시분할 스캔 제어기, 스테핑 모터의 단순 구동기, CPU 마이크로 오퍼레이션 타이밍 신호
**회피**: 상태 수가 매우 많은 시스템, 제한된 레지스터로 최대한 많은 카운팅이 필요한 공간 제약 환경

체크리스트:
1. 전원 켜짐이나 노이즈로 인해 두 개 이상의 '1'이 존재하는 불법 상태 복구 회로(Self-correcting)가 존재하는가?
2. 상태 전환을 위한 초기화 트리거(Preset)가 명확히 보장되는가?
3. 순차 제어의 단계 수가 충분히 적어 링 카운터의 낮은 자원 효율을 감내할 수 있는가?

## 6. 기대효과 및 결론

링 카운터는 복잡한 해독 로직을 제거하여 가장 빠르고 직관적인 One-hot 제어 신호를 생성한다. 그러나 상태 수와 동일한 수의 플립플롭이 필요하며 노이즈로 인한 불법 상태 이탈 시 치명적인 시스템 오류를 유발할 수 있다는 한계가 있다. 이를 안정적으로 쓰려면 "자기 보정(Self-correcting)" 로직 추가가 반드시 병행되어야 한다.

## 7. 발전 흐름도

```text
Shift Register
    ↓
Feedback Loop 추가
    ↓
One-hot 초기화 및 제어
    ↓
Ring Counter (순차 타이밍 제어기)
```

## 8. 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| 시프트 레지스터 (Shift Register) | 데이터를 클럭에 따라 옆으로 넘기는 링 카운터의 뼈대 |
| One-hot 인코딩 | 전체 비트 중 오직 1개만 활성화하는 직관적 상태 표현 기법 |
| 디코더 (Decoder) | 이진 카운터에서 필요한 부가 회로 (링 카운터에서는 불필요) |
| 불법 상태 (Illegal State) | 둘 이상의 비트가 1이 되어 시스템이 오작동하는 조건 |
