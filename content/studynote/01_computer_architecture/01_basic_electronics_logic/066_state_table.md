## 0. 핵심 인사이트

> **핵심**: 상태표 (State Table)는 순차 회로의 현재 상태와 입력에 따른 다음 상태 및 출력을 대응시킨 진리표다.
> **비유**: 여행지(현재)와 표(입력)를 보여주면 다음 목적지를 알려주는 열차 시간표와 같다.

---

📝 모범 답안

---

## 1. 개요 및 필요성

상태표 (State Table)는 상태도 (State Diagram)의 시각적 정보를 논리식으로 변환하기 위한 중간 단계다. 표 형식이 없으면 모든 상태와 입력의 조합을 빠짐없이 검증하기 어려워 논리 누락이 발생한다. 복잡한 제어 논리나 순차 회로를 논리 게이트로 합성 (Logic Synthesis)할 때 필수적인 기준 자료가 된다.

---

## 2. 구성요소

| 요소 | 역할 | 핵심 포인트 |
|:---|:---|:---|
| 현재 상태 (Current State) | 전이 전 회로의 상태 | 플립플롭의 현재 저장 값 |
| 입력 (Input) | 외부에서 인가되는 신호 | 상태 전이의 트리거 |
| 다음 상태 (Next State) | 클럭 에지 이후의 상태 | 차기 플립플롭 저장 값 |
| 출력 (Output) | 조건에 따른 회로의 최종 결과 | Moore/Mealy 여부에 따라 다름 |

---

## 3. 구조 및 원리

**핵심 조건**: 모든 (현재 상태 × 가능한 입력) 조합이 표에 정의되어야 한다.

동작 순서:
1. 현재 상태 변수와 입력 변수의 모든 조합을 나열한다.
2. 각 조합에 대해 상태도나 설계 명세서에 따라 다음 상태를 채운다.
3. Moore 또는 Mealy 모델에 맞춰 출력 값을 채운다.
4. 카르노 맵 (Karnaugh Map)을 이용해 플립플롭 입력 방정식을 도출한다.
5. 유도된 논리식을 바탕으로 실제 순차 회로를 합성한다.

```text
[입력 / 상태 / 제어 조건]
            ↓
     [핵심 처리 로직]
            ↓
    [출력 / 상태 갱신 / 효과]
```

---

## 4. 비교 및 연결

| 항목 | 상태표 (State Table) | 상태도 (State Diagram) |
|:---|:---|:---|
| 표현 방식 | 테이블 (행과 열) | 그래프 (노드와 엣지) |
| 주요 용도 | 논리식 유도 및 빈틈없는 검증 | 전체 흐름의 직관적 이해 |
| 장단점 | 모든 케이스 파악 용이 / 직관성 낮음 | 직관성 높음 / 누락 확인 어려움 |

상태도는 전체 동작 시나리오를 설계자와 소통하는 데 유리하고, 상태표는 기계적인 합성이나 디버깅 시 논리적 결함을 방지하는 데 필수적이다.

---

## 5. 실무 적용 및 판단

**채택**: FSM (Finite State Machine) 설계, 컴파일러 어휘 분석기 설계, 순차 회로 최적화
**회피**: 상태가 폭발적으로 많은 시스템 (이 경우 알고리즘 기반 설계 필요)

체크리스트:
1. 입력 변수와 상태 변수에 따른 모든 행이 누락 없이 채워졌는가?
2. 닿을 수 없는 상태(Unreachable State)가 정의되어 있지는 않은가?
3. Don't Care 조건을 적절히 활용하여 게이트 최소화를 고려했는가?

---

## 6. 기대효과 및 결론

상태표를 작성하면 복잡한 순차 논리를 체계적으로 축소하고 정확히 합성할 수 있어 설계 오류가 감소한다. 한계는 상태 수와 입력 변수가 늘어날수록 표의 크기가 기하급수적으로 커진다는 점이다. **상태표는 겉보기엔 단순한 나열 같지만, 하드웨어 합성을 위해 "인간의 아이디어를 기계의 언어로 번역하는 가장 확실한 검증판"이다.**

---

## 7. 발전 흐름도

```
동작 명세서 및 상태도
    ↓
상태표 (State Table)
    ↓
상태 축소 및 할당
    ↓
논리 합성 (회로 구현)
```

---

## 8. 관련 개념 맵

| 개념 | 연결 포인트 |
|:---|:---|
| FSM (Finite State Machine) | 상태표로 기술되는 제어 모델 |
| 카르노 맵 (Karnaugh Map) | 상태표를 최소화된 논리식으로 변환하는 도구 |
| 순차 회로 (Sequential Circuit) | 상태표의 최종 구현체 |
| 축소 상태표 (Reduced State Table) | 중복 상태를 제거해 하드웨어를 최적화한 표 |
