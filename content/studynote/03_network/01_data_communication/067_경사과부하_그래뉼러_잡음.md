## 0. 핵심 인사이트

> **핵심**: 경사 과부하 잡음은 신호 변화가 너무 빨라 스텝이 따라가지 못할 때, 그래뉼러 잡음은 신호 변화가 너무 작아 계단이 거칠게 들릴 때 발생한다.
> **비유**: 경사 과부하 잡음 (Slope Overload Noise) / 그래뉼러 잡음 (Granular Noise)은(는) 데이터통신 기초와 신호 처리 안에서 데이터와 제어 규칙을 질서 있게 맞춰 주는 교통 체계와 같다.

> 📝 모범 답안

## 1. 개요 및 필요성

델타 변조는 단순하지만, 스텝 크기 선택이 어긋나면 잡음이 바로 드러난다.

이 두 잡음은 단순히 "나쁜 잡음"이 아니라, 왜 적응형 변조가 필요한지를 보여 주는 대표 사례다.

---

## 2. 구성요소

```text
Input change
  ├─ too fast  → Slope overload
  └─ too slow  → Granular noise
```

| 잡음 | 원인 |
| :-- | :-- |
| Slope Overload | 입력 변화율 > 스텝 추적 능력 |
| Granular Noise | 입력 변화율 < 스텝 크기 |

경사 과부하는 신호가 급하게 변할 때 추적이 늦어져 생기고, 그래뉼러 잡음은 거의 평탄한 구간에서 계단이 너무 거칠게 들릴 때 생긴다.

---

## 3. 구조 및 원리

**핵심 조건**: 경사 과부하 잡음 (Slope Overload Noise) / 그래뉼러 잡음 (Granular Noise)은(는) 대역폭, 지연, 신호 대 잡음비 조건을 함께 만족할 때 안정적으로 동작한다.

동작 순서:

| 문제 | 특징 | 대응 |
| :-- | :-- | :-- |
| Slope Overload | 큰 변화 추적 실패 | 스텝 증가/적응형 조절 |
| Granular Noise | 미세 변화 거칠어짐 | 스텝 감소/적응형 조절 |

| 관련 방식 | 역할 |
| :-- | :-- |
| DM | 두 잡음에 취약 |
| ADM | 두 잡음 완화 |
| DPCM | 예측으로 잡음 완화 |

두 잡음은 서로 반대 방향의 문제처럼 보이지만, 사실 같은 스텝 크기 선택 문제에서 나온다.

---

## 4. 비교 및 연결

### 체크리스트

1. 신호 변화율과 스텝 크기의 관계를 이해하는가?
2. 두 잡음의 원인을 구분하는가?
3. ADM 같은 보완책을 설명할 수 있는가?
4. 음성 신호의 구간별 특성을 고려하는가?
5. 품질과 단순성의 트레이드오프를 아는가?

### 안티패턴

- 두 잡음을 같은 현상으로 보는 설계
- 스텝 크기만 키우면 된다고 생각하는 설계
- 적응형 보완 없이 DM을 고집하는 설계
- 품질 저하를 무시하는 설계

기술사 관점에서는 이 두 잡음을 "델타 변조의 한계"로 요약하고, ADM이 왜 필요한지 연결해야 한다.

## 6. 기대효과 및 결론

경사 과부하와 그래뉼러 잡음을 이해하면 델타 변조의 품질 한계를 정확히 설명할 수 있다.

결론적으로 둘은 델타 변조에서 스텝 크기 조절의 중요성을 보여 주는 대표 잡음이다.
