## 0. 핵심 인사이트

> **핵심**: 다익스트라 (Dijkstra) 알고리즘은 비음수 가중치 그래프에서 단일 출발점 (Single Source)으로부터 모든 정점까지의 최단 거리를 탐욕적 (Greedy) 방법으로 계산한다.
> **비유**: 다익스트라 (Dijkstra)은(는) 지도 위 갈림길에서 규칙적으로 길을 좁혀 가며 최적의 경로를 찾는 것과 같다.

---

> 📝 모범 답안

## 1. 개요 및 필요성

다익스트라 알고리즘은 1956년 에츠허르 다익스트라가 설계한 최단 경로 알고리즘이다. 시작 정점 s에서 출발하여 현재 알려진 최단 거리가 가장 짧은 미방문 정점을 우선 처리하는 탐욕 전략으로, 각 정점을 한 번씩만 처리한다.

| 특성 | 내용 |
|:---|:---|
| 시간 복잡도 | O((V+E)log V) — 이진 힙 |
| 공간 복잡도 | O(V) |
| 전제 조건 | 비음수 가중치 (Non-negative weights) |
| 핵심 자료구조 | 우선순위 큐 (Min-Heap) |
| 알고리즘 유형 | 탐욕 (Greedy) |

다익스트라가 필요한 상황:

- GPS 경로 안내 (도로 거리/시간 기반 최단 경로)
- 네트워크 라우팅 (OSPF, IS-IS 프로토콜)
- 게임 경로 탐색 (이동 비용이 다른 지형)

📢 **섹션 요약 비유**: 다익스트라는 가장 가까운 정류장에서 버스를 타는 방식으로 목적지까지 가는 알고리즘이다. 항상 "지금까지 알려진 가장 가까운 곳"을 먼저 방문한다.

## 2. 구성요소

### 기본 동작 순서 (이완, Relaxation)

```
그래프: A─(4)─B, A─(2)─C, C─(1)─B, B─(5)─D, C─(8)─D
시작: A

초기: dist = {A:0, B:∞, C:∞, D:∞}

1단계: A 처리 (dist=0)
  → B: 0+4=4 < ∞ → dist[B]=4
  → C: 0+2=2 < ∞ → dist[C]=2
  dist = {A:0, B:4, C:2, D:∞}

2단계: C 처리 (dist=2, 최솟값)
  → B: 2+1=3 < 4 → dist[B]=3 (이완!)
  → D: 2+8=10 < ∞ → dist[D]=10
  dist = {A:0, B:3, C:2, D:10}

3단계: B 처리 (dist=3)
  → D: 3+5=8 < 10 → dist[D]=8 (이완!)
  dist = {A:0, B:3, C:2, D:8}

4단계: D 처리 (dist=8) → 완료
최종: A→0, B→3, C→2, D→8
```

### ASCII 다이어그램 — 이완 과정과 우선순위 큐

```
┌──────────────────────────────────────────────────────────┐
│                     (4)                                  │
│            A ──────────── B                              │
│            │              │                              │
│           (2)            (5)                             │
│            │              │                              │
│            C ──(1)──────► B    ← 이완: 2+1=3 < 4        │
│            │                                             │
│           (8)                                            │
│            │                                             │
│            D                                             │
│                                                          │
│  우선순위 큐 (Min-Heap):                                   │
│  [(0,A)] → [(2,C),(4,B)] → [(3,B),(4,B),(10,D)]          │
│          → [(4,B),(8,D),(10,D)] → [(8,D),(10,D)]         │
│  ※ 중복 항목(4,B)은 꺼낼 때 dist 불일치로 무시             │
└──────────────────────────────────────────────────────────┘
```

### 이완 (Relaxation) 연산

다익스트라의 핵심 연산:

```
if dist[u] + weight(u,v) < dist[v]:
    dist[v] = dist[u] + weight(u,v)
    parent[v] = u
    우선순위 큐에 (dist[v], v) 삽입
```

| 단계 | 설명 |
|:---|:---|
| 초기화 | dist[s]=0, 나머지 ∞, 큐에 (0,s) 삽입 |
| 반복 | 큐에서 최솟값 꺼냄 → 이미 처리된 정점이면 스킵 |
| 이완 | 인접 간선 전체에 대해 거리 갱신 시 큐에 삽입 |
| 종료 | 큐가 빌 때까지 반복 |

📢 **섹션 요약 비유**: 이완은 "더 짧은 길을 발견했을 때 지도를 업데이트"하는 과정이다. 처음에는 모든 길이 무한히 멀어 보이다가, 탐색할수록 더 좋은 경로가 발견된다.

## 3. 구조 및 원리

**핵심 조건**: 다익스트라 (Dijkstra)은(는) 입력 규모, 데이터 분포, 정확성 요구, 메모리 계층, 종료 조건이 맞아야 기대 성능을 낸다. 평균 성능만이 아니라 최악 조건과 경계 사례까지 함께 검토해야 한다.

동작 순서:
1. 문제를 입력·상태·제약으로 모델링한다.
2. 핵심 규칙(분할, 선택, 갱신, 이완, 비교, 점화식)을 적용한다.
3. 중간 결과를 누적하거나 병합하면서 종료 조건에 도달한다.
4. 최종 결과를 검증하고 복잡도·경계 조건을 함께 확인한다.

```
그래프 모델
(V, E, weight/state)
      ↓
탐색 후보 집합
(stack / queue / heap / frontier)
      ↓
방문·이완·갱신 규칙 적용
      ↓
경로/트리/유량/매칭 결과 산출
```

### 최단 경로 알고리즘 비교

| 알고리즘 | 시간 복잡도 | 음수 간선 | 음수 사이클 | 출발점 |
|:---|:---:|:---:|:---:|:---:|
| 다익스트라 | O((V+E)log V) | 불가 | 불가 | 단일 |
| 벨만-포드 | O(VE) | 가능 | 검출 가능 | 단일 |
| 플로이드-워샬 | O(V³) | 가능 | 검출 가능 | 전체 쌍 |
| BFS | O(V+E) | 불가 (비가중치) | 해당 없음 | 단일 |

### 음수 간선에서 다익스트라가 실패하는 이유

```
A ─(3)→ B ─(-5)→ C
A ─(2)→ C

다익스트라: A→C = 2 (잘못됨)
실제 최단:  A→B→C = 3-5 = -2 (더 짧음)

이유: B를 처리하기 전에 C가 이미 처리됨 → 이완 기회 상실
```

📢 **섹션 요약 비유**: 음수 간선에서 다익스트라가 실패하는 것은 "지금까지 가장 싼 표"를 먼저 결제했는데, 나중에 더 싼 환불 가능 표가 발견된 상황과 같다. 이미 결제한 것은 취소가 안 된다.

## 4. 비교 및 연결

### 실무 시나리오

**시나리오 1**: GPS 내비게이션 (T-Map, 카카오맵)
- 도로 그래프에서 출발지→목적지 최단 경로
- 실시간 교통 정보 반영: 간선 가중치 동적 업데이트
- 실제 구현: 다익스트라 + 이분할(양방향) + A* 혼합

**시나리오 2**: OSPF (Open Shortest Path First) 라우팅 프로토콜
- 라우터 간 링크 상태 정보로 그래프 구성
- 다익스트라로 최단 경로 트리 (SPF Tree) 계산
- 링크 변화 발생 시 다익스트라 재실행

**시나리오 3**: 게임 경로 탐색 (지형 비용 차등)
- 늪지(비용 5), 평지(비용 1), 도로(비용 0.5)
- 다익스트라로 최소 이동 비용 경로 탐색

### 기술사 판단 포인트

| 상황 | 선택 알고리즘 | 이유 |
|:---|:---|:---|
| 비음수 가중치, 단일 출발 | 다익스트라 | O((V+E)log V) 최적 |
| 음수 간선, 단일 출발 | 벨만-포드 | 음수 간선 처리 가능 |
| 전체 쌍 최단 경로 | 플로이드-워샬 | O(V³), 밀집 그래프 |
| 비가중치 최단 경로 | BFS | O(V+E) 가장 빠름 |
| 실시간 동적 가중치 | D* Lite / A* | 동적 경로 재계산 |

📢 **섹션 요약 비유**: 다익스트라는 "지금 할인 중인 가장 싼 항공권"을 예약하고 목적지를 향해 나아가는 전략이다. 할인율이 음수(추가 비용 발생)가 없는 한 항상 최저가 경로를 찾는다.

## 5. 실무 적용 및 판단

다익스트라 (Dijkstra) 알고리즘은 비음수 가중치 그래프에서 단일 출발 최단 경로를 O((V+E)log V)에 보장하는 실무 표준 알고리즘이다. GPS, 라우팅 프로토콜, 게임 AI 등 방대한 분야에서 직접 활용되며, 음수 간선 처리는 벨만-포드로 위임하는 명확한 역할 분리가 설계 포인트다.

**핵심 결론**: 간선 비용이 모두 양수인 환경에서는 다익스트라가 최단 경로의 표준이다. 음수 비용이 나타나는 순간 알고리즘을 교체하라.

📢 **섹션 요약 비유**: 다익스트라는 항상 남은 구간 중 "이미 확정된 가장 싼 경로"에 올라타는 전략이다. 확정된 경로는 뒤집히지 않기 때문에 각 정점을 딱 한 번만 처리하면 된다.

## 6. 기대효과 및 결론

다익스트라 (Dijkstra)은(는) 관계형 문제를 경로·연결성·흐름·구조 최적화 관점으로 바꿔 해석하게 해 준다. 효과는 탐색의 체계화와 최적 경로/구조 도출에 있지만, 그래프 밀도, 가중치 특성, 동적 변경, 메모리 비용이 한계가 된다. 실무에서는 정적 이론보다 업데이트 빈도와 근사 허용 범위를 같이 봐야 하며, 향후에는 대규모 분산 그래프와 휴리스틱 가속이 더 중요해진다.

## 7. 발전 흐름도

```text
[그래프 이론 (Graph Theory)]
    │
    ▼
[BFS 너비 우선 탐색 (Breadth-First Search)]
    │
    ▼
[다익스트라 알고리즘 (Dijkstra Algorithm)]
    │
    ▼
[우선순위 큐 (Priority Queue)]
    │
    ▼
[A* 알고리즘 (A* Algorithm)]
    │
    ▼
[벨만-포드 알고리즘 (Bellman-Ford Algorithm)]
```

그래프 탐색에서 최단 경로 문제로 발전하며 다익스트라가 우선순위 큐를 활용해 효율성을 높이고 휴리스틱 탐색으로 이어지는 흐름이다.
