## 핵심 인사이트 (3줄 요약)

> 1. **본질**: 가설 검정은 표본 데이터를 이용해 귀무 가설(H0)을 기각할지 판단하는 통계 절차다.
> 2. **가치**: p-value, 유의수준, 검정력(power)을 함께 봐야 의미 있는 결론을 낼 수 있다.
> 3. **판단**: H0를 "참"으로 증명하는 것이 아니라, H1을 지지할 만큼 H0를 기각할 수 있는지 판단한다.

---

## Ⅰ. 개요 및 필요성

데이터가 우연인지 실제 효과인지 구분하려면 검정이 필요하다. 가설 검정은 이런 불확실성을 정량적으로 다룬다.

그래서 A/B 테스트, 품질 관리, 과학적 실험에서 필수다.

- **📢 섹션 요약 비유**: 두 팀이 누가 더 빠른지 달리기 기록으로 판정하는 일이다.

---

## Ⅱ. 아키텍처 및 핵심 원리

```text
H0 / H1
  ↓
Test Statistic
  ↓
p-value
  ↓
Decision
```

| 항목 | 의미 |
| :-- | :-- |
| H0 | 차이 없음/효과 없음 |
| H1 | 차이 있음/효과 있음 |
| p-value | H0 하에서 관측 결과의 희귀도 |
| α | 유의수준 |

가설 검정은 "우연이라고 보기엔 너무 드문가?"를 묻는 과정이다. 따라서 p-value만 숫자로 외우면 안 된다.

- **📢 섹션 요약 비유**: 이상한 일이 얼마나 드문지 계산해 보는 탐정이다.

---

## Ⅲ. 비교 및 연결

| 개념 | 의미 |
| :-- | :-- |
| H0 | 기본 가정 |
| H1 | 대안 가정 |
| p-value | 관측치의 희귀도 |
| Power | 진짜 효과를 잡아낼 확률 |

| 오류 | 의미 |
| :-- | :-- |
| Type I | H0가 참인데 기각 |
| Type II | H0가 거짓인데 기각 실패 |

가설 검정은 오류를 완전히 없애는 게 아니라, 둘 사이의 균형을 정하는 일이다.

- **📢 섹션 요약 비유**: 억울하게 잡을지, 놓칠지 사이에서 기준선을 정하는 것이다.

---

## Ⅳ. 실무 적용 및 기술사 판단

### 체크리스트

1. H0와 H1이 명확한가?
2. 유의수준 α를 정했는가?
3. 검정통계량과 p-value를 올바르게 해석하는가?
4. 검정력과 표본 수를 고려했는가?
5. 오류 유형을 설명할 수 있는가?

### 안티패턴

- p-value를 효과 크기로 착각하는 설계
- 귀무 가설을 참이라고 증명하려는 설계
- 표본 수를 무시하는 설계
- 검정 방법 선택을 무작정 하는 설계

기술사 관점에서는 가설 검정을 "판정 도구"가 아니라 "불확실성을 다루는 절차"로 이해해야 한다.

- **📢 섹션 요약 비유**: 의심이 충분히 작아질 때만 결론을 내리는 규칙이다.

---

## Ⅴ. 기대효과 및 결론

가설 검정을 이해하면 실험과 분석에서 결론을 더 신뢰할 수 있다. 그래서 데이터 기반 의사결정의 기본이 된다.

결론적으로 가설 검정은 귀무 가설을 기각할지 판단하는 통계 절차다.

- **📢 섹션 요약 비유**: 우연인지 아닌지 기준을 정해 판정하는 것이다.
