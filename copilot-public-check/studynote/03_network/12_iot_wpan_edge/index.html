12. Iot Wpan Edge

601. 사물인터넷 (IoT, Internet of Things)의 3대 요소 (디바이스, 네트워크, 클라우드/플랫폼) LAST READ

605. 블루투스 (Bluetooth) - IEEE 802.15.1, ISM 대역(2.4GHz), 피코넷(Piconet), 스캐터넷(Scatternet) 마스터/슬레이브 LAST READ

608. 비컨 (Beacon) 기술 - iBeacon(애플 환경), Eddystone(오픈 소스 블루투스 로케이터) LAST READ
609. ZigBee (지그비) - IEEE 802.15.4 초저전력 제어/감시용 메쉬 네트워킹 표준, 250Kbps LAST READ
610. Z-Wave (Z웨이브) - 홈네트워크 최적화 900MHz 무선 통신 반도체 생태계 주도 LAST READ
611. Thread 프로토콜 - IPv6 통신 기반 메시 WPAN 프로토콜 (스마트홈 IoT 지원) LAST READ
612. Matter (매터) 보안 통일 표준(CSA) - 애플/구글/아마존 간 통일형 스마트홈 상호 운용성 표준 (위 Layer 적용) LAST READ
613. 6LoWPAN - IEEE 802.15.4 환경의 저전력 장치를 IP 계층인 IPv6 로 인터넷 연동시키는 헤더 압축/단편화 (IoT 핵심) LAST READ
614. RPL (IPv6 Routing Protocol for Low-Power and Lossy Networks) - IoT 무선 최적 라우팅 알고리즘 LAST READ
615. LPWAN (Low-Power Wide-Area Network) 개요 (저전력 광역 통신) - 수십km 커버리지 LAST READ
616. 비면허 대역 LPWAN 분야 LAST READ
617. LoRa (Long Range) / LoRaWAN 표준 - CSS (Chirp Spread Spectrum) 방식의 비면허 글로벌 저전력 장거리 LAST READ
618. Sigfox - 초협대역(UNB) 100bps 극초저전력, 소용량/프랑스 기반 상용화 LAST READ
619. 면허 대역 LPWAN 분야 (이동통신사 기반형 IoT) LAST READ

622. MQTT (Message Queuing Telemetry Transport) - TCP 기반 퍼블리시-서브스크라이브 경량 메시지 (QoS 0/1/2 등급 지원) 브로커(Broker) 중심 분산형 LAST READ
623. CoAP (Constrained Application Protocol) - UDP 제어 기반, REST/HTTP 메타 대응 경량 프로토콜, 브로커리스 구조(DTLS 접속 지원) LAST READ
624. LwM2M (Lightweight M2M) 표준 프로토콜 관리 메커니즘 LAST READ
625. oneM2M 아키텍처 (국제 표준 통합 M2M 구조화 플랫폼) LAST READ
626. 엣지 컴퓨팅 (Edge Computing, 포그 컴퓨팅 구분) - 종단 클라이언트 인접 노드 데이터 분산 처리 방식 LAST READ
627. MEC (Multi-access Edge Computing / Mobile Edge Computing) - 5G, 이통망 기지국 근접하여 연산, 초저지연 확보 LAST READ
