💡 핵심 인사이트
10BASE-T는 거추장스러운 동축 케이블 대신 다루기 쉬운 UTP 케이블(랜선)과 스타(Star) 토폴로지를 도입하여 현대 유선 네트워크의 형태를 정립했습니다.
이어 등장한 100BASE-TX (Fast Ethernet)는 10BASE-T와 물리적인 호환성을 유지하면서도, 4B/5B 인코딩 같은 신호 압축 기술을 통해 속도를 10배 끌어올린 혁신이었습니다.

Ⅰ. 10BASE-T: UTP 이더넷의 대중화

10BASE-T는 IEEE 802.3i 표준으로, 현대 사무실과 가정에서 흔히 보는 RJ-45 잭과 UTP 케이블을 사용하는 최초의 대중적인 이더넷 규격입니다.

  1. 규격 해석: 10Mbps 속도 / 기저대역(Baseband) 전송 / T(Twisted Pair, 꼬임 쌍선).
  2. 사용 케이블: Cat 3(카테고리 3) 이상의 UTP 케이블.
  3. 핀 사용 (2 Pairs): UTP 케이블 내부의 8가닥(4쌍) 중 **2쌍(4가닥)**만 사용합니다.
    • 핀 1, 2번: 송신(Tx)
    • 핀 3, 6번: 수신(Rx)
  4. 인코딩: **맨체스터 인코딩(Manchester Encoding)**을 사용합니다. 클럭과 데이터를 동시에 전송하지만, 대역폭 효율성이 낮아 10Mbps 전송을 위해 20MHz의 대역폭이 필요합니다.
[10BASE-T / 100BASE-TX 핀 배열 (T568B 기준)]
Pin 1: 흰주 (Tx +)  ─┐ 송신
Pin 2: 주황 (Tx -)  ─┘
Pin 3: 흰녹 (Rx +)  ─┐ 수신
Pin 4: 파랑 (사용 안 함)
Pin 5: 흰파 (사용 안 함)
Pin 6: 녹색 (Rx -)  ─┘ 수신
Pin 7: 흰갈 (사용 안 함)
Pin 8: 갈색 (사용 안 함)

📢 섹션 요약 비유: 10BASE-T는 복잡한 철로(동축)를 걷어내고, 누구나 쉽게 꽂을 수 있는 전화선 모양의 플러그(RJ-45)를 도입한 인터넷의 플러그 앤 플레이 혁명이었습니다.

Ⅱ. 100BASE-TX: Fast Ethernet의 등장

네트워크 트래픽이 급증하면서 10Mbps로는 한계에 부딪혔고, 이를 10배로 높인 100Mbps 규격인 **Fast Ethernet (IEEE 802.3u)**이 등장했습니다. 그중 가장 널리 쓰인 물리 규격이 100BASE-TX입니다.

  1. 사용 케이블: Cat 5 이상의 UTP 케이블.
  2. 호환성: 10BASE-T와 똑같이 2쌍(핀 1,2,3,6)만 사용하므로, 기존의 케이블 인프라를 교체할 필요 없이 장비(스위치/랜카드)만 업그레이드하면 되었습니다. (이것이 100BASE-TX가 성공한 가장 큰 이유입니다.)

어떻게 똑같은 선으로 10배 빨라졌을까?

단순히 주파수를 10배로 높이면 케이블에 엄청난 간섭(누화)과 손실이 발생합니다. 100BASE-TX는 효율적인 인코딩과 변조 방식을 도입했습니다.

  1. 4B/5B 블록 코딩: 4비트 데이터를 5비트의 특정 패턴으로 매핑합니다. 연속된 0이나 1을 없애 클럭 동기화를 돕고 에러 검출 기능을 가집니다. 이로 인해 100Mbps 데이터를 125Mbps 속도로 변환합니다.
  2. MLT-3 인코딩: 125Mbps로 변환된 디지털 데이터를 (+1, 0, -1)의 3가지 전압 레벨을 사용하여 전기 신호로 바꿉니다. 3진법을 쓰기 때문에 주파수를 확 낮출 수 있습니다. 결과적으로 케이블에 실리는 실제 최대 주파수는 10배가 아닌 약 31.25MHz에 불과하여 Cat 5 케이블로도 충분히 전송이 가능해졌습니다.

Ⅲ. Auto-Negotiation (자동 협상)

Fast Ethernet의 도입으로, 한 사무실에 10Mbps 랜카드와 100Mbps 랜카드가 혼재하게 되었습니다. 스위치가 이를 어떻게 구분할까요?

오토 네고시에이션(Auto-Negotiation) 기능이 이때 도입되었습니다. 랜선을 꽂는 순간 스위치와 PC의 랜카드는 FLP(Fast Link Pulse)라는 짧은 전기 펄스를 주고받으며 서로의 최고 성능을 확인합니다.

  1. "나 100Mbps 전이중(Full Duplex) 지원해!"
  2. "어, 나는 10Mbps 반이중(Half Duplex)밖에 안 되는데."
  3. "알았어, 그럼 너한테 맞춰서 10Mbps 반이중으로 통신할게."

이렇게 양쪽 장비가 지원하는 **공통분모 중 가장 빠른 속도와 통신 방식(이중 방식)**으로 링크를 자동으로 설정합니다.

📢 섹션 요약 비유: 100BASE-TX는 도로(케이블)는 그대로 둔 채, 차량에 테트리스(4B/5B)로 짐을 효율적으로 싣고 신호등 체계(MLT-3)를 개선하여 통행량을 10배로 늘린 기적 같은 교통 공학입니다. 스위치와 PC가 속도를 협상하는 것은 서로 눈치를 보며 최적의 언어(속도)를 맞추는 통역사와 같습니다.
