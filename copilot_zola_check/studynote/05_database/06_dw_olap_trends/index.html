06. 데이터 웨어하우스, OLAP 및 최신 트렌드

321. 데이터 웨어하우스 (Data Warehouse, DW) - 의사결정 지원을 위한 통합, 주젯 중심, 시계열, 비휘발성 저장소 (Inmon 모델) LAST READ 2026-04-07
322. DW 4대 특징 - 주젯 지향성(Subject-oriented), 통합성(Integrated), 시계열성(Time-variant), 비휘발성(Non-volatile) LAST READ
323. 데이터 마트 (Data Mart) - 특정 부서/조직 중심의 소규모 DW (Kimball 모델 - 상향식) LAST READ 2026-04-07
324. ODS (Operational Data Store) - DW로 가기 전의 임시/운영 데이터 통합 영역 LAST READ
325. ETL (Extract, Transform, Load) 프로세스 - 소스 추출 -> 정제/변환 -> 타겟 적재 LAST READ 2026-04-07
326. ELT (Extract, Load, Transform) 프로세스 - 클라우드 기반 현대 아키텍처, 먼저 적재 후 웨어하우스 내에서 변환 처리 LAST READ 2026-04-07
327. OLTP (On-Line Transaction Processing) - 실시간 트랜잭션, 정규화된 RDB, 빠른 응답 속도 LAST READ
328. OLAP (On-Line Analytical Processing) - 대용량 다차원 분석, 비정규화(스타 스키마), 읽기 위주 LAST READ
329. OLAP 연산 (Operation) - 롤업, 드릴다운, 슬라이스, 다이스, 피벗 LAST READ
330. 롤업 (Roll-up) - 요약 / 드릴다운 (Drill-down) - 구체화 (계층 구조 상하 이동) LAST READ 2026-04-07
331. 슬라이스 (Slice) - 특정 차원의 단일 평면 절단 / 다이스 (Dice) - 여러 차원의 작은 주사위 모양 추출 LAST READ
332. 피벗 (Pivot) - 보고서 축 전환 (행렬 변환) LAST READ
333. 다차원 모델링 - 팩트 (Fact / 측정값)와 차원 (Dimension / 분석 기준) 구성 LAST READ
334. 스타 스키마 (Star Schema) - 사실 테이블 1개, 정규화 안된 다수 차원 테이블 방사형 배치 (빠른 조인, 중복 존재) LAST READ
335. 스노우플레이크 스키마 (Snowflake Schema) - 차원 테이블을 3NF 정규화하여 중복 제거, 조인 복잡성 증가 눈송이 형태 LAST READ
336. MOLAP (Multidimensional OLAP) - 다차원 큐브(Cube) 사전 생성 구조, 초고속 검색, 큐브 갱신 비용 큼 LAST READ
337. ROLAP (Relational OLAP) - 관계형 DB 기반 SQL 실시간 분석, 대용량 처리에 적합 LAST READ
338. HOLAP (Hybrid OLAP) - MOLAP의 속도 + ROLAP의 대용량 처리 결합 LAST READ
339. 데이터 레이크 (Data Lake) - 원시 데이터(Raw data), 정형/반정형/비정형 모두 저장하는 스키마 온 리드(Schema-on-read) 중앙 저장소 LAST READ
340. 스키마 온 라이트 (Schema-on-write) - RDBMS의 입력 시점 스키마 검증 LAST READ
341. 스키마 온 리드 (Schema-on-read) - 데이터 레이크/NoSQL의 조회 시점 스키마 적용 LAST READ
342. 메타데이터 카탈로그 (Hive Metastore, AWS Glue) - 데이터 레이크 자산 검색 지원 LAST READ
