핵심 인사이트 (3줄 요약)

  1. 본질: 로지스틱 회귀는 선형 점수를 시그모이드 (Sigmoid) 함수로 바꿔 이진 분류 확률을 추정한다.
  2. 가치: 해석이 쉽고, 확률 출력과 선형 결정 경계를 동시에 제공한다.
  3. 판단 포인트: 로지스틱 회귀는 회귀가 아니라 분류 모델이며, log loss (로그 손실)를 사용한다.

Ⅰ. 개요 및 필요성

이진 분류에서는 결과가 0 또는 1이다. 하지만 단순 선형 모델은 0~1 확률을 직접 표현하기 어렵다.

로지스틱 회귀는 선형 결합을 확률로 변환해 이런 문제를 해결한다.

  • 📢 섹션 요약 비유: 로지스틱 회귀는 온도계 눈금을 확률로 바꾸는 장치다.

Ⅱ. 아키텍처 및 핵심 원리

입력 특성의 선형 결합 z = w·x + b를 시그모이드 함수에 넣어 0~1 확률로 만든다. 임계값을 넘으면 1, 아니면 0으로 분류한다.

x → z = w·x + b → sigmoid(z) → P(y=1) → class
요소의미포인트
z선형 점수결정 경계
sigmoid확률 변환0~1 범위
log loss학습 손실확률 품질

핵심은 출력이 확률이므로 임계값 조정이 가능하고, 결정 경계는 선형이라는 점이다.

  • 📢 섹션 요약 비유: 시그모이드는 숫자를 0과 1 사이로 눌러주는 버튼이다.

Ⅲ. 비교 및 연결

로지스틱 회귀는 선형 회귀와 다르다. 선형 회귀는 연속값 예측이고, 로지스틱 회귀는 분류 확률 예측이다.

출력연속값확률

의사결정나무나 SVM과 비교했을 때 로지스틱 회귀는 해석이 쉽고, 계수 해석이 가능하다는 장점이 있다.

  • 📢 섹션 요약 비유: 선형 회귀는 점수를 맞히는 시험, 로지스틱 회귀는 합격/불합격을 가리는 시험이다.

Ⅳ. 실무 적용 및 기술사 판단

실무에서는 class imbalance, regularization, threshold tuning, feature scaling이 중요하다. 확률 임계값을 0.5로 고정할 필요는 없다.

체크리스트

  1. 로그 손실과 정규화를 쓰는가?
  2. 클래스 불균형을 처리하는가?
  3. 임계값을 업무 목적에 맞게 조정하는가?
  4. 계수 해석이 필요한 상황인가?

안티패턴

  • 로지스틱 회귀를 회귀 문제로 오해하는 경우
  • 확률 임계값을 무조건 0.5로만 쓰는 경우
  • 스케일링 없이 특성을 섞는 경우

기술사 관점에서는 로지스틱 회귀가 확률적 분류기라는 점과 선형 결정 경계의 해석 가능성을 함께 설명해야 한다.

  • 📢 섹션 요약 비유: 로지스틱 회귀는 문 앞에 서서 "통과할까요?"를 점수 대신 확률로 말하는 심판이다.

Ⅴ. 기대효과 및 결론

로지스틱 회귀는 단순하지만 강력한 이진 분류 기본기다. 해석성과 확률 출력이 필요한 문제에 특히 적합하다.

정리하면, 선형 점수를 시그모이드로 눌러 확률을 만든 뒤 분류하는 모델이다.

  • 📢 섹션 요약 비유: 로지스틱 회귀는 0과 1 사이를 오가는 조절 손잡이다.
