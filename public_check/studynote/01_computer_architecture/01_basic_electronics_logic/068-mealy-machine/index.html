0. 핵심 인사이트

핵심: 밀리 머신 (Mealy Machine)은 출력이 "현재 상태"와 "현재 입력" 모두에 의해 결정되는 순차 논리 모델이다. 비유: 자신이 서 있는 위치(상태)와 날아오는 공(입력)을 동시에 보고 즉각 방망이를 휘두르는 타자와 같다.

📝 모범 답안

1. 개요 및 필요성

시스템이 외부 입력 변화에 클럭 주기를 기다리지 않고 즉각 반응해야 할 때가 있다. 밀리 머신 (Mealy Machine)은 입력이 출력 회로에 직접 연결되어 한 클럭 빠른 반응 속도를 제공한다. 상태 수가 적어 회로 면적을 줄일 수 있어 자원이 제한된 환경이나 통신 프로토콜 파서 등에서 필수적이다.

2. 구성요소

요소역할핵심 포인트
상태 레지스터 (State Register)현재 상태 저장 및 유지동기적 상태 갱신
다음 상태 논리 (Next State Logic)상태와 입력으로 다음 상태 도출클럭을 위한 준비
출력 논리 (Output Logic)현재 상태와 입력을 조합하여 출력 결정비동기적 즉각 반응 가능

3. 구조 및 원리

핵심 조건: 출력식 $Z(t)$는 현재 상태 $S(t)$와 현재 입력 $X(t)$의 조합함수여야 한다. ($Z(t) = f(S(t), X(t))$)

동작 순서:

  1. 상태 레지스터가 클럭에 맞춰 현재 상태를 출력한다.
  2. 외부에서 들어온 입력 신호가 다음 상태 논리와 출력 논리로 동시에 들어간다.
  3. 출력 논리는 현재 상태와 입력 신호를 조합하여 즉시 출력을 생성한다. (이때 입력이 변하면 출력도 즉각 변한다)
  4. 다음 상태 논리는 다음 클럭에서 갱신할 상태를 준비한다.
  5. 다음 클럭 에지가 오면 상태가 갱신된다.
       ┌───────────────────────┐
[입력] ┼─→ (다음 상태 논리) ─→ [상태 레지스터] ─┐
       └────────────────────────────────────────┼─→ (출력 논리) ─→ [출력]

4. 비교 및 연결

항목밀리 머신 (Mealy Machine)무어 머신 (Moore Machine)
출력 결정현재 상태 + 입력현재 상태 단독
반응 속도빠름 (클럭 대기 없음)상대적으로 1클럭 느림
글리치 노이즈취약함 (입력 노이즈가 출력에 반영)강건함 (상태로 차단)

밀리 머신은 출력을 위해 불필요한 상태 분할을 할 필요가 없어 하드웨어가 작지만, 입력의 노이즈가 여과 없이 출력으로 나가는 단점이 있다.

5. 실무 적용 및 판단

채택: 통신 프로토콜 파싱, 빠른 인터럽트 반응기, 상태 수를 최소화해야 하는 칩 설계 회피: 출력 신호가 다른 동기회로의 직접적인 클럭/제어 입력으로 쓰여 글리치가 치명적인 경우

체크리스트:

  1. 입력의 비동기적 변화가 출력에 반영되어도 뒷단 회로가 안전한가?
  2. 타이밍 제약(최장 경로 지연)을 만족하는가?
  3. 무어 머신 대비 상태 수를 효과적으로 줄였는가?

6. 기대효과 및 결론

빠른 응답성과 최소화된 레지스터 사용으로 고속, 경량 하드웨어 구현이 가능하다. 한계는 입력 신호의 노이즈가 출력단 글리치로 직결될 수 있어 타이밍 검증이 복잡하다는 점이다. 밀리 머신은 "지연 없는 즉각적 제어"가 필요할 때 가장 우선적으로 고려하는 기민한 FSM이다.

7. 발전 흐름도

요구사항 (빠른 반응, 면적 최소화)
    ↓
밀리 머신 기반 설계
    ↓
타이밍 및 글리치 분석
    ↓
통신 프로토콜 컨트롤러 구현

8. 관련 개념 맵

개념연결 포인트
FSM (Finite State Machine)설계의 근간이 되는 논리적 상태 기계
무어 머신 (Moore Machine)안정성을 위해 반응 속도를 타협한 대안적 모델
상태 전이도 (State Transition Diagram)엣지(Edge)에 입/출력을 모두 표기하여 밀리 머신을 표현
글리치 (Glitch)밀리 설계 시 반드시 제거하거나 회피해야 할 노이즈 현상
