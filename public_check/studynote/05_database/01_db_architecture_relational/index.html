01. 데이터베이스 기초 및 아키텍처

1. 데이터 (Data) / 정보 (Information) / 지식 (Knowledge) / 지혜 (Wisdom) - DIKW 피라미드 2026-05-05
2. 데이터베이스 (Database)의 정의 - 통합(Integrated), 저장(Stored), 운영(Operational), 공용(Shared) 데이터 2026-05-05
3. 데이터베이스 관리 시스템 (DBMS) - 사용자와 DB 사이의 인터페이스 (데이터 독립성 제공) 2026-05-05
4. 데이터 독립성 (Data Independence) - 논리적 독립성 vs 물리적 독립성 2026-05-05
5. 스키마 (Schema) - 데이터베이스의 논리적 구조와 제약 조건에 대한 명세 2026-05-05
6. 3단계 스키마 아키텍처 (ANSI/SPARC) 2026-05-05
7. 외부 스키마 (External Schema) - 사용자 관점, 서브 스키마 2026-05-05
8. 개념 스키마 (Conceptual Schema) - 조직 전체 관점, 논리적 구조 2026-05-05
9. 내부 스키마 (Internal Schema) - 물리적 저장 장치 관점 2026-05-05
10. 스키마 매핑 (Mapping) - 외부/개념 사상, 개념/내부 사상 2026-05-05
11. 시스템 카탈로그 (System Catalog) / 데이터 사전 (Data Dictionary) - 메타데이터(Metadata) 저장소 2026-05-05
12. 메타데이터 (Metadata) - 데이터에 대한 데이터 2026-05-05
13. 데이터 디렉터리 (Data Directory) - 시스템만 접근 가능한 카탈로그 부분 2026-05-05
14. 데이터 모델 (Data Model) 구성 요소 - 구조(Structure), 연산(Operation), 제약조건(Constraint) 2026-05-05
15. 계층형 데이터 모델 (Hierarchical Model) - 트리 구조 (1:N) 2026-05-05
16. 망형 데이터 모델 (Network Model) - 그래프 구조 (N:M 허용) 2026-05-05
17. 관계형 데이터 모델 (Relational Model) - 테이블 구조, E.F. Codd 제안 2026-05-05
18. 객체지향 데이터 모델 (OODBMS) / 객체 관계형 데이터 모델 (ORDBMS) 2026-05-05
19. DBMS 언어 2026-05-05
20. DDL (Data Definition Language) - 데이터 정의 언어 (CREATE, ALTER, DROP, TRUNCATE) 2026-05-05
21. DML (Data Manipulation Language) - 데이터 조작 언어 (SELECT, INSERT, UPDATE, DELETE) 2026-05-05
22. DCL (Data Control Language) - 데이터 제어 언어 (GRANT, REVOKE) 2026-05-05
23. TCL (Transaction Control Language) - 트랜잭션 제어 (COMMIT, ROLLBACK, SAVEPOINT) 2026-05-05
24. 절차적 DML (네비게이션) vs 비절차적 DML (선언적, SQL) 2026-05-05
25. 데이터베이스 관리자 (DBA, Database Administrator) 2026-05-05
26. 데이터 관리자 (DA, Data Administrator) - 데이터 표준, 메타데이터 관리 2026-05-05
27. 데이터베이스 설계자 (Database Designer) 2026-05-05
28. 데이터베이스 사용자 - 일반 사용자, 응용 프로그래머 2026-05-05
29. 데이터베이스 파일 시스템 (File System) 문제점 - 데이터 종속성, 데이터 중복성 2026-05-05
30. 데이터 무결성 (Integrity) / 보안성 (Security) 2026-05-05
31. 클라이언트-서버 DBMS 아키텍처 (2-Tier, 3-Tier) 2026-05-05
32. TP 모니터 (Transaction Processing Monitor) / 미들웨어 2026-05-05
33. 파일 저장 구조 - 히프(Heap), 순차(Sequential), 해시(Hash), 인덱스(Indexed) 파일 2026-05-05
34. 고정 길이 레코드 vs 가변 길이 레코드 2026-05-05
35. 블로킹 팩터 (Blocking Factor) - 하나의 블록에 저장되는 레코드 수 2026-05-05
36. B-Tree (다진 탐색 트리) 원리 및 구조 2026-05-05
37. B+Tree - 리프 노드에만 데이터 저장, 리프 노드 간 연결 리스트 (RDB 인덱스 기본) 2026-05-05
38. 관계 대수 (Relational Algebra) - 절차적 언어, "어떻게" 구할 것인가 명시 2026-05-05
39. 일반 집합 연산자 - 합집합(Union), 교집합(Intersection), 차집합(Difference), 카티션 프로덕트(Cartesian Product) 2026-05-05
40. 순수 관계 연산자 - 셀렉트(Select, σ), 프로젝트(Project, π), 조인(Join, ⋈), 디비전(Division, ÷) 2026-05-05
41. 셀렉트(Select) - 수평적 부분집합 (행 추출) 2026-05-05
42. 프로젝트(Project) - 수직적 부분집합 (열 추출) 2026-05-05
43. 조인(Join) - 공통 속성 기준으로 두 릴레이션 결합 2026-05-05
44. 디비전(Division) - 속성 값을 모두 가진 튜플 추출 2026-05-05
45. 관계 해석 (Relational Calculus) - 비절차적 언어, "무엇을" 구할 것인가 명시 (튜플 관계 해석, 도메인 관계 해석) 2026-05-05
46. 인-메모리 데이터베이스 (IMDB, In-Memory DB) - Redis, Memcached, SAP HANA (디스크 I/O 병목 제거) 2026-05-05
47. 컬럼 기반 저장소 (Columnar Store) - 분석(OLAP) 최적화, 높은 압축률 2026-05-05
48. 로우 기반 저장소 (Row Store) - 트랜잭션(OLTP) 최적화 2026-05-05
49. 스토리지 엔진 (Storage Engine) 구조 (InnoDB, MyISAM 등) 2026-05-05
50. 버퍼 풀 (Buffer Pool) / 버퍼 관리자 - 디스크 접근 최소화 2026-05-05
51. 로깅 엔진 (Logging Engine) - 복구(Recovery)를 위한 로그(WAL) 작성 2026-05-05
52. 옵티마이저 (Optimizer) - 최적의 SQL 실행 계획 생성 2026-05-05
53. 파서 (Parser) - SQL 구문 분석 및 파스 트리 생성 2026-05-05
54. 카탈로그 매니저 - 메타데이터 접근 2026-05-05
55. 커넥션 풀 (Connection Pool) - 데이터베이스 연결 오버헤드 감소 2026-05-05
56. 데이터 딕셔너리 캐시 (Data Dictionary Cache) 2026-05-05
57. 공유 풀 (Shared Pool) - Oracle 인스턴스 구조 2026-05-05
58. 데이터베이스 인스턴스 (Database Instance) - 메모리 구조 + 백그라운드 프로세스 2026-05-05
59. 영구 저장소 (Persistent Storage) - 데이터 파일, 로그 파일, 제어 파일 2026-05-05
60. 서버리스 데이터베이스 (Serverless DB) - Amazon Aurora Serverless 등 자동 확장 아키텍처 2026-05-05
