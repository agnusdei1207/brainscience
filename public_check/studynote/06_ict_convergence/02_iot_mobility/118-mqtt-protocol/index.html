0. 핵심 인사이트

핵심: MQTT는 Pub/Sub(발행/구독) 기반 경량 메시징 프로토콜로, 대역폭이 제한된 IoT 환경에서 센서 데이터를 최소 2바이트 헤더로 전송할 수 있는 사실상 IoT 메시징 표준이다. 비유: 현실 공간 곳곳에 신경과 감각 기관을 깔아, 상황을 느끼자마자 즉시 반응하는 도시의 신경망과 같다.

1. 개요 및 필요성

│    MQTT Pub/Sub 아키텍처                               │
├───────────────────────────────────────────────────────┤
│  [Publisher]                [Subscriber]               │

└───────────────────────────────────────────────────────┘

4. 비교 및 연결

MQTT 5.0 주요 개선

  • Shared Subscription: 같은 Topic을 여러 Subscriber가 분산 처리 (로드밸런싱).
  • Request/Response: Pub/Sub 위에 RPC 패턴 구현.
  • Properties: 메시지에 메타데이터(Content-Type, Correlation Data) 추가.

MQTT는 AWS IoT Core·Azure IoT Hub·Google Cloud IoT의 기본 프로토콜이며, MQTT over QUIC로 더욱 빠른 전송이 진행 중이다.

결론적으로 MQTT 프로토콜 (Message Queuing Telemetry Transport) - IoT 경량 메시징는 기술 자체만으로 성과가 보장되지 않으며, 적용 맥락, 운영 역량, 데이터 품질, 보안·거버넌스 조건이 함께 충족될 때 비로소 실질적 가치가 구현된다.
