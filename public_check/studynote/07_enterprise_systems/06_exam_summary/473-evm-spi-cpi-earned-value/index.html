0. 핵심 인사이트

핵심: EVM(Earned Value Management)은 프로젝트의 일정(Schedule)과 비용(Cost) 성과를 계획 가치(PV), 획득 가치(EV), 실제 비용(AC)이라는 3개 지표로 통합하여 현재 상태와 완료 시점을 예측하는 객관적 프로젝트 관리 기법이다. 비유: EVM SPI CPI 진척 통계는 복잡한 현장을 한 장의 설계도와 운영 규칙으로 묶어 방향을 맞추는 나침반과 같다.

📝 모범 답안

1. 개요 및 필요성

"프로젝트가 50% 예산을 썼는데 얼마나 진행됐나요?" — 이 질문의 답이 진척도 30%라면 프로젝트는 위기 상황이다. 그러나 전통적인 일정-비용 관리는 "비용을 얼마 썼는가"와 "일정이 어느 단계인가"를 별개로 보아 이러한 통합적 분석이 불가능했다.

EVM은 1960년대 미국 국방부(DOD)가 방산 프로젝트의 비용 초과를 제어하기 위해 도입한 기법으로, 현재 PMI(PMBOK)·ISO 21500·국내 공공 SW 사업의 표준 성과 관리 도구이다.

세 가지 기본값: PV(Planned Value, 계획 가치) = 지금까지 계획했던 작업의 예산, EV(Earned Value, 획득 가치) = 실제로 완료된 작업의 예산, AC(Actual Cost, 실제 비용) = 지금까지 실제 지출한 비용.

2. 구성요소

EVM 핵심 공식

지표공식의미기준값
SV (일정 편차)SV = EV - PV(+)선행, (-)지연0
CV (비용 편차)CV = EV - AC(+)절감, (-)초과0
SPI (일정 성과 지수)SPI = EV / PV>1 선행, <1 지연1.0
CPI (비용 성과 지수)CPI = EV / AC>1 절감, <1 초과1.0
EAC (최종 예상 비용)EAC = BAC / CPI현재 효율로의 완료 예측= BAC
ETC (잔여 예상 비용)ETC = EAC - AC앞으로 필요한 예산—
VAC (완료 시 편차)VAC = BAC - EAC최종 예산 초과/절감 예측0
TCPI (완료 성과 지수)TCPI = (BAC-EV)/(BAC-AC)남은 작업의 필요 효율= 1.0

3. 구조 및 원리

핵심 조건: 범위 정의, 표준화된 산출물, 의사결정 거버넌스, 성과 지표가 하나의 관리 체계로 묶여야 EVM SPI CPI 진척 통계이 형식적 문서가 아니라 실행 도구가 된다.

EVM SPI CPI 진척 통계는 문서 양식을 늘리는 기법이 아니라 전략과 실행 사이의 의사결정 틀을 표준화하는 도구다. 따라서 구조를 이해할 때는 산출물 자체보다 그것이 어떤 판단 근거가 되고, 어떤 검토 주기를 통해 갱신되는지를 같이 봐야 한다.

동작 순서:

  1. 경보 기준 설정: SPI < 0.9 또는 CPI < 0.9 → 월간 보고에서 원인 분석 및 시정 계획 수립 의무화.
  2. 롤업 분석: 전체 WBS의 EVM을 임계 경로 활동 레벨까지 분해하여 문제 활동 조기 탐지.
  3. BAC(예산) = 1억 원 / 현재 진행률 계획: 50% / 실제 완료: 40% / 실제 지출: 5,500만 원.
  4. PV = 5,000만 원 (50% × 1억).

EVM 계산 예시

  • BAC(예산) = 1억 원 / 현재 진행률 계획: 50% / 실제 완료: 40% / 실제 지출: 5,500만 원
  • PV = 5,000만 원 (50% × 1억)
  • EV = 4,000만 원 (40% × 1억)
  • AC = 5,500만 원
  • SV = 4,000 - 5,000 = -1,000만 원 (일정 지연)
  • CV = 4,000 - 5,500 = -1,500만 원 (비용 초과)
  • SPI = 4,000/5,000 = 0.80 (20% 일정 지연)
  • CPI = 4,000/5,500 = 0.73 (27% 비용 초과)
  • EAC = 1억/0.73 = 1억 3,700만 원 (최종 예상 비용)

CPM(472)과 EVM의 통합

CPM이 "언제 완료되는가"를 분석한다면, EVM은 "얼마의 비용으로 완료되는가"를 예측한다. 두 기법을 통합하면 임계 경로 상 활동의 비용 성과를 중점 관리하는 일정-비용 통합 관리가 가능하다.

4. 비교 및 연결

공공 SW 사업 EVM 적용 시 판단 기준

  1. 경보 기준 설정: SPI < 0.9 또는 CPI < 0.9 → 월간 보고에서 원인 분석 및 시정 계획 수립 의무화
  2. TCPI 활용: TCPI > 1.1이면 잔여 작업에서 현실적으로 불가능한 효율 요구 → EAC 재산정 및 범위 조정 검토
  3. 롤업 분석: 전체 WBS의 EVM을 임계 경로 활동 레벨까지 분해하여 문제 활동 조기 탐지
  4. 발주처 보고: 월별 EVM 대시보드(S-curve + 주요 지표)를 시각화하여 의사결정권자에게 보고

5. 실무 적용 및 판단

기대효과: 프로젝트 조기 경보로 실패 프로젝트 조기 구제 또는 종료 결정, 예산 초과 예방, 발주처 신뢰 향상.

한계: EVM은 완료율(%) 정의가 주관적이어서 진척도 측정 정확도가 핵심 전제, 소규모 프로젝트에서는 관리 오버헤드 과다.

6. 기대효과 및 결론

EVM SPI CPI 진척 통계는 가시성 향상, 의사결정 정합성 강화, 실행 통제 고도화 측면에서 조직의 성과와 안정성을 높일 수 있는 체계다. 다만 EVM은 완료율(%) 정의가 주관적이어서 진척도 측정 정확도가 핵심 전제, 소규모 프로젝트에서는 관리 오버헤드 과다.가 발생하면 도입 효과가 빠르게 약화되므로, 명확한 책임 구조와 지속적 피드백 체계를 전제로 적용 범위와 우선순위를 단계적으로 관리해야 한다. 향후에는 디지털 전환과 지능형 분석 도구가 결합되어 계획 수립과 성과 통제가 더 실시간으로 연결되는 방향으로 발전할 가능성이 크다.
