0. 핵심 인사이트

핵심: 과적합(Overfitting)은 모델이 훈련 데이터의 노이즈까지 학습하여 새 데이터에서 성능이 급락하는 현상이고, 과소적합(Underfitting)은 모델이 너무 단순하여 훈련 데이터의 패턴조차 포착하지 못하는 현상이다. 둘 다 머신러닝 모델의 일반화(Generalization)를 방해한다. 비유: 과소적합은 5문제 연습하고 100문제 시험보는 것(준비 부족), 과적합은 교과서 문제 답을 다 외웠지만 새 문제는 못 푸는 것(암기 과잉)이다. 진정한 학습은 원리를 이해해서 새 문제도 풀 수 있어야 한다.

📝 모범 답안

1. 개요 및 필요성

┌────────────────────────────────────────────────────────────┐
│        과소적합 vs 적정 적합 vs 과적합                       │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  과소적합               적정 적합            과적합          │
│  (Underfitting)        (Just Right)        (Overfitting)   │
│                                                            │
│  훈련 오차: 높음        훈련 오차: 낮음      훈련 오차: 매우↓ │
│  검증 오차: 높음        검증 오차: 낮음      검증 오차: 높음  │
│                                                            │
│  선형 모델로           중간 복잡도          10차 다항식으로  │
│  복잡한 패턴 학습      곡선 학습            노이즈까지 학습   │
└────────────────────────────────────────────────────────────┘

2. 구성요소

학습 곡선 (Learning Curve) 진단

과소적합:                     과적합:
오차│                         오차│
   │─────── 훈련 오차          │   ────── 훈련 오차
   │─────── 검증 오차          │
   │(두 선이 높게 수렴)         │  ──────── 검증 오차
   └──────────────────         └──────────────────
     훈련 데이터 크기              훈련 데이터 크기

과적합 방지 기법

import tensorflow as tf

model = tf.keras.Sequential([
    tf.keras.layers.Dense(128, activation='relu'),
    tf.keras.layers.Dropout(0.3),       # 드롭아웃: 30% 뉴런 임시 제거
    tf.keras.layers.Dense(64, activation='relu',
        kernel_regularizer=tf.keras.regularizers.l2(0.01)),  # L2 정규화
    tf.keras.layers.Dense(1)
])

# 조기 종료: 검증 오차가 증가하기 시작하면 훈련 중단
early_stopping = tf.keras.callbacks.EarlyStopping(
    monitor='val_loss', patience=10, restore_best_weights=True)

3. 구조 및 원리

핵심 조건: 과적합·과소적합 (Overfitting / Underfitting) — 모델 일반화의 두 극단의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

증상과소적합과적합
편향-분산높은 편향높은 분산
학습 곡선훈련·검증 오차 모두 높음훈련↓ 검증↑ 큰 갭
해결 방향모델 복잡도↑, 피처 추가정규화, 데이터 증강

데이터 증강 (Data Augmentation)

# 이미지 데이터 증강으로 과적합 방지
data_augmentation = tf.keras.Sequential([
    tf.keras.layers.RandomFlip("horizontal"),
    tf.keras.layers.RandomRotation(0.2),
    tf.keras.layers.RandomZoom(0.2),
])
# 제한된 훈련 데이터를 다양한 변형으로 가상 확대 → 과적합 감소

4. 비교 및 연결

체계적 진단 및 처방 프로세스

1. 베이스라인 모델 훈련
       │
       ▼
2. 학습 곡선 분석
   과소적합? → 모델 복잡도↑, 피처 엔지니어링, 에포크↑
   과적합? → 정규화, 드롭아웃, 데이터 증강, 조기 종료
       │
       ▼
3. 교차 검증(K-Fold)으로 일반화 성능 검증
       │
       ▼
4. 테스트 세트로 최종 평가 (딱 한 번만)

안티패턴

  • 테스트 세트로 반복 평가하며 모델을 튜닝하는 안티패턴("테스트 세트 누수"). 테스트 세트는 모델 개발이 완전히 끝난 후 최종 성능을 측정하는 데 딱 한 번만 사용해야 한다. 반복 사용하면 테스트 세트에 대한 암묵적 과적합이 발생한다.

5. 실무 적용 및 판단

기대효과내용
일반화 향상새 데이터에서도 안정적 성능
진단 기반 최적화학습 곡선으로 정확한 문제 파악
신뢰할 수 있는 모델운영 환경에서 예측 가능한 동작

전이학습(Transfer Learning)은 대규모 데이터로 사전 훈련된 모델(BERT, ViT)을 소규모 도메인 데이터에 파인튜닝하여 과소적합을 방지하면서 과적합도 줄이는 현대 ML의 핵심 패러다임이다.
