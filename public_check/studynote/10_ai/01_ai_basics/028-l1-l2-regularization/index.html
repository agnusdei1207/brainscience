0. 핵심 인사이트

핵심: L1(Lasso)과 L2(Ridge) 규제화는 손실 함수에 가중치 크기에 비례하는 패널티를 추가하여 모델 과적합(Overfitting)을 방지한다. L1은 희소(Sparse) 가중치를 유도해 Feature Selection 효과를, L2는 가중치를 균등하게 축소해 안정적 일반화를 제공한다. 비유: 규제화는 모델에게 "너무 복잡하게 외우지 마라"는 제약이다. L1은 "쓸모없는 공식은 아예 지워라(가중치 0화)", L2는 "모든 공식을 조금씩 단순하게 만들어라"라고 제약을 준다.

📝 모범 답안

1. 개요 및 필요성

┌──────────────────────────────────────────────────────┐
│         L1/L2 규제화 수식 비교                        │
├──────────────────────────────────────────────────────┤
│                                                       │
│  일반 손실 함수:  L = Loss(y, ŷ)                      │
│                                                       │
│  L1 Lasso:  L = Loss + λ × Σ|wᵢ|                    │
│  L2 Ridge:  L = Loss + λ × Σwᵢ²                     │
│  ElasticNet: L = Loss + λ₁×Σ|wᵢ| + λ₂×Σwᵢ²          │
│                                                       │
│  λ (람다) = 규제 강도 (하이퍼파라미터)                │
│  λ ↑ → 규제 강함 → 언더피팅 위험                     │
│  λ ↓ → 규제 약함 → 오버피팅 위험                     │
└──────────────────────────────────────────────────────┘

2. 구성요소

기하학적 해석

L1 제약 (다이아몬드):          L2 제약 (원):
       w₂                           w₂
        |                             |
    ◇ 다이아몬드                  ○ 원형
        |                             |
   ─────┼─────  w₁              ─────┼─────  w₁
        |                             |
  모서리에서 교점 → w₁=0 가능   원에서 교점 → 모두 작은 값
  (Feature Selection)           (Weight Decay)

그래디언트 관점

L2: 가중치 업데이트 시 wᵢ × (1-2λη) → 비율적 감소 (Weight Decay)
L1: 가중치 업데이트 시 wᵢ - λη×sign(wᵢ) → 절댓값에서 일정량 차감
    → 작은 가중치는 0으로 수렴 (Sparse)

3. 구조 및 원리

핵심 조건: L1/L2 규제화 상세 (L1/L2 Regularization)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

비교L1 (Lasso)L2 (Ridge)ElasticNet
희소성✅ 가중치 0화❌중간
다중공선성 처리약함강함강함
Feature Selection✅ 내장❌부분
수학적 안정성미분 불연속연속연속

4. 비교 및 연결

L1/L2 규제화 상세 (L1/L2 Regularization)은(는) 유사 개념과 비교할 때 적용 범위, 계산 비용, 해석 가능성, 운영 난이도에서 차이가 난다. 따라서 대안 기술과의 경계와 연결 관계를 함께 판단해야 한다.

5. 실무 적용 및 판단

L1 Lasso 적합:
  - 수천 개 Feature 중 핵심 Feature 선택 필요
  - 의료 데이터: 수백 개 유전자 중 핵심 유전자 선택
  - 텍스트 분류: 수만 개 단어 중 핵심 단어만 남기기

L2 Ridge 적합:
  - Feature 간 상관관계가 높은 경우 (다중공선성)
  - 모든 Feature가 다소 관련 있어 제거보다 축소가 적합
  - 금융 데이터: 서로 연관된 경제 지표들

ElasticNet 적합:
  - Feature 수 > 샘플 수 (고차원 데이터)
  - L1+L2 균형 필요 (상관된 Feature 그룹에서 일부 선택)
기대효과내용
과적합 방지훈련 데이터 암기 대신 패턴 학습
Feature Selection (L1)자동 불필요 특성 제거
일반화 성능테스트 데이터 예측력 향상

딥러닝에서는 L2 규제화(Weight Decay)가 Adam 옵티마이저에 통합된 AdamW로 구현되어 표준화됐다. L1 희소 가중치는 뉴럴 네트워크 가지치기(Pruning)와 결합되어 모델 경량화에 활용된다.

6. 기대효과 및 결론

ElasticNet 적합:

  • Feature 수 > 샘플 수 (고차원 데이터)
  • L1+L2 균형 필요 (상관된 Feature 그룹에서 일부 선택)

딥러닝에서는 L2 규제화(Weight Decay)가 Adam 옵티마이저에 통합된 AdamW로 구현되어 표준화됐다. L1 희소 가중치는 뉴럴 네트워크 가지치기(Pruning)와 결합되어 모델 경량화에 활용된다.
