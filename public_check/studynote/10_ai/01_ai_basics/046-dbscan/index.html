0. 핵심 인사이트

핵심: DBSCAN — 밀도 기반 군집화은(는) 인공지능 시스템에서 문제를 표현하고 의사결정 또는 학습으로 연결하는 핵심 개념이다. 비유: DBSCAN의 점 유형은 모임 분류 — 핵심 점(모임 주최자: 주변에 친구 많음), 경계 점(참가자: 주최자 알지만 본인은 친구 적음), 잡음(아는 사람 없는 혼자)!

📝 모범 답안

1. 개요 및 필요성

밀도 기반 군집화 직관:

k-means 한계:
  원형 군집만 식별 가능
  이상치에 민감
  k를 미리 지정해야 함

DBSCAN 핵심 아이디어:
  "밀도가 높은 지역 = 군집"
  밀도 기준 이하 = 이상치(Noise)

  직관: 별이 모여 있는 곳 = 별자리
        홀로 떨어진 별 = 이상치

점 유형:

매개변수: ε (반경), minPts (최소 이웃)

핵심 점 (Core Point):
  ε 반경 내 minPts개 이상 이웃
  → 밀도 충족 = 군집의 중심

경계 점 (Border Point):
  ε 반경 내 minPts 미만 이웃
  BUT 핵심 점의 ε 반경 내에 있음
  → 군집에 속하지만 중심 아님

잡음 점 (Noise Point):
  핵심 점도 아니고 경계 점도 아님
  → 이상치 (Outlier)

예: ε=1, minPts=3

  A•  •B       D•
  •C      •E        •F (F = Noise)

  A,B,C가 서로 ε 내에 있고 각각 3개 이웃
  → A,B,C = Core Points → 같은 군집
  D,E = Border Points (핵심 점의 ε 내, 하지만 minPts 미달)
  F = Noise

2. 구성요소

DBSCAN 알고리즘:

입력: 데이터셋 D, ε, minPts
출력: 군집 레이블 (-1 = Noise)

의사코드:
  1. 모든 점 미방문(unvisited)으로 초기화

  2. 각 점 P에 대해:
     이미 방문 → 건너뜀
     P를 방문 표시

     N = ε-이웃(P)   (P에서 ε 내 모든 점)

     if |N| < minPts:
       P = Noise (-1 표시)  # 나중에 경계점이 될 수도 있음
     else:
       새 군집 C 생성
       P를 C에 추가
       씨앗 집합 S = N

       while S 비어있지 않음:
         Q = S에서 점 하나 꺼냄
         Q 미방문이면: Q를 방문 표시
                      N' = ε-이웃(Q)
                      if |N'| >= minPts:
                        S = S ∪ N'
         Q가 어떤 군집에도 없으면: Q를 C에 추가

시간 복잡도:
  이웃 탐색 O(n log n) (공간 인덱스)
  전체: O(n log n)

  최악 (인덱스 없음): O(n²)
  → 큰 데이터셋: KD-Tree, Ball Tree 사용

결과:
  군집 (정수 라벨): 0, 1, 2, ...
  이상치: -1

3. 구조 및 원리

핵심 조건: DBSCAN — 밀도 기반 군집화의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

ε (Epsilon)과 minPts 선택:

ε 결정법 (k-거리 그래프):
  1. 각 점의 k번째 (= minPts-1번째) 이웃 거리 계산
  2. 오름차순 정렬 → 그래프 시각화
  3. 팔꿈치(Elbow) 지점 = 적절한 ε

  팔꿈치 전: 밀도 높은 지역 (군집 내부)
  팔꿈치 후: 급격히 증가 (이상치)
  팔꿈치: 군집 경계

minPts 선택:
  일반 규칙: minPts ≥ 차원 수 + 1
  2D: minPts = 3~5
  고차원: minPts = 더 크게

  minPts 작으면: 작은 군집도 군집으로 인식
  minPts 크면: 큰 핵심 군집만 인식

ε 영향:
  ε 너무 작음:
  → 거의 모든 점 = Noise

  ε 너무 큼:
  → 모든 점 = 하나의 군집

예: 지리 데이터
  위도/경도 포인트
  ε = 0.5km, minPts = 5

  상업 지역: 점 밀집 → 군집
  외딴 집: Noise

  k-거리 그래프로 ε = 0.5km 확인

4. 비교 및 연결

DBSCAN 한계:
  가변 밀도 군집: 하나의 ε으로 못 잡음

  예:
  군집 A: 매우 촘촘 (밀도 높음)
  군집 B: 느슨함 (밀도 낮음)
  → A에 맞는 ε: B를 군집으로 못 잡음
  → B에 맞는 ε: A와 B가 하나의 군집으로 합쳐짐

HDBSCAN (Hierarchical DBSCAN):
  ε을 여러 값으로 시도
  → 계층적 군집 트리 생성
  → 안정적인 군집 자동 선택

  장점:
  가변 밀도 처리
  k만 조정 (ε 불필요)
  더 강건한 군집

  단점:
  DBSCAN보다 느림

OPTICS (Ordering Points To Identify Clustering Structure):
  도달 가능 거리(Reachability Distance) 기반
  DBSCAN 일반화
  밀도 변화 시각화

비교:

| 알고리즘 | k 필요 | 이상치 | 형태 | 속도 |
|--------|------|------|------|------|
| k-means | O | X | 구형만 | 빠름 |
| DBSCAN | X | O | 임의 | 보통 |
| HDBSCAN | X | O | 임의 | 느림 |

실무 선택:
  이상치 탐지 중요 + 임의 형태: DBSCAN
  가변 밀도: HDBSCAN
  간단한 원형 군집: k-means

5. 실무 적용 및 판단

금융 거래 이상치 탐지 (DBSCAN 활용):

문제:
  신용카드 거래 이상치 탐지
  하루 100만 건 거래
  이상 거래 패턴 자동 식별

데이터 특징:
  features: [금액, 시간대, 상점카테고리, 위치, 빈도]
  정상 거래: 일상적 패턴 → 밀집 군집
  이상 거래: 패턴 이탈 → Noise

구현:
  import sklearn
  from sklearn.cluster import DBSCAN
  from sklearn.preprocessing import StandardScaler

  # 정규화 (단위 통일)
  scaler = StandardScaler()
  X_scaled = scaler.fit_transform(transactions)

  # DBSCAN 적용
  db = DBSCAN(eps=0.5, min_samples=10)
  labels = db.fit_predict(X_scaled)

  # Noise = 이상 거래
  anomalies = transactions[labels == -1]

  # 결과: 약 2% 이상 거래 탐지

성능:
  정밀도(Precision): 87% (이상 탐지의 87%가 실제 이상)
  재현율(Recall): 73% (실제 이상의 73% 탐지)

  k-means 대비:
  이상치 탐지 정밀도 20%p 향상
  (k-means는 Noise 개념 없어 이상치 군집에 포함)

한계 및 보완:
  고차원: t-SNE 차원 축소 후 DBSCAN
  실시간: Micro-cluster DBSCAN (스트리밍)
  레이블 없음: 정기 전문가 검토로 정밀도 보정

6. 기대효과 및 결론

k-means 대비: 이상치 탐지 정밀도 20%p 향상 (k-means는 Noise 개념 없어 이상치 군집에 포함)

한계 및 보완: 고차원: t-SNE 차원 축소 후 DBSCAN 실시간: Micro-cluster DBSCAN (스트리밍) 레이블 없음: 정기 전문가 검토로 정밀도 보정
