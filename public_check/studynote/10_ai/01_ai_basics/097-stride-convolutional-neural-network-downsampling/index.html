0. 핵심 인사이트

핵심: 스트라이드 (Stride)는 CNN (Convolutional Neural Network)에서 필터 (Filter)가 입력 이미지를 순회하며 특성을 추출할 때, 한 번에 이동하는 픽셀(보폭)의 간격이다. 비유: 스트라이드는 해변에서 금속 탐지기로 동전을 찾는 보폭과 같다. 보폭이 작으면 모래사장 전체를 꼼꼼히 뒤져 모든 동전을 찾지만 하루 종일 걸리고, 보폭이 크면 작은 동전은 놓칠 수 있지만 해변 전체를 순식간에 탐색할 수 있다.

📝 모범 답안

1. 개요 및 필요성

스트라이드 (Stride)는 합성곱 층 (Convolution Layer)이 입력 데이터를 스캔할 때 필터가 이동하는 픽셀 수를 정의하는 매개변수다. 스트라이드가 1이면 필터가 한 칸씩 이동하며 촘촘하게 이미지를 훑고, 2 이상이면 듬성듬성 건너뛰며 이동한다.

이 개념이 필요한 이유는 이미지 해상도가 커질수록 모델이 처리해야 할 연산량이 기하급수적으로 증가하기 때문이다. 모든 픽셀을 1칸씩 스캔하면 미세한 특징을 전부 보존할 수 있지만, 수백만 개의 픽셀을 처리하느라 GPU 메모리와 계산 자원에 심각한 병목(Bottleneck)이 발생한다. 따라서 공간적 차원을 줄이면서도 의미 있는 전역 특징(Global Feature)을 유지하기 위해 보폭을 조절하는 기법이 필수적이다.

2. 구성요소

합성곱 연산에서 스트라이드는 입력 이미지의 크기, 필터의 크기, 패딩(Padding)과 결합하여 출력 특성 맵의 크기를 결정한다. 스트라이드가 커질수록 출력 크기는 반비례하여 작아진다.

출력 특성 맵 크기 계산 공식: $$ \text{Output Size} = \lfloor \frac{\text{Input} + 2 \times \text{Padding} - \text{Filter}}{\text{Stride}} \rfloor + 1 $$

┌──────────────────────────────────────────────────────────────┐
│       Stride 1 vs Stride 2 의 스캔 방식 비교 (1D 예시)       │
├──────────────────────────────────────────────────────────────┤
│ [입력 데이터]  1   2   3   4   5                           │
│                                                              │
│ [Stride = 1] ┌─┴─┐                                           │
│  필터 이동   1,2,3 -> 2,3,4 -> 3,4,5  (출력 크기: 3)         │
│                                                              │
│ [Stride = 2] ┌─┴─┐                                           │
│  필터 이동   1,2,3 ----------> 3,4,5  (출력 크기: 2)         │
│                                                              │
│ * Stride가 커지면 필터의 중첩(Overlap) 영역이 줄어듦       │
└──────────────────────────────────────────────────────────────┘

이 다이어그램은 스트라이드의 크기에 따라 필터가 데이터를 건너뛰는 방식을 보여준다. Stride=2를 적용하면 가로와 세로 차원이 각각 1/2로 줄어들어 전체 특성 맵의 면적(연산량)은 1/4로 극적으로 압축된다.

3. 구조 및 원리

핵심 조건: 스트라이드 (Stride)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

해상도를 줄이는 차원 축소 (Downsampling) 기법으로는 맥스 풀링 (Max Pooling)과 스트라이드 합성곱 (Strided Convolution)이 자주 비교된다.

항목맥스 풀링 (Max Pooling)스트라이드 합성곱 (Strided Convolution)
방식촘촘히 스캔(Stride 1) 후 가장 큰 값만 남김처음부터 듬성듬성 스캔(Stride $\ge$ 2)
연산량특징 추출 연산 후 풀링 연산 추가 (비효율 발생 가능)특징 추출과 차원 축소를 한 번에 처리
정보 손실정해진 규칙(Max/Average)에 의해 강제로 정보 폐기가중치(Weight) 학습을 통해 중요한 정보를 스스로 유지
적용 트렌드과거 아키텍처 (VGGNet 등)현대 아키텍처 (ResNet, MobileNet 등)

최근의 딥러닝 트렌드는 별도의 풀링 층을 두는 대신, 합성곱 층 내부에서 스트라이드를 키워 모델이 차원 축소 과정 자체를 "학습"하게 만드는 방향으로 발전했다.

4. 비교 및 연결

실무에서 아키텍처를 설계할 때 스트라이드 설정은 연산 자원과 모델 정확도를 결정짓는 핵심 의사결정이다. 자원이 제한된 엣지 디바이스(Edge Device)나 실시간 처리가 필요한 시스템에서는 스트라이드 튜닝이 필수적이다.

5. 실무 적용 및 판단

  1. 입출력 차원 매칭: 설정한 스트라이드 값으로 나눈 결과가 정수로 딱 떨어지는가? (나머지가 생기면 프레임워크에 따라 비대칭 패딩 문제가 발생할 수 있다.)
  2. 미세 특징의 중요도: 질병 진단 의료 이미지처럼 1픽셀의 미세한 점이 중요한 도메인인가? (이 경우 전반부에 너무 큰 스트라이드를 주면 치명적이다.)
  3. 병목 구간 회피: 초기 층(Layer)의 입력 해상도가 너무 커서 OOM (Out Of Memory)이 발생하지 않는가?
  • 채택 (Stride $\ge$ 2): 스마트폰 얼굴 인식, 자율주행 차량의 객체 탐지처럼 초당 프레임(FPS)과 연산 속도가 생명인 실시간 비전 모델 설계 시 우선 채택한다.
  • 회피 (Stride 1 유지): 초고해상도 복원 (Super Resolution), 의료 영상 세그멘테이션 (Segmentation) 등 원본 이미지의 디테일과 픽셀 단위의 정확한 위치 정보가 필요한 경우엔 공간 차원을 줄이지 말아야 한다.

스트라이드의 도입은 딥러닝 모델이 무거운 이미지 데이터를 빠르고 효율적으로 소화하게 만든 일등 공신이다. 이를 통해 연산 병목을 제거하고, 전체 네트워크를 더 깊게 쌓을 수 있는(Deep Network) 토대를 마련했다.

하지만 스트라이드를 과도하게 높이면 중요한 위치 정보(Spatial Information)가 영구적으로 유실될 한계가 존재한다. 따라서 현대의 CNN은 초기 층에서는 미세한 특징을 뽑고(Stride 1), 깊어질수록 공간을 압축하며 추상적인 특징을 잡는(Stride 2) 계층적 구조를 통해 속도와 정확도의 최적 타협점을 찾는다.

7. 발전 흐름도

합성곱 층 연산 기초 확립
    │
    ▼
스트라이드 (Stride) · 필터 이동 보폭 제어
    │
    ▼
맥스 풀링 (Max Pooling) 대체 · Strided Convolution 활성화
    │
    ▼
모바일 최적화 네트워크 (MobileNet 등) · 연산량 감소
    │
    ▼
확장 합성곱 (Dilated Convolution) · 해상도 유지하며 수용 영역 확장

이 흐름도는 "보폭 제어 → 풀링 대체 → 경량화 → 단점(해상도 저하) 보완"으로 이어지는 합성곱 구조의 진화 과정을 보여준다.

패딩 (Padding)스트라이드 적용 시 가장자리 정보 유실과 차원을 보정하는 짝꿍 기법
