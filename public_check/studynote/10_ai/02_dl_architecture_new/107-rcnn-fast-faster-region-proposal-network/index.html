0. 핵심 인사이트

핵심: 객체 탐지(Object Detection) 영역에서 영역 추정(Region Proposal)과 CNN (Convolutional Neural Network) 분류를 분리하여 수행하는 2-Stage 모델의 발전 과정(R-CNN → Fast R-CNN → Faster R-CNN)이다. 비유: R-CNN 시리즈의 진화는 범인을 찾는 경찰의 수사망 압축 과정과 같다. 동네 집을 다 뒤지는 대신 수상한 집 2,000곳만 뒤지는 것(R-CNN)에서 출발해, 동네 전체 사진을 한 번에 찍어 수상한 곳만 확대해 보는 방식(Fast)으로, 결국 드론을 띄워 수상한 곳 자체를 인공지능이 즉시 찾아내는 방식(Faster)으로 진화한 것이다.

📝 모범 답안

1. 개요 및 필요성

R-CNN (Regions with Convolutional Neural Network features) 계열 모델은 이미지 내에서 물체가 있을 만한 위치를 먼저 찾고, 그 위치에 있는 물체가 무엇인지 분류(Classification)하는 2-Stage 객체 탐지 방식의 표준이다. 과거의 객체 탐지는 슬라이딩 윈도우 방식으로 이미지 전체를 훑으며 분석했기 때문에 컴퓨팅 자원 낭비가 극심했다. 이를 해결하기 위해 물체가 있을 법한 후보 영역만 골라내어 분석하는 방식이 도입되었으나, 초기 R-CNN은 2,000개의 후보 영역을 각각 CNN에 통과시켜야 하므로 병목 현상이 심각했다. 이를 해결하기 위해 연산 공유와 신경망 통합이라는 두 번의 핵심적인 혁신을 거쳐 지금의 Faster R-CNN으로 진화하게 되었다.

2. 구성요소

R-CNN 계열의 진화는 "반복되는 CNN 연산을 어떻게 줄일 것인가"와 "병목이 되는 외부 알고리즘을 어떻게 내재화할 것인가"에 초점이 맞춰져 있다.

  1. R-CNN (2014): 이미지에서 Selective Search 알고리즘으로 2,000개의 RoI (Region of Interest) 후보 영역을 추출하고, 각 영역을 동일한 크기로 잘라내어 2,000번의 CNN 연산을 수행한다. 속도가 매우 느리다.
  2. Fast R-CNN (2015): 이미지 전체를 CNN에 단 한 번만 통과시켜 특성 맵(Feature Map)을 생성한다. 그리고 Selective Search로 찾은 좌표를 이 특성 맵에 투영하여 RoI Pooling 계층을 통해 엑기스만 추출한다. 2,000번의 CNN 연산을 1번으로 줄였다.
  3. Faster R-CNN (2015): 가장 큰 병목이었던 Selective Search (CPU 연산)를 버리고, 후보 영역 자체를 찾아내는 소형 신경망 RPN을 도입했다. 이로써 추출부터 분류까지 완벽한 종단간(End-to-End) 딥러닝 모델이 완성되었다.
┌─────────────────────────────────────────────────────────────┐
│               [ 2-Stage Object Detection 진화 ]             │
├─────────────────────────────────────────────────────────────┤
│ [R-CNN]                                                     │
│ 이미지 ─(Selective Search)─▶ 2,000개 조각 ─(CNN 2,000번)─▶ 판별 │
│                                                             │
│ [Fast R-CNN]                                                │
│ 이미지 ─(CNN 1번)─▶ 특성 맵 ─(RoI Pooling)─▶ 2,000개 추출 ─▶ 판별 │
│                 ▲                                           │
│                 └─ (Selective Search로 좌표만 전달)          │
│                                                             │
│ [Faster R-CNN]  ★ 병목 완전 제거                            │
│ 이미지 ─(CNN 1번)─▶ 특성 맵 ┬─(RPN)─▶ 후보 영역 좌표 제안       │
│                            └─(RoI Pooling)─▶ 최종 판별     │
└─────────────────────────────────────────────────────────────┘

여기서 RPN은 앵커 박스(Anchor Box)라는 다양한 비율과 크기의 기본 틀을 특성 맵 위에 겹쳐보며 물체의 존재 확률과 위치를 빠르게 계산해낸다.

3. 구조 및 원리

핵심 조건: R-CNN, Fast R-CNN, Faster R-CNN (2-Stage 탐지기) 진화의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

2-Stage 계열의 핵심 경쟁자는 1-Stage 탐지기인 YOLO와 SSD (Single Shot MultiBox Detector)다. 두 방식은 정확도와 속도라는 명확한 트레이드오프를 가진다.

비교 항목2-Stage (Faster R-CNN)1-Stage (YOLO, SSD)
처리 방식후보 영역 추출 후 → 분류 (직렬 처리)이미지 전체를 그리드로 나누어 동시 예측
속도FPS (Frames Per Second) 낮음수십~수백 FPS의 극히 빠른 속도
정확도매우 높음 (작은 객체에 강함)다소 낮음 (작은/겹친 객체에 약함)
핵심 활용처의료 영상, 위성 사진 분석, 정밀 결함 검출자율주행, 실시간 CCTV, 모바일 앱

Faster R-CNN의 성공 이후, 분할(Segmentation) 작업을 추가한 Mask R-CNN으로 모델이 확장되며 컴퓨터 비전의 기초 뼈대로 자리 잡았다.

4. 비교 및 연결

실무에서 객체 탐지 모델을 선정할 때는 지연 시간(Latency)의 한계선과 오탐/미탐의 치명도를 기준으로 판단해야 한다.

  1. Faster R-CNN 채택 시점:
    • 반도체 웨이퍼 결함 검출이나 엑스레이 기반 암세포 탐지처럼, 약간 느려도 미세한 객체를 100% 잡아내야 하는 QA (Quality Assurance) 도메인에서 우선 채택한다.
  2. 최적화 전략:
    • Faster R-CNN은 여전히 무겁기 때문에, 백본(Backbone) 네트워크를 무거운 ResNet-101에서 가벼운 MobileNet으로 교체하여 속도와 정확도의 타협점을 찾는 튜닝이 필수적이다.
  3. 안티패턴:
    • 실시간성이 생명인 초고속 드론 장애물 회피 시스템에 Faster R-CNN을 무리하게 도입하여 추론 지연(Inference Delay)으로 사고를 유발하는 설계는 피해야 한다.

5. 실무 적용 및 판단

R-CNN에서 Faster R-CNN으로의 발전은 단순히 속도 향상을 넘어, 객체 탐지의 모든 과정을 딥러닝 하나로 통합했다는 데에 큰 의의가 있다. 이를 통해 개발자는 복잡한 외부 알고리즘 파이프라인을 관리할 필요 없이 모델 튜닝에만 집중할 수 있게 되었다.

한계점으로는 구조적 복잡성으로 인해 메모리 사용량이 많고 온디바이스(On-Device) 추론에는 부담이 된다는 점이 있다. 결론적으로 Faster R-CNN은 객체 탐지 역사상 가장 우아한 아키텍처 혁신이며, 정확도를 타협할 수 없는 모든 비전 시스템의 든든한 기준으로 기억되어야 한다.
