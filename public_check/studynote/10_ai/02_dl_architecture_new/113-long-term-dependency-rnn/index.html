0. 핵심 인사이트

핵심: 장기 의존성 문제(Long-term Dependency)는 RNN이 시퀀스가 길어질 때 초기 시간 단계의 정보를 후반 단계까지 유지하지 못하는 근본적 한계이며, 역전파 시 기울기가 시간 축을 따라 **기하급수적으로 소실(Vanishing)하거나 폭발(Exploding)**하는 것이 수학적 원인이다. 비유: 100명이 릴레이로 소문을 전달하면, 마지막 사람은 원래 메시지를 거의 기억 못 한다(소실). 또는 과장이 반복되어 완전히 다른 이야기가 된다(폭발).

📝 모범 답안

1. 개요 및 필요성

┌───────────────────────────────────────────────────────┐
│    기울기 소실/폭발 메커니즘                            │
├───────────────────────────────────────────────────────┤
│  역전파 시 기울기 = ∂L/∂h₁ = ∂L/∂h_T × ∏(∂h_t/∂h_{t-1})│
│                              = ∂L/∂h_T × W_h^T        │
│                                                       │
│  |W_h| < 1 → W_h^100 ≈ 0       (기울기 소실 📉)     │
│  |W_h| > 1 → W_h^100 ≈ ∞       (기울기 폭발 📈)     │
│                                                       │
│  결과: T=100일 때 h₁의 영향이 h₁₀₀에 도달 못 함      │
│  → "100단어 전 주어를 현재 동사와 연결 불가능"        │
└───────────────────────────────────────────────────────┘

2. 구성요소

LSTM의 해결 메커니즘

게이트역할
Forget Gate ($f_t$)이전 기억 중 버릴 것 결정
Input Gate ($i_t$)새 정보 중 저장할 것 결정
Output Gate ($o_t$)현재 출력에 쓸 기억 결정
Cell State ($C_t$)장기 기억 고속도로 (기울기 직통)

Cell State = 기울기 고속도로

$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$

Cell State는 행렬 곱셈이 아닌 **원소별 곱(Hadamard Product)**으로 전파되므로, $W_h^T$ 반복 곱셈이 없어 기울기가 소실되지 않는다.

3. 구조 및 원리

핵심 조건: 장기 의존성 문제 (Long-term Dependency in RNN)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

비교바닐라 RNNLSTMTransformer
장기 의존성실패성공 (게이트)완전 해결 (Attention)
경로 길이O(T)O(T) (but 보호됨)O(1) (직접 접근)
병렬화불가불가완전 가능

4. 비교 및 연결

기울기 폭발 해결

  • Gradient Clipping: 기울기 norm이 임계값을 넘으면 잘라내기. torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

장기 의존성이 중요한 태스크

  1. 기계 번역: 주어-동사 일치 (50+ 단어 거리).
  2. 음악 생성: 조성·리듬 패턴 유지 (수백 노트).
  3. DNA 서열 분석: 수천 염기 거리의 상호작용.

5. 실무 적용 및 판단

장기 의존성 문제는 시퀀스 모델링의 가장 근본적인 도전이었으며, LSTM(1997)이 20년간 해법으로 군림했다. Transformer(2017)가 Self-Attention으로 경로 길이를 O(1)로 줄여 완전히 극복했고, 현재 Mamba·RWKV 등 선형 복잡도 시퀀스 모델이 Attention의 $O(T^2)$ 비용을 줄이면서 장기 의존성을 유지하는 새로운 접근을 시도하고 있다.

6. 기대효과 및 결론

장기 의존성 문제는 시퀀스 모델링의 가장 근본적인 도전이었으며, LSTM(1997)이 20년간 해법으로 군림했다. Transformer(2017)가 Self-Attention으로 경로 길이를 O(1)로 줄여 완전히 극복했고, 현재 Mamba·RWKV 등 선형 복잡도 시퀀스 모델이 Attention의 $O(T^2)$ 비용을 줄이면서 장기 의존성을 유지하는 새로운 접근을 시도하고 있다.
