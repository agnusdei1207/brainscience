0. 핵심 인사이트

핵심: BPTT(Backpropagation Through Time)는 RNN의 순환 구조를 시간 축으로 펼친(Unfolding) 후 일반 역전파를 적용하는 학습 알고리즘이며, 펼친 길이 T에 비례하여 $O(T)$의 시간·메모리 비용이 발생한다. 비유: BPTT는 1000페이지 소설을 처음부터 끝까지 형광펜(기울기)으로 표시하는 것이고, Truncated BPTT는 20페이지씩 끊어서 표시하는 것이다.

1. 개요 및 필요성

┌───────────────────────────────────────────────────────┐
│    BPTT: 시간 축 펼침 후 역전파                       │
├───────────────────────────────────────────────────────┤
│  [RNN 순환 구조]        [시간 축 펼침 (Unfolding)]    │
│   ┌──▶ h ──┐            h₁ → h₂ → h₃ → h₄          │
│   │   │    │            ↑    ↑    ↑    ↑             │
│   └── x ───┘            x₁   x₂   x₃   x₄          │
│                                                       │
│  역전파: L → h₄ → h₃ → h₂ → h₁ (시간 역방향)       │
│  기울기: ∂L/∂W = Σ(∂L/∂h_t × ∂h_t/∂W)              │
│                                                       │
│  문제: T=1000이면 h₁까지 1000단계 역전파 → 폭발/소실 │
│  해결: Truncated BPTT (k=20으로 잘라서 역전파)       │
└───────────────────────────────────────────────────────┘

3. 구조 및 원리

핵심 조건: BPTT (Backpropagation Through Time)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

비교BPTT (RNN)일반 역전파 (FC/CNN)
축시간 축 (T 단계)레이어 축 (L 층)
가중치 공유$W_h$ 모든 시간 단계에서 공유레이어별 독립
기울기 누적시간 단계별 기울기 합산레이어별 계산

4. 비교 및 연결

Truncated BPTT 설정 가이드

  • k = 20~50: 일반 NLP·음성 태스크.
  • k = 100~200: 장거리 의존성이 중요한 태스크 (음악 생성).
  • LSTM + k = 35: PyTorch 기본 언어 모델 설정.

5. 실무 적용 및 판단

BPTT는 RNN 학습의 유일한 방법이었으나, Transformer의 Self-Attention은 시간 축 펼침이 불필요하여 BPTT 자체가 필요 없다. 하지만 실시간 스트리밍·엣지 환경에서 RNN/LSTM이 여전히 사용되므로 BPTT의 원리 이해는 필수다.

6. 기대효과 및 결론

BPTT는 RNN 학습의 유일한 방법이었으나, Transformer의 Self-Attention은 시간 축 펼침이 불필요하여 BPTT 자체가 필요 없다. 하지만 실시간 스트리밍·엣지 환경에서 RNN/LSTM이 여전히 사용되므로 BPTT의 원리 이해는 필수다.
