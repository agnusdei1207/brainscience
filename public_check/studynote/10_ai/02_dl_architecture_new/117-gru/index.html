0. 핵심 인사이트

핵심: GRU(Gated Recurrent Unit)는 LSTM의 **3개 게이트(Forget·Input·Output)를 2개 게이트(Reset·Update)**로 간소화하고, Cell State를 제거하여 Hidden State 하나로 장기 기억을 관리하는 경량 시퀀스 모델이다. 비유: LSTM은 3개 수도꼭지(F/I/O)가 있는 정수기이고, GRU는 2개(R/Z)로 줄인 간편 정수기다. 물 맛(성능)은 비슷하지만 구조가 더 단순하다.

📝 모범 답안

1. 개요 및 필요성

┌───────────────────────────────────────────────────────┐
│    GRU vs LSTM 구조 비교                              │
├───────────────────────────────────────────────────────┤
│  [LSTM]                     [GRU]                     │
│   게이트: 3개 (F/I/O)       게이트: 2개 (R/Z)        │
│   상태: C_t + h_t            상태: h_t만              │
│   파라미터: 4개 가중치 행렬   파라미터: 3개 가중치 행렬│
│                                                       │
│  GRU 수식:                                            │
│   z_t = σ(W_z·[h_{t-1}, x_t])   (Update Gate)       │
│   r_t = σ(W_r·[h_{t-1}, x_t])   (Reset Gate)        │
│   h̃_t = tanh(W·[r_t⊙h_{t-1}, x_t]) (Candidate)    │
│   h_t = (1-z_t)⊙h_{t-1} + z_t⊙h̃_t (Output)       │
└───────────────────────────────────────────────────────┘

2. 구성요소

GRU 2개 게이트

게이트수식역할LSTM 대응
Update (z_t)σ(W_z·[h,x])과거 vs 새 정보 비율Forget + Input
Reset (r_t)σ(W_r·[h,x])후보 계산 시 과거 무시 정도별도 없음

z_t의 이중 역할

  • $h_t = (1-z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$
  • z_t가 크면 → 새 정보 채택, 과거 무시 (Input).
  • z_t가 작으면 → 과거 유지, 새 정보 무시 (Forget).
  • 하나의 게이트로 Forget과 Input을 동시에 제어한다.

3. 구조 및 원리

핵심 조건: GRU (Gated Recurrent Unit)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

4. 비교 및 연결

GRU 선택 기준

  • 데이터 적음: GRU (파라미터 적어 과적합 방지).
  • 데이터 풍부 + 복잡한 장기 의존성: LSTM (Cell State의 추가 용량).
  • 엣지 디바이스: GRU (경량).

5. 실무 적용 및 판단

GRU는 LSTM의 "경제적 대안"이며, 실무에서는 둘 다 실험하고 검증 성능이 좋은 쪽을 선택하는 것이 정답이다. Transformer 시대에도 실시간 스트리밍·엣지 환경에서 GRU는 유효하다.

6. 기대효과 및 결론
