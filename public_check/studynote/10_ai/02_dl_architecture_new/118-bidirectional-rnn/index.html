0. 핵심 인사이트

핵심: 양방향 RNN(Bi-RNN)은 시퀀스를 순방향(좌→우)과 역방향(우→좌) 두 개의 RNN으로 동시에 처리하여, 각 시간 단계에서 과거+미래 컨텍스트를 모두 활용하는 시퀀스 모델이다. 비유: 단방향 RNN은 소설을 앞에서부터만 읽는 것이고, Bi-RNN은 앞뒤를 동시에 읽어서 각 문장의 의미를 더 정확히 파악하는 것이다.

1. 개요 및 필요성

┌───────────────────────────────────────────────────────┐
│    양방향 RNN 구조                                    │
├───────────────────────────────────────────────────────┤
│  순방향: x₁ → h₁→ → h₂→ → h₃→ → h₄→              │
│  역방향: x₁ ← h₁← ← h₂← ← h₃← ← h₄← ← x₄      │
│                                                       │
│  출력: y_t = f([h_t→ ; h_t←])  (양쪽 결합)           │
│                                                       │
│  h₃에서: 과거(x₁,x₂,x₃) + 미래(x₃,x₄) 모두 반영   │
└───────────────────────────────────────────────────────┘

2. 구성요소

단방향 vs 양방향

비교단방향 RNN양방향 RNN
컨텍스트과거만과거 + 미래
파라미터1×2× (두 방향)
실시간가능불가 (전체 시퀀스 필요)
적합생성·스트리밍분류·NER·인코더

Bi-LSTM / Bi-GRU

실무에서는 바닐라 Bi-RNN보다 Bi-LSTM·Bi-GRU를 사용하여 장기 의존성도 양방향으로 포착한다.

3. 구조 및 원리

핵심 조건: 양방향 RNN (Bidirectional RNN)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

병렬화불가불가가능
대표GPT (디코더)BERT (인코더)BERT/GPT

4. 비교 및 연결

적합 태스크

  1. NER (개체명 인식): "Apple은 회사? 과일?" → 뒤의 단어로 판단.
  2. 감성 분석: 문장 전체를 보고 긍·부정 판단.
  3. Seq2Seq 인코더: 번역 모델의 입력 인코딩.

부적합 태스크

  • 실시간 텍스트 생성: 다음 단어를 예측해야 하므로 미래 정보 사용 불가.

5. 실무 적용 및 판단

Bi-RNN은 BERT가 양방향 Transformer 인코더로 계승한 핵심 아이디어(양방향 컨텍스트)의 선구자이며, 시퀀스 분류·NER 태스크에서 단방향 대비 일관된 성능 향상을 보인다.
