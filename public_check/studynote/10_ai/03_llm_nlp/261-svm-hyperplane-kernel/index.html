0. 핵심 인사이트

핵심: SVM(Support Vector Machine)은 클래스를 구분하는 초평면(Hyperplane) 중 마진(Margin)이 최대인 것을 찾는 분류기로, 경계면 근처의 극소수 포인트(서포트 벡터)만이 결정에 참여한다. 비유: SVM은 "두 팀 사이에 경계선을 그을 때, 양쪽 팀원에서 가장 멀리 떨어진 선을 택하는 심판"이다. 이 선(최대 마진)이 가장 안전하고 공정한 경계다.

📝 모범 답안

1. 개요 및 필요성

SVM은 Vapnik과 Cortes(1995)가 제안한 지도 학습 알고리즘으로, **통계 학습 이론(Statistical Learning Theory)**에 기반한 가장 수학적으로 엄밀한 분류기 중 하나다.

핵심 동기: 두 클래스를 분리하는 초평면이 무수히 많을 때, 어느 것을 선택해야 하는가? → 마진(Margin)이 가장 큰 초평면을 선택하면 일반화 성능이 가장 높다.

SVM이 빛나는 상황:

  • 고차원 데이터 (특성 수 >> 샘플 수)
  • 명확한 마진 구분이 가능한 데이터
  • 텍스트 분류, 이미지 분류 (딥러닝 이전)
  • 소규모 데이터셋에서 신뢰할 수 있는 경계 필요 시
비교 항목SVMLogistic Regression결정 트리
결정 경계최대 마진 초평면확률 기반 선형 경계축에 평행한 분할
비선형 처리커널 트릭특성 공학 필요자연적으로 비선형
고차원강함중간약함
확률 출력기본 없음 (Platt Scaling 별도)자연적가능

2. 구성요소

최대 마진 초평면 (Maximum Margin Hyperplane)

  2차원 예시:
  ┌──────────────────────────────────────────┐
  │                                          │
  │   ○  ○                                   │
  │  ○  ○  ●---서포트 벡터(Support Vector)  │
  │           ‖  ← 마진(Margin)             │
  │ ─────────────────────── 초평면          │
  │           ‖                             │
  │     ●---서포트 벡터        ● ●          │
  │                             ●           │
  │   클래스 -1               클래스 +1     │
  └──────────────────────────────────────────┘

  초평면: w·x + b = 0
  마진 = 2 / ‖w‖  → 마진 최대화 ≡ ‖w‖ 최소화

  서포트 벡터: 마진 경계에 놓인 점 (결정에 참여하는 유일한 샘플)

하드 마진 vs 소프트 마진

  하드 마진 (Hard Margin): 완전 선형 분리 가능 가정
  ┌────────────────────────────────────────┐
  │ min  1/2 ‖w‖²                         │
  │  s.t. y_i(w·x_i + b) ≥ 1  ∀i         │
  │ (어떤 오분류도 허용하지 않음)          │
  └────────────────────────────────────────┘

  소프트 마진 (Soft Margin): 슬랙 변수 ξ 도입
  ┌────────────────────────────────────────┐
  │ min  1/2 ‖w‖² + C·Σξ_i               │
  │  s.t. y_i(w·x_i + b) ≥ 1 - ξ_i       │
  │       ξ_i ≥ 0                         │
  │ C: 오분류 페널티 (클수록 엄격)         │
  └────────────────────────────────────────┘

커널 트릭 (Kernel Trick)

비선형 데이터를 고차원으로 변환하지 않고, **커널 함수(Kernel Function)**를 통해 내적을 직접 계산한다.

  원본 공간 (비선형 분리)      고차원 공간 (선형 분리)
  ┌─────────────────┐          ┌─────────────────────┐
  │  ●   ○   ●      │  φ(x)   │        ─────        │
  │ ○ ●●●● ○       │ ──────► │    ○   ─────   ○    │
  │  ●   ○   ●      │          │  ●●●● ─────         │
  └─────────────────┘          └─────────────────────┘

  K(x_i, x_j) = φ(x_i)·φ(x_j)  ← 고차원 변환 없이 계산!

주요 커널 함수

커널수식적합 상황
선형 (Linear)K(x,x') = x·x'선형 분리 가능, 고차원 텍스트
다항식 (Polynomial)K(x,x') = (γx·x'+r)^d중간 복잡도 비선형 패턴
RBF/가우시안 (Radial Basis Function)K(x,x') = exp(-γ‖x-x'‖²)가장 범용적, 기본값
시그모이드 (Sigmoid)K(x,x') = tanh(γx·x'+r)신경망 유사 경계

3. 구조 및 원리

핵심 조건: SVM (Support Vector Machine)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

C 파라미터와 γ 파라미터의 효과

  C (소프트 마진 조절):
  ┌────────────────────────────────────────┐
  │ C 작음 → 마진 넓음 → 오분류 허용      │
  │          → 과소적합(Underfitting) 위험 │
  │                                        │
  │ C 큼   → 마진 좁음 → 오분류 불허      │
  │          → 과적합(Overfitting) 위험    │
  └────────────────────────────────────────┘

  γ (RBF 커널 영향 범위):
  ┌────────────────────────────────────────┐
  │ γ 작음 → 넓은 영향 → 부드러운 경계   │
  │          → 과소적합 위험              │
  │ γ 큼   → 좁은 영향 → 복잡한 경계     │
  │          → 과적합 위험                │
  └────────────────────────────────────────┘
지표SVM 장점SVM 단점
고차원 성능강함 (커널 트릭)커널 선택이 어려움
소규모 데이터강함대규모에서 느림 O(n²~n³)
노이즈 내성중간노이즈가 많으면 서포트 벡터 불안정
확률 출력기본 없음Platt Scaling 별도 필요
해석 가능성낮음 (커널 공간)비선형 경계 해석 어려움

4. 비교 및 연결

SVM 적용 전략

  1. 전처리 필수: SVM은 특성 스케일에 민감 → StandardScaler 적용
  2. 커널 선택: 기본적으로 RBF 사용, 선형 분리 가능성 확인 후 Linear 고려
  3. 하이퍼파라미터 탐색: Grid Search로 C, γ 조합 탐색
  4. 대규모 데이터: LinearSVC (SGD 기반) 사용 → O(n) 스케일

SVM의 현재 위치

  딥러닝 등장 이후 SVM의 포지셔닝:
  ┌──────────────────────────────────────────────┐
  │ 강점 유지 영역:                               │
  │  - 소규모 고차원 데이터 (텍스트, 유전자)     │
  │  - 데이터가 부족한 의료 진단                 │
  │  - 이론적 근거가 필요한 규제 환경            │
  │                                              │
  │ 딥러닝에 밀린 영역:                          │
  │  - 이미지 분류 (CNN이 월등)                  │
  │  - 대규모 자연어 처리 (Transformer 우위)     │
  └──────────────────────────────────────────────┘

기술사 답안 포인트

  • "서포트 벡터가 중요한 이유": 결정 경계를 결정하는 것은 전체 데이터 아닌 경계면 샘플들뿐 → 메모리 효율적
  • "커널 선택 기준": 특성 수가 샘플 수보다 많으면 Linear, 비선형 패턴이 있으면 RBF
  • "SVM과 딥러닝 비교": 딥러닝은 특성 자동 추출, SVM은 이론적 보장이 강점

5. 실무 적용 및 판단

SVM을 올바르게 적용하면:

  1. 이론적 일반화 보장: 마진 최대화는 VC 차원(Vapnik-Chervonenkis Dimension) 이론에 의해 과적합을 제어
  2. 고차원 강건성: 특성이 수천 개여도 서포트 벡터만 메모리에 유지하므로 효율적
  3. 비선형 처리: 커널 트릭으로 원본 공간에서 계산 불가능한 비선형 경계를 선형으로 해결
  4. 해석 가능 결정 경계: 서포트 벡터를 확인하여 경계를 정의하는 핵심 샘플 파악
