0. 핵심 인사이트

핵심: 시그모이드(Sigmoid) 함수 σ(x)=1/(1+e⁻ˣ)는 출력을 (0,1) 범위로 압축해 확률적 해석을 가능하게 하지만, 입력이 크거나 작을 때 기울기가 거의 0이 되는 **포화 영역(Saturation Region)**에 진입해 기울기 소실 문제(Vanishing Gradient Problem)를 유발한다. 비유: 시그모이드는 물을 S자 관으로 흘리는 것 — 중앙에서는 물이 잘 흐르지만(기울기 0.25), 양쪽 끝으로 갈수록 관이 막혀 물이 거의 흐르지 않는다(기울기 ≈ 0).

📝 모범 답안

1. 개요 및 필요성

시그모이드 함수 정의

σ(x) = 1 / (1 + e^(-x))

도함수: σ'(x) = σ(x) × (1 - σ(x))
최대 기울기: x=0일 때 σ'(0) = 0.25

시그모이드는 모든 실수 입력을 (0, 1) 사이로 압축한다:

  • x → +∞ : σ(x) → 1
  • x = 0 : σ(x) = 0.5
  • x → -∞ : σ(x) → 0

역사적 배경

1980년대 역전파(Backpropagation)의 표준 활성화 함수로 채택되었다. 계단 함수(Step Function)는 미분 불가능하지만 시그모이드는 연속적으로 미분 가능하여 역전파 적용이 가능하다. 초기 신경망 연구에서 로지스틱 회귀와의 연관성으로 널리 사용되었다.

포화 영역 (Saturation Region)

|x| > 4 이상에서 σ'(x) ≈ 0 (포화)

  x = 0:   σ'(0) = 0.25      ← 최대 기울기
  x = 2:   σ'(2) ≈ 0.105
  x = 4:   σ'(4) ≈ 0.018
  x = 6:   σ'(6) ≈ 0.002     ← 거의 0
  x = 10:  σ'(10) ≈ 0.00005  ← 사실상 0

Sigmoid의 비중심 출력 문제

출력이 항상 양수 (0,1) → 역전파 시 가중치 갱신이 모두 같은 방향으로만 발생:

∂L/∂wⱼ = δ × xⱼ  (xⱼ는 이전 층 Sigmoid 출력 → 항상 양수)
→ 모든 가중치가 동시에 증가 또는 동시에 감소 → 지그재그(zigzag) 학습

이를 **출력 비중심화 문제(Non-zero Centered Output Problem)**라 한다. Tanh는 출력이 (-1,1)이므로 이 문제가 없다.

기술사 시험 핵심 논점

  1. 기울기 소실의 수학적 원인: σ'(x) = σ(x)(1-σ(x)) ≤ 0.25 → 역전파 시 층마다 0.25 이하로 곱해짐 → 기하급수적 감소
  2. 왜 ReLU로 대체되었는가: ReLU는 양수 구간에서 기울기=1 → 곱해도 기울기가 줄지 않음
  3. Tanh의 장점과 한계: 중심화된 출력(-1,1)으로 비중심화 문제 해결, 그러나 최대 기울기=1이지만 여전히 포화 구간 존재
  4. 언제 Sigmoid를 사용하는가: 출력층의 이진 분류 (이진 크로스 엔트로피와 조합), LSTM 게이트

6. 기대효과 및 결론

시그모이드 (Sigmoid) 활성화는 정확도, 효율, 확장성, 자동화 수준을 높이는 데 기여하지만 데이터 품질과 운영 통제를 함께 확보해야 한다.

다만 실제 효과를 얻으려면 계산 비용, 데이터 편향, 해석 가능성, 운영 복잡도 같은 전제 조건을 함께 관리해야 한다. 따라서 시그모이드 (Sigmoid) 활성화는 단일 기법의 성능보다 문제 적합성·자원 제약·거버넌스를 함께 설계할 때 가장 큰 가치를 만든다.
