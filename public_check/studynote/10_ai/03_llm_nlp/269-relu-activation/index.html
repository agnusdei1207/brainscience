0. 핵심 인사이트

핵심: ReLU(Rectified Linear Unit)는 f(x)=max(0,x)로 정의되며, 양수 구간에서 기울기=1을 유지해 기울기 소실 문제(Vanishing Gradient Problem)를 해결하고, 연산이 단순해 Sigmoid 대비 6배 빠른 학습을 가능하게 한다. 비유: ReLU는 신경망의 "전류 차단기" — 양수 신호는 그대로 통과시키고(기울기=1), 음수 신호는 차단한다(기울기=0). Sigmoid는 모든 신호를 약하게 만들었지만, ReLU는 통과 신호의 강도를 유지한다.

📝 모범 답안

1. 개요 및 필요성

ReLU 정의

ReLU: f(x) = max(0, x)

도함수: f'(x) = 1  (x > 0)
               0  (x < 0)
               미정의 (x = 0, 실제로는 0 또는 1 중 하나 선택)

Sigmoid 대비 ReLU의 혁신

기울기최대 0.25, 포화 시 ≈0양수 구간 항상 1
기울기 소실심각양수 구간에서 없음

등장 배경

2010년 전후 딥러닝 연구자들은 Sigmoid의 기울기 소실로 인해 4층 이상의 신경망을 학습시키기 어려웠다. 나이어(Nair)와 힌튼(Hinton)이 2010년 ReLU를 제안하고, 2012년 AlexNet이 ImageNet에서 압도적 성능을 보이며 ReLU를 딥러닝 표준으로 확립했다.

희소 활성화 (Sparse Activation)

ReLU는 약 50%의 뉴런을 비활성화한다(출력=0). 이는 **희소 표현(Sparse Representation)**을 만들어:

  • 계산 효율 향상 (0 곱셈 스킵 가능)
  • 과적합(Overfitting) 자연스러운 억제
  • 뇌의 실제 뉴런 발화 패턴과 유사

기술사 시험 핵심 논점

  1. ReLU 기울기 소실 해결 원리: f'(x)=1 (x>0) → 역전파 시 기울기가 감쇠 없이 통과 → 깊은 신경망 학습 가능
  2. 죽은 ReLU 원인과 대책: 큰 학습률 → 가중치 갱신 → 항상 음수 입력 → Leaky ReLU / 학습률 조정
  3. 희소 활성화의 장점: ~50% 뉴런 비활성화 → 계산 효율 + 자연스러운 정규화 효과
  4. Swish/GELU 등장 배경: 단순 ReLU보다 부드러운 전환 → 대규모 모델에서 성능 향상
ReLU:  파라미터 없음 (단순 max 연산)
PReLU: 층당 노드 수만큼 α 파라미터 추가
ELU:   파라미터 없음 (α는 하이퍼파라미터)
GELU:  파라미터 없음

6. 기대효과 및 결론

ReLU (Rectified Linear Unit)는 정확도, 효율, 확장성, 자동화 수준을 높이는 데 기여하지만 데이터 품질과 운영 통제를 함께 확보해야 한다.

다만 실제 효과를 얻으려면 계산 비용, 데이터 편향, 해석 가능성, 운영 복잡도 같은 전제 조건을 함께 관리해야 한다. 따라서 ReLU (Rectified Linear Unit)는 단일 기법의 성능보다 문제 적합성·자원 제약·거버넌스를 함께 설계할 때 가장 큰 가치를 만든다.
