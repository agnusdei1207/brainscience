0. 핵심 인사이트

핵심: 순전파(Forward Propagation)는 입력 데이터가 신경망의 입력층→은닉층→출력층 방향으로 흐르며 행렬 곱과 활성화 함수를 순차 적용해 예측값을 계산하는 과정이다. 비유: 순전파는 수도관에서 물이 저수지(입력)에서 수도꼭지(출력)로 흐르는 과정 — 각 밸브(층)를 통과하며 압력(값)이 변환되고, 최종 수도꼭지에서 나온 물의 양을 측정해 목표 수량과 비교한다.

📝 모범 답안

1. 개요 및 필요성

순전파 정의

순전파는 신경망에 입력 x를 넣으면 출력 ŷ이 계산되는 전방향 연산 흐름이다. 각 층(Layer)에서 수행되는 연산:

층 ℓ의 순전파 연산:
  zˡ = Wˡ × aˡ⁻¹ + bˡ    ← 선형 변환 (Linear Transformation)
  aˡ = f(zˡ)              ← 활성화 함수 적용 (Non-linear)

  여기서:
  - aˡ   : 층 ℓ의 활성화 출력 (Activation Output)
  - Wˡ   : 층 ℓ의 가중치 행렬 (Weight Matrix)
  - bˡ   : 층 ℓ의 편향 벡터 (Bias Vector)
  - zˡ   : 층 ℓ의 사전 활성화 값 (Pre-activation)
  - f    : 활성화 함수 (Activation Function)

순전파의 역할

순전파는 두 가지 목적으로 실행된다:

  1. 학습(Training): 손실 계산 후 역전파 준비 → 중간 값 저장 필요
  2. 추론(Inference): 학습된 모델로 새 데이터 예측 → 중간 값 저장 불필요

2. 구성요소

3층 MLP 순전파 전체 흐름

┌──────────────────────────────────────────────────────────────────┐
│                순전파 (Forward Propagation) 흐름                  │
│                                                                  │
│  입력층         은닉층 1         은닉층 2         출력층            │
│                                                                  │
│  a⁰ = x         z¹ = W¹a⁰+b¹   z² = W²a¹+b²   z³ = W³a²+b³    │
│  ↓               ↓               ↓               ↓              │
│ [x₁]           a¹ = ReLU(z¹)   a² = ReLU(z²)  ŷ = σ(z³)       │
│ [x₂]                                                             │
│ [x₃]    ←─────  저장: z¹,a¹  ───  저장: z²,a²  ───  저장: z³   │
│                   (역전파에서 사용)                                │
│                                                                  │
│  ↓                                                               │
│  손실 계산: L = loss(ŷ, y_target)                                 │
│  예) 이진 분류: L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]               │
└──────────────────────────────────────────────────────────────────┘

행렬 연산으로 이해하는 순전파

단일 샘플 (n=1):

z = W × x + b
  W: [n_out × n_in], x: [n_in × 1], b: [n_out × 1]
  z: [n_out × 1]

배치 처리 (N개 샘플):

Z = W × X + b (브로드캐스팅)
  W: [n_out × n_in], X: [n_in × N], b: [n_out × 1]
  Z: [n_out × N]

연산 그래프 (Computational Graph)

┌──────────────────────────────────────────────────────────────┐
│              연산 그래프 (Computational Graph)                │
│                                                              │
│  x ────────────────────────────────────────────────────┐    │
│                                                         │    │
│  W ──► [×] ──► z = Wx+b ──► [f] ──► a ──► [Loss] ──► L│    │
│                  ↑                                      │    │
│  b ─────────────┘                          ↑            │    │
│                                       y_true ───────────┘    │
│                                                              │
│  노드: 연산 (×, +, f, Loss)                                  │
│  엣지: 데이터 흐름                                            │
│  순전파: 왼쪽 → 오른쪽 (예측)                                 │
│  역전파: 오른쪽 → 왼쪽 (기울기 전파)                           │
└──────────────────────────────────────────────────────────────┘

손실 함수 (Loss Function) 계산

문제 유형출력층손실 함수
이진 분류Sigmoid이진 크로스 엔트로피 (Binary CE)
다중 분류Softmax범주형 크로스 엔트로피 (Categorical CE)
회귀LinearMSE (Mean Squared Error)
다레이블 분류Sigmoid × K이진 CE × K

3. 구조 및 원리

핵심 조건: 순전파 (Forward Propagation)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

  1. 순전파 (Forward Propagation)의 입력 조건과 목적을 정의한다.
  2. 핵심 연산 또는 추론 규칙을 적용한다.
  3. 결과를 평가 지표와 피드백으로 검증한다.

4. 비교 및 연결

비교 항목순전파 (Forward)역전파 (Backward)
방향입력층 → 출력층출력층 → 입력층
목적예측값(ŷ) 계산기울기(∂L/∂W) 계산
연산행렬 곱 + 활성화연쇄 법칙 + 야코비안
저장z, a 값 저장기울기 누적
추론 시✅ 실행❌ 실행 안 함
학습 시✅ 실행✅ 실행

배치 처리 (Batch Processing)

처리 방식설명특징
확률적 경사 하강 (SGD)N=1, 샘플 1개씩빠른 업데이트, 높은 분산
미니배치 (Mini-batch GD)N=32~256, 배치 단위GPU 병렬화, 표준 방법
배치 경사 하강 (Batch GD)N=전체 데이터안정적, 메모리 비효율

기술사 시험 핵심 논점

  1. 순전파에서 저장하는 값: z(선형 결합)와 a(활성화 출력) → 역전파의 국소 기울기 계산에 필수
  2. 배치 처리 효율: 행렬 연산(GEMM, General Matrix Multiply)으로 GPU에서 병렬 처리 → 단일 샘플 대비 수십~수백 배 속도
  3. 순전파의 계산 복잡도: 각 층에서 O(n_in × n_out) → 전체 O(L × d²) (L: 층 수, d: 평균 노드 수)
  4. 추론(Inference) 최적화: 역전파 불필요 → no_grad() 모드로 중간값 저장 생략 → 메모리·속도 절약

PyTorch 코드 관점 이해

# 순전파 = 모델 호출
output = model(input)   # z¹, a¹, z², a², ..., ŷ 순차 계산

# 손실 계산
loss = criterion(output, target)   # L = CE(ŷ, y)

# 역전파 (순전파 후 실행)
loss.backward()   # ∂L/∂W, ∂L/∂b 계산

# 추론 시 - 중간 값 저장 생략
with torch.no_grad():
    output = model(input)   # 메모리 절약

6. 기대효과 및 결론

순전파 (Forward Propagation)는 정확도, 효율, 확장성, 자동화 수준을 높이는 데 기여하지만 데이터 품질과 운영 통제를 함께 확보해야 한다.

다만 실제 효과를 얻으려면 계산 비용, 데이터 편향, 해석 가능성, 운영 복잡도 같은 전제 조건을 함께 관리해야 한다. 따라서 순전파 (Forward Propagation)는 단일 기법의 성능보다 문제 적합성·자원 제약·거버넌스를 함께 설계할 때 가장 큰 가치를 만든다.
