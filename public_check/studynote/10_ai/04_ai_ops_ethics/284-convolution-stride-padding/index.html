0. 핵심 인사이트

핵심: 합성곱(Convolution)은 필터(Filter/Kernel)를 입력 위에 슬라이딩하며 특징(Feature)을 추출하는 연산으로, CNN (Convolutional Neural Network)의 핵심 빌딩 블록이다. 비유: 합성곱 필터는 '도장'이다. 동일한 도장(필터)을 종이(입력) 위에서 일정 간격(스트라이드)으로 찍으며 문양(특징)을 추출한다. 가장자리에 여백(패딩)을 미리 만들어두면 종이 끝까지 고르게 찍을 수 있다.

📝 모범 답안

1. 개요 및 필요성

합성곱 연산의 탄생 배경

완전 연결 계층(FCN, Fully Connected Network)은 이미지를 1차원 벡터로 펼쳐 처리하기 때문에 **공간 정보(Spatial Information)**를 완전히 무시하고, 파라미터 수가 폭발적으로 증가한다. 예를 들어 224×224×3 이미지를 512차원 은닉층에 연결하면 약 7,700만 개의 파라미터가 필요하다.

합성곱 연산(Convolution Operation)은 이러한 문제를 **가중치 공유(Weight Sharing)**와 **지역 연결(Local Connectivity)**로 해결한다. 필터 하나가 전체 입력 맵(Feature Map) 위를 슬라이딩하며 동일한 가중치를 재사용하므로 파라미터가 크게 줄어든다.

핵심 개념 정의

용어정의비고
필터/커널 (Filter/Kernel)학습 가능한 가중치 행렬 (예: 3×3×C)특징 감지기 역할
특징 맵 (Feature Map)필터를 적용한 결과 출력활성화 맵(Activation Map)
스트라이드 (Stride)필터가 이동하는 간격 (픽셀 수)클수록 출력 크기 감소
패딩 (Padding)입력 가장자리에 추가하는 테두리제로 패딩(Zero Padding) 일반적
수용 영역 (Receptive Field)출력 뉴런 하나가 참조하는 입력 영역깊을수록 넓어짐

2. 구성요소

출력 크기 공식

$$O = \left\lfloor \frac{I - F + 2P}{S} \right\rfloor + 1$$

  • I: 입력 크기 (Input Size)
  • F: 필터 크기 (Filter Size)
  • P: 패딩 크기 (Padding)
  • S: 스트라이드 (Stride)

예시: 입력 32×32, 필터 3×3, 스트라이드 1, 패딩 0 → (32 - 3 + 0) / 1 + 1 = 30×30

예시: 입력 32×32, 필터 3×3, 스트라이드 1, 패딩 1 (Same Padding) → (32 - 3 + 2) / 1 + 1 = 32×32 (크기 유지)

합성곱 연산 흐름

입력 특징 맵 (5×5)           필터 (3×3)          출력 특징 맵 (3×3)

3. 구조 및 원리

핵심 조건: 합성곱 연산 (Convolution)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

  1. 합성곱 연산 (Convolution)의 입력 조건과 목적을 정의한다.
  2. 핵심 연산 또는 추론 규칙을 적용한다.
  3. 결과를 평가 지표와 피드백으로 검증한다.

4. 비교 및 연결

패딩 종류설명출력 크기사용 목적
유효 패딩 (Valid Padding)패딩 없음 (P=0)입력보다 작아짐정보 압축
동일 패딩 (Same Padding)출력=입력 유지I × I특징 맵 크기 보존

팽창 합성곱 (Dilated/Atrous Convolution)

팽창 합성곱은 필터 원소 사이에 **팽창률(Dilation Rate, d)**만큼 간격을 두어 수용 영역을 지수적으로 확장한다.

일반 3×3 합성곱       팽창률 2인 3×3 합성곱
(수용 영역: 3×3)      (수용 영역: 5×5)
┌─────────┐           ┌─────────────────┐
│ ■ ■ ■   │           │ ■ · ■ · ■       │
│ ■ ■ ■   │           │ · · · · ·       │
│ ■ ■ ■   │           │ ■ · ■ · ■       │
└─────────┘           │ · · · · ·       │
                      │ ■ · ■ · ■       │
                      └─────────────────┘
■ = 활성 가중치, · = 건너뜀
파라미터 수는 동일, 수용 영역만 확장

전치 합성곱 (Transposed Convolution, 업샘플링)

전치 합성곱(Transposed Convolution, 디컨볼루션이라고도 불리지만 수학적 디컨볼루션은 아님)은 피처 맵을 업샘플링하는 학습 가능한 방법으로, 인코더-디코더(Encoder-Decoder) 구조와 생성 모델(GAN, Generative Adversarial Network)에서 사용된다.

스트라이드출력 크기 (32×32, 3×3 필터, 패딩 0)특성
130×30세밀한 특징 유지
215×15해상도 절반, 계산량 감소
48×8빠른 다운샘플링

다른 합성곱 변형과 연결

  • 깊이별 분리 합성곱 (Depthwise Separable Convolution): MobileNet에서 사용. 채널별로 공간 합성곱 후 1×1 합성곱 적용 → 계산량 대폭 감소
  • 그룹 합성곱 (Group Convolution): 채널을 그룹으로 나눠 독립적으로 합성곱 → ResNeXt에서 활용
  • 팽창 합성곱 (Dilated Convolution): DeepLab, WaveNet에서 수용 영역 확장에 사용

설계 선택 기준

패딩 선택:

  • Same Padding: U-Net, ResNet 등 크기 유지가 중요한 구조
  • Valid Padding: 정보 손실을 감수하더라도 경계 아티팩트(Boundary Artifact) 없애고 싶을 때

스트라이드 선택:

  • Stride=1: 공간 정보 최대 보존 (분류·검출 초기 레이어)
  • Stride=2: 풀링 대신 다운샘플링 (최근 VGG 이후 트렌드)
  • Stride=4 이상: ViT (Vision Transformer) 패치 임베딩에서 사용

팽창 합성곱 활용:

  • 시맨틱 분할 (Semantic Segmentation): DeepLabV3+에서 다중 팽창률(ASPP, Atrous Spatial Pyramid Pooling) 적용
  • 음성 생성 (Audio Generation): WaveNet에서 장거리 의존성 포착

기술사 서술 포인트

"합성곱 연산에서 스트라이드와 패딩은 출력 해상도와 수용 영역의 균형을 결정하는 설계 변수이다. 동일 패딩(Same Padding)은 잔차 연결(Residual Connection)과 같이 크기 일치가 필요한 아키텍처에서 필수적이며, 팽창 합성곱은 파라미터 증가 없이 수용 영역을 지수적으로 확대하여 밀집 예측(Dense Prediction) 태스크에 적합하다."

5. 실무 적용 및 판단

합성곱 연산의 핵심 가치

  1. 파라미터 효율성: 가중치 공유로 완전 연결 대비 파라미터 수 수십~수천 배 감소
  2. 공간 계층성: 저수준(엣지·코너) → 고수준(얼굴·물체) 특징을 계층적으로 학습
  3. 이동 등변성 (Translation Equivariance): 입력이 이동하면 출력도 동일하게 이동 (분류에서는 풀링으로 불변성 확보)

공식 정리 (시험 필수)

┌─────────────────────────────────────────────────────────┐
│           출력 크기 공식                                 │
│                                                         │
│   O = floor( (I - F + 2P) / S ) + 1                    │
│                                                         │
│   - 동일 패딩 조건: P = (F-1) / 2  (S=1일 때)          │
│   - 팽창 합성곱 유효 필터 크기: F_d = F + (F-1)(d-1)   │
│     예) F=3, d=2 → F_d = 3 + 2×1 = 5                  │
└─────────────────────────────────────────────────────────┘

6. 기대효과 및 결론

합성곱 연산 (Convolution)은 정확도, 효율, 확장성, 자동화 수준을 높이는 데 기여하지만 데이터 품질과 운영 통제를 함께 확보해야 한다.

다만 실제 효과를 얻으려면 계산 비용, 데이터 편향, 해석 가능성, 운영 복잡도 같은 전제 조건을 함께 관리해야 한다. 따라서 합성곱 연산 (Convolution)은 단일 기법의 성능보다 문제 적합성·자원 제약·거버넌스를 함께 설계할 때 가장 큰 가치를 만든다.
