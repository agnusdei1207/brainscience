0. 핵심 인사이트

핵심: PEFT (Parameter-Efficient Fine-Tuning, 파라미터 효율적 미세 조정)는 대형 모델의 전체 가중치를 동결(Freeze)하고 소수의 추가 파라미터만 학습하는 파인 튜닝 기법으로, LoRA (Low-Rank Adaptation, 저랭크 적응)는 가중치 업데이트 ΔW를 두 개의 저랭크 행렬 A·B의 곱으로 근사하는 가장 인기 있는 PEFT 방법이다. 비유: 175B 파라미터 전체를 파인 튜닝하는 건 직원 1억 명 회사에서 모든 직원의 업무 방식을 바꾸는 것이고, LoRA는 핵심 의사결정자 10명(저랭크 행렬)의 업무 방식만 바꿔서 회사 전체 방향을 조정하는 것이다. 10명만 교육해도 전체 성과가 바뀌는 마법이다.

📝 모범 답안

1. 개요 및 필요성

GPT-3는 175B(1750억) 개의 파라미터를 가진다. 전체 파인 튜닝을 위해 역전파 그래디언트를 모든 파라미터에 대해 저장하면 FP32 기준 700GB 이상의 GPU 메모리가 필요하다. 이는 수십 장의 고가 A100 GPU를 요구하며, 대부분의 기업과 연구자에게 접근 불가능한 수준이다.

PEFT는 이 문제를 "대부분의 파라미터는 동결(Frozen)하고, 핵심 위치에 소수의 학습 가능한 파라미터만 추가한다"는 아이디어로 해결한다. LoRA는 가중치 행렬의 실제 업데이트가 **낮은 내재 차원(Low Intrinsic Dimension)**에서 이루어진다는 가설을 기반으로, ΔW를 두 저랭크 행렬의 곱으로 표현한다.

2. 구성요소

│         LoRA (Low-Rank Adaptation) 수학적 구조                     │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  전체 파인 튜닝:                                                    │
│  W' = W + ΔW  (W: d×d 행렬, ΔW: d×d 행렬 전체 학습)              │
│  파라미터 수: d×d (예: 4096×4096 = 16.7M)                         │
│                                                                  │
│  LoRA:                                                           │
│  W' = W + ΔW = W + (B · A)                                      │
│    W: d×d  ← 동결 (Frozen, 학습 안 함)                             │
│    A: d×r  ← 학습 가능 (r << d, 예: r=8, d=4096 → 4096×8 = 32K) │
│    B: r×d  ← 학습 가능 (r=8, d=4096 → 8×4096 = 32K)             │
│    ΔW = B·A: d×d  (행렬 곱이지만 파라미터는 2×d×r만 학습)           │
│                                                                  │
│  파라미터 절감 비율:                                                 │
│  전체: d² = 16.7M | LoRA(r=8): 2×d×r = 65K → 0.39% 만 학습!     │
│                                                                  │
│  ┌────────────────────────────────────────────────┐              │
│  │  입력 x                                         │              │
│  │    ├──▶ W (동결) ──────────────────────┐       │              │
│  │    └──▶ A (학습) ──▶ B (학습) ──────▶ + ──▶ 출력│              │
│  └────────────────────────────────────────────────┘              │
│                                                                  │
│  초기화: A = 랜덤 가우시안, B = 0 (학습 초기 ΔW=0으로 시작)          │
│  스케일링: ΔW에 α/r 비율로 스케일 적용 (α: 스케일 하이퍼파라미터)      │
└──────────────────────────────────────────────────────────────────┘

3. 구조 및 원리

핵심 조건: PEFT (Parameter-Efficient Fine-Tuning) / LoRA (Low-Rank Adaptation)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

QLoRA (Quantized LoRA): LoRA에 4비트 양자화(Quantization)를 결합하여 70B LLM을 단일 48GB GPU(예: RTX 4090 2장)에서 파인 튜닝 가능하게 한다. 2023년 등장 직후 오픈소스 LLM 커뮤니티의 표준 파인 튜닝 방법으로 자리 잡았다.

LoRA 병합 (LoRA Merging): 훈련 완료 후 W' = W + B·A를 계산하여 원본 가중치에 통합하면, 추론 시 별도의 A·B 행렬 연산이 필요 없어 추론 속도 패널티가 제로다.

4. 비교 및 연결

LoRA 하이퍼파라미터 설계 가이드:

  • r (랭크): 4~64. 태스크 복잡도가 높을수록 크게. 기본값 r=8
  • alpha: 보통 r의 2배. ΔW의 스케일 조정
  • target_modules: Q, V 행렬에만 적용 (Attention 레이어 권장)
  • lora_dropout: 0.05~0.1 (과적합 방지)

LoRA 적용 레이어 선택: 어텐션 레이어의 Q, V 행렬에 LoRA를 적용하는 것이 가장 효과적이다. K 행렬은 Q와 유사 역할을 해 중복될 수 있으며, FFN(Feed-Forward Network) 레이어 추가 적용 시 성능 향상과 파라미터 증가 트레이드오프를 고려해야 한다.

5. 실무 적용 및 판단

PEFT/LoRA는 LLM 파인 튜닝의 민주화를 실현했다. 수십 장의 A100 GPU가 필요하던 작업을 RTX 3090 한 장으로 가능하게 하여, 개인 연구자와 스타트업도 최신 LLM을 자신의 도메인에 맞게 커스터마이징할 수 있게 됐다. LoRA를 기반으로 한 다양한 변형(DoRA, AdaLoRA, GaLore)이 계속 등장하며 파라미터 효율성의 한계를 계속 넓히고 있다. MLOps 파이프라인에서 LoRA 파인 튜닝은 이제 표준 구성 요소다.
