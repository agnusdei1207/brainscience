0. 핵심 인사이트

핵심: 라그랑주 승수법 (Lagrange Multiplier Method) 은 제약 조건 하에서 목적 함수의 극값을 구하는 기법으로, 제약을 라그랑지안 (Lagrangian) 함수에 통합해 무제약 최적화로 변환한다. 비유: 라그랑주 승수법은 "울타리 안에서만 산책할 수 있을 때, 울타리 경계를 방정식에 녹여서 자유롭게 최적점을 찾는" 방법이다. 울타리(제약)를 없애는 대신 비용(승수)으로 환산한다.

📝 모범 답안

1. 개요 및 필요성

제약 최적화 문제의 등장

머신러닝에서 많은 최적화 문제는 제약 조건이 있다.

문제목적 함수제약 조건
SVM 마진 최대화min (1/2)
포트폴리오 최적화min 분산기대 수익 ≥ r
PCAmax w·Cw

단순 편미분으로는 제약을 처리할 수 없어 라그랑주 승수법이 필요하다.

2. 구성요소

등식 제약의 라그랑지안

  문제:  min f(x)
         s.t. g(x) = 0

  라그랑지안 (Lagrangian):
  L(x, λ) = f(x) + λ · g(x)
  ────────────────────────────────────────────
  최적 조건: ∇ₓL = 0, ∂L/∂λ = 0
  → ∇f(x*) = -λ ∇g(x*)  (기울기 평행 조건)
  → g(x*) = 0            (제약 만족 조건)

KKT (Karush-Kuhn-Tucker) 조건 (부등식 제약)

  문제:  min f(x)
         s.t. gᵢ(x) ≤ 0  (i = 1, ..., m)

  KKT 조건 (필요충분 조건):
  ┌──────────────────────────────────────────────────┐
  │ 1. 정류성: ∇ₓL = ∇f(x*) + Σ μᵢ ∇gᵢ(x*) = 0   │
  │ 2. 원시 가능성: gᵢ(x*) ≤ 0                     │
  │ 3. 쌍대 가능성: μᵢ ≥ 0                          │
  │ 4. 상보적 이완: μᵢ · gᵢ(x*) = 0               │
  └──────────────────────────────────────────────────┘
  핵심: 조건 4 → gᵢ = 0 (활성 제약) 이거나 μᵢ = 0

SVM (Support Vector Machine) 마진 최대화 유도

  SVM 원시 문제 (Primal Problem):
  ┌───────────────────────────────────────────┐
  │  min  (1/2)||w||²                         │
  │   w,b                                     │
  │  s.t. yᵢ(w·xᵢ + b) ≥ 1  (i=1,...,n)    │
  └───────────────────────────────────────────┘
               ↓ 라그랑지안 구성
  L(w,b,α) = (1/2)||w||² - Σᵢ αᵢ[yᵢ(w·xᵢ+b)-1]

               ↓ KKT 조건 적용
  ∂L/∂w = 0 → w = Σᵢ αᵢ yᵢ xᵢ
  ∂L/∂b = 0 → Σᵢ αᵢ yᵢ = 0

               ↓ 쌍대 문제 (Dual Problem)
  ┌───────────────────────────────────────────┐
  │  max  Σᵢ αᵢ - (1/2) Σᵢ Σⱼ αᵢαⱼ yᵢyⱼ xᵢ·xⱼ│
  │   α                                       │
  │  s.t. αᵢ ≥ 0, Σᵢ αᵢ yᵢ = 0              │
  └───────────────────────────────────────────┘
  → αᵢ > 0 인 데이터만 서포트 벡터 (Support Vector)

새들 포인트 (Saddle Point)

라그랑지안의 최적해는 x 에 대해서는 최솟값, λ 에 대해서는 최댓값인 안장점 (Saddle Point) 이다.

  z
  ↑    마치 말 안장처럼:
  │     x 방향 → 아래로 볼록 (최소)
  │     λ 방향 → 위로 볼록 (최대)
  └──────── λ
        (Saddle Point: 최소·최대 동시)

3. 구조 및 원리

핵심 조건: 라그랑주 승수법 (Lagrange Multiplier)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

원시 문제 vs 쌍대 문제 (Primal vs Dual)

항목원시 문제쌍대 문제
최적화 변수w, b (차원 d)α (데이터 수 n)
목적min (1/2)
핵심고차원 특징 공간내적 계산만 필요
커널 트릭불가가능 (xᵢ·xⱼ → K(xᵢ,xⱼ))

커널 트릭 (Kernel Trick) 연계

쌍대 문제에서 xᵢ·xⱼ 내적을 커널 함수 K(xᵢ,xⱼ) 로 교체하면 명시적 고차원 매핑 없이 비선형 분류 가능.

커널수식특성
선형 (Linear)xᵢᵀxⱼ선형 분류
RBF (Radial Basis Function)exp(-γ
다항 (Polynomial)(γxᵢᵀxⱼ+r)ᵈd차 상호작용

4. 비교 및 연결

SVM 활용 예시

from sklearn.svm import SVC

# RBF 커널 SVM
clf = SVC(kernel='rbf', C=1.0, gamma='scale')
clf.fit(X_train, y_train)

# 서포트 벡터 확인
print(f"서포트 벡터 수: {len(clf.support_vectors_)}")
print(f"전체 데이터 대비 비율: {len(clf.support_vectors_)/len(X_train)*100:.1f}%")

기술사 출제 포인트

  • 라그랑지안 구성: L = f + λg (등식), L = f + μg (부등식, μ≥0)
  • KKT 조건 4가지를 모두 나열하고 상보적 이완 조건 설명
  • SVM 원시→쌍대 변환 수식 전개 (w = Σ αᵢ yᵢ xᵢ)
  • 서포트 벡터가 αᵢ > 0 인 데이터인 이유 (KKT 상보적 이완)
  • 커널 트릭: 쌍대 문제의 내적을 커널로 교체해 비선형 확장

5. 실무 적용 및 판단

  • 이론적 우아함: 제약 최적화를 무제약 문제로 우아하게 변환
  • SVM 최적성: 글로벌 최솟값 보장 (볼록 최적화)
  • 범용성: SVM 외에도 포트폴리오, 역학 등 수많은 공학 문제에 적용
  • 한계: 비볼록 (Non-Convex) 문제에서는 전역 최적 보장 안 됨

라그랑주 승수법과 KKT 조건은 수리 최적화의 핵심 도구이자 SVM 의 이론적 기반이다. 기술사 시험에서는 라그랑지안 구성, KKT 4조건, SVM 원시-쌍대 변환, 서포트 벡터의 의미를 논리적으로 서술하면 고득점 가능하다.
