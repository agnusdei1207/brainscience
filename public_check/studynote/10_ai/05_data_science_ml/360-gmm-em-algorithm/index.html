0. 핵심 인사이트

핵심: GMM(Gaussian Mixture Model, 가우시안 혼합 모델)은 데이터가 K개의 가우시안 분포(정규 분포) 혼합으로 생성됐다고 가정하는 생성 모델이며, EM 알고리즘(Expectation-Maximization Algorithm, 기대값-최대화 알고리즘)으로 파라미터를 추정한다. 비유: GMM은 "두 종류의 물감이 섞인 그림"을 분리하는 AI다. 파란색과 노란색이 섞인 그림(데이터)을 보고, "이 부분은 70% 파랑, 30% 노랑"으로 분리 추정하는 것이 GMM이고, 이를 반복적으로 정확히 추정하는 과정이 EM 알고리즘이다.

📝 모범 답안

1. 개요 및 필요성

키 분포를 보면 남성(평균 175cm)과 여성(평균 162cm)이 섞여있어 이중 봉우리(bimodal) 분포를 보인다. 단일 가우시안으로는 이 분포를 표현 못한다. GMM은 "이 데이터는 2개의 가우시안 분포가 혼합된 것"으로 모델링하여, 남성 분포와 여성 분포를 동시에 추정한다. 각 데이터 포인트는 "80% 확률로 남성 분포, 20% 확률로 여성 분포"처럼 소프트하게 배정된다.

2. 구성요소

┌──────────────────────────────────────────────────────────┐
│           GMM + EM 알고리즘 반복 구조                    │
├──────────────────────────────────────────────────────────┤
│  GMM 모델:  p(x) = Σₖ πₖ · N(x | μₖ, Σₖ)             │
│  πₖ: 혼합 가중치, Σπₖ=1                                │
│  μₖ: k번째 분포의 평균                                  │
│  Σₖ: k번째 분포의 공분산 행렬                           │
│                                                          │
│  E-step (Expectation):                                   │
│  γ(zₙₖ) = πₖN(xₙ|μₖ,Σₖ) / Σⱼπⱼ N(xₙ|μⱼ,Σⱼ)         │
│  → 각 포인트 xₙ이 군집 k에 속할 사후 확률(책임감)      │
│                                                          │
│  M-step (Maximization):                                  │
│  Nₖ = Σₙ γ(zₙₖ)                                       │
│  μₖ = (1/Nₖ) Σₙ γ(zₙₖ) xₙ                            │
│  Σₖ = (1/Nₖ) Σₙ γ(zₙₖ)(xₙ-μₖ)(xₙ-μₖ)ᵀ               │
│  πₖ = Nₖ/N                                              │
│                                                          │
│  반복: E→M→E→M→... 로그 우도 수렴까지                  │
└──────────────────────────────────────────────────────────┘
알고리즘배정 방식군집 형태겹침 허용
K-Means하드 (0/1)구형❌
GMM + EM소프트 (확률)타원형✅

3. 구조 및 원리

핵심 조건: GMM (Gaussian Mixture Model) 과 EM 알고리즘의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

EM 알고리즘의 일반화: GMM은 EM의 한 응용이며, EM은 잠재 변수(Latent Variable)가 있는 모든 확률 모델에 적용 가능하다. HMM(Hidden Markov Model, 은닉 마르코프 모델) 학습(Baum-Welch 알고리즘)도 EM의 특수 케이스다. K를 자동 결정하는 방법: BIC = -2logL + k·log(n), AIC = -2logL + 2k (k: 파라미터 수). BIC가 낮은 K를 선택한다.

4. 비교 및 연결

금융 수익률 모델링에서 정상 시장(정규 분포)과 위기 시장(꼬리 두꺼운 분포)을 2-component GMM으로 모델링하면 리스크를 더 정확히 추정한다. 이상치 탐지: 낮은 사후 확률(모든 K에서 낮은 γ)을 가진 샘플 = 이상치. sklearn.mixture.GaussianMixture로 구현 가능. 초기화 방법: k-means++로 초기 μ를 설정하면 EM 수렴이 빠르다.

5. 실무 적용 및 판단

GMM은 K-Means보다 표현력이 높고 확률적 해석이 가능하다는 점에서 연속형 데이터의 밀도 추정, 이상치 탐지, 클러스터 겹침 허용이 필요한 모든 상황에 적합하다. EM 알고리즘의 이해는 HMM, VAE, 베이즈 네트워크 등 잠재 변수 모델 전반의 토대가 되어 AI 수학의 핵심 축이다.

6. 기대효과 및 결론

GMM은 K-Means보다 표현력이 높고 확률적 해석이 가능하다는 점에서 연속형 데이터의 밀도 추정, 이상치 탐지, 클러스터 겹침 허용이 필요한 모든 상황에 적합하다. EM 알고리즘의 이해는 HMM, VAE, 베이즈 네트워크 등 잠재 변수 모델 전반의 토대가 되어 AI 수학의 핵심 축이다.
