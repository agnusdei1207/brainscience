0. 핵심 인사이트

핵심: VAE (Variational Autoencoder)는 입력 데이터를 잠재 공간(Latent Space)의 확률 분포 N(μ,σ²)로 인코딩하고, 그 분포에서 샘플링한 잠재 변수(Latent Variable) z를 디코딩하여 생성 모델(Generative Model)을 학습한다. 비유: 일반 오토인코더가 여행 사진을 특정 장소 좌표로 압축하는 것이라면, VAE는 사진을 "이 지역 어딘가의 좌표 분포"로 표현한다. 분포로 표현하면 그 지역의 아직 가보지 않은 곳도 생성할 수 있다.

📝 모범 답안

1. 개요 및 필요성

일반 오토인코더(Autoencoder, AE)는 입력 x를 인코더(Encoder)가 잠재 벡터 z로 압축하고 디코더(Decoder)가 x̂로 복원한다. 이 잠재 공간(Latent Space)은 훈련 데이터 점들로 채워지지만, 점 사이 공간은 비어 있어 새로운 데이터를 생성하기 어렵다.

VAE는 이 문제를 **확률적 잠재 공간(Probabilistic Latent Space)**으로 해결한다. 인코더는 단일 벡터 z가 아닌 분포의 파라미터 (μ, σ²)를 출력하고, z는 이 분포에서 샘플링된다. 이로써 잠재 공간 전체가 연속적으로 채워지고, 임의의 점에서 샘플링해 새로운 데이터를 생성할 수 있다.

그러나 샘플링 과정(z ~ N(μ, σ²))은 확률적(Stochastic) 연산으로 역전파(Backpropagation)가 불가능하다. **재파라미터화 트릭(Reparameterization Trick)**은 이 문제를 우회하여 역전파 경로를 살린다.

2. 구성요소

│    │                                                       │

└────────────────────────────────────────────────────────────┘

재파라미터화 트릭

문제: z ~ N(μ, σ²)는 샘플링 연산 → 역전파 불가

해결: z = μ + ε · σ,  ε ~ N(0, I)
     (확률적 부분 ε을 그래디언트 흐름 밖으로 분리)

역전파 경로:
∂z/∂μ = 1   (μ에 대한 그래디언트 흐름 가능)
∂z/∂σ = ε   (σ에 대한 그래디언트 흐름 가능)
∂z/∂ε = σ   (ε은 외부에서 샘플링, 역전파 불필요)

ELBO (Evidence Lower Bound) 최대화

VAE의 목적: log p_θ(x) 최대화 (데이터 로그 가능도)

log p_θ(x) ≥ E_q[log p_θ(x|z)] - KL(q_φ(z|x) || p(z))
                  ↑                        ↑
          재구성 손실                   KLD 규제
        (Reconstruction Loss)    (KL Divergence)

KLD 항 계산 (q_φ ~ N(μ, σ²), p ~ N(0, I)):

KL(N(μ,σ²) || N(0,I)) = -½ Σⱼ (1 + log σ²ⱼ - μ²ⱼ - σ²ⱼ)
손실 항역할역할 최소화 결과
재구성 손실-E[log p(x|z)]x̂가 x에 가까워짐
KLD 규제KL(q||p)z 분포가 N(0,I)에 가까워짐
합계 (ELBO)두 항의 합생성 품질 + 잠재 공간 구조화

3. 구조 및 원리

핵심 조건: VAE (Variational Autoencoder) 재파라미터화 트릭 (Reparameterization Trick)의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

동작 순서:

구분AE (Autoencoder)VAEGAN
잠재 공간불연속 점들연속 확률 분포없음 (직접 생성)
생성 방식불가z ~ N(0,I)에서 샘플링노이즈 → 생성자
손실 함수재구성만ELBO (재구성+KLD)미니맥스
학습 안정성안정적안정적불안정 (모드 붕괴)
생성 품질블러리(Blurry)블러리선명(Sharp)
잠재 공간 해석어려움가능 (선형 보간)가능

VAE + GAN (VAE-GAN) 하이브리드: VAE의 안정적 학습과 GAN의 선명한 생성 품질을 결합한 방법. DALL-E 초기 버전이 VQ-VAE (Vector Quantized VAE) 기반이다.

4. 비교 및 연결

잠재 공간 조작(Latent Space Manipulation):

  • 선형 보간(Linear Interpolation): z₁과 z₂ 사이 z = λz₁ + (1-λ)z₂로 이미지 부드러운 전환
  • 속성 분리(Disentanglement): β-VAE에서 KLD 가중치 β > 1 증가 시 잠재 변수별 독립 속성 학습 (표정, 조명 분리 등)

구현 주의사항:

  1. log σ² 대신 σ²를 직접 출력하면 수치 불안정 → 반드시 log σ² 출력 후 exp로 변환
  2. KLD 가중치 어닐링(β annealing): 초반에 β를 0으로 시작해 점진적 증가로 학습 안정화
  3. 재구성 손실: 픽셀 데이터면 BCE (Binary Cross-Entropy), 연속 데이터면 MSE 사용

기술사 답안 포인트:

  1. 재파라미터화 트릭의 필요성(샘플링의 역전파 불가)과 z = μ + ε·σ 수식을 명확히 설명한다.
  2. ELBO의 두 항(재구성 손실 + KLD)의 역할과 트레이드오프를 설명한다.
  3. KLD 항이 잠재 공간을 N(0,I)에 가깝게 만드는 효과와 생성 품질에 미치는 영향을 설명한다.
  4. GAN과 비교하여 VAE의 장단점(안정적 학습 vs 블러리 생성)을 언급한다.

5. 실무 적용 및 판단

VAE의 재파라미터화 트릭은 확률적 계산 그래프를 역전파 가능하게 만드는 범용 기법으로, VAE 이후 여러 확률 모델 학습에 적용되었다. 정규화된 잠재 공간은 데이터 생성, 속성 편집, 데이터 증강, 이상 탐지(Anomaly Detection) 등 다양한 응용에 활용된다.

현재는 디퓨전 모델(Diffusion Model)이 생성 품질에서 VAE를 크게 앞서지만, VAE의 잠재 공간 압축 구조는 Latent Diffusion Model (LDM, Stable Diffusion의 기반)에서 계산 효율을 위한 필수 구성 요소로 여전히 활용된다.
