0. 핵심 인사이트

핵심: 예측 오차는 편향² (Bias²) + 분산 (Variance) + 줄일 수 없는 노이즈 (Irreducible Noise) 세 항의 합으로 분해되며, 편향과 분산은 트레이드오프 관계다. 비유: 편향은 "과녁 중심에서 체계적으로 빗나가는 것", 분산은 "여기저기 흩어져 일관성 없는 것"이다. 명중률을 높이려면 두 가지를 동시에 줄여야 한다.

📝 모범 답안

1. 개요 및 필요성

머신러닝 모델의 일반화 오차(Generalization Error)를 개선하려면 오차의 원천을 정확히 진단해야 한다. 편향-분산 분해 (Bias-Variance Decomposition)는 오차를 수학적으로 해부하는 핵심 도구다.

  • 편향(Bias): 모델의 예측 평균과 실제 값의 차이 → 모델 복잡도 부족 (과소적합)
  • 분산(Variance): 다른 학습 데이터로 훈련 시 예측값의 변동성 → 모델 복잡도 과잉 (과적합)

앙상블 방법은 이 두 문제를 구조적으로 해결한다.

2. 구성요소

편향-분산 분해 수식

E[(y - ŷ)²] = Bias²(ŷ) + Var(ŷ) + σ²_noise

Bias(ŷ)  = E[ŷ] - y_true
Var(ŷ)   = E[(ŷ - E[ŷ])²]
σ²_noise = 데이터의 본질적 노이즈 (줄일 수 없음)

Bagging의 분산 감소 수식

n개의 독립 부트스트랩 모델 ŷ₁, …, ŷₙ의 평균:

ŷ_bag = (1/n) Σᵢ ŷᵢ

Var(ŷ_bag) = σ²/n  (완전 독립 모델 가정)

실제: 트리 간 상관계수 ρ가 있으면
Var(ŷ_bag) = ρσ² + (1-ρ)σ²/n

상관계수 ρ를 줄일수록 분산 감소 효과 극대화 → Random Forest는 특성 무작위 선택으로 ρ 감소

Boosting의 편향 감소 구조

F₀(x) = 초기 예측 (상수)
Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x)   (η: 학습률)
hₘ(x): m번째 약한 학습기 (이전 잔차 학습)

┌───────────────────────────────────────────────────────┐
│ Bagging (병렬)                                        │
│  데이터 → [트리1] ─┐                                  │
│  데이터 → [트리2] ─┼─ 평균(회귀)/투표(분류) → ŷ_bag  │
│  데이터 → [트리n] ─┘                                  │
│                                                       │
│ Boosting (순차)                                       │
│  데이터 → [트리1] → 잔차1 →                           │
│           [트리2] → 잔차2 → ... →                     │
│           [트리n] → 합산 → ŷ_boost                    │
└───────────────────────────────────────────────────────┘
방법해결 문제결합 방식대표 알고리즘
Bagging높은 분산 (과적합)병렬 평균/투표Random Forest
Boosting높은 편향 (과소적합)순차 잔차 학습XGBoost, LightGBM
Stacking편향+분산메타 모델 결합다양한 기반 모델

3. 구조 및 원리

핵심 조건: 앙상블 편향-분산 (Bias-Variance) 수식의 성능과 타당성은 입력 표현, 핵심 구조 또는 연산, 학습·추론 절차, 평가 기준, 자원 제약이 서로 정합될 때 확보된다.

4. 비교 및 연결

Random Forest 설정:

  • n_estimators ↑ → 분산 감소, 연산 증가
  • max_features ↓ → ρ 감소 (특성 다양성), 편향 소폭 증가
  • max_depth 제한 → 개별 트리 분산 통제

XGBoost/LightGBM 설정:

  • n_estimators × learning_rate 균형이 핵심
  • subsample, colsample_bytree → Bagging 요소 추가로 과적합 방지
  • early stopping → 과적합 임계점 탐지

기술사 판단: 검증 손실이 훈련 손실보다 현저히 높으면(높은 분산) → Bagging 강화, 훈련 손실 자체가 높으면(높은 편향) → Boosting 반복 수 증가 또는 모델 복잡도 상향.

5. 실무 적용 및 판단

편향-분산 수식은 모델 성능 개선의 방향성을 제시하는 나침반이다. Bagging은 분산을 √n 배 감소시키는 수학적 보장이 있으며, Boosting은 약한 학습기를 결합해 강한 학습기를 만들 수 있다는 AdaBoost 이론에 기반한다. 두 방법의 특성을 정확히 이해하면 데이터/문제에 맞는 앙상블 전략을 선택할 수 있다.

6. 기대효과 및 결론

편향-분산 수식은 모델 성능 개선의 방향성을 제시하는 나침반이다. Bagging은 분산을 √n 배 감소시키는 수학적 보장이 있으며, Boosting은 약한 학습기를 결합해 강한 학습기를 만들 수 있다는 AdaBoost 이론에 기반한다. 두 방법의 특성을 정확히 이해하면 데이터/문제에 맞는 앙상블 전략을 선택할 수 있다.
