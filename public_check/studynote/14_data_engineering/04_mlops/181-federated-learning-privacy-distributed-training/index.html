0. 핵심 인사이트

핵심: 연방 학습(Federated Learning)은 데이터를 중앙 서버로 이동시키지 않고, 모델 가중치(Gradient/Weight)만 교환하여 분산 환경에서 전역 모델을 학습하는 프라이버시 우선 패러다임이다. 비유: 숙련도가 쌓일수록 판단이 정교해지는 훈련 체계처럼, 데이터와 피드백이 구조적으로 누적되어 성능이 만들어지는 방식과 같다.

📝 모범 답안

1. 개요 및 필요성

기존 머신러닝(Machine Learning) 패러다임은 모든 학습 데이터를 중앙 서버에 집중시켜야 했다. 그러나 다음과 같은 현실적 장벽이 존재한다.

장벽 유형구체적 사례규제 근거
개인정보 보호환자 진료 기록, 위치 데이터GDPR, HIPAA, 개인정보보호법
기업 기밀금융 거래 패턴, 산업 공정 데이터영업 비밀 보호법
물리적 전송 비용IoT 센서 수백만 개의 로우 데이터대역폭·비용 제약
데이터 주권국가별 데이터 현지화 요구EU GDPR Art.44, 중국 데이터안전법

2017년 Google이 스마트폰 키보드(Gboard)의 다음 단어 예측 개선을 위해 **연방 학습(Federated Learning)**을 제안했으며, 이후 의료·금융·통신 분야로 확산되었다.

2. 구성요소

요소역할핵심 포인트
핵심 대상해당 주제가 직접 다루는 데이터·모델·인프라의 중심 객체무엇을 저장·처리·최적화하는지가 기술의 경계를 결정한다
제어 메커니즘처리 순서, 규칙, 알고리즘, 오케스트레이션성능·정합성·확장성은 제어 방식에 따라 달라진다
운영 레이어모니터링, 품질 검증, 거버넌스, 비용 관리실무에서는 기능보다 운영 가능성이 채택 여부를 좌우한다
전통적 ML 방식:
  디바이스 A → 원시 데이터 전송 → 중앙 서버(학습)
  디바이스 B → 원시 데이터 전송 ↗
  디바이스 C → 원시 데이터 전송 ↗

연방 학습(FL) 방식:
  디바이스 A → (로컬 학습) → 가중치 Δ전송 → 중앙 집계 서버
  디바이스 B → (로컬 학습) → 가중치 Δ전송 ↗  (전역 모델 배포)
  디바이스 C → (로컬 학습) → 가중치 Δ전송 ↗

McMahan et al. (2017)이 제안한 FedAvg는 FL의 표준 알고리즘이다.

알고리즘 흐름:

라운드 t마다:
1. 서버가 전역 모델 w_t를 클라이언트 K개 중 C 비율 선택하여 배포
2. 각 선택된 클라이언트 k는:
   - 로컬 데이터 D_k로 E 에포크(Epoch) SGD 수행
   - 로컬 업데이트된 w_k^{t+1} 서버에 전송
3. 서버 집계:
   w_{t+1} = Σ_{k=1}^{K} (n_k / n) * w_k^{t+1}
   (n_k: k번 클라이언트의 데이터 수, n: 전체 데이터 수)
파라미터의미권장 설정
C (참여 비율)라운드당 참여 클라이언트 비율0.1 ~ 0.3
E (로컬 에포크)로컬 학습 반복 횟수1 ~ 10
B (배치 크기)로컬 미니배치 크기32 ~ 256
η (학습률)SGD 학습률디바이스 이질성 고려
클라이언트 k의 DP 적용:
  Δw_k_noisy = Δw_k + N(0, σ²Δf²)
  
  여기서:
  - Δf: 민감도 (Sensitivity) = 클리핑 임계값 C
  - σ: 노이즈 배율 (Noise Multiplier)
  - N: 가우시안 분포 노이즈

┌─────────────────────────────────────────────────────┐
│         보안 집계 프로토콜                              │
│                                                      │
│  클라이언트 A: w_A + r_AB + r_AC (마스킹)            │
│  클라이언트 B: w_B - r_AB + r_BC (마스킹)            │
│  클라이언트 C: w_C - r_AC - r_BC (마스킹)            │
│                    ↓ 합산                             │
│  서버: (w_A + w_B + w_C)  ← 개별 가중치 알 수 없음    │
└─────────────────────────────────────────────────────┘

서버는 합산 결과만 알 수 있고, 개별 클라이언트의 가중치는 알 수 없다.

6. 기대효과 및 결론

McMahan et al.

연방 학습 (Federated Learning)의 효과는 성능 향상 자체보다도 예측 가능성과 운영 일관성을 확보하는 데 있다. 반대로 데이터 품질, 거버넌스, 모니터링 없이 도입하면 복잡도만 늘고 실질 가치는 줄어든다. 따라서 이 주제는 기능 도입이 아니라 구조적 운영 역량과 함께 판단해야 하며, 향후에는 자동화·실시간성·설명 가능성·비용 최적화와 결합된 방향으로 발전한다.

    ├─► 안전한 집계 (Secure Aggregation): 암호화

Cross-Silo (병원 간) · Cross-Device (모바일) 연방 학습
  1. FedAvg는 학교마다 학생 수가 다를 때, 학생 수가 많은 학교의 의견을 더 많이 반영하는 것처럼 데이터가 많은 디바이스의 가중치를 더 비중 있게 합산하는 방법이에요.
  2. Non-IID 문제는 한 학교는 수학 문제만 풀고, 다른 학교는 국어만 풀었을 때, 두 학교의 요약을 합치면 엉뚱한 교과서가 되는 것처럼, 데이터 분포가 다를 때 모델이 이상해지는 문제예요.
